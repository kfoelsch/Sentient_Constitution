*بعبارات بسيطة: هذا مسوّدة بالعربية لقياس التكلفة والمنهج، لا نصًا دستوريًا ثانيًا.*

**المحلّ.** العربية الفصحى الحديثة (الشكل الكتابي المشترك). لا تثبّت لهجةً محكية، ولا بلدًا. المصرية والشامية والمغربية وغيرها تبقى أبوابًا منفصلة إن جاءت لاحقًا.

**الشريحة الأولى حسب العمارة.** ترتيب الإرسال يطلب أولًا موجزات الدخول السهل، ورقة أرضية الحقوق، والباب العام. هذا التجريب يترجم [الديباجة](core_00_preamble.md) و[الفصل الأول، الجزء أ](core_01_a_values_principles.md) عمدًا لقياس تكلفة ملف `core_*` مرقّم. العربية هي الخانة (3) بعد الإسبانية والهندية.
