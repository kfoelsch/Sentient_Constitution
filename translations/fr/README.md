# Édition en français — pilote (non contraignant)

> **État des traductions :** le brouillon du chapitre sept est complet et assisté par IA, mais n’a pas été révisé indépendamment par une personne lectrice. Il a été préparé à partir de l’édition `SC-Corpus-2026.10.21` ; l’original anglais numéroté demeure la source contraignante. Les autres traductions peuvent refléter des versions antérieures et ne sont pas certifiées.

*En termes simples : c’est un brouillon en français pour mesurer le coût et la méthode, pas un second texte constitutionnel.*

**Locale.** Français international (vous ; pas de tutoiement). Ne fige pas un pays. Le français **n’est pas** un substitut de l’indonésien dans l’ordre d’envoi : beaucoup de ce décompte a déjà plus d’anglais, ou n’a pas la littératie française d’un instrument constitutionnel.

**Couverture.** Ce pilote rassemble les traductions listées ci-dessous, dont le [Préambule](core_00_preamble.md), le [Chapitre un, Partie A](core_01_a_values_principles.md) et le [chapitre sept](core_07_charters.md). Le brouillon complet du chapitre sept a été préparé à partir de l’édition `SC-Corpus-2026.10.21` ; les autres fichiers peuvent refléter des versions anglaises antérieures. Toutes ces traductions restent non contraignantes et non certifiées. Une porte de lecture n’est pas une intervention politique.
