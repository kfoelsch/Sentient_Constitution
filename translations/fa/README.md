*به زبان ساده: این پیش‌نویس فارسی برای اندازه‌گیری هزینه و روش است، نه متن دوم قانون اساسی.*

**محل زبانی.** فارسی نوشتاری ایرانی. دولتی را منجمد نمی‌کند. دری درِ نزدیک اما جدا می‌ماند اگر خواسته شود. درِ خواننده مداخلهٔ سیاسی نیست.

**برش نخست، بنا بر معماری.** ترتیب ارسال نخست خلاصه‌های ورود آسان، برگهٔ کف حقوق، و درِ عمومی را می‌خواهد. این آزمایش عمداً [دیباچه](core_00_preamble.md) و [فصل یکم، بخش الف](core_01_a_values_principles.md) را ترجمه می‌کند تا هزینهٔ یک `core_*` شماره‌دار اندازه‌گیری شود.
