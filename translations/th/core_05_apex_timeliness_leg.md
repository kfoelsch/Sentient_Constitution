# บทนิยามบทที่ห้า: ความทันเวลา (ขาของจตุรภาค)

<details>
<summary><strong><span style="color: #2563eb;">ตำแหน่งในคลังข้อความ (ไม่ใช่บทบัญญัติที่ใช้บังคับ): โครงสร้างไฟล์และกฎการอ่าน</span></strong></summary>

> เนื้อหาต่อไปนี้เป็น **แนวทางสำหรับผู้อ่านเท่านั้น** ไม่เพิ่ม ไม่ลด และไม่ทำให้ภาระผูกพันที่ใช้บังคับแคบลงในไฟล์นี้หรือในบทอื่น
>
> ไฟล์นี้เป็น **โครงการนำร่องด้านภาษาสำหรับผู้อ่าน** ของ [บทที่ห้า ขาความทันเวลาของจตุรภาคภาษาอังกฤษ](../../core_05_apex_timeliness_leg.md) **ไม่ใช่** ส่วนที่มีผลผูกพันของรัฐธรรมนูญของผู้มีความรู้สึก **ไม่ใช่** รัฐธรรมนูญฉบับที่สอง **ไม่ใช่** ฉบับจัดส่ง **ตรึงไว้** กับ `SC-Corpus-2026.08.09` หากคำแปลนี้กับต้นฉบับภาษาอังกฤษดูเหมือนไม่ตรงกัน ให้ไฟล์ที่มีหมายเลข [`core_05_apex_timeliness_leg.md`](../../core_05_apex_timeliness_leg.md) เป็นฝ่ายชนะ ลำดับการอ่านและข้อมูลฉบับคงไว้ใน [README.md](../../README.md) วิธีทำและอภิธานศัพท์: [translations/th/README.md](README.md)
>
> **ก่อนหน้า (ภาษานี้):** [core_05_apex_participation_leg.md](core_05_apex_participation_leg.md)
>
> **ถัดไป (ยังเป็นภาษาอังกฤษ):** [core_05_band_accountability.md](../../core_05_band_accountability.md)
> **ส่วนโค้งการอ่าน:** O/M/A/C → การแยกขา → ตระกูลการวัด

*พูดแบบตรง ๆ: เคลื่อนปัญหาผ่านการตรวจพบ การโต้แย้ง การยุติ และการซ่อมให้ทันเวลา — นาฬิกาที่ประกาศซึ่งปล่อยให้ภัยสะสมไม่ใช่ความทันเวลา*

- O: เคลื่อนปัญหาผ่านการตรวจพบ การโต้แย้ง การยุติ และการซ่อมให้ทันเวลา — ขาของจตุรภาคที่รายการนี้ตั้งชื่อ
  - **ในขอบเขต:** หน้าที่ตอบสนองที่ชั้นหลักการ ปรับตาม [ส่วนได้เสียที่เป็นสาระ](core_00_preamble.md#material-stake) ตลอด:
    - การตรวจพบ;
    - ความสามารถในการโต้แย้ง;
    - การยุติ;
    - การเยียวยา; และ
    - การแก้ของการบริหารอย่างรับผิดชอบ
    ในวงจรชีวิตการประสานทางรัฐธรรมนูญ
  - **พึ่งพา:** เงื่อนไขและช่องทางที่ขานี้ต้องการเพื่อให้ทำงาน ขอบเขตละเอียดของแต่ละคำและกฎวิธีวัดอยู่ในบทนิยามของมันเอง; เริ่มจาก [การแยกขาของจตุรภาค](#timeliness-tetrad-leg-decomposition):
    - [การยุติที่ทันเวลา](../../core_05_band_accountability.md#timely-resolution-constitutional);
    - [การยึดครองเส้นทางการยุติ](../../core_05_band_accountability.md#capture-of-resolution-pathways);
    - [ประสิทธิภาพทางรัฐธรรมนูญ](../../core_05_band_continuity.md#constitutional-efficiency); และ
    - [ภาระที่หลีกเลี่ยงได้](../../core_05_band_continuity.md#avoidable-burden).
  - **นอกขอบเขต:** รายละเอียดบทนิยามใบ ชั้นการวัด และกลไกการนำไปใช้ที่เป็นของ [การยุติที่ทันเวลา](../../core_05_band_accountability.md#timely-resolution-constitutional) ใบพี่น้อง และ CJS
<a id="timeliness-constitutional-m"></a>
- M: ปัญหาเคลื่อนทันเวลาจริงหรือไม่ บรรทัดนี้ตั้งชื่อเฉพาะสิ่งที่ต้องดู; กฎวิธีวัดอยู่บนแต่ละบทนิยามที่ลิงก์ แผนที่หัวข้อ: [การแยกขาของจตุรภาค](#timeliness-tetrad-leg-decomposition)
<a id="timeliness-constitutional-a"></a>
- A:
  - ตัดสินภายใต้ [จตุรภาคทางรัฐธรรมนูญ](core_00_preamble.md#constitutional-tetrad) โดยปรับตาม [ส่วนได้เสียที่เป็นสาระ](core_00_preamble.md#material-stake)
  - ถามว่าความทันเวลาจริงหรือไม่ — ความเร็วที่รักษาสิทธิ ไม่ใช่ปริมาณผ่านดิบ — ไม่ใช่พิธีอย่างเดียว
  - อ่านคู่กับ:
    - [การยุติที่ทันเวลา](../../core_05_band_accountability.md#timely-resolution-constitutional);
    - [การยึดครองเส้นทางการยุติ](../../core_05_band_accountability.md#capture-of-resolution-pathways);
    - [ประสิทธิภาพทางรัฐธรรมนูญ](../../core_05_band_continuity.md#constitutional-efficiency);
    - [ภาระที่หลีกเลี่ยงได้](../../core_05_band_continuity.md#avoidable-burden);
    - [ข้อบกพร่องการบริหารอย่างรับผิดชอบ](../../core_05_band_continuity.md#stewardship-defect-constitutional); และ
    - [หน้าที่ทบทวนและแก้](../../core_05_band_continuity.md#review-and-correction-duty-constitutional).
  - ความทันเวลาตัดข้ามการมีส่วนร่วม การกำกับดูแล และความรับผิดชอบ แต่ถูกทำให้กลวงได้อย่างอิสระในที่ที่มีโครงสร้างรูปนามแต่ปัญหาที่เป็นสาระไม่เคลื่อน
<a id="timeliness-constitutional-c"></a>
- C: ไม่ปฏิบัติตามเมื่อ:
  - มีพิธี SLA ที่ประกาศ หรือตัวชี้วัดปริมาณผ่าน ที่ปล่อยให้การตรวจพบ การโต้แย้ง การยุติ หรือการซ่อมค้างอย่างเป็นสาระ;
  - มีกองค้างที่ออกแบบไว้;
  - มีความล่าช้าที่สร้างเอง;
  - มีการค้างไม่มีกำหนด;
  - เลื่อนการซ่อมหลังได้รับแจ้งในที่ที่การแก้ทำได้; หรือ
  - มีข้อกล่าวอ้างประสิทธิภาพที่ข้ามการตรวจสอบ การระบุตัวรายคน หรือสิทธิในการโต้แย้ง

### การแยกขาของจตุรภาค

*พูดแบบตรง ๆ: แผนที่นี้แจกใบความทันเวลา; พวกมันสืบทอดขอบเขตของขานี้ เว้นแต่จะกล่าวเป็นอย่างอื่น*

บทนิยามใบภายใต้ขานี้สืบทอดขอบเขตของมัน เว้นแต่จะทำให้แคบหรือกว้างโดยชัด แผนที่หัวข้อเต็ม: [เข็มทิศของบทที่ห้า](core_05__definitions_home.md#chapter-five-compass-and-definition-map)

**ใบของตระกูลการวัดความทันเวลา** — ชั้นการวัดที่ใช้บังคับ:

- [การยุติที่ทันเวลา](../../core_05_band_accountability.md#timely-resolution-constitutional)
- [การยึดครองเส้นทางการยุติ](../../core_05_band_accountability.md#capture-of-resolution-pathways)

**ตัดข้าม.** ความทันเวลาวิ่งผ่านการมีส่วนร่วม การกำกับดูแล และความรับผิดชอบ; ขาเหล่านั้นต้องเกิดทันเวลาจึงจะมีประโยชน์

**คำอิสระและกึ่งอิสระ** ที่นำความทันเวลาไปใช้อยู่ใน [core_05_band_accountability.md](../../core_05_band_accountability.md)

### การวัดความทันเวลา

<details>
<summary><strong><span style="color: #2563eb;">ตามรอย</span></strong></summary>

- ปลายทาง: ตระกูลการวัดความทันเวลา — ม้วนรวมแบบลิงก์อย่างเดียว; ชั้นรายคำอยู่ในบทนิยามใบ — ดู [การยุติที่ทันเวลา](../../core_05_band_accountability.md#timely-resolution-constitutional) [การยึดครองเส้นทางการยุติ](../../core_05_band_accountability.md#capture-of-resolution-pathways) และ [ความทันเวลา](#timeliness-constitutional) (ม้วนรวมหัวขาแบบลิงก์อย่างเดียว)
- อ่านคู่กับ: [การมีส่วนร่วม](core_05_apex_participation_leg.md#participation-constitutional) [การกำกับดูแล](core_05_apex_oversight_leg.md#oversight-constitutional) และ [ความรับผิดชอบ](core_05_apex_accountability_leg.md#accountability) — ความทันเวลายังวิ่งผ่านอีกสามขาของจตุรภาค; ขาเหล่านั้นต้องเกิดทันเวลาจึงจะมีประโยชน์
- อ่านคู่กับ: [บทที่สิบเอ็ด §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline)

</details>

<br>

*พูดแบบตรง ๆ: คำถามเหล่านี้ถามว่าปัญหาเคลื่อนทันเวลาจริงหรือไม่ — ไม่ใช่ว่าแผงแสดงแสดงปริมาณผ่าน นี่คือบ้านของบทที่ห้าสำหรับตระกูลการวัดความทันเวลา; คำปรารภ §2 คงคำถามหมวดภาษาเรียบง่ายไว้ และตารางตระกูลกับการจัดเส้นทางบทนิยามอยู่ที่นี่*

*ความเป็นสาระ* ([การกำหนดความเป็นสาระ](../../core_05_band_oversight.md#materiality-determination)) เป็นเชิงบูรณาการ — ไม่ใช่หมวดการวัดแยก; มันปรับว่าตระกูลนี้ใช้แรงเพียงใดภายใต้ [ส่วนได้เสียที่เป็นสาระ](core_00_preamble.md#material-stake)

| ตระกูลการวัด | คำถามเรียบง่าย | การใช้ทางรัฐธรรมนูญหลัก |
|---|---|---|
| [การยุติที่ทันเวลา](../../core_05_band_accountability.md#timely-resolution-constitutional) | ข้อพิพาทถูกยุติขณะที่การเยียวยายังมีความหมายอยู่หรือไม่ | กันไม่ให้ความล่าช้าทำให้สิทธิกลวง |
| วินัยต้านความล่าช้าและเส้นทางยุติ | สิ่งจูงใจและโครงสร้างหลีกเลี่ยงกองค้างที่ออกแบบไว้ การยึดครอง และกำหนดเวลาที่กลวงหรือไม่ | จับระบอบความล่าช้าและ [การยึดครองเส้นทางการยุติ](../../core_05_band_accountability.md#capture-of-resolution-pathways) |

การวัดเหล่านี้ถามว่านาฬิกากระบวนการ เส้นทางการยุติ และความเร็วในการซ่อมทำให้ขา **ความทันเวลา** ของ [จตุรภาคทางรัฐธรรมนูญ](core_00_preamble.md#constitutional-tetrad) ยังจริงในการปฏิบัติหรือไม่ — ไม่ใช่มีอยู่บนกระดาษอย่างเดียว
