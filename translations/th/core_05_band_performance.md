# บทนิยามสมรรถนะทางรัฐธรรมนูญ

<details>
<summary><strong><span style="color: #2563eb;">ตำแหน่งในคลังข้อความ (ไม่ใช่บทบัญญัติที่ใช้บังคับ): โครงสร้างไฟล์และกฎการอ่าน</span></strong></summary>

> เนื้อหาต่อไปนี้เป็น **แนวทางสำหรับผู้อ่านเท่านั้น** ไม่เพิ่ม ไม่ลด และไม่ทำให้ภาระผูกพันที่ใช้บังคับแคบลงในไฟล์นี้หรือในบทอื่น
>
> ไฟล์นี้เป็น **โครงการนำร่องด้านภาษาสำหรับผู้อ่าน** ของ [บทที่ห้า แถบสมรรถนะทางรัฐธรรมนูญภาษาอังกฤษ](../../core_05_band_performance.md) **ไม่ใช่** ส่วนที่มีผลผูกพันของรัฐธรรมนูญของผู้มีความรู้สึก **ไม่ใช่** รัฐธรรมนูญฉบับที่สอง **ไม่ใช่** ฉบับจัดส่ง **ตรึงไว้** กับ `SC-Corpus-2026.08.09` หากคำแปลนี้กับต้นฉบับภาษาอังกฤษดูเหมือนไม่ตรงกัน ให้ไฟล์ที่มีหมายเลข [`core_05_band_performance.md`](../../core_05_band_performance.md) เป็นฝ่ายชนะ ลำดับการอ่านและข้อมูลฉบับคงไว้ใน [README.md](../../README.md) วิธีทำและอภิธานศัพท์: [translations/th/README.md](README.md)
>
> มี **แถบสมรรถนะทางรัฐธรรมนูญของบทที่ห้า** — **บ้านตระกูลการวัด** ของบทที่ห้าสำหรับหมวดสมรรถนะทางรัฐธรรมนูญข้ามแนว สมรรถนะทางรัฐธรรมนูญเป็นเครื่องมือของทั้งเป้าประสงค์ [**ความเจริญงอกงาม**](core_00_preamble.md#flourishing) และ [**ความต่อเนื่อง**](core_00_preamble.md#continuity) และ **ไม่ใช่** ขาของจตุรภาค บทนิยามใบของมัน (ประสิทธิภาพทางรัฐธรรมนูญ ภาระที่หลีกเลี่ยงได้ ขีดความสามารถในการผลิต หน้าที่ลดภาระ) คง **บ้านฉบับหลักไว้ใน [แถบความต่อเนื่อง](core_05_band_continuity.md)** โดยการออกแบบ: เป็นสมาชิกกลุ่มของแถบความต่อเนื่องภายใต้การบริหารอย่างรับผิดชอบ / ขีดความสามารถของระบบร่วม และ [กลุ่มที่พึ่งพาสัดส่วน–ภาระ–ประสิทธิภาพ](core_05_band_continuity.md#proportionality-necessity-feasibility-burden-and-efficiency-cluster) ที่ซึ่งขีดความสามารถที่ยืนยาว ของเสีย และการส่งมอบผลลัพธ์ต่อทรัพยากรอยู่กับหัวข้อความต่อเนื่อง ไฟล์นี้จัดเส้นทางหมวดการวัดของคำปรารภ ไม่เก็บตัวบทใบเหล่านั้น ใบย้ายมาที่นี่ได้เฉพาะเมื่อมีการตัดสินใจวางตำแหน่งที่ชัดและลงวันที่ ลำดับการอ่านและเข็มทิศอยู่ใน [core_05__definitions_home.md](core_05__definitions_home.md#chapter-five-foundational-definitions)

*พูดแบบตรง ๆ: ไฟล์นี้คือบ้านของคำถามว่า ระบบส่งมอบผลลัพธ์ทางรัฐธรรมนูญจริงโดยไม่มีของเสียไร้ประโยชน์หรือไม่ บทนิยามละเอียดอยู่ในแถบความต่อเนื่อง*

ไฟล์นี้คือบ้านของตระกูลการวัด **สมรรถนะทางรัฐธรรมนูญ** — คำถามว่า ระบบส่งมอบผลลัพธ์ทางรัฐธรรมนูญจริงโดยไม่มีของเสียไร้ประโยชน์หรือไม่ บทนิยามละเอียดเอง **ไม่อยู่ที่นี่** ทั้งหมดอยู่ใน [แถบความต่อเนื่อง](core_05_band_continuity.md)
- เพราะ: บทนิยามเหล่านั้นเป็นของหัวข้อการบริหารอย่างรับผิดชอบของความต่อเนื่อง — ขีดความสามารถที่ยืนยาว ของเสีย และการได้ผลลัพธ์จริงจากทรัพยากรที่ใช้ ดู [กลุ่มหัวข้อประสิทธิภาพ / ขีดความสามารถ / ภาระ](core_05_band_continuity.md#constitutional-efficiency) และ [กลุ่มสัดส่วน–ภาระ–ประสิทธิภาพ](core_05_band_continuity.md#proportionality-necessity-feasibility-burden-and-efficiency-cluster)
- คำถามยังรองรับทั้งสองเป้าประสงค์ทางรัฐธรรมนูญ ([**ความเจริญงอกงาม**](core_00_preamble.md#flourishing) และ [**ความต่อเนื่อง**](core_00_preamble.md#continuity))

### การวัดสมรรถนะทางรัฐธรรมนูญ (ตระกูลการวัดของคำปรารภ)

*พูดแบบตรง ๆ: คำถามเหล่านี้ถามว่า ผลลัพธ์ทางรัฐธรรมนูญถูกส่งมอบจริงโดยไม่เสียเวลา ความพยายาม หรือวัสดุของผู้มีความรู้สึกหรือไม่*

*บ้านของบทที่ห้าสำหรับตระกูลการวัดสมรรถนะทางรัฐธรรมนูญ คำปรารภ §2 คงคำถามหมวดภาษาเรียบง่ายไว้ในตารางภาพรวม; ตารางตระกูล การใช้ทางรัฐธรรมนูญ และการจัดเส้นทางบทนิยามอยู่ที่นี่*

*ความเป็นสาระ* ([การกำหนดความเป็นสาระ](core_05_band_oversight.md#materiality-determination)) เป็นเชิงบูรณาการ — ไม่ใช่หมวดการวัดแยก; มันปรับว่าตระกูลนี้ใช้แรงเพียงใดภายใต้ [ส่วนได้เสียที่เป็นสาระ](core_00_preamble.md#material-stake)

| ตระกูลการวัด | คำถามเรียบง่าย | การใช้ทางรัฐธรรมนูญหลัก |
|---|---|---|
| [ประสิทธิภาพทางรัฐธรรมนูญ](core_05_band_continuity.md#constitutional-efficiency) | ผลลัพธ์ทางรัฐธรรมนูญถูกส่งมอบจริงหรือไม่ | ป้องกันไม่ให้ตัวชี้วัดตัวแทนแทนที่การคุ้มครองจริง |
| [ภาระที่หลีกเลี่ยงได้](core_05_band_continuity.md#avoidable-burden) | ระบบกำลังเสียเวลา ความพยายาม วัสดุ โครงสร้างพื้นฐาน หรือพลังงานของผู้มีความรู้สึกหรือไม่ | ลดแรงเสียดทานที่ไม่จำเป็น |
| [ขีดความสามารถในการผลิต](core_05_band_continuity.md#productive-capacity-constitutional) | ผู้มีความรู้สึกและระบบยังผลิตผลลัพธ์ที่สอดคล้องต่อไปได้หรือไม่ | ปกป้องขีดความสามารถที่ยืนยาวโดยไม่ย้ายภาระทางนิเวศ |

การวัดข้ามแนวเหล่านี้ถามว่าระบบส่งมอบผลลัพธ์ทางรัฐธรรมนูญอย่างมีประสิทธิผล หลีกเลี่ยงของเสียไร้ประโยชน์ และรักษาขีดความสามารถในการผลิตผลลัพธ์ที่สอดคล้องต่อไปหรือไม่ — เป็นเครื่องมือของทั้ง [**ความเจริญงอกงาม**](core_00_preamble.md#flourishing) และ [**ความต่อเนื่อง**](core_00_preamble.md#continuity)

- ชั้นการวัดที่ใช้บังคับอยู่ในบ้านบทนิยามของบทที่ห้า — ดู [ประสิทธิภาพทางรัฐธรรมนูญ](core_05_band_continuity.md#constitutional-efficiency) [ภาระที่หลีกเลี่ยงได้](core_05_band_continuity.md#avoidable-burden) [ขีดความสามารถในการผลิต](core_05_band_continuity.md#productive-capacity-constitutional) และ [หน้าที่ลดภาระ](core_05_band_continuity.md#burden-reduction-duty-constitutional)
- เป้าสมรรถนะ รางวัล และมาตรวัดทรัพยากรใช้ได้เฉพาะเท่าที่ยังตามรอยไปถึงผลลัพธ์ทางรัฐธรรมนูญได้
- พวกมันทดแทนประสิทธิภาพทางรัฐธรรมนูญ [ขีดความสามารถในการผลิต](core_05_band_continuity.md#productive-capacity-constitutional) หรือการปฏิบัติตามพื้นสิทธิไม่ได้
- อ่านคู่กับ [บทที่เจ็ด §3 การประเมินการรับรองระบบทั้งระบบ](../../core_07_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation) ในที่ที่สมรรถนะทั้งระบบอยู่ในขอบเขตอย่างเป็นสาระ
