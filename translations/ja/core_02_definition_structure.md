*平たい言葉で言えば：本節は第二章の職務記述である。それは定義スタックの第一層を所管する：すべての憲法定義は連関した部分から組み立てられる — 用語が何か（O）、どう測定され評価されなければならないか（評価と織り合わせられた測定登録、M/E）、実務で何が成り立たなければならないか（C） — そしてそれらの部分は整合したままでいなければならない。一つを満たしつつ他を迂回することは数えない。執行、統治、測定の運用は後の章に住み、本章が確立することを遵守しなければならない。*

すべての憲法定義は、連関した部分から組み立てられなければならない。各部分にはちょうど一つの仕事がある：
- **存在論（O）** — その用語が何についてのものか。
- **測定（M）** — 各段階でどの測定が適用されるか。測定の経路づけは評価を指し示す。合格/不合格の結果を定めない。
- **評価（A）** — その用語がどう評価されなければならないか。第五章の葉定義では、**測定（M）**登録は**評価（A）**構成要素に織り込まれる。[§1.3 評価構成要素](#13-assessment-components)を見よ。
- **遵守（C）** — 実務で何が真でなければならないか。

それらの部分は、各定義の内側で一貫したままでいなければならない。執行、統治、実施、測定の運用、監査、定義的範囲を超える分類の仕組みは後の章に属する；それらは、ここで確立された[憲法上の制約](../../core_05_band_integrative.md#constitutional-constraint)を遵守しなければならない。

すべての定義は、システムが実際に走る全体について満たされなければならない — 感知者、機械、場所にまたがるシステムを含む。O、M、A、C の部分は、同じ範囲のうえで、同じ試験条件のもとで、ともに通らなければならない。システムの切れ端を切り出し、何が数えるかを狭め、または他の部分を弱めることで一部分だけを通すことは数えない。

#### 1.1 存在論的構成要素（O）— それが何か

*平たい言葉で言えば：O の部分は一つの単純な問いに答える — **この用語は何についてのものか？** それは対象を名指し、縁を引く。用語をどう測定し、どう判断するかを述べず、何が合格または不合格として数えるかも述べない。それらは後に来る。*

存在論の部分（O）は、その用語が何についてのものかを述べる。用語をどう測定し評価するかを述べてはならず、何が合格または不合格として数えるかを述べてもならない — それらは測定（M）、評価（A）、遵守（C）の部分に住む。それはまた、システムが実際に働く仕方と一致しなければならない：名前、公式のカテゴリ、管轄、または述べられた目的は、実際の振る舞いや実際の効果が別のことを言うときに、用語が何を覆うかを決着しない。

定義において、O の部分はラベル付きフィールドの短いリストとして書かれる。各フィールドは平たい問いに答える：

- **範囲内：** その用語が*実際に*覆うもの。システムの実際の部分、それらがどうともに働くか、何に依拠するか、この用語にとって実際に大切な効果を列挙する。
- **範囲外：** その用語が*覆わない*もの。隣接する概念、兄弟の本拠、または事項の外の通常の事例を名指せ — 空洞なラベル、紙の代替物、その他の不遵守の枠づけではない。それらは C（**第一次の失敗**）に属する。
- **依存するもの：** *（適用されるときにだけ用いる）* この用語がその上に組み立てられる、*他の*すでに定義されたもの — たとえば、すでに置かれていると仮定する限度、最低の床、または目標。その他のものが存在するときにだけ用語が意味をなすなら、ここで名指す。

意図して O の部分に**入らない**ものがある：

- その用語が*流れ込む*先、またはそれが*その内側に座る*より大きな群 — それは定義の相互参照に属し、ここではない；
- 用語がどう測定され評価されるか — それは M と A に属する；
- 何が用語を満たすことまたは破ることとして数えるか — それは C に属する。実際の効果なしに充足を主張するラベルや書類仕事を含む。

第五章の葉定義は、本節に述べられた存在論構成要素の形を用いて、それらの O 要件を運ばなければならない。

#### 1.2 測定構成要素（M）— どう測定されなければならないか

*平たい言葉で言えば：M の部分は一つの単純な問いに答える — **この用語を判断するために何を見るべきか？** それは適用される測定を名指す。用語が合格するか不合格するかは述べない。それは後に来る。*

測定の部分（M）は、各段階でどの測定が用語に適用されるかを述べる。それは評価を正しい証拠へ向ける。何が合格または不合格として数えるかを述べてはならない — それは遵守の部分（C）だけに属する。

第五章の葉定義では、M は読者向け見出し**測定と評価の仕方**のもとで評価の部分（A）に織り込まれる。各段階はまずその測定を名指し、次いですぐ下の行に対応する評価を置く。フィールドは次のように働く：

- **第一次の測定：** 最初に見るべき主なもの — この文脈でこの用語について評価者が追うべき最初の証拠の筋道。
- **第二次の測定：** *（適用されるときに用いる）* 第一次とともに含めなければならない追加の測定 — 任意の追加物ではない。点検を広げ、問題が狭い証拠の切れ端の後ろに隠れられないようにする。
- **第三次の測定：** *（適用されるときに用いる）* 測定そのものへの誠実性点検 — とくに数、ラベル、自己報告、または形式的カテゴリが、実際の成果の代わりに立ちうるところ。

すべての定義が三つの段階を必要とするわけではない。第一次の測定だけを宣言する用語もある。より広いまたはより深い点検が必要なときに、第二次または第三次の測定を加える用語もある。

意図して M の部分に**入らない**ものがある：

- 何が用語を満たすことまたは破ることとして数えるか — それは C に属する；
- その用語が何についてのものか — それは O に属する；
- それ自体としての完全な評価義務 — それは A に属する（ただし各測定は、その下の行の評価と対になる）。

第五章の葉定義は、本節に述べられた測定構成要素の形を用いて、それらの M 要件を運ばなければならない。

#### 1.3 評価構成要素（A）— どう評価されなければならないか
<details>
<summary><strong><span style="color: #2563eb;">追跡</span></strong></summary>

<br>

*平たい言葉で言えば：A の部分は一つの単純な問いに答える — **この用語はどう判断されなければならないか？** それは評価者が何を見なければならないか、どの条件のもとでか、不確かさをどう扱うかを述べる。用語が合格するか不合格するかは述べない。それは後に来る。*

評価の部分（A）は、定義がどう評価されなければならないかを述べる。何が合格または不合格として数えるかを述べてはならない — それは遵守の部分（C）だけに属する。

第五章の個々の用語定義では、測定（M）と評価（A）は、**測定と評価の仕方**と題された一つの節にともに現れる。

その節の内側で、各段階は対である：測定が先に来て、その測定についての評価はすぐ下の行に座る。評価のフィールドは次のとおりである：

- **第一次の評価：** 第一次の測定をどう判断するか — 評価者が最初に評価しなければならないこと、およびその点検が実際に達しなければならないもの（実質であり、ラベルや書類仕事だけではない）。
- **第二次の評価：** *（適用されるときに用いる）* 第二次の測定をどう判断するか — 第一次の測定が良く見えても、より広い証拠がなお大切なときに、何を含めなければならないか。
- **第三次の評価：** *（適用されるときに用いる）* 第三次の測定をどう判断するか — 代替指標、計量、または形式的カテゴリがなお実際の成果を追っているかの点検。

すべての段階を通じて、A の部分は次をしなければならない：

- 何が評価されなければならないかを述べる；
- 評価がどの条件のもとで起きなければならないかを述べる；
- 大切なところでは不確かさをどう扱うかを述べる。

意図して A の部分に**入らない**ものがある：

- 何が用語を満たすことまたは破ることとして数えるか — それは C に属する；
- その用語が何についてのものか — それは O に属する；
- 各段階でどの測定がそれ自体として適用されるか — それは M に属する（ただし各測定は、その下の行の評価と対になる）。

第五章の葉定義は、本節に述べられた評価構成要素の形を用いて、それらの A 要件を運ばなければならない。

これらの評価規則が試験にかけられるとき、判断は十分な実際の証拠に依らなければならない — 主張や書類仕事だけではない — そして同じ規則は、その用語が適用されるどこでも適用されなければならない。

#### 1.4 遵守構成要素（C）— 実務で何が真でなければならないか

*平たい言葉で言えば：C の部分は一つの単純な問いに答える — **実際に何が成り立たなければならず、いつこの用語は破られたか？** それは満たされなければならない実世界の条件と、数える失敗を述べる — システムが自らについて主張することではなく、振る舞いと効果に見られるものに基づく。*

遵守の部分（C）は、用語が満たされるために成り立たなければならない実世界の条件を述べる。それは観察可能な振る舞いと効果から働かなければならない — システム自身の主張、書類仕事、または述べられた意図からではない。

第五章の個々の用語定義では、遵守の部分（C）は見出し**何が成り立たなければならないか**のもとで現れる。フィールドは次のように働く：

- **第一次の失敗：** 第一次の段階で用語が破られるとき — たとえば主な測定が空洞であり、たどれず、またはシステムが実際に働く仕方と矛盾するとき。
- **第二次の失敗：** *（適用されるときに用いる）* 第二次の段階で用語が破られるとき — たとえば第一次の点検は安定して見えても、より広い何かがなお用語を打ち負かすとき。それが依拠するシステムの破綻や、それが相互作用する接続されたシステムなど。
- **第三次の失敗：** *（適用されるときに用いる）* 第三次の段階で用語が破られるとき — たとえば代替指標または計量がそれだけで足りると扱われるとき、または既知の乖離が無視され、または未訂正のまま残されるとき。

すべての定義が三つの失敗段階を列挙するわけではない。第一次の失敗だけを宣言する用語もある。段階に揃えた破れの条件が必要なときに、第二次または第三次の失敗を加える用語もある。

すべての段階を通じて、C の部分は次をしなければならない：

- 観察でき執行できる成果を述べる；
- 定義がいつ満たされ、いつ侵害されるかを述べる；
- ラベル、形式的カテゴリ、または述べられた目的だけではなく、実際の振る舞いと効果に結びついたままでいる。

意図して C の部分に**入らない**ものがある：

- その用語が何についてのものか — それは O に属する；
- どの測定が適用されるか、または評価がどう走らなければならないか — それは M と A に属する。

第五章の葉定義は、本節に述べられた遵守構成要素の形を用いて、それらの C 要件を運ばなければならない。

### 2. 定義の誠実性要件

<br>

*平たい言葉で言えば：定義を正しく組み立てるだけでは足りない — 適用されるときに損なわれずにいなければならない。定義は断片ごとに満たされ、解釈によって弱められ、範囲の切り出しによって弄られてはならない — それが表す成果が劣化しているあいだに測定を最適化することを含む。文言が複数の読みを許すところでは、保護範囲を完全に保全する読みを選べ。*

<a id="21-core-integrity-conditions"></a>
#### 2.1 中核的誠実性の条件
すべての定義は、適用されるときにまとまって成り立たなければならない。[§1 目的と役割](#1-purpose-and-role)が求める連関した部分は、次でなければならない：
- なお互いに一致する
- すべてがともに満たされる；一つまたは二つを満たすだけでは足りない
- 同じシステムのうえで、同じ条件のもとで満たされる — 狭い切れ端で一部分を通し、別の切れ端で他の部分を通すことはできない

どの部分の失敗も、定義が満たされていないことを意味する。

<a id="22-non-compliance-by-structural-or-applied-weakening"></a>
#### 2.2 構造的または適用上の弱化による不遵守
定義は、それが組み立てられ、読まれ、または適用される仕方が、一部分を満たしつつ次を許すなら、満たされない：
- 他の部分を掘り崩し、迂回し、または衝突すること
- システム全体が走っているときに、定義の完全な意味、評価、実世界の要件を満たさない結果を生じること
- 一部分だけ、選ばれた事例だけ、またはある条件のもとだけで通すことを許すこと — 定義が実際に求める条件のもとでは成り立たない合格

<a id="23-construction-constraints"></a>
#### 2.3 組み立ての制約
定義は、次のように書かれなければならない：
- すべての部分（O, M, E, C）は、システムが実際に振る舞い、実際に産出することを反映する条件のもとで、ともにしか満たされえない
- いかなる部分も、一般化し、物事を分割し、範囲を狭め、または実際に大切なシステム要素、相互作用、効果を外す記述によって満たされてはならない
- いかなる測定も、それが捉えるべき結果の代わりに立ってはならない；それが表す実世界の結果から乖離する測定（[代替指標の乖離](../../core_05_band_oversight.md#proxy-divergence)を見よ）は定義を満たせず、測定の選択は、評価されなければならないもの、または実務で成り立たなければならないものを縮めてはならない
- 述べられていない仮定、隠れた依存、または外された条件は、評価されなければならないもの、または実務で成り立たなければならないものを変え、または弱めてはならない

<a id="24-interpretation-rule-under-ambiguity"></a>
#### 2.4 曖昧さのもとでの解釈規則
定義が一つより多くの合理的な仕方で読めるとき、その完全な意味を保つ読みを用いよ。その読みが、定義がどう適用されるかを統治する。その読みはまた評価を厳格に保たなければならず、実世界の要件を損なわれずに保たなければならない。

定義を適用することが、定義の内側の矛盾、それが述べる範囲と実際に覆われなければならないもののあいだの隙間、または求められる他の部分を迂回しつつ一部分だけを通すことを強いるなら、その定義は遵守を判断し、または決めるために用いられてはならない。

壊れた定義は、それ自体で不遵守である。それは、システムがうまく振る舞っているように見えるときでも、まだ何も間違っていないときでも成り立つ。

一つの合理的な読みが、文言と構造が許す他の読みと比べて、保障を弱め、点検されなければならないものを狭め、または求められる実世界の成果を下げるなら、そのより弱い読みは許されない。

*平たい言葉で言えば：定義は紙の上でまとまって成り立つだけでは足りない — 実世界の定義スタックを通じてまとまって成り立たなければならない。その部分は、通常、劣化した、敵対的な運用を通じて、時間を通じて、接続されたシステムを通じて、合理的に見通せたすべての状況で、その文言のすべての公正な読みのもとで、同じ仕方で並ばなければならない。*

「合理的に予見可能な」が**第二から第四章**のどこに現れても、それは第五章、第 3 節 — 依存クラスター（真理と認識的誠実性クラスター；予見可能性の勤勉）の予見可能性の定義が述べることと正確に同じ意味である — より緩いものではない。各使用は、それらの定義へ明確に戻って指さなければならない。

定義の部分は、次を通じて一貫したままでいなければならない：
- システムが走る条件の全範囲 — 通常の運用、劣化した運用、敵対的圧力、時間を通じた変化、他のシステムとの相互作用を、それらが大切であるところでは含む。
- 第五章、第 3 節 — 依存クラスター（真理と認識的誠実性クラスター；予見可能性の勤勉）（予見可能性）に述べられた、すべての合理的に予見可能な条件
- 定義の文言と構造が許すすべての合理的な読み
