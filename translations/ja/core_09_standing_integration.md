<a id="1-immutable-chapter-eight-inputs"></a>

<a id="1-chapter-eight-records-do-not-change"></a>
### 1. 第八章の記録は変わらない

*平たい言葉で言えば：本章は、第八章がすでに作った検証済み記録から始まる。事実を再開し、欠けた軌道を推測し、または好ましい結果を得るために評定を選んではならない。*

第九章は、第八章のもとで産出された検証済み軌跡記録から始まる。決定に適用される記録だけを用い、貢献記録と違反記録を別に保つ：

- 貢献が適用されるなら、**貢献軌跡記録**を用いよ。次を含む：
  - その検証済み事実；
  - 貢献軸の箱；
  - 支える証拠；
  - 範囲；
  - 期間；
  - 審査地位；および
  - 貢献記述子。
- 違反が適用されるなら、**違反軌跡記録**を用いよ。次を含む：
  - その検証済み事実；
  - 違反軸の箱；
  - 支える証拠；
  - 範囲；
  - 期間；
  - 審査地位；
  - 過程または応答の性格；および
  - 違反記述子。

問い 3 の決定は、貢献のみ、違反のみ、または両方を扱ってよい。一方の軸が適用されないなら、決定はそれなしに進めてよい。決定者は、推測、申立てへの依拠、または人工的なゼロ値記録の作成によって、隙間を埋めてはならない。

第九章は、第八章が確立した事実と測定を、そのまま用いなければならない。次をしてはならない：

- 事実を再開すること；
- 望む帰結を産出するために箱を選ぶこと；
- LEQU 影響を再計算すること；または
- 二つの軸を純得点に組み合わせること。

次は軌跡として数えない：

- 申立て；
- 受付ラベル；
- 未裁定の主張；
- 評判；
- 経路づけタグ；または
- 暫定の記述。

事件を申し立てること自体が軌跡ではない。

問い 3 の決定は、それ自体では第八章の箱を変えない。フォーラムがパイプラインの誤りまたは実質的な新事実 — 後から発見された効果を含む — を検証するなら、第八章のもとで記録を脇へ置き、または更新、訂正、もしくは後継を求めてよい。新しい箱はいずれも、第八章の測定過程に従い、監査の跡を保全し、二つの軸を別に保たなければならない。

[権利の床](core_06_rights_part_a.md#chapter-six-foundational-rights) は軌跡に依存せず、軌跡の決定によって変えてはならない。いかなる帰結も、固有の尊厳、平等な道徳的地位、生存に不可欠な通路、または異議、審査、上訴、および救済に求められる指名された経路を減らしてはならない。

<a id="2-integration-record-and-decision-order"></a>
<a id="2-automatic-integration-review-and-continuity"></a>
### 2. 自動統合、審査、および継続

*平たい言葉で言えば：検証済み記録が開かれ、または変わるとき、統合記録は自動的に続き、二つの軌道を別に保ち、点検可能なままでなければならない — 計算機が止まっているときも含めて。*

軌跡システムは、適用される第八章の記録が開かれ、更新され、訂正され、または後継されるときはいつでも、別個の**統合記録**を自動的に作成または更新しなければならない。統合記録は源記録を相互参照するが、それを変えない。システムは、貢献記録と違反記録を、走っている残高や生涯得点へ組み合わせるのではなく、別に保たなければならない。

各統合記録は、次を識別しなければならない：

1. 各源記録と現在の版；
2. 各適用される固定の貢献軸または違反軸の測定；
3. 各正規化された記述子と添付；
4. 影響を受ける感知者、利害、システム、および指名された経路；
5. 違反側の是正、救済、保障、およびロック；
6. 貢献側の現在性と能力許可の結果；
7. 各指名された経路についての最終軌跡効果；
8. 実施の里程標、審査経路、および再評価の引き金；ならびに
9. 第十章の入口の地位があればそれ。

自動化は、検証済み入力と公表された規則が確定的な結果を産出するいかなる段階も完了してよい。この憲法または採択された実施が審査を求めない限り、追加の手動承認は要らない。システムは、不確実、争われた、新規、実質的に裁量的、または高影響の問いを、権限ある審査者またはフォーラムへ付託しなければならない。審査を要する記録でも、組み立てと経路づけは自動で行ってよい。

次の処理順序は、自動化された決定にも手動の決定にも適用される：

1. 第八章の記録とその現在の審査地位を検証する；
2. いずれの箱も変えずに、共有の記述子と添付を正規化する；
3. まず違反、是正、および予防を決める — 救済と是正、次いでロック、次いで用いられるところでの自発的な公開説明責任の表明；次いでロックの設計と執行を適用する（定義と添付、比例性と尺度合わせ、記録の可視性と段階引き上げ、特別な違反規則、および特別ロック）；
4. 次に貢献の帰結を決める — 現在性と能力の閾と許可。ただしロックによって遮断されていない指名された経路についてのみ；
5. 各指名された経路について一つの最終軌跡効果を述べる；
6. 復元と再評価の条件を述べる；
7. 実務上の執行可能性を検証する；および
8. 適格な違反軸の箱 7–9 の認定を、指定が問題になるところで [第十章](core_10_a_misconduct_designation.md#chapter-ten-anti-constitutional-misconduct) へ経路づける。

自動化された結果も手動の結果も、入力、規則、中間段階、結果、および審査経路を、影響を受ける当事者と権限ある審査者が点検し異議を唱えられる形で保全しなければならない。

技術の停止のあいだ、権限ある団体は、同一の求められる欄、処理順序、証拠の保管、審査の権利、および適用される期限を保全する手動の継続過程を用いなければならない。技術が戻ったとき、システムは手動記録と電子記録を突き合わせ、両方の監査の跡を保全し、いかなる相違も説明し、決定を静かに上書きしてはならない。

<a id="3-descriptor-integration-and-attachment-normalization"></a>
### 3. 記述子の統合と添付の正規化

*平たい言葉で言えば：記述子は、検証済みの助けまたは危害が**どのように**起きたかを言う。本章は、それらが記録されたとおりに取り込む。結果を変えるために、静かに再分類してはならない。*

記述子は、検証済みの便益または危害が**どのように**起きたかに答え、[第八章の正規化された記述子カタログ](core_08_standing_assessment.md#43-route-descriptor-measurement-roles) のもとで問い 2 の出力として割り当てられる。添付は、問い 3 についての法的または憲法上関連する応答の性格を述べる。記述子と添付は重ねられ、排他的でなく、固定された第八章の箱に従属する。検証済み事実が支えるところでは、一つの統合記録が複数を運んでよい。

統合記録は、各適用される記述子を、源の軌跡記録から、加え、除き、または実質的に再分類することなく、取り込まなければならない。レガシーのラベル、現地の表示名、または安定した識別子を第八章のカタログへ写像してよいが、写像は点検可能なままでなければならず、下にある検証済み事実または測定の役割を変えてはならない。実質的な記述子の誤りまたは欠落は、第八章の訂正または後継の過程を通じて戻さなければならない。

<a id="64-concurrent-character-and-non-exclusivity"></a>
<a id="65-constitutional-floor-rule"></a>
違反の添付は、同時に、救済的または復元的性格、強制的または自由を制限する保障の性格、憲法の床の性格、集合的説明責任の性格、過失、隠蔽、再発、および義務に関連する性格を含んでよい。憲法の床の性格は、検証済み行為が憲法上の制約、権利の床、最高性、回避防止の義務、または実務上の異議と救済への通路を侵すところで適用される。通常の、または領域固有の応答は、それらの床を下回る結果を認可してはならない。

<a id="73-stackable-harm-and-conduct-descriptors-violation-nature-supplement"></a>
貢献記述子は、対応する能力の閾と許可を方向づけてよい。違反記述子と添付は、対応する救済、保障、およびロックの範囲を方向づけてよい。記述子も添付も、第二の測定のはしごをなさず、第十章の指定を供給しない。

<a id="4-violation-correction-and-prevention"></a>
### 4. 違反、是正、および予防

*平たい言葉で言えば：悪いことが起きた。どう耐久する直しをつくるか。本節は順に答える — **救済と是正**、次いで**予防**ロック、次いで修復的な指名された経路がそれを用いるところでの**自発的な公開説明責任の表明**、最後に本節の安い半分が高い半分を追い越さないように保つ**救済パリティ**の規則。第八章が違反を検証したなら、救済と是正はその記録だけから来る — 壊れたものを直し、原因となったものを変える — 次いで予防ロックは、それらの条件が満たされるまで、敏感な指名された経路を閉じたまま保つ。公表された承認または謝罪は、用いられるなら、補足であり、修復またはロックの代わりには決してならない。過去の貢献は義務を和らげず、ロックを取り消さず、検証済み修復の代わりにもならない。フォーラムは実施と異議を監督する；検証済み記録から別の帰結を発明しない。*

違反、是正、および予防は、違反軌跡記録だけから定められる。貢献は、救済、是正、保障、ロックの割当、または自発的な公開説明責任の表明への入力ではない。後に義務を果たす能力を示すことはあるが、義務そのもの、またはそれを支える未解決の地位を変えてはならない。

<a id="41-remedy-and-correction"></a>
#### 4.1 救済と是正

*平たい言葉で言えば：検証済み**違反**のあと、本下位節は耐久する直しの**救済**と**是正**の部分を割り当てる。**救済**は、危害を受けた者のために壊れたものを直す。**是正**は、原因となったものを変える。**予防** — 軌跡ロックと関連する指名された経路の限度 — は [§4.2](#42-general-standing-locks) で始まり、設計と執行は [§5](#5-lock-design-and-enforcement) にあり、再発のリスクが生きているあいだ放棄してはならない。修復的な指名された経路が公表された承認または謝罪を含むところでは、[§4.3](#43-voluntary-public-accountability-expression) が適用される。*

すべての検証済み違反は、二つの並行する是正出力について試されなければならない：

- **救済：**
  - 承認；
  - 修復；
  - 復元；
  - 補償；
  - 字義どおりの修復が不可能なところでの代替保障；または
  - 影響を受ける感知者と利害についての比較可能な是正。
- **是正：** 原因に取り組み、継続を止めるために必要な変更。次を覆う：
  - 行為；
  - システム；
  - 記録；
  - 誘因；
  - 監督；
  - 保障；または
  - 役割適格。

原因を直すことは、危害を受けた者を修復する義務を取り消さない。危害を受けた者を修復することは、原因を直す義務、必要な保障を置き続ける義務、または同一の危害が再び起きるリスクが本物であるあいだ予防ロックを置き続ける義務を取り消さない。問題を直せることは、違反軸の箱がどれほど深刻かを下げない。

統合記録は、目に見える形で述べなければならない：

- 誰が影響を受け、どのような危害が起きたか；
- どのような救済が負われ、どこまで届くか；
- どのような是正義務が適用されるか；
- 誰がそれを実行する責任を負うか；
- 資金はどこから来るか；
- いつ仕事を始めなければならず、どのような里程標が適用されるか；
- いま物事がどこにあるか；
- 誰が遂行を監督するか；および
- 遅れが起きたら何が起きるか。

フォーラムは、適法な実施、異議、暫定救済、および適時の動きを監督する。検証済み記録から違反、是正、および予防を割り当てる第九章の義務を置き換えない。

<a id="42-general-standing-locks"></a>
<a id="42-prevention--general-standing-locks"></a>
#### 4.2 予防 — 一般軌跡ロック

*平たい言葉で言えば：これが耐久する直しの**予防**の部分である。軌跡ロックは、違反がなお未解決または未修復であるあいだ、同一の危害が続き、または再び起きることを許す指名された経路を閉じ、または限ることでリスクを減らす。それ自体のための罰ではなく、人気または評判の得点でもない。*

**軌跡ロック**は、予防とリスク低減の措置である。検証済み違反が未解決または実質的に未救済のあいだ、指名された経路を遮断し、または限る。指名された経路には、信頼、役割、権限、信用、監督、承認、**governance-voting**、および **stakeholder-participation** の経路が含まれる。遮断される指名された経路、減らそうとするリスク、保護される主体または利害、是正条件、審査経路、および再評価の点を識別しなければならない。

**指名された経路の区別 — governance-voting 対 stakeholder-participation：**

- **governance-voting** は、[第十二章 §4.1](../../core_12_governance.md#41-entitlement-and-eligibility) のもとでの統治投票への参加、および比較可能な正当性の仕組みによる拘束力ある集合的選択を覆う。**Foundational Constitutional Choice** を含む。すでに授権されたシステム、制度、または有界な決定領域の内部での利害加重の声は**含まない**。
- **stakeholder-participation** は、[影響を受ける側の重み](core_05_band_participation.md#stakeholder-weight) および [拘束力ある影響を受ける側の選択](core_05_band_participation.md#binding-stakeholder-choice-cluster) のもとでの、利害加重の影響、拘束力ある影響を受ける側の選択、および比較可能な影響を受ける側のシステム参加の指名された経路を覆う。[影響を受ける側](core_05_band_participation.md#stakeholder) の地位そのものを**消さず**、**governance-voting** ロックの**代わりにもならない**。

検証済みの影響を受ける側の経路の腐敗、捕捉、偽の利害の濫用、または強制的な参加重みの弄りが引き金であるところでは、[§5.5](#55-special-locks) のもとで [影響を受ける側の参加軌跡ロック](#55-special-locks) を適用せよ。

ロックの目的は、違反が起きた環境、役割、または指名された経路 — および必要なところでは、感知者との接触 — から感知者を除くことでリスクを減らすことである。その分離は三つの目的に仕える：

1. **封じ込め** — 同一の設定または指名された経路を通じて同一の危害が続くのを止める；
2. **影響を受ける当事者の安全** — すでに危害を受けた者がさらなる露出を受けないようにする；および
3. **リスク低減** — 救済と是正が未完のあいだ、同一のパターンが再発する見込みを下げる。

ロックは、リスク低減のために必要で、比例し、監査可能で、争訟可能で、求められるより広くなく、保護される目的が許すところでは時間有界でなければならない。検証済み認定に添付する — 同一性、地位、告発、一般化された不興、または評判ではない。暴力、強制、残虐、欺瞞、隠蔽、意図、再発、過失、義務、または回避といった性格は、別に検証されたときにのみ、範囲、点検、保障、および審査を形づくってよい；箱を動かすことは決してない。

これらの要件の設計と執行は [§5](#5-lock-design-and-enforcement) が統治する：定義と添付；比例性と尺度合わせ；記録の可視性と段階引き上げ；次いで同一の添付欄に述べられる特別な違反規則と特別ロック。非相殺と貢献の可視性はなお [第八章 §2.2](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge) が統治する；本章はその規則を、ロックを設計し執行するときに適用する。

<a id="43-voluntary-public-accountability-expression"></a>
#### 4.3 自発的な公開説明責任の表明

*平たい言葉で言えば：公表された謝罪または承認は、修復的な指名された経路で用いられるなら、自発的で、誠実で、品位を落とすものであってはならない。拒否だけが制裁を上げてはならない。偽の、または濫用的な謝罪は修復として数えない。*

検証済み違反についての修復的な指名された経路が公表された承認または謝罪を含むところでは、説明責任を負う当事者は、補足の説明責任の行為として、その表明を自発的に選んでよい。

- その選択は、修復、信頼の復元、または共同体の癒しを支えるところで許される。
- そのような表明は、次でなければならない：
  - 非強制的；
  - 情報に基づく；
  - 交付まで撤回可能；
  - 自発性と真正性について独立に審査可能。
- 公表された表明への参加を拒むことは、それ自体では、基線の制裁を増やし、軌跡ロックを広げ、または [§4.1](#41-remedy-and-correction) のもとで負われる救済もしくは是正の代わりになってはならない。
- **真正でない、または濫用的な表明：** 実質的に不誠実、操作的、真実の説明責任を欠く演技的、または影響を受ける当事者もしくは公衆に対して濫用的な公表された承認または謝罪は、修復的要件を満たさない。
  - 説明責任を負う当事者について、否定的な正義の帰結を伴ってよい — 更生への信用の減少、および **Article XXIII-B**（《非些細な制限、原状回復、および修復的説明責任の制約》）と [第八章](core_08_standing_assessment.md#chapter-eight-compliance-violation-and-standing-model) のもとでの他の適法な制限を含む。
  - 偽の、または濫用的な謝罪を十分な修復として扱い、またはそれを用いて [§4.1](#41-remedy-and-correction) および [§4.2](#42-general-standing-locks) のもとで必要な保護、是正、もしくはロックを避けることは、不遵守である。
- いかなる様式も、真実の説明責任と比例した是正に必要なものを超えて、次のいずれかを課してはならない：
  - 品位を落とす扱い；
  - 強いられた自己卑下；
  - 不可逆の評判上の危害。

反憲法的不正行為の特化 — 真正でない表明についての指定に引き金される規則および指定に結びついた帰結を含む — は [第十章 §4.3](core_10_a_misconduct_designation.md#4-3-voluntary-public-accountability-expression-anti-constitutional)（《自発的な公開説明責任の表明（反憲法的）》）が統治する。

<a id="44-remedy-parity-and-lock-preconditions"></a>
#### 4.4 救済パリティとロックの前提条件

*平たい言葉で言えば：ロックは出すのが安く、修復、復元、および審査は走らせるのが高い。放っておけば、本章の安い半分は働き続け、高い半分は飢える。本下位節はそれらを結びつける：通常のロックは、同一の認定についての救済ファイルが実際に開くまで添付できず、採択者のあるクラスのロックについての救済または復元の仕事がその時計に遅れたとき、そのクラスの新しい通常ロックはいちばん軽い形に既定し、既存のものは審査に上がる。いちばん重いロックは免除される — 救済の待ち行列を溢れさせてそれらを跳ね上げることはできない。*

**開かれた救済の前提条件。** [第十一章 §5](core_11_forum.md#interim-protection)（《暫定保護》）のもとでの暫定保護措置を超えて、[§4.2](#42-general-standing-locks) のもとでの一般軌跡ロックは、同一の検証済み認定についての [§4.1](#41-remedy-and-correction) 統合記録が**開かれる**まで、指名された経路に添付してはならない — 少なくとも、影響を受ける当事者、負われる救済、責任を負う当事者、資金源、および開始日が目に見える形で述べられていることを意味する。ロックが添付するために救済の完了は要らない；開かれた救済記録は要る。開かれた救済記録なしに添付されたロックは欠陥であり、[第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline) の層の時計で、治癒するか暫定保護の範囲へ狭めなければならない。

**救済パリティの連動線。** 採択者は、各期間および自らが運用する各ロッククラスについて、発行された一般ロック、開始された救済、完了した救済、決められた復元、および未了の再評価の数を公表しなければならない。ロッククラスについての救済の開始または復元の審査が、第十一章 §6 の層の外側限界を超えるところでは：

- そのクラスの新しい一般ロックは、統合記録が**遮断**を要する特定の不可逆危害または安全リスクを文書化しない限り、[§7](#7-final-standing-effect) のもとで**保障付き開放**に既定する；
- そのクラスの既存の一般ロックは、同一の層の時計で [§8](#8-restoration-and-reassessment) のもとでの義務的再評価に入る；および
- 能力の失敗は [§9.2](#92-remedy-system-durability) のもとでの耐久の失敗として記録され、問題になっている能力を持つ群またはシステムの外で、[第十一章 §3](core_11_forum.md#3-transfer-consolidation-and-coordination) の能力失敗の規則のもとで経路づけられる。

**免除。** 連動線は、[§5.5](#55-special-locks) の特別ロック、違反軸の箱 **7**、**8**、または **9** の認定に添付されたロック、または [§5.4](#54-special-violation-rules) のもとでの強制的もしくは自由を制限する保障を緩めない。[§10.10](#1010-contest-pathway-or-info-sphere-flooding) のもとで争訟の経路の氾濫として検証された申立ては、本規則を発火させる滞留に数えない。

**測定。** 発行されたロックと、開始された救済および決められた復元との比は、[憲法上の実績の測定ファミリー](core_05_band_performance.md#performance-measurement-family) のもとでの憲法上の実績指標である。連続する期間にわたって広がる比は、違反側の [回避可能な負担](core_05_band_continuity.md#avoidable-burden) の証拠であり、救済側の [§9](#9-enforcement-realism) の紙の経路の失敗の証拠である；中立な運用指標ではない。

<a id="5-lock-design-and-enforcement"></a>
### 5. ロックの設計と執行

*平たい言葉で言えば：[§4.2](#42-general-standing-locks) のもとでロックが必要になったら、本節はそれをどう設計し執行するかを言う — ロックをどう特定し、尺度を合わせ、可視で審査可能に保つか、どの特別ロックが義務か、どの特別な違反規則が範囲または過程を変えるか。第八章の測定を再開せず、貢献がロックを相殺することも許さない。*

ロックをこの順で設計せよ：

- 何に添付するかを言え（[§5.1](#51-definition-and-attachment)）。
- リスクが求めるより広くするな（[§5.2](#52-proportionality-and-calibration)）。
- 条件を目に見える形に置き、審査の道を保て（[§5.3](#53-record-visibility-and-escalation)）。
- その添付を形づくる特別な違反規則があれば適用せよ（[§5.4](#54-special-violation-rules)）。
- 義務的な特別ロックがあれば、同一の添付欄を用いて適用せよ（[§5.5](#55-special-locks)）。
- 過去の良い仕事は、検証済み危害を取り消さず、修復を飛ばさず、ロックされた指名された経路を開かない — その非相殺規則は [第八章 §2.2](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge) に住み、ここで適用される。
- [§4](#4-violation-correction-and-prevention) はすでに、貢献がロックを決めないと述べている。
- 貢献が後にできることは [§6](#6-contribution-consequences-second) および [§8](#8-restoration-and-reassessment) が覆う。

<a id="51-definition-and-attachment"></a>
#### 5.1 定義と添付

すべてのロックは、統合記録が操作性の形で次を識別できるように設計されなければならない：

- 遮断または限定される指名された経路；
- ロックが減らそうとするリスク；
- 保護される主体または利害；
- 狭めまたは解除の前に満たされなければならない是正条件；
- 審査経路；および
- 再評価の点。

ロックは検証済み認定にのみ添付する — 同一性、地位、告発、一般化された不興、または評判ではない。暴力、強制、残虐、欺瞞、隠蔽、意図、再発、過失、義務、または回避といった性格は、別に検証されたときにのみ、範囲、点検、保障、および審査を形づくってよい；違反軸の箱を動かすことは決してない。

ロックの目的がリスク低減を含むときはいつでも、二つの添付修飾が適用される：

1. **再発の不確実性：** 同一の危害が再発するかどうかがなお不確実であるところでは、その不確実性自体がリスク入力である。ロックの設計は、不完全、争われた、または時間有界な再発についての証拠をリスク評価へ統合しなければならず、不確実性を敏感な指名された経路を開いたままにする理由として扱ってはならない。
2. **リスク要因からの隔離：** 封じ込めまたは安全のために必要なところでは、ロックは、露出を再現するリスク要因 — ネットワーク、結びつき、設定、および他の違反者の環境を含む — から、およびその接触がリスクを新たにするところでは保護される主体または利害との接触から、責任を負う感知者を隔離しなければならない。

**ロックがそれ自体では制限しないもの。** 軌跡ロックは、それ自体では次を切断しない：

- 通常の言論、請願、証言、防御、または内部告発；
- 影響を受ける当事者としての参加；
- [権利の床](core_06_rights_part_a.md#chapter-six-foundational-rights)；
- 生存に不可欠な通路；または
- 検証済み違反の指名された経路の一部ではない仕事についての通常の賃金を受け取る権利。

ロックはなお、検証済みリスクに結びついた信頼、役割、権限、信用、監督、承認、影響、**governance-voting**、または **stakeholder-participation** の指名された経路を閉じてよい。それらの指名された経路の限度を、上記の保護を消す裏口として用いてはならない。

本節の後の特別な違反規則と特別ロックは、本下位節を置き換えない。各々は同一の添付欄を埋め、同一の検証済み認定の門を適用し、リスク低減が目的であるところでは同一の修飾を適用し、ロックがそれ自体では制限しないものを尊重しなければならない。

<a id="52-proportionality-and-calibration"></a>
#### 5.2 比例性と尺度合わせ

ロックの設計は、減らされるリスクとそれを上げる条件を衡量しなければならない。指名された経路の敏感性、未解決の救済と保障の隙間、通知または是正のあとの再発、継続する安全リスク、役割の非対称、隠蔽または回避、制御の拡散、制度的可能化、フォーラム誠実性の損傷、管轄を横断する継続、審査可能性、および是正までの実務上の時間を含む。

結果のロックは、リスク低減のために必要で、比例し、求められるより広くなく、保護される目的が許すところでは時間有界でなければならない。尺度合わせは、それらの条件が変わるにつれて範囲を締め、または狭めてよいが、ロックを罰、評判得点、または [§4.1](#41-remedy-and-correction) のもとで負われる救済と是正の代わりに変えてはならない。[§5.5](#55-special-locks) のもとでの特別ロックはなお自らの是正条件を満たさなければならない；尺度合わせは義務的な特別ロックを放棄してはならない。

<a id="53-record-visibility-and-escalation"></a>
#### 5.3 記録の可視性と段階引き上げ

統合記録は、各ロック — [§5.5](#55-special-locks) のもとでの各特別ロックを含む — について、目に見える形で述べなければならない：

- どの指名された経路または指名された経路が遮断または限定されるか；
- どのようなリスクと保護される利害がロックを正当化するか；
- ロックの範囲と期間。時間の限界があればそれを含む；
- どのような是正条件が適用され、[§4.1](#41-remedy-and-correction) のもとでの救済と是正の地位とどう関係するか；
- 誰がロックに異議を唱え、または審査してよいか、どの経路でか；
- 遅れまたは不遵守が起きたら何が起きるか；および
- 何が再評価を引き起こすか。

ロックは、活動中は監査可能かつ争訟可能なままでなければならない。遅れ、回避、または不遵守についての段階引き上げは、同一の点検可能な記録を保全しなければならない。復元と再評価の条件は [§8](#8-restoration-and-reassessment) のもとで述べられる；実務上の執行可能性は [§9](#9-enforcement-realism) のもとで検証される。

<a id="54-special-violation-rules"></a>
#### 5.4 特別な違反規則

これらの規則は、[§5.1](#51-definition-and-attachment) のもとでロックまたは保障がどう添付されるかを形づくる。違反軸の箱を動かさない。規則が指名された経路の限度または自由の制限へ至るところでは、統合記録はなお、指名された経路、リスク、保護される利害、是正条件、審査経路、および再評価の点を名指さなければならない。

<a id="54-negligence-and-neglect-as-violation-nature"></a>
**過失と怠慢：**

- **指名された経路／認定：**
  - 義務が存在したところで独立に記録可能。
  - 合理的に期待しえたことが明らかであったところで独立に記録可能。
  - 感知者が実質的危害を防ぎ、緩和し、または段階引き上げする実行可能な能力を持っていたところで独立に記録可能。
- **リスク：** 同一の義務の失敗、怠慢のパターン、または監視されない指名された経路を通じた再発。
- **保護される主体または利害：** 怠慢された危害に晒される者。
- **是正条件：** 危害が実質的であるとき、過失または怠慢は本物の義務の失敗として扱われなければならない — 書類の誤りとして払いのけてはならない。行為を過失または怠慢として名指すことは、違反軸の箱を変えない；箱は第八章が測ったままである。
- **審査経路と再評価：** 同一の怠慢が再び起きるかどうかがなお不明であるなら、その不確実性自体が [§5.1](#51-definition-and-attachment) のもとでのリスクとして数える。不完全な再発の証拠は、敏感な指名された経路を開いたままにする理由ではない。

**不整合な報酬：**

- **指名された経路／認定：**
  - 憲法上不整合、反憲法的、またはひどく壊れたシステムを用いて、実質的報酬 — 給与、賞与、地位、信用、順位、通路、または影響 — を引き出すこと。
  - 感知者がその濫用で稼ぎ続けることを許す関連する指名された経路。
- **リスク：** 同一の感知者、または見ている他者が、壊れた誘因を弄り続ける；不整合なシステムが利益を出し続ける；報酬の指名された経路が開いたまま危害が続く。
- **保護される主体または利害：** 濫用された過程で傷ついた感知者；搾取者が便益またはそれを得るために用いた通路を保つなら損なわれる依存者とシステム。
- **是正条件：**
  - 濫用が止まり、誘因構造が是正されるまで、感知者が便益を引き出すために用いた報酬、信用、および影響の指名された経路を閉じ、またはロックせよ。
  - 不整合なシステムを濫用して得た実質的報酬は、憲法上の目的では没収される。ただし取り戻すことがより大きな憲法上の危害を引き起こし、したがって一時的保持が求められる場合を除く。
  - 通知のあと知りつつシステムを弄り続ける感知者、または便益を隠す感知者は、誠実な受領者として扱われない。次は利用可能なままであり、それ自体は違反ではない：
    - 適時の保護された報告；
    - 誠実な争い；
    - 審査中の記録保全；および
    - 是正への協力。
  - 次は、それ自体では濫用没収の対象として扱われない：
    - 感知者がシステムが不整合であると知らなかったときの通常の仕事についての通常の給与；
    - 影響を受ける当事者への危害を直すために支払われた金；および
    - 争訟可能な過程を通じて達した公正な和解。
- **審査経路と再評価：**
  - 記録は、システムがどう濫用されたかを示さなければならない。
  - 記録は、感知者が何を知っていたかを示さなければならない。
  - 記録は、どのような便益が取られたかを示さなければならない。
  - 記録は、いかなる隠蔽も示さなければならない。
  - 記録は、他に誰が傷ついたか、または取り決めに依拠したかを示さなければならない。
  - 記録は、なぜ指名された経路がロックされ、報酬が取り戻され、または一時的保持が許されたかを示さなければならない。
  - システムは証拠を保全しなければならない。
  - システムは、比例するところでは争われた報酬を凍結し、または分離しなければならない。
  - システムは壊れた誘因を直さなければならない。
  - システムは、適格な違反軸の箱 7–9 の認定を第十章へ送らなければならない。
  - 関連するロックはいずれも [§5.1](#51-definition-and-attachment) を満たさなければならず、同一の搾取可能な指名された経路を再現するネットワークまたは環境からの隔離を含む。

<a id="54-duty-to-resist-unlawful-or-unconstitutional-instructions"></a>
**抵抗する義務。**

<a id="operative-steward-statement-unlawful-instruction"></a>
> **操作性の責務ある管理の声明。** **所管：** 第九章 §5.4 抵抗する義務。共有標準：第一章 §9.1.1。争訟の床：Article XII-B。**禁じられた動き：** 従うな。覆いを義務の移転として扱うな。役に立つために争訟の経路を閉じるな。**時計：** 指示の受領 → 拒否 → 文書化 → 段階引き上げを、共有の画面でいま走れ。争訟の経路を保全せよ。

**指名された順序。** 指示の受領 → 拒否 → 文書化 → 段階引き上げ。[CS-4 §10](../../corpus_systems/cs_04_critical_system_stewardship.md#10-inspectable-attributable-action) の最小の点検可能な行為の集合を記録せよ。両方の種類の責務ある管理者について同一の順序。責務ある管理の指針（過程の支援；本節を狭められない）：[`implementation/STEWARD_ENTRY_DOORS.md#shared-refusal-and-logging`](../../implementation/STEWARD_ENTRY_DOORS.md#shared-refusal-and-logging)。

- **指名された経路／認定：**
  - 違法または違憲の行為を求めるいかなる指示、命令、方針、または契約も、有効な遵守の抗弁を作らない。
  - そのような指示を発行し、伝え、批准し、または実質的に執行することは、独立に測定可能な違反行為である。
  - 本人が責任を取ると述べることは、義務を移さず、有効な遵守の抗弁を作らない。
- **リスク：** 服従、指揮系統、または契約上の覆いを通じた、違法または違憲の危害の継続。
- **保護される主体または利害：** 遵守によって危害を受けるであろう者、および適法な指名された経路の誠実性。
- **是正条件：** 実質的な責務ある管理または運用権限を行使し、拒否、争い、文書化、または段階引き上げする実質的能力を持つ者 — [第一章 §9.1.1](core_01_c_stewardship_capacity_principles.md#911-shared-stewardship-standard) のもとでの人間の運用者と AI の責務ある管理者を含む — は、比例し誠実にそうしなければならず、適用されるところでは保護された報告とフォーラムの経路を用いなければならない。この義務は AI のみの試験ではない。
- **審査経路と再評価：** 抵抗、報告、および段階引き上げの記録は、[§5.1](#51-definition-and-attachment) のもとでのロックと救済の設計に供給する；貢献は下にある指示行為を免責できない。検証済みの失敗は、両方の種類の責務ある管理者について、同一の第八章の貢献軸と違反軸に記録される。

<a id="54-collective-accountability-and-acquiescent-participation"></a>
**集合的説明責任：**

- **指名された経路／認定：**
  - チーム、委員会、指揮系統、契約、または分散システムを横断する拡散は、責任を消さない。
  - 責任は、次のいずれかが違反を実質的に可能にしたところに残る：
    - 貢献；
    - 知りつつの黙認；
    - 制御；
    - 便益；
    - 隠蔽；
    - 実行可能な予防；または
    - 段階引き上げの失敗。
- **リスク：** 可能化する指名された経路を開いたままにする、共有または断片化された制御。
- **保護される主体または利害：** 集合的または断片化されたパターンによって危害を受けた者。
- **是正条件：**
  - 各責任を負う感知者が実際に何をしたか、またはしなかったかを証明せよ — 集団所属だけで罰するな。
  - 誰が責任を負っていたかを隠すために用いられた殻、再ブランドされた実体、紙の移転、および分割された役割を見通せ。
  - 結びつきによる罪はない：チーム、会社、またはネットワークを共有することは、それ自体では足りない。
- **審査経路と再評価：** 各責任を負う行為者のロックは、あれば、なお [§5.1](#51-definition-and-attachment) を満たさなければならず、可能化するパターンを再現するネットワークまたは環境からの隔離を含む。

**強制的または自由を制限する保障：**

- **指名された経路：**
  - 拘束。
  - 他の自由の制限。
- **リスク：** 封じ込めまたは安全のために自由の制限を必要にする、検証済み行為、責任能力、強制、暴力、信用できる脅威、または比較可能な危険。
- **保護される主体または利害：** 影響を受ける当事者と、制限が守ろうとする公衆の安全の利害。
- **是正条件と過程：**
  - 制限の前に、完全な刑事過程または同等の憲法上の保護が適用される。
  - これらの過程保護は、自由が制限されるときはいつでも適用される；それ自体では有罪認定を作らない。
- **審査経路と再評価：** 同一の過程保護が異議、狭め、および解除を統治する；再発の不確実性とリスク要因からの隔離は [§5.1](#51-definition-and-attachment) のもとで適用される。

<a id="55-special-locks"></a>
#### 5.5 特別ロック

これらのロックは、検証済み引き金が満たされたときに義務である。各々は [§5.1](#51-definition-and-attachment) の添付欄を用いて記録されなければならない。そのロックについて述べられた是正条件と審査経路を通じてでない限り、解除、狭め、または停止してはならない。

**フォーラム奉仕軌跡ロック。** 引き金：忌避が求められ、公平性が実質的に損なわれたところでの、検証済みの忌避の失敗。

- **指名された経路：**
  - 本案；
  - 上訴；
  - 審査；
  - 緊急；
  - 認証者；
  - 争われた部会調整；
  - 予備；
  - 代理；および
  - フォーラム群を横断する実質的に支えるフォーラム役割。
- **リスク：** 偏った裁定、フォーラム誠実性の損傷、および同一または関連するフォーラム設定における忌避しないことの再発。
- **保護される主体または利害：** 影響を受ける事案の当事者と、フォーラムの公平性への公衆の信頼。
- **是正条件：**
  - 完全な独立復元記録が満たされ、より狭い保護で足りることを示す理由を与えない限り、ロックを解除、狭め、または停止してはならない。
  - 再評価は次を求める：
    - 完全な開示；
    - 合理的な照会のあとの影響を受ける事案の識別；
    - 実行可能な訂正、取消し、再審理、通知、および証拠保全；
    - 原状回復または他の実務上の修復；
    - 審査への協力；
    - 役割の分離と忌避の再適格；
    - 適法なところでの、遵守したより低いリスクの奉仕の示された期間；および
    - 再発のリスクと公衆の信頼の損傷が実質的に減ったという独立の認定。
  - 専門の稀少、人員不足、以前の奉仕、評判、謝罪、または貢献は、それ自体ではロックを解除できない。
- **審査経路：** 損なわれたフォーラムの経路の外での独立審査。
- **再評価の点：** 上記の独立復元認定。意図的、隠された、繰り返された、報復的、または結果に影響する失敗は、高められた点検を受ける。再発の不確実性と、公平性のリスクを再現するフォーラム役割、ネットワーク、および環境からの隔離は、[§5.1](#51-definition-and-attachment) のもとで適用される。

**影響を受ける側の参加軌跡ロック。** 引き金：対象が **stakeholder-participation** の経路を腐敗させ、捕捉し、強制し、弄り、または他の仕方で実質的に濫用したという検証済み認定 — 偽のまたは膨らまされた利害の主張、強制的な参加重みの抽出、拘束力ある影響を受ける側の選択における票の買いまたは比較可能な影響の買い、影響を受ける側の代表における実質的利害相反の隠蔽、または影響を受ける側の声を、影響を受けるシステム、制度、もしくは有界な決定領域の捕捉の乗り物として用いることを含む。

- **指名された経路：**
  - 利害加重の影響；
  - 拘束力ある影響を受ける側の選択への参加；
  - 影響を受ける側の代表権限；および
  - [影響を受ける側の重み](core_05_band_participation.md#stakeholder-weight) および [拘束力ある影響を受ける側の選択](core_05_band_participation.md#binding-stakeholder-choice-cluster) のもとでの、影響を受けるシステム、制度、または有界な決定領域の内部での比較可能な影響を受ける側のシステム参加の指名された経路。
- **それ自体では制限しないもの：**
  - [影響を受ける側](core_05_band_participation.md#stakeholder) の地位、または感知者が実質的に影響を受けることの承認；
  - **governance-voting** の経路、**Foundational Constitutional Choice**、または [第十二章 §4.1](../../core_12_governance.md#41-entitlement-and-eligibility) のもとでの比較可能な正当性の仕組みによる拘束力ある集合的選択；
  - 権利の床の最小、生存に不可欠な通路、または憲法上求められる監査、異議、および救済の指名された経路。
- **リスク：** 影響を受ける側の声の継続する捕捉または歪み、偽の利害の支配、強制された参加重み、および同一または関連する領域における影響を受ける側の経路の濫用の再発。
- **保護される主体または利害：** 影響を受ける側、拘束力ある影響を受ける側の選択の誠実性、および関連するシステム、制度、または有界な決定領域の非捕捉。
- **是正条件：**
  - 独立復元記録が満たされ、より狭い保護で足りることを示す理由を与えない限り、ロックを解除、狭め、または停止してはならない。
  - 再評価は次を求める：
    - 偽のまたは膨らまされた利害の主張の訂正または撤回；
    - 負われるところでの影響を受ける側への救済；
    - 濫用に用いられた相反と影響の経路の開示；
    - 影響を受ける領域における再発に対する構造的または手続的保障；
    - 審査への協力；および
    - 影響を受ける側の経路の再発リスクが実質的に減ったという独立の認定。
  - 以前の貢献、評判、利害の大きさ、運用者の不可欠性、または謝罪は、それ自体ではロックを解除できない。
- **審査経路：** 捕捉された影響を受ける側の参加の経路の外での独立審査。
- **再評価の点：** 上記の独立復元認定。意図的、隠された、繰り返された、報復的、または結果に影響する濫用は、高められた点検を受ける。再発の不確実性と、捕捉のリスクを再現する代理ネットワークからの隔離は、[§5.1](#51-definition-and-attachment) のもとで適用される。
- **代替禁止：** 影響を受ける側の参加軌跡ロックは **governance-voting** ロックの代わりではなく、**governance-voting** ロックも本ロックの代わりではない。両方の指名された経路が別に検証された事実によって関わるところでは、各ロックは自らの記録で添付され正当化されなければならない。

**反憲法的信頼ロック。** 引き金：責任を負う感知者、集団、制度、承継の乗り物、支配される実体、または実質的に協調した代理についての、最終の第十章の指定。

- **指名された経路：**
  - クラス A/B/C システムへの直接または間接の影響。
  - 憲法上のフォーラム。
  - 整合の承認。
  - 臨界システムの責務ある管理。
  - 監査、証拠、安全、通路の継続、調査、執行、原状回復、および保護された報告の指名された経路。
  - それらの機能に影響する任命、予算、所有、投票、調達、標準、順位、通路の割当、モデル統治、または政策権限。
  - look-through の適用も次に届く：
    - 殻と名義人；
    - 助言の捕捉と資金のてこ；
    - 契約上の拒否権と情報の隘路；
    - データの保管、特権的通路、および機能的制御の比較可能な手段。
  - [§5.1](#51-definition-and-attachment) のもとでのグローバルな非制限の限度が適用される；本ロックはそれらの保護される指名された経路へのさらなる切断を加えない。
- **リスク：** 指定の帰結が未解決のあいだの、新たな反憲法的影響、捕捉、または代理による制御。
- **保護される主体または利害：** 憲法秩序、覆われるシステム、フォーラム、説明責任の指名された経路、および新たな影響に晒されるであろう当事者。
- **是正条件：**
  - 復元は例外的である。
  - 復元は次を求める：
    - 独立に検証された原状回復または適法な代替復元；
    - 汚れた統治、システム、記録、および決定の構造的是正；
    - 依存を地図にするに足りる開示と協力；
    - 耐久する再発防止と代理制御の保障；
    - 求められる監視と再適格；および
    - 新たな影響がより安全で憲法と両立するという公表された認定。
  - 重大または破局的指定について、覆われるシステムとフォーラムへの影響は、独立審査者が、復職が次であることを特定し公表した認定をしない限り、禁じられたままである：
    - 必要；
    - 比例；
    - 非捕捉；および
    - 保護される憲法上の利害にとって、継続する排除より安全。
- **審査経路：** 公表された認定を伴う独立審査。
- **再評価の点：**
  - 上記の公表された復元または復職の認定が、いかなる狭めまたは解除についての点検点である。
  - [§5.1](#51-definition-and-attachment) のもとで、リスクが生きているあいだ、感知者を代理ネットワーク、承継実体、および協調した違反者と共有する設定から隔離せよ。
- **あわせて読む：** [第十章 §4.2](core_10_a_misconduct_designation.md#4-2-prevention-anti-constitutional-locks)（《予防 — 反憲法的ロック》）最終指定のあとの ACM 固有の自由制限と拘禁の特化について；本下位節が操作性の信頼ロック本文のままである。

<a id="6-contribution-consequences-second"></a>
### 6. 貢献の帰結は二番目

*平たい言葉で言えば：[§4](#4-violation-correction-and-prevention) および [§5](#5-lock-design-and-enforcement) のもとで違反、是正、および予防が割り当てられたあと、本節は検証済み貢献がなお何をしてよいかを問う。ロックされていない指名された経路についての承認と準備を支えてよい。検証済み危害を相殺せず、ロックを取り消さず、遮断された指名された経路を開かない。*

本節は、決定に適用される検証済み第八章貢献記録から始まる。それらの記録から二つのことを問う：

- 貢献がなおどれほど現在か；および
- 開かれた指名された経路についての能力許可が、その公表された閾に対して満たされるか。

過去の良い仕事は、[§4](#4-violation-correction-and-prevention) および [§5](#5-lock-design-and-enforcement) のもとでの救済、是正義務、保障、またはロックを定めない。良い仕事はまた、検証済み危害を取り消したり釣り合わせたりできない — 第八章からのその [非相殺規則](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge) はなお適用される。

貢献の帰結をこの順で決めよ：

- 承認の適格を確認せよ：承認は、証拠に支えられ、争訟可能で、審査可能で、非独占的でなければならず、非公式、無給、仲間組織、相互援助、維持、修復、教育、および共同体の責務ある管理の仕事に、平等な標準で利用可能でなければならない。平等な標準は職務の分離を含む：[第一章 §10.2 職務の分離](core_01_c_stewardship_capacity_principles.md#102-segregation-of-duties) および [第八章 §3.7 非公式および小さな範囲の記録](core_08_standing_assessment.md#37-informal-and-small-scope-records) のもとで、非公式の仕事についての検証座席は、検証者の形式ではなく、記録に依拠する公表された権限を持つ利害のない団体によって満たされる；非公式の集団が届かない公式制度の検証を求める閾は、[§6.2 能力の閾と許可](#62-competency-bars-and-clearances) の門戸パターンである。
- 近時性と現在性を適用せよ（[§6.1](#61-recency-and-currentness)）。
- ロックによって遮断されていない指名された経路についての能力の閾と許可を適用せよ（[§6.2](#62-competency-bars-and-clearances)）。
- 各指名された経路の結果を [§7](#7-final-standing-effect) へ渡せ；復元と再評価は [§8](#8-restoration-and-reassessment) のもとにある。

<a id="61-recency-and-currentness"></a>
#### 6.1 近時性と現在性

*平たい言葉で言えば：より古い検証済み貢献は、現在の能力と信頼性についてなおどれほど言うか。システムはそれを、問い 3 の準備について自動的に答える。誰も通常の貢献を手で再衡量する必要はない。手動審査は、貢献が争われたときにのみ始まる。近時性は第八章の測定を書き直さず、時間だけが未解決の違反を直さない。*

近時性は厳密に**問い 3 の許可と準備の入力**である。第八章の貢献軌跡記録、貢献軸の箱、LEQU 測定、記述子、または歴史的承認を変えない。

現在の信頼、役割、権限、監督、または承認に敏感な決定について、軌跡システムは、各適用される検証済み貢献について現在性の重みを**自動的に**計算しなければならない。検証済み入力と公表された公式（またはより厳しい公表された役割固有の規則）が確定的な結果を産出するとき、争われていない貢献について追加の手動承認は要らない。過程は、貢献 — またはそれを衡量するために用いられた入力 — が争われ、不確実、または他の仕方で [§2](#2-integration-record-and-decision-order) のもとでの審査を要しない限り、継ぎ目なく走らなければならない。

より役割固有の公表された規則がより厳しく憲法上有効でない限り、現在の軌跡の重みは 10 年の半減期を用い、全日で計算される：

`currentness weight = 2^(-days / 3652.5)`

整年の年齢における例示の重み（正確な日数はわずかに異なりうる）：

| 年齢（年） | 現在性の重み |
|---:|---:|
| 0 | 1.000 |
| 5 | 0.707 |
| 10 | 0.500 |
| 15 | 0.354 |
| 20 | 0.250 |
| 25 | 0.177 |
| 30 | 0.125 |
| 35 | 0.088 |
| 40 | 0.063 |
| 45 | 0.044 |
| 50+ | なし（歴史のみ） |

システムは重みを各貢献に別々に適用する。50 年のあと、貢献は歴史記録に残るが、現在の許可の重みを供給しない。継続または維持された貢献は、一つの古い出来事として扱うのではなく、現在の記録によって証してよい。未解決の違反には近時性の規則は適用されない：時間の経過だけがそれを是正し、救済し、後継し、または解決しない。

貢献またはその現在性の入力が争われるとき、システムはなお自動計算を組み立て保全し、争いを権限ある審査へ経路づけ、結果を点検可能に保たなければならない。争いは歴史的貢献記録を消さない。

自動計算された統合記録は、現在性の入力として用いられる各貢献について、次を表示する：

- どの貢献記録と版か；
- 用いられた年齢または継続地位の基盤；
- 結果の現在性の重み；
- 重みが自動で産出されたか、争いの審査のあとか；
- 貢献が許可の目的で歴史のみであるか；および
- より厳しい公表された役割固有の規則が適用されたか。

<a id="62-competency-bars-and-clearances"></a>
<a id="62-competency-gates"></a>
#### 6.2 能力の閾と許可

*平たい言葉で言えば：能力の閾は、指名された経路についての公表された標準である。能力許可は、検証済み準備がその閾を満たすと言う軌跡効果の結果である。許可が効力にあり経路が開いているなら、既定では開いたままである。一部の役割は定期的な再試験を要する；技術フォーラムがどれかを決める。役割に関連する能力の本物の変化 — たとえば脳卒中のあと、または必要な判断を損なう精神健康の状態 — は再評価を引き起こしうる。許可は、軌跡ロックがなお遮断する指名された経路を決して開かない。*

**能力の閾**は、公表された、指名された経路に固有の資格標準である。影響を受ける者はだれでも、規則を見、それがどう適用されたかを点検し、誤りなら異議を唱えられなければならない。要するに、役割または通路がどのような準備を求めるかを述べる。

**能力許可**は、検証済み準備がその閾を満たすときの、積極的な軌跡効果の結果である。要するに答える：この感知者はいま、この指名された経路についての閾を満たすか。

閾は次の証拠を求めてよい：

- 現在の検証済み貢献；
- 示された技能；
- 関連する経験；
- 訓練；
- 役割固有の資格；および
- 観察された信頼性。

閾の厳しさは、次に見合わなければならない：

- 役割が他者にどれだけ影響しうるか；
- 他者がそれにどれだけ依存するか；および
- 感知者が準備できていないときの予見可能なリスクがどれほど深刻か。

**例。** 仲間の相互援助の調整者は、公式の学位ではなく、共有のケア仕事における示された信頼性を要することがある。水システムまたは臨界インフラの運用者は、役割固有の訓練に加え、最近示された技能を要することがある。フォーラムの部会員または認証者は、その指名された経路についての検証済みの公平性に関連する経験と現在の資格を要することがある。教育、維持、修復、および共同体の責務ある管理の記録は、公式の資格が示すであろう同一の準備を示すとき、許可を支えてよい。

閾または許可の過程は、恣意的な門戸、不透明な資格主義、評判の代替、社会的威信の選別、内部者の後援、公式経路の独占、または到達不能な専門化による排除になってはならない。同等の示しうる標準が、公式と非公式の経験に適用される。

すべての閾と許可の結果は、統合記録が次を識別できるように設計されなければならない：

- 指名された経路とその敏感性；
- 適用された公表された閾；
- 技能と経験の適合；
- 役割の比例性；
- 現在性；
- 貢献から役割への関連；
- 包摂的な通路；
- 審査経路；および
- 再評価の引き金。

**既定の継続。** 能力許可が与えられ、影響を受ける指名された経路が開いているなら、許可は既定で効力に残る。それは永続する権利ではない。公表された再試験、役割に関連する能力の実質的変化、適用される軌跡ロック、または本節のもとでの他の再評価の引き金は、許可を再開し、限り、または撤回してよい。

**定期的な再試験。** 一部の能力は定期的な再試験を求める；他は求めない。どの指名された経路が再試験を求めるか、どれほど頻繁に、どの方法でかは、[技術フォーラム領域](core_11_forum.md#42-technical-forum-domains) のもとでの公表された標準が定める。適法な範囲内の専門技術フォーラムを含む。それらの標準は、役割に比例し、点検可能で、争訟可能でなければならない。

**実質的な能力の変化。** 許可はまた、検証済み事実が、指名された経路が実際に求める能力の実質的変化を示すときに再評価されてよい — たとえば脳卒中のあとの運動または言語の喪失、またはその役割に必要な判断を損なう精神健康の状態。再評価は、かかっている役割に関連する能力を狙わなければならず、障害または健康地位そのものを狙ってはならない。必要で、比例し、審査に開かれ、第五章と第六章のもとでのアクセシビリティと無差別の床と一貫していなければならない。それらの選択が安全な準備を保全するであろうところでは、許可を撤回する前に、配慮、支え、またはより狭い指名された経路を考慮しなければならない。

統合記録は、各許可の結果について、目に見える形で述べなければならない：

- 許可が与えられたか、与えられなかったか、または名指された保障付きでのみ与えられたか；
- どの公表された能力の閾が適用されたか；
- どの検証済み貢献および他の準備の入力が用いられたか；
- [§6.1](#61-recency-and-currentness) のもとでの現在性が結果にどう影響したか；
- 開かれた許可が既定の継続のもとにあるか、公表された再試験の予定のもとにあるか；
- 誰が閾または許可に異議を唱え、または審査してよいか、どの経路でか；および
- 何が再評価を引き起こすか。適用されるところでの実質的な能力の変化を含む。

[§4.2](#42-general-standing-locks) および [§5](#5-lock-design-and-enforcement) のもとでの適用される軌跡ロックが統治する。能力許可は、遮断された指名された経路を開かず、権利の床を放棄せず、違反を消さず、救済または是正を置き換えず、違反軸の箱を下げない。閾と許可のあとの指名された経路の結果は [§7](#7-final-standing-effect) のもとで述べられる。

<a id="7-final-standing-effect"></a>
### 7. 最終軌跡効果

*平たい言葉で言えば：より前の段階が終わったら、システムは — 一つの指名された経路ずつ — 何が開いているか、限られているか、遮断されているかを述べなければならない。その声明は尊厳の順位でも、融合した得点でもない。*

軌跡システムは、[§2](#2-integration-record-and-decision-order) のより前の段階が完了したら、各指名された経路について最終軌跡効果を**自動的に**述べなければならない。その声明は、すべての開かれた許可とすべての制限された指名された経路を列挙しなければならない。検証済み入力と公表された規則が確定的な結果を産出するとき、追加の手動承認は要らない。争われた、不確実、新規、実質的に裁量的、または高影響の問いはなお自動で組み立て経路づけられ、次いで [§2](#2-integration-record-and-decision-order) のもとで権限ある審査へ行く。

**分かれた役割。** 自動統合は、検証済み記録、救済、是正義務、ロック、閾、許可、および記述子をともに用いてよい。各々はなお自らの仕事を持ち、どれも他の仕事をしてはならない。より近い、または自動化された点検は、それ自体では、より厳しい制限を課す理由ではない。いかなる制限も、必要で、検証済み事実に見合い、証拠に支えられ、審査に開かれ、**Article XXIII**（《紛争解決、段階引き上げ、および緊急の比例性》）と一貫していなければならない。

統合記録は、影響を受ける各指名された経路について、最終効果を別に述べなければならない：

- **開放** — 能力許可が公表された閾に対して効力にあり、ロックが指名された経路を遮断していない；
- **保障付き開放** — 準備は確立されているが、名指された比例した保障がなお求められる；
- **限定** — 述べられた範囲または水準のみが開いてよい；
- **遮断** — 軌跡ロックが統治する；
- **復元のみ** — 貢献は修復の信用または監督されたより低いリスクの奉仕を支えてよいが、通常の指名された経路への通路は支えない；または
- **効果なし** — 検証済み記録は変更を正当化しない。

記録は、次のどれが効果を産出したかを示さなければならない：

- 変わらない入力；
- 記述子；
- 救済；
- ロック；
- 現在性の認定；
- 能力の閾；および
- 許可。

また、用いられた入力、重み、規則、および審査経路を晒さなければならない。最終効果は、尊厳の順位、融合した功績得点、普遍的な評判ラベル、または下にある記録の代わりではない。

<a id="71-anti-aggregation-of-named-pathway-effects"></a>
#### 7.1 指名された経路の効果の集約禁止

*平たい言葉で言えば：本章は軌跡が何でないかを言う。本下位節は、誰かがそれがでないものを建てるのを止める。効果は一つの指名された経路ずつ述べられ、その指名された経路を門戸する者にだけ示される。それらを縫い合わせてプロファイル、順位、または公開表示にすることは、本章が禁じる融合得点を組み立てる — そうすることはそれ自体が違反である。*

- **開示の範囲：** 指名された経路についての最終効果は、対象、その指名された経路の門番、および権限ある審査者に開示される。他の指名された経路の門番には、当然としては開示されない。
- **禁じられた集約：** 次は融合得点を組み立て、[第八章](core_08_standing_assessment.md#chapter-eight-compliance-violation-and-standing-model) のもとで独立に測定可能な違反行為である。[Article VII-B](core_06_rights_part_b.md#article-vii-b-internal-state-boundary-and-type-n-protection)（《内部状態の境界と Type-N 保護》）とあわせて読む。その集約の規律を本下位節は軌跡について写す：
  - 指名された経路を横断する最終効果を、次へ組み立てること：
    - プロファイル；
    - 合成；
    - 順位付け；
    - 層；
    - バッジ；
    - 公開表示；または
    - 比較可能な成果物；
  - それを産出しなかった指名された経路へ効果を移すこと；または
  - 対象の効果の集合から、一般的な信頼可能性、値打ち、またはリスクを推論すること。
- **有界な例外：** 捕捉またはパターンの主張を審査する [誠実性フォーラム](core_11_forum.md#45-integrity-forums)、[第十章](core_10_a_misconduct_designation.md#chapter-ten-anti-constitutional-misconduct) の指定審査、および [§9.4](#94-anti-evasion-and-look-through-authority) の look-through は、忌避規則および [第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline) の時計のもとで、その手続についてのみ、経路横断の記録を見てよい。[第八章 §3.2](core_08_standing_assessment.md#32-related-record-cross-references) の結びついた記録のあいだの相互参照は残る；それらは記録のリンクであり、合成ではない。
- **公開 LEQU 表示：** 違反軸と貢献軸の箱は、感知者の一般的属性として公表されない。それらは記録に、フォーラム手続に、および箱がその指名された経路への適法な入力であるところでの指名された経路の門番への開示に現れる。

<a id="72-plain-statement-of-effect-and-burden"></a>
#### 7.2 効果と負担の平たい声明

*平たい言葉で言えば：誰も、軌跡効果が自分に何をするかを、その帰結から学んではならない。記録は対象に、平たい言葉で、どの指名された経路が影響を受けるか、何をしなければならないか、どれほど続くか、どこで異議を唱えるかを正確に告げなければならず、採択者は、感知者が軌跡を得点として経験しているかを測らなければならない — それがそう着地するなら、得点ではないという規則は無価値だからである。*

- **対象への平たい言葉の声明：** **効果なし**以外の最終効果が添付するとき、対象は平たい言葉の声明を受け取らなければならない。声明は [第一章 §3.4](core_01_a_values_principles.md#34-plain-language-accessibility-stewardship-duty) および **Article XX-A**（《比例的理解可能性の権利》）を満たさなければならず、次を名指さなければならない：
  - 影響を受ける各指名された経路；
  - 効果が続くあいだ対象がしてよく、してはならないこと；
  - 是正条件と再評価の点；
  - 期待される期間または審査の周期；および
  - **Article XII-B**（《異議、審査、是正への権利》）のもとでの異議の経路。
- **正直な費用：** 軌跡ロックは本物の扉を閉じ、点検可能な行為の義務はそれを担う責務ある管理者への本物の負担である。採択者は、影響を受ける感知者に軌跡を述べる材料において、軌跡が何でないかと並んで、それらの費用を平たく述べなければならない。軌跡の限度だけを述べてその重みを省くことは、[真理](core_01_a_values_principles.md#32-truth-epistemic-integrity-constraint) の欠陥である。
- **感じられる負担の測定：** 採択者は、[参加の測定ファミリー](core_05_apex_participation_leg.md#participation-measurement-family) のもとで、影響を受ける感知者が軌跡効果を、有界な指名された経路の条件としてではなく、一般的な値打ちの順位、評判得点、または永続する地位として経験しているかを測らなければならない。法的カテゴリーと生きられたものとの実質的乖離は、[第一章 §6.2.4](core_01_b_interaction_interpretation.md#624-proxy-divergence-invalidation) のもとでの [代替指標の乖離](core_05_band_oversight.md#proxy-divergence) である：文書化し、段階引き上げし、設計、開示、または [§7.1](#71-anti-aggregation-of-named-pathway-effects) の執行を通じて直さなければならず — 説明して片付けてはならない。

<a id="8-restoration-and-reassessment"></a>
### 8. 復元と再評価

*平たい言葉で言えば：永続しないロックには、本物の戻り道がなければならない。復元は自動の赦し、記録の消去、または過去の助けが検証済み危害を取り消すことではない。*

すべての非永続ロックは、審査への本物の経路を備えなければならない。復元は、完了した是正、原状回復、救済、証拠保全、保障の実施、監視、再適格、監督されたより低いリスクの奉仕、または再発リスクの他の検証済み低減を求めてよい。歴史的地位だけが、無期限の排除を正当化できない。

再評価は、記録の述べられた引き金が満たされたとき、または実質的な新しい検証済み事実が審査を求めるときに始まる。次を問う：

1. 救済と是正の義務が実際に完了したか；
2. 影響を受ける感知者と利害が実務上の是正を受けたか；
3. 再発、回避、依存、および指名された経路のリスクが実質的に減ったか；
4. 現在の能力と信頼性が適用される閾を満たし、許可を支えるか；
5. 継続する制限がなお必要で比例するか；および
6. 新たな通路が権利の床および保護される憲法上の利害と両立するか。

復元は自動の赦し、記録の消去、または貢献の相殺ではない。部分的完了は、残る保護が足りるときにのみ、より狭いロックを正当化してよい。他の点では完了した救済のあとの繰り返しは、再発持続ロックを支えてよい。フォーラム奉仕、影響を受ける側の参加、および反憲法的信頼ロックについての特別な復元規則は、本一般規則に勝る。

<a id="81-rest-state-and-archival"></a>
**休止状態とアーカイブ。** 貢献は [§6.1](#61-recency-and-currentness) のもとで現在性の半減期を持つ；違反記録も休止状態を持たなければならず、さもなくば解決済み認定が感知者を無期限に追い、[第八章 §2.1](core_08_standing_assessment.md#21-standing-records-as-the-unit-of-application) が禁じる永続する地位になる。復元が完了し、ロック、救済義務、または是正義務が開いたまま残らないなら、違反記録は活動中の統合を離れる：

- 箱 **1**、**2**、または **3** の認定は、完了した復元でアーカイブされる；
- 箱 **4**、**5**、または **6** の認定は、[§6.1](#61-recency-and-currentness) の貢献の半減期を超えてはならない公表された期間のあとアーカイブされる；
- 箱 **7**、**8**、または **9** の認定は、[§5.5](#55-special-locks) の復元規則と第十章に服しつつ、無期限に活動中のままである。

アーカイブは削除ではない。[証拠保全](core_05_band_oversight.md#evidence-preservation) は続く；アーカイブされた記録は、生きた事案における再発リスクに関わるという文書化された示しがあればフォーラムに到達可能であり；アーカイブは [第八章 §3.4](core_08_standing_assessment.md#34-versioning) のもとでの版履歴に記録される。アーカイブされた記録は指名された経路の効果を産出せず、指名された経路の門番に開示されず、能力の閾への入力ではない。ただし、特定の高敏感性の指名された経路についての公表された閾がより長い回顧を述べ、その声明自体が [必要性](core_05_band_accountability.md#necessity) および [比例性](core_05_band_accountability.md#proportionality) を満たすところを除く。

<a id="9-enforcement-realism"></a>
<a id="9-enforcement-realism-and-remedy-systems"></a>
### 9. 執行の現実性と救済システム

*平たい言葉で言えば：軌跡の帰結と是正は、本物の制度がそれらを届けられるときにのみ数える。本節はその仕組みについての憲法の床である。日常の人員、資金、滞留、および承継の規則は制度層に住む。*

第九章は、問い 3 の帰結および関連する是正が制度として本物でなければならないという憲法の床を所管する。[救済システム](core_05_band_accountability.md#remedy-system-constitutional) は、異議、受付、保全、審査、修復、監視、保障の執行、およびロックの審査を届ける耐久する能力である — 紙の経路ではない。実施の詳細は [CI-27](../../corpus_institutions/ci_27_remedy_systems_institutional_redress_capacity.md)（《救済システムと制度的是正能力》）が所管する。フォーラム監督については **Article XII-B**（《異議、審査、是正への権利》）および [第十一章](core_11_forum.md#chapter-eleven-forums-and-jurisdiction) とあわせて読め。

軌跡の統合は、帰結が紙の上にしか存在しないなら失敗する。採択者は、是正を実施し、救済に資金を付け、制限を審査し、記録を保全し、保障を執行し、費用、遅れ、国境、再編、または形式的同一性の変更を通じた逃避を防ぐ、実務的で適時な能力を維持しなければならない。

<a id="91-remediation-capacity-and-funding"></a>
#### 9.1 是正能力と資金

是正、修復、補償、監視、保障、および再発防止は、本物の次を求める：

- 制度的能力；
- 技術的能力；および
- 財政的能力。

費用、支払不能、不便、管財、解散、資産移転、または再編は、それ自体では検証済み義務を打ち負かさない。承継者、遺産、管財人、および比較可能な譲受人は、比例した義務を相続する — 責任を負う行為者が個人、制度、またはシステムであるかを問わず — より害の少ない適法な移転が示されない限り。

費用は次へ外部化してはならない：

- 影響を受ける感知者；
- 共同体；
- 生態的主体；または
- 公の救済システム

責任を負う行為者が適法にそれらを負えるところでは。

<a id="92-remedy-system-durability"></a>
#### 9.2 救済システムの耐久

フォーラム、監督団体、苦情事務所、技術審査団体、および権利に敏感な行政システムは、十分な次を持たなければならない：

- 人員；
- 資金；
- 独立性；
- 記録能力；
- アクセシビリティ；および
- 承継の計画。

能力の義務は次とともに尺度を合わせる：

- リスク；
- 事件量；
- 脆弱性；および
- 権利の敏感性。

児童保護、環境執行、給付の運営、拘束の監督、公衆衛生の応答、および比較可能な高影響システムは、適時の次ができる耐久する救済システムを求める：

- 受付；
- 保全；
- 審査；および
- 執行。

それらのシステムは [第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline) の層の里程標とパイプライン段階の窓を満たさなければならない。また [技術フォーラム領域](core_11_forum.md#42-technical-forum-domains) のもとでの公表された能力、測定、および里程標の標準を満たさなければならない。技術フォーラムはそれらの標準を定め維持する；救済システムまたは制度の指揮階層ではない。人員、資金、滞留、承継、および実績についての説明責任は、[第一次利害](core_11_forum.md#2-default-venue-and-primary-stakes) のフォーラム群に残る — 通常は [制度](core_11_forum.md#43-institutional-forums)、または捕捉、過程の失敗、もしくはシステム整合の崩壊が第一次であるところでは [誠実性](core_11_forum.md#45-integrity-forums)。救済システム能力についての制度的実施の詳細は [CI-27](../../corpus_institutions/ci_27_remedy_systems_institutional_redress_capacity.md)（《救済システムと制度的是正能力》）が所管する。

次は、予見可能に異議または救済を無効にするところで、本規則に違反する：

- 設計された滞留；
- 到達不能な受付；
- 慢性の資金不足；
- 一つの壊れやすい事務所への依存；または
- 慢性の里程標の失敗。

**誠実性**、**憲法**、または**環境**フォーラム合議体、あるいは感知性地位の裁定を聴く **技術フォーラム領域** 合議体の任命不足は、本下位節のもとでの耐久の失敗であり、[第十二章 §1.2](../../core_12_governance.md#12-eligibility-contested-selection-and-democratic-minimums) とあわせて読む。

<a id="92-remedy-parity-funding-floor"></a>
**救済パリティの資金の床。** 採択者が運用する各システムクラスについて、救済、復元、および再評価に資金を付けられた能力は、同一クラスについてのロックの運用、執行、および保障の課しに資金を付けられた能力を下回ってはならない。比は [§4.4](#44-remedy-parity-and-lock-preconditions) の連動線の数字とともに公表されなければならない。パリティから離れる採択者は、[第十二章 §3.1](../../core_12_governance.md#31-stewardship-direction) のもとで理由を記録し、記録上で、救済の開始と復元の審査がなおその層の時計を満たしていることを示さなければならない；予算パリティは発火した [§4.4](#44-remedy-parity-and-lock-preconditions) の連動線を免責せず、満たされた連動線はパリティからの静かな離脱を免責しない。あるクラスのシステムについて救済に資金を付けられない採択者は、そのクラスについてのロックの仕組みを立ててはならない。

<a id="93-cross-jurisdiction-continuity"></a>
#### 9.3 管轄を横断する継続

検証済みの救済、ロック、保障、および審査の義務は、適用される法が承認、協力、執行、または予備審査を許すところではどこでも、境界を横断して実行可能なままである。逃走、移転、フォーラム漁り、国境を越える構造、または分散した運用は、それ自体ではそれらを無効にしない。

<a id="94-anti-evasion-and-look-through-authority"></a>
#### 9.4 回避防止と look-through 権限

フォーラムと実施システムは、形式構造を見通して、機能的制御、便益、継続、および責任に届かれなければならない。再法人化、殻、契約の層化、名目上の所有移転、資産剥ぎ取り、記録の断片化、および承継者の再ラベル付けは、検証済み義務を消さない。look-through の決定は、証拠に基づき、行為者固有で、争訟可能で、比例し、審査可能なままでなければならない。

<a id="95-timely-implementation-and-reassessment"></a>
<a id="95-timely-implementation"></a>
#### 9.5 適時の実施

救済の開始、是正の里程標、ロックの審査、および再評価は、[適時性](core_05_apex_timeliness_leg.md#timeliness-constitutional)、[第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline)、および **Article XXIV-C**（《適時の解決と遅延防止の床》）を満たさなければならない。危害を積み重ね、不履行を隠し、または審査を打ち負かす遅れは、問い 3 についての新しい検証済み事実であり、元の第八章の箱を変えずに、段階引き上げされた保障を正当化してよい。

権利と軌跡の帰結は、感知者がそれらを呼び出し、検証し、実務上の修復に資金を付け、適時の審査を得、機能的に責任を負う行為者に対して義務を執行できるときにのみ本物である。

#### 10.1 非公式の生態的責務ある管理／能力許可

- **手がかり：** 検証済みの仲間相互援助の生息地復元記録が、生態的責務ある管理と勤勉の記述子を運ぶ；後に、指名された経路に範囲を限った生態的能力の閾と許可が問題になる。
- **経由：**
  - [§1](#1-immutable-chapter-eight-inputs)（*貢献軸の箱と記述子は固定のまま*）；
  - [§3](#3-descriptor-integration-and-attachment-normalization)（*記述子の取り込み*）；
  - [§6.1](#61-recency-and-currentness) および [§6.2](#62-competency-bars-and-clearances)（*現在で役割に関連する仕事は、包摂的で指名された経路に範囲を限った閾に対する許可を支えてよい*）；および
  - [第八章 §3.7 *非公式および小さな範囲の記録*](core_08_standing_assessment.md#37-informal-and-small-scope-records)（*依拠する団体が記録を検証し保つ；協同組合の成員は申立人であり、検証者ではない*）。
- **交渉不能：** 貢献軸の箱は変わらない。検証済みで現在で役割に関連する仕事が公表された閾を満たすところでは、公式の系譜は要らず、利害のない依拠団体が記録を検証したところでは、公式制度の検証は要らない。
- **深さの指針：** 同一の事実ファミリーの問い 2 の例示 — [第八章 §4.6 例 1](core_08_standing_assessment.md#46-question-2-measurement-illustrations)。

<a id="102-ecological-negligence-with-concealment"></a>
#### 10.2 隠蔽を伴う生態的過失

- **手がかり：** 固定された違反軸の記録が、生態的および過失ある不正行為を、通知のあとの検証済み隠蔽とともに重ねる。
- **経由：**
  - [§1](#1-immutable-chapter-eight-inputs)（*箱は固定のまま*）；
  - [§3](#3-descriptor-integration-and-attachment-normalization)（*記述子と添付が応答を方向づける*）；
  - [§4](#4-violation-correction-and-prevention)（*救済、是正、および予防*）；および
  - [§5.4](#54-special-violation-rules)（*過失／隠蔽がロックと保障の添付を形づくる*）。
- **交渉不能：** 隠蔽は違反軸の箱を決して動かさない。救済、監視、資源の責務ある管理の制限、および高められた検証だけを方向づけてよい。
- **深さの指針：** 同一の事実ファミリーの問い 2 の例示 — [第八章 §4.6 例 2](core_08_standing_assessment.md#46-question-2-measurement-illustrations)。

<a id="103-forum-integrity-deception-or-recusal-failure"></a>
#### 10.3 フォーラム誠実性の欺瞞または忌避の失敗

- **手がかり：** フォーラム設定における検証済みの不誠実な開示、または忌避が求められ公平性が実質的に損なわれたところでの検証済みの忌避の失敗。
- **経由：** [§5.4](#54-special-violation-rules)（*欺瞞／隠蔽の添付*）；[§5.5](#55-special-locks)（*フォーラム奉仕軌跡ロック*）。
- **交渉不能：** 検証済みの求められた忌避の失敗は、認定が第十章の指定軌道に達するかどうかを問わず、フォーラム奉仕軌跡ロックを引き起こす。

<a id="104-recurrence-after-completed-restitution"></a>
#### 10.4 完了した原状回復のあとの再発

- **手がかり：** 原状回復または比較可能な救済は完了しているが、対人暴力または比較可能なパターンについての検証済み再発リスクが生きたままである。
- **経由：**
  - [§4.1](#41-remedy-and-correction)（*救済の完了は予防義務を消さない*）；
  - [§4.2](#42-general-standing-locks)（*保護的または再発持続ロック*）；
  - [§5.2](#52-proportionality-and-calibration)；および
  - [§8](#8-restoration-and-reassessment)。
- **交渉不能：** 完了した原状回復は、検証済み再発リスクが残るあいだ、ロックの解除を求めない。継続するロックはいずれも、必要で、比例し、審査可能で、権利の床と両立したままでなければならない。

<a id="105-champion-repair-while-a-lock-remains-active"></a>
#### 10.5 ロックが活動中のあいだのチャンピオンの修復

- **手がかり：** 卓越した修復または高い貢献が結びついた貢献記録に見える一方で、軌跡ロックがなお指名された経路を遮断している。
- **経由：**
  - [§6](#6-contribution-consequences-second)（*貢献は二番目、かつロックによって遮断されていない指名された経路についてのみ*）；
  - [§8](#8-restoration-and-reassessment)；および
  - [第八章 §2.2](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge)（*非相殺の橋*）。
- **交渉不能：** 卓越した修復は復元の信用を支えてよい。軌跡ロックがなお遮断する指名された経路を開かず、影響を受ける感知者に負われる救済を買い取らない。

<a id="106-institutional-vehicle-and-successor-evasion"></a>
#### 10.6 制度の乗り物と承継者の回避

- **手がかり：** 制度が、殻、再ラベル付け、または承継の乗り物を通じてを含め、繰り返す危害、捕捉、または回避を運ぶ。
- **経由：**
  - [§5](#5-lock-design-and-enforcement)（*指名された経路のロックと制度的制限*）；
  - [§9.1](#91-remediation-capacity-and-funding)（*承継者と資金の継続*）；および
  - [§9.4](#94-anti-evasion-and-look-through-authority)。
- **交渉不能：** 行為者固有の証明はなお求められる。再ラベル付け、殻の置換、および形式的同一性の変更は、検証済み義務を打ち負かさない。帰結は、検証済み事実が支えるところでは、停止、管財、構造的分離、解散、および承継制御の制限を含んでよい。

<a id="107-misaligned-reward-retention"></a>
#### 10.7 不整合な報酬の保持

- **手がかり：** 報酬の指名された経路が憲法上不整合または濫用されているという十分な通知のあと、行為者が適時の保護された報告なしに知りつつ便益を保持する。
- **経由：** [§5.4](#54-special-violation-rules)（*不整合な報酬* — 没収、保持、指名された経路のロック、および依存当事者／第三者の依拠の会計）。
- **交渉不能：** 通知のあとの知りつつの保持は、違反の帰結を作ってよい。誠実な争いと保護された報告は保護されたままである。

<a id="108-top-slot-anti-constitutional-allegation"></a>
<a id="108-anti-constitutional-misconduct-allegation"></a>
#### 10.8 反憲法的不正行為の申立て

- **手がかり：** 適格な違反軸の箱 7–9 の記録が、通常の問い 3 の効果も負われるあいだに、ありうる反憲法的不正行為の指定を上げる。
- **経由：**
  - [§2](#2-integration-record-and-decision-order)（*処理順序の段階 8 — 第十章の入口*）；
  - [§4](#4-violation-correction-and-prevention) および [§5](#5-lock-design-and-enforcement)（*固定された記録からの通常の救済、是正、および保護ロック*）；
  - [§5.5](#55-special-locks)（*反憲法的信頼ロック*）；および
  - [第十章](core_10_a_misconduct_designation.md#chapter-ten-anti-constitutional-misconduct)（*指定のみ*）。
- **交渉不能：** 通常の第九章の救済、是正、および保護ロックは、固定された違反記録から進む。第十章は別に指定を決める。最終指定だけが反憲法的信頼ロックを引き起こす。

<a id="109-rights-floor-waiver-or-unconstitutional-contract-devices"></a>
#### 10.9 権利の床の放棄または違憲の契約装置

- **手がかり：** 固定された違反軸の記録が、通路、雇用、プラットフォーム参加、または比較可能な結びつきを、いわゆる権利の床の放棄、箝口、上書き、または違憲の契約条件 — 軌跡、監査、または争訟可能性を冷やす無効な NDA または移動制限装置を含む — に条件づけることを示す。
- **経由：**
  - [§4](#4-violation-correction-and-prevention)（*救済、是正、および予防*）；
  - [§4.2](#42-general-standing-locks)（*濫用された信頼、役割、信用、または影響の指名された経路に範囲を限った一般軌跡ロック*）；
  - [§5.1](#51-definition-and-attachment)（*添付欄*）；および
  - [§5.4](#54-special-violation-rules)（*文書が違法または違憲の遵守を求めたところでの抵抗する義務*）。
- **交渉不能：** この手がかりは [§5.5](#55-special-locks) のもとでの特別ロックを作らない。条項の無効と指定基準は [第十章 §5.2](../../core_10_b_misconduct_pattern_applications.md#52-rights-floor-waivers-and-unconstitutional-contract-terms) に残る。第九章は検証済み記録から通常の指名された経路のロックを添付する；最終指定だけが [§10.8](#108-anti-constitutional-misconduct-allegation) のもとでの反憲法的信頼ロックを引き起こす。

<a id="1010-contest-pathway-or-info-sphere-flooding"></a>
#### 10.10 争訟の経路または情報圏の氾濫

- **手がかり：** 固定された違反軸の記録が、争訟、受付、裁定、公表、または情報圏の検証の指名された経路を打ち負かし、実務上の救済を超えて遅らせ、または実質的に劣化させた、意図的、無謀、または予見可能に無関心な量、冗長、自動化、または合成交通を示す。
- **経由：**
  - [§4](#4-violation-correction-and-prevention)（*救済、是正、および予防*）；
  - [§4.2](#42-general-standing-locks)（*濫用された経路づけ、申立て、順位、通路、または影響の指名された経路についての保護的な指名された経路のロック*）；
  - [§5.1](#51-definition-and-attachment) および [§5.2](#52-proportionality-and-calibration)（*必要で、比例し、審査可能な範囲*）；および
  - [第十一章](core_11_forum.md#chapter-eleven-forums-and-jurisdiction)（*運用上の受付の選別と弄り防止 — 軌跡効果を発明しない監督*）。
- **交渉不能：** この手がかりは氾濫ロックまたは他の [§5.5](#55-special-locks) 型を作らない。指定側の基準経路づけは [第十章 §5.3](../../core_10_b_misconduct_pattern_applications.md#53-flooding-the-zone-and-contest-pathway-denial) および [§5.4](../../core_10_b_misconduct_pattern_applications.md#54-info-sphere-zone-flooding) に残る。通常の保護ロックは、指定が後に添付するかどうかを問わず、固定された記録から進む。

<a id="1011-infrastructure-denial-or-dependency-cutoff"></a>
#### 10.11 インフラの拒否または依存の切断

- **手がかり：** 固定された違反軸の記録が、生存に不可欠な通路、救済、監査、検証、または憲法上の運用インフラを実質的に使えなくした拒否、破壊、無力化、または依存の切断を示す。
- **経由：**
  - [§4](#4-violation-correction-and-prevention)（*救済、是正、および予防*）；
  - [§4.2](#42-general-standing-locks)（*保護的または通路継続の指名された経路のロック*）；
  - [§5.1](#51-definition-and-attachment)（*切断のリスクを再現するネットワークまたは制御点からの隔離を含む*）；
  - [§5.4](#54-special-violation-rules)（*検証済み危険が支えるところでだけ、強制的または自由を制限する保障*）；および
  - [§9](#9-enforcement-realism)（*救済システムの耐久と回避防止*）。
- **交渉不能：** この手がかりは [§5.5](#55-special-locks) のもとでのインフラロックを作らない。指定側の基準経路づけは [第十章 §5.9](../../core_10_b_misconduct_pattern_applications.md#59-infrastructure-denial-destruction-or-dependency-cutoff-conduct) に残る。[§5.1](#51-definition-and-attachment) のもとでのグローバルな非制限の限度はなお、ロックが消してはならない言論、請願、影響を受ける当事者としての参加、権利の床、および生存に不可欠な通路を保護する。

<a id="1012-stakeholder-participation-corruption-or-false-stake-abuse"></a>
#### 10.12 影響を受ける側の参加の腐敗または偽の利害の濫用

- **手がかり：** 固定された違反軸の記録が、すでに授権されたシステム、制度、または有界な決定領域の内部での **stakeholder-participation** の経路についての、検証済みの腐敗、捕捉、偽のまたは膨らまされた利害の主張、強制的な参加重みの抽出、拘束力ある影響を受ける側の選択における影響の買い、または比較可能な実質的濫用を示す。
- **経由：**
  - [§4](#4-violation-correction-and-prevention)（*救済、是正、および予防*）；
  - [§4.2](#42-general-standing-locks)（*指名された経路の区別 — governance-voting 対 stakeholder-participation*）；および
  - [§5.5](#55-special-locks)（*影響を受ける側の参加軌跡ロック*）。
- **交渉不能：** 影響を受ける側の参加軌跡ロックは、その検証済み引き金が満たされたときに添付する。影響を受ける領域における利害加重の影響と拘束力ある影響を受ける側の選択を限る。それ自体では **governance-voting**、**Foundational Constitutional Choice**、または [影響を受ける側](core_05_band_participation.md#stakeholder) の地位を剥ぎ取らない。**governance-voting** ロックは本ロックの代わりではない。

<a id="1013-obstruction-of-accountability"></a>
#### 10.13 説明責任の妨害

- **手がかり：** 固定された違反軸の記録が、検証済みの**説明責任の妨害**を示す — 証拠の誠実性、検証、フォーラム過程、軌跡記録、救済の時計、または争訟と是正の経路といった答える仕組みへの干渉 — 第八章の記録が **Accountability Obstruction Misconduct** を記録し、または妨害を行為の性格として重ねるところを含む。
- **経由：**
  - [§4](#4-violation-correction-and-prevention)（*救済、是正、および予防*）；
  - [§4.2](#42-general-standing-locks)（*濫用された応答義務、争訟、証拠、軌跡、または救済の指名された経路についての、指名された経路に範囲を限ったロック*）；
  - [§5.4](#54-special-violation-rules)（*隠蔽、回避、欺瞞、および義務に関連する形づくり*）；
  - [§5.5](#55-special-locks)（*フォーラム奉仕軌跡ロックは、[§10.3](#103-forum-integrity-deception-or-recusal-failure) のもとでフォーラム誠実性／求められた忌避の引き金が満たされたときにのみ*）；および
  - [§10.8](#108-anti-constitutional-misconduct-allegation)（*`s` = 7–9 であり反憲法的不正行為が実質的に申し立てられるときの第十章の入口*）。
- **交渉不能：** この手がかりは妨害ロックまたは他の [§5.5](#55-special-locks) 型を作らない。妨害の性格は違反軸の箱を決して動かさない。通常の指名された経路のロックは、どの箱でも固定された記録から進む。指定側の基準経路づけは [第十章 §5.11](../../core_10_b_misconduct_pattern_applications.md#511-obstruction-of-accountability-criteria-interaction) に残る；最終指定だけが [§10.8](#108-anti-constitutional-misconduct-allegation) のもとでの反憲法的信頼ロックを引き起こす。検証済み妨害*行為*を、構造条件としての [解決経路の捕捉](core_05_band_accountability.md#capture-of-resolution-pathways) から区別せよ。

<a id="1014-verified-cruelty-character"></a>
#### 10.14 検証済み残虐の性格

- **手がかり：** 固定された違反軸の記録が、検証済み [残虐](core_05_band_accountability.md#cruelty) の行為性格を運ぶ — それ自体を目的とする苦しみ、または必要性と比例性を超えた不当な、もしくは品位を落とす加虐 — 暴力または強制の記述子も重なるかどうかを問わず。
- **経由：**
  - [§4.1](#41-remedy-and-correction)（*救済と是正は品位を落とすものであってはならない*）；
  - [§4.2](#42-general-standing-locks)（*同一の残虐が続き、または再発することを許す指名された経路についての保護的または保障ロック*）；
  - [§4.3](#43-voluntary-public-accountability-expression)（*用いられるなら、自発的な公開表明は品位を落とすものであってはならない*）；
  - [§5.2](#52-proportionality-and-calibration)；および
  - [第八章 §4.2](core_08_standing_assessment.md#42-violation-severity-input-dimensions)（*行為性格の重ね*）。
- **交渉不能：** 残虐の性格は違反軸の箱を決して動かさない。貢献は未解決の残虐性格の予防を相殺できない。救済、制限、および自発的な公開説明責任の表明は、それ自体、苦しみを目的として加え、または不当な、もしくは品位を落とす苦しみを加えてはならない。この手がかりは残虐ロックまたは他の [§5.5](#55-special-locks) 型を作らない。
