*平たい言葉で言えば：感知者と、彼らが依存する生きたシステムを、長期にわたって動かし続けよ — 安定し、持続可能で、立ち直ることができ、生態的に健全であること — いま見かけだけ良いことではない。*

- **それが何か**
  - **範囲内：** この目的に照らしてシステムを判定すること。[憲法上の目的の分解](#continuity-aim-decomposition)に列挙された継続の構築ブロックと測定ファミリーを用いる。目的は、感知者と彼らが依存する生命を支えるシステムについての、長い時間地平の安定、持続可能性、回復力、および生態的福祉である。
  - **依存するもの：** [前文 §1](core_00_preamble.md#continuity) で名指された主題。各用語の詳細な範囲と測定の仕方の規則は、その用語自身の定義に住む；[憲法上の目的の分解](#continuity-aim-decomposition)から始めよ：
    - [責務ある管理](../../core_05_band_continuity.md#stewardship-constitutional)；
    - [自己治癒](../../core_05_band_continuity.md#self-healing-constitutional)；
    - [持続可能性](../../core_05_band_continuity.md#sustainability)；
    - [生態的誠実性](../../core_05_band_continuity.md#ecological-integrity-constitutional)；
    - [環境的前提条件](../../core_05_band_continuity.md#environmental-preconditions-constitutional)；
    - [世代間責任](../../core_05_band_continuity.md#intergenerational-responsibility-constitutional)；
    - [依存](../../core_05_band_continuity.md#dependency)；および
    - [比例的なシステム横断貢献](../../core_05_band_continuity.md#proportionate-cross-system-support-constitutional)。
  - **範囲外：** [先住民の継続](../../core_05_band_continuity.md#indigenous-continuity-constitutional) — 本文が明示的に引き入れるときを除く；葉定義の詳細、測定段階、および帯ファイルと CJS が所管する実施の仕組み。
<a id="continuity-aim-constitutional-m"></a>
<a id="continuity-aim-constitutional-a"></a>
- **測定と評価の仕方**
  - **第一次の測定：** [継続の測定ファミリー](#continuity-measurement-family) — *感知者とシステムは持ちこたえられるか — 生態的に、信頼でき、失敗を横断して。* [憲法上の目的の分解](#continuity-aim-decomposition)も見よ。この行は測定を指し示すだけである；測定の仕方の規則は、リンクされた各定義に座る。
  - **第一次の評価：** [憲法四元](core_00_preamble.md#constitutional-tetrad)のもとで、[実質的利害](core_00_preamble.md#material-stake)に応じて尺度を合わせて判定せよ。システムが、修復し、適応し、リスクに誠実に向き合い、生態的限度の内側に留まる持続する能力を保つかを問え — 今日の数字が穏やかに見えるかではない。主張された継続の成果を、[構成要素](#continuity-aim-decomposition)の条件に結びつけよ。第四章および [第一章 §11.1.5](core_01_c_stewardship_capacity_principles.md#1115-constitutional-outcome-claims-discipline)のもとで。
<a id="continuity-aim-constitutional-c"></a>
- **何が成り立たなければならないか**
  - **第一次の失敗：**
    - **継続** を用いて是正を永久に先送りすること；
    - 「安定」を、隠れたリスクの押しつけ、不可逆的危害、または生態的負担の他者への転嫁のうえに乗るときに遵守として扱うこと；
    - ありふれた「明かりを点けておく」話を用いて [争訟可能性](../../core_05_band_accountability.md#contestability) または [適時の解決](../../core_05_band_accountability.md#timely-resolution-constitutional) を阻むこと；または
    - **継続** を、[第一章 §6 過程衝突の解決](core_01_b_interaction_interpretation.md#6-process-conflict-resolution) のもとでの明確な許可なしに [繁栄](core_05_apex_flourishing_aim.md#flourishing-constitutional) を実質的に打ち負かす仕方で追うこと。

### 憲法上の目的の分解

*平たい言葉で言えば：この地図は継続の構築ブロック — 安定、持続可能性、生態的福祉、依存、およびシステム横断の支援 — と、各葉がどこに住むかを列挙する。*

この目的のもとにある定義は、明示的に狭めまたは広げない限り、その範囲を相続する。完全な主題地図：[第五章の羅針](core_05__definitions_home.md#chapter-five-compass-and-definition-map)。

**主な構築ブロック**（[前文 §1](core_00_preamble.md#continuity) で名指されたもの — 長い時間地平の安定、持続可能性、回復力、および生態的福祉）— 各用語がどこに住むか、および複数がともに適用されるときにどのクラスターを読むか：

- **安定と回復力：**
  - [責務ある管理](../../core_05_band_continuity.md#stewardship-constitutional)
  - [自己治癒](../../core_05_band_continuity.md#self-healing-constitutional)
  - [*回復力、安全、可逆性、自己治癒、連鎖的失敗、実存的リスク、環境的前提条件、および福祉*](../../core_05_band_continuity.md#resilience-safety-reversibility-self-healing-and-systemic-harm-cluster)
  - [Def.C2 *責務ある管理、統治の規律、共有システムの能力*](../../core_05_band_continuity.md#stewardship-governance-discipline-and-shared-system-capacity-cluster)

  - [持続可能性](../../core_05_band_continuity.md#sustainability)

- **生態的福祉：**
  - [生態的誠実性](../../core_05_band_continuity.md#ecological-integrity-constitutional)

*平たい言葉で言えば：これらの問いは、感知者と彼らが依存する生きたシステムが持ちこたえられるか — 生態的に、信頼でき、失敗を横断して — を問う。これは継続の測定ファミリーについての第五章の本拠である；前文 §2 は平たい言葉のカテゴリの問いを保ち、ファミリー表と定義の経路づけはここに住む。*

*実質性*（[実質性の判定](../../core_05_band_oversight.md#materiality-determination)）は統合的である — 別個の測定カテゴリではない。[実質的利害](core_00_preamble.md#material-stake)のもとでこのファミリーがどれだけ強く適用されるかの尺度を合わせる。

| 下位ファミリー | 平たい問い | 主な憲法上の用法 |
|---|---|---|
| 生態的足跡と環境的前提条件 | どのような環境負担がつくられ、または移されているか。 | [生態的足跡](../../core_05_band_continuity.md#ecological-footprint)、[環境的前提条件](../../core_05_band_continuity.md#environmental-preconditions-constitutional)；**Articles I-A** および **I-B** のもとでの開示 |
| 回復力、可逆性、およびシステム的リスク | 失敗は封じ込め、逆転し、誠実に段階を上げられるか。 | [可逆性](../../core_05_band_continuity.md#reversibility-constitutional)、[連鎖的失敗](../../core_05_band_continuity.md#cascading-failure)、[実存的リスク](../../core_05_band_continuity.md#existential-risk)、[自己治癒](../../core_05_band_continuity.md#self-healing-constitutional)；[*回復力、安全、可逆性、自己治癒、連鎖的失敗、実存的リスク、環境的前提条件、および福祉*](../../core_05_band_continuity.md#resilience-safety-reversibility-self-healing-and-systemic-harm-cluster) |
| 依存と資源の流れ | 共有された依存は可視で持続されているか。 | [依存](../../core_05_band_continuity.md#dependency)；**Article IV-A**（*依存の地図化と資源流の透明性*） |
| システム横断の支援 | 文書化されたリターンは、共有インフラと生態的修復を支えるか。 | [比例的なシステム横断貢献](../../core_05_band_continuity.md#proportionate-cross-system-support-constitutional)；**Article IV-B**（*システム横断の公正と持続可能性*） |
