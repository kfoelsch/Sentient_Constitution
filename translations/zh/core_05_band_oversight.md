<a id="oversight-independent-terms"></a>

### 监督：独立术语

<a id="adversarial-scaled-and-exploited-conditions"></a>

#### 对抗、规模化与遭利用的条件

<details>
<summary><strong><span style="color: #2563eb;">溯源</span></strong></summary>

- 一并阅读：[风险](../../core_05_band_continuity.md#risk)、[依赖](../../core_05_band_continuity.md#dependency)和[系统俘获](../../core_05_band_continuity.md#system-capture)。

</details>

<br>

*简言之：系统在压力下如何表现——有感知者操纵系统、跨账户协调、大规模运行或蓄意滥用系统时的表现。*

- **定义**
  - **范围内：**系统或行为者以最大化自身优势的方式行事，且这些行为可能改变[风险](../../core_05_band_continuity.md#risk)、[依赖](../../core_05_band_continuity.md#dependency)或[系统俘获](../../core_05_band_continuity.md#system-capture)的运行条件，包括：
    - 滥用系统结构；
    - 跨实例协调；
    - 大规模部署——其数量、并发或覆盖范围足以使行为或影响有别于小规模或理想实验室使用；
    - 重复互动；以及
    - 适应性或蓄意滥用。
  - **范围外：**普通善意使用、理想实验室测试或一次性的滥用轶事——这些情形不涉及压力、规模、跨实例协调或蓄意利用。
<a id="adversarial-scaled-and-exploited-conditions-a"></a>
- **衡量与评估方式**
  - **主要衡量：**[监督衡量族](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核验并依赖系统所呈现的内容？* 在此据此判断：面对操纵、规模化、协调和蓄意滥用时，监督是否仍然有效，而不只是在普通或理想实验室条件下有效。

    **主要评估：**结合[风险](../../core_05_band_continuity.md#risk)和[依赖](../../core_05_band_continuity.md#dependency)，纳入根据系统激励、访问权限和能力而合理可能出现的策略，涵盖：
    - 滥用；
    - 协调；
    - 规模化；以及
    - 适应性响应。
<a id="adversarial-scaled-and-exploited-conditions-c"></a>
- **必须满足的要求**
  - **主要失效：**在相关情况下未评估这些条件，即不合规；尤其是低估[风险](../../core_05_band_continuity.md#risk)或掩盖[系统俘获](../../core_05_band_continuity.md#system-capture)时。以下任一情形均不得替代对压力、规模、跨实例协调或蓄意利用的评估：
    - 普通善意使用；
    - 理想实验室测试；或
    - 一次性的滥用轶事。

<a id="capability-requirement"></a>

#### 能力要求

<details>
<summary><strong><span style="color: #2563eb;">溯源</span></strong></summary>

- 簇组成部分：[*实质影响、实质性、按分类分级的治理、监督与能力要求*](core_05_band_oversight.md#实质性影响风险与代理指标完整性)。
- 一并阅读：[实质影响](core_05_band_oversight.md#实质影响)、[透明度](core_05_band_oversight.md#透明度)和[系统边界](../../core_05_band_continuity.md#system-boundaries)。

</details>

<br>

- **定义**
  - **范围内：**系统所具备、足以实现特定结果且不取决于具体实现机制的强制功能。
  - **范围外：**并未被声称为实现特定结果所必需能力的可选功能、设想中的路线图事项或设计偏好。
<a id="capability-requirement-a"></a>
- **衡量与评估方式**
  - **主要衡量：**[监督衡量族](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核验并依赖系统所呈现的内容？* 在此据此判断：所声称的能力是否在实践中得到证明，而不只是写在设计或文档中。

    **主要评估：**根据系统实际做了什么判断能力，而不是依据：
    - 设计文档；
    - 计划；或
    - 预期行为。
    相关证明必须足够清楚，使人能够评估[透明度](core_05_band_oversight.md#透明度)，也使外部人员能够评估[实质影响](core_05_band_oversight.md#实质影响)。
<a id="capability-requirement-c"></a>
- **必须满足的要求**
  - 系统必须在可审计的[系统边界](../../core_05_band_continuity.md#system-boundaries)内，于实践中证明其能够实现所指定的结果。
  - **主要失效：**声称、记录或计划了某项能力，却未证明系统在其所陈述、获授权或被使用的条件下实现了指定结果。

<a id="classification-scaled-governance"></a>

#### 按分类分级的治理

<details>
<summary><strong><span style="color: #2563eb;">溯源</span></strong></summary>

- 上游原则：[宪法四元](../../core_00_preamble.md#constitutional-tetrad)——按[实质利害](../../core_00_preamble.md#material-stake)分级。
- 簇组成部分：[*实质影响、实质性、按分类分级的治理、监督与能力要求*](core_05_band_oversight.md#实质性影响风险与代理指标完整性)。
- 一并阅读：[依赖](../../core_05_band_continuity.md#dependency)、[实质影响](core_05_band_oversight.md#实质影响)、[风险](../../core_05_band_continuity.md#risk)、[系统边界完整性](../../core_05_band_continuity.md#system-boundary-integrity)、[领域特定实质性](core_05_band_oversight.md#领域特定实质性)及[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)。
- 下游：[第九章 §3 整系统认证评价](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评价](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)——按分类分级的整系统评价义务。

</details>

<br>

*简言之：利害越大，监督越严格——系统接受监督和核查的程度必须匹配其实际重要性，不能采用方便自己的低分类标签。*

- **定义**
  - **范围内：**[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)、核验和程序纪律必须达到的严格程度，须按[实质利害](../../core_00_preamble.md#material-stake)分级，涵盖：
    - [实质影响](core_05_band_oversight.md#实质影响)；
    - [依赖](../../core_05_band_continuity.md#dependency)；以及
    - [风险](../../core_05_band_continuity.md#risk)。
    系统依据 *[corpus_systems.md](../../corpus_systems.md)* 的 CS-3——系统分类与处理——及相关规则所确定的分类，决定监督强度。
  - **范围外：**
    - CS-3（*系统分类机制*）下真实分类相同的系统之间适用的普通统一程序细节；或
    - 由 CS-3（*系统分类机制*）负责的实现类型划分及分类指派机制——
    这些内容分别归属其自身定义；本条负责按实质利害确定监督强度，不负责分类规则本身。
<a id="classification-scaled-governance-a"></a>
- **衡量与评估方式**
  - **主要衡量：**[监督衡量族](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核验并依赖系统所呈现的内容？* 在此据此判断监督深度和核验负担是否匹配系统的真实利害、影响、依赖和风险，而非其自行指定的低分类。

    **主要评估：**依据实施规则确定真实分类，并结合[实质性](core_05_band_oversight.md#实质性)和[系统边界完整性](../../core_05_band_continuity.md#system-boundary-integrity)阅读。若系统整体影响要求更强的[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)或治理，自行指定或非正式采用低分类并不足够。依[第九章 §3 整系统认证评价](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)、[§4 涉及事项的评价](../../core_09_a_system_alignment_certification_evaluation.md#4-evaluations-where-implicated)和[§5 权利底线与领域评价](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)进行的整系统审查按分类分级：
    - **A 类、B 类和 C 类**——必须进行完整深度的评价；
    - **L 类**——必须评价，但其规模按影响确定；以及
    - **P 类**——系统有效维持 **P 类**期间，鼓励评价。
<a id="classification-scaled-governance-c"></a>
- **必须满足的要求**
  - **主要失效：**
    - 采用不区分真实利害差异的统一监督标准；
    - 分类标签低报系统的真实利害、影响、依赖或风险；
    - 系统运行或被标记的分类低于其整体影响所要求的等级；或
    - [实质影响](core_05_band_oversight.md#实质影响)、[依赖](../../core_05_band_continuity.md#dependency)或[风险](../../core_05_band_continuity.md#risk)要求更强治理时，跳过按分类产生的义务。

<a id="gate"></a>

#### 闸门

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：权利底线：**[第 XXVIII-A 条](../../core_06_rights_part_e.md#article-xxviii-a-phased-adoption-and-rights-floor-continuity)（*分阶段采纳与权利底线连续性*）**。
- 规范归属：本定义说明闸门是什么。[闸门标准](core_05_band_oversight.md#闸门标准)说明必须证明什么条件，闸门才会开启。实施细节见 **CS-10.3**（*闸门标准与推进规则*）和 **CI-14**（*过渡治理与制度演进*）。
- 配合阅读：[闸门标准](core_05_band_oversight.md#闸门标准)、[可审计性](core_05_band_oversight.md#可审计性)、[可质疑性](../../core_05_band_accountability.md#contestability)和[可逆性](../../core_05_band_continuity.md#reversibility)。

</details>

<br>

*通俗地说：闸门是过渡中的检查点。计划到此暂停，只有已公布的测试通过并经核查后才能继续。它不是日历上的一个日期。*

- **定义**
  - **适用范围：**依据**第 XXVIII-A 条**（*分阶段采纳与权利底线连续性*）制定的过渡计划中，两个阶段之间的检查点，或计划扩大采纳范围之前的检查点。在此，计划若符合[闸门标准](#闸门标准)便可推进；若不符合则须暂停。
  - **不适用范围：**
    - 不会开启或扩大宪法运行范围的一般项目里程碑；以及
    - 仅凭自由裁量作出的批准步骤，且没有已公布的待满足标准。
<a id="gate-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*

    **主要评估：**根据记录确认，计划只有在依照已公布标准作出并记录决定后才能推进；受影响者能够看到该决定、相关证据及其日期。
  - **次要衡量指标：**[闸门标准](core_05_band_oversight.md#闸门标准)、[可审计性](core_05_band_oversight.md#可审计性)和[可质疑性](../../core_05_band_accountability.md#contestability)。

    **次要评估：**评估主要追溯记录时，检验受影响的利益相关方能否质疑闸门决定，以及采纳范围是否曾在未经过闸门的情况下扩大。
<a id="gate-c"></a>
- **必须满足的条件**
  - **主要失效：**把闸门当成日期或走形式：因为时间已过、图方便或受到压力就推进，或在没有依照已公布标准作出并记录决定的情况下推进。
  - **次要失效：**未经过闸门就扩大采纳范围。

<a id="gate-criteria"></a>

#### 闸门标准

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：权利底线：**[第 XXVIII-A 条](../../core_06_rights_part_e.md#article-xxviii-a-phased-adoption-and-rights-floor-continuity)（*分阶段采纳与权利底线连续性*）**；**[第 XXVIII-B 条](../../core_06_rights_part_e.md#article-xxviii-b-transitional-authority-limits-and-reauthorization)（*过渡期权限限制与重新授权*）**。
- 规范归属：本定义说明闸门标准是什么。具体计划的标准内容由该计划依 **CS-10.3**（*闸门标准与推进规则*）和 **CI-14**（*过渡治理与制度演进*）规定，不得缩窄本定义。
- 配合阅读：[闸门](core_05_band_oversight.md#闸门)、[可审计性](core_05_band_oversight.md#可审计性)、[可质疑性](../../core_05_band_accountability.md#contestability)、[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)和[可逆性](../../core_05_band_continuity.md#reversibility)。

</details>

<br>

*通俗地说：闸门标准是过渡计划必须预先公布、之后必须凭经核查的证据实际通过的具体测试，只有通过后才能继续。标准须在结果揭晓前确定，不能事后制定。*

- **定义**
  - **适用范围：**过渡计划在阶段开始前公布的具体、可衡量条件；闸门开启前，必须以经核实的证据证明这些条件已满足。每项标准都须说明：
    - 衡量什么；
    - 门槛为何；
    - 由谁负责；以及
    - 由谁独立核验。
  - **适用范围：**标准须按实质利害的程度分级，并根据利害涵盖以下事项：
    - 关键服务的连续性及维持生存所需的服务获取；
    - 监督、审计和可质疑渠道是否准备就绪；
    - 回滚和备用方案是否可行；以及
    - **第 XXVIII-A 条**（*分阶段采纳与权利底线连续性*）规定的权利底线达成情况及执行准备里程碑。
  - **不适用范围：**
    - 无法衡量的目标或愿景；
    - 具体计划的标准内容，该内容由该计划自行规定；以及
    - 非过渡闸门决定所用的标准。
<a id="gate-criteria-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*

    **主要评估：**根据记录确认：
    - 标准在阶段开始前已经公布；
    - 每项标准都说明衡量对象、门槛、负责人和独立核验者；
    - 证据由负责人以外的独立人员核实；以及
    - 受影响的利益相关方在标准采纳前能够提出意见，之后能够看到证据和决定。
  - **次要衡量指标：**[可审计性](core_05_band_oversight.md#可审计性)、[可质疑性](../../core_05_band_accountability.md#contestability)和[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)。

    **次要评估：**评估主要追溯记录时，检验标准是否足以匹配转移事项的类别和利害程度，以及任何豁免是否经独立批准并配有有时限的补偿性控制。
<a id="gate-criteria-c"></a>
- **必须满足的条件**
  - **主要失效：**标准未公布、含糊或不可衡量；在结果已知后才设定或放宽；仅由标准负责人核验；或仅凭断言而非证据判定通过。
  - **次要失效：**豁免未经独立批准或没有有时限的补偿性控制；或标准未按转移事项的类别和利害程度分级。

- 上游：原则：[第一章 §13.1.3 比例性](../../core_01_b_interaction_interpretation.md#1313-proportionality)（*提高的门槛*）。

- 下游：[第 I-D 条](../../core_06_rights_part_a.md#article-i-d-existential-risk-and-ecological-recovery-capacity)（*生存风险与生态恢复能力*）；[第 XI-B 条](../../core_06_rights_part_b.md#article-xi-b-expression)（*表达*）；[第 XIV-C 条](../../core_06_rights_part_c.md#article-xiv-c-autonomous-lethal-systems-and-autonomous-coercion-tools)（*自主致命系统与自主胁迫工具*）；[第十二章 §3](../../core_12_a_misconduct_designation.md#3-violation-axis-s-7-9-slot-assignment-incident-gravity)（*违规轴 s = 7–9：反宪法指定*）；[第十七章 §1](../../core_17_amendment_ratification.md#1-heightened-review-for-rights-affecting-changes)（*影响权利的变更之加强审查*）。

</details>

<br>

*通俗地说：有些决定风险太高，普通检查并不足够。加强审查要求更严格：提出推进的一方必须证明理由成立，确实评估过更安全的方案，而且外部人士能够看见并质疑其推理。最高级审查是最严格的检查，只用于少数错误决定会造成最大损害的情形。*

- **定义**
  - **适用范围——加强审查：**凡本宪法条款要求加强审查、加强宪法审查或强化审查时，适用的更严格审查标准。依此标准：
    - 提出采取行动、继续行动或扩大行动的一方负有证明要求均已满足的举证责任；
    - [必要性](../../core_05_band_accountability.md#necessity)和[比例性](../../core_05_band_accountability.md#proportionality)须按更严格标准适用——必须真正考虑能够实现活动正当目的且在实质上更安全的替代方案，任何限制都须针对所要处理的伤害作严格限缩；
    - 审查须独立于行动方，决定及其理由须公开，并可依据[可质疑性](../../core_05_band_accountability.md#contestability)提出异议；以及
    - 记录须公开说明不确定性、假设、证据局限和意见分歧。
    <a id="highest-scrutiny"></a>
  - **适用范围——最高级审查：**同一标准中最严格的层级，仅在条款明确规定时适用——包括依[第 I-D 条](../../core_06_rights_part_a.md#article-i-d-existential-risk-and-ecological-recovery-capacity)（*生存风险与生态恢复能力*）涉及可信因果路径、可能导致生存风险或生态恢复能力不可逆丧失的情形；依[第 XI-B 条](../../core_06_rights_part_b.md#article-xi-b-expression)（*表达*）对表达内容作限制的情形；以及依[第十二章 §3](../../core_12_a_misconduct_designation.md#3-violation-axis-s-7-9-slot-assignment-incident-gravity)（*违规轴 s = 7–9：反宪法指定*）作出最终反宪法不当行为指定的情形。除加强审查的一切要求外，还须满足：
    - 在清楚且经核实的证据证明每项必要要素之前，受审查行为推定为不合规；
    - 未解决的疑问、缺失的证据或未经检验的假设均须对受审查行为不利；以及
    - 审查者在职能上必须独立于原决定及任何从该决定中获益者。
  - **不适用范围：**
    - 一般的[必要性](../../core_05_band_accountability.md#necessity)和[比例性](../../core_05_band_accountability.md#proportionality)审查；没有加强审查触发条件时，这些标准仍普遍适用；
    - 触发条件本身；该条件由援引此标准的条款规定；
    - 依[第一章 §15.4.3 纳入层](../../core_01_b_interaction_interpretation.md#1543-incorporation-layer)，在纳入文本之间作选择时适用的[最大保护效力](../../core_05_band_integrative.md#fullest-protective-effect)规则；以及
    - “加强”一词的其他用法，即指更强的保障、权重、优先级或控制，而非审查标准（例如第十章的加强保障或栖息地的提高优先级）。
<a id="heightened-scrutiny-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此用它检验更严格的审查是否真正进行且可供外部核查，而非仅仅宣布进行过。

    **主要评估：**根据记录确认举证责任由行动方承担，替代方案分析确实进行，审查保持独立，理由、不确定性和意见分歧均以他人能够提出异议的形式公开。对于最高级审查，还须确认每项必要要素都有清楚且经核实的证据支持，并且未解决的疑问均对受审查行为不利。
  - **次要衡量指标：**[必要性](../../core_05_band_accountability.md#necessity)、[比例性](../../core_05_band_accountability.md#proportionality)和[可质疑性](../../core_05_band_accountability.md#contestability)。

    **次要评估：**按本条要求的更严格标准阅读这些共同衡量指标。通过一般审查不代表通过加强或最高级审查。
<a id="heightened-scrutiny-c"></a>
- **必须满足的条件**
  - **主要失效：**条款要求加强或最高级审查时，若出现下列情况，即属不合规：
    - 将举证责任转嫁给受影响者；
    - 以核对清单、纸面上有利的成本效益估算或短期收益代替完整审查；
    - 省略独立审查、理由公开或真正提出异议的机会；或
    - 对于最高级审查，依据未经核实的证据继续行动，或将疑问解释为有利于受审查行为。
  - **次要失效：**把一般必要性或比例性审查通过，当作符合加强审查标准。

<a id="press-and-journalistic-activity-constitutional"></a>

#### 新闻媒体与新闻活动

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 集群组成部分：[信息领域、表达、新闻媒体与新闻活动及善意（按发布范围适用的完整性）](../../core_05_band_participation.md#info-sphere)

</details>

<br>

*通俗地说：新闻工作是有感知者实际从事的活动——采集新闻、保护消息来源、调查和发布——而不是徽章、头衔或记者证。意图压制这些活动的行为须接受加强审查。*

- **定义**
  - **适用范围：**实质上发挥新闻功能的新闻活动，依据有感知者实际做了什么判断，而非其资历或机构身份；包括：
    - 新闻采集；
    - 消息来源保护；
    - 调查；以及
    - 发布。
    从事这些工作的有感知者行使[表达](../../core_05_band_participation.md#expression)与[集会](../../core_05_band_participation.md#assembly)权利底线，并依据[第 XI-C 条](../../core_06_rights_part_b.md#article-xi-c-press-and-journalistic-activity)（*新闻媒体与新闻活动*）受到[加强审查](core_05_band_oversight.md#加强审查)保护，免受国家和运营者意图损害该活动的行为侵害。
  - **不适用范围：**记者证、机构头衔，或不属于新闻采集、调查或具有新闻功能之发布的一般商业言论。
<a id="press-and-journalistic-activity-constitutional-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此用它检验新闻功能及针对新闻媒体的损害是否清晰可见且可供质疑，而非被资历、头衔或机构身份掩盖。

    **主要评估：**不看某人持有什么徽章、头衔、组织形式或机构身份，而是判断活动实际做了什么，是否涉及：
    - 新闻采集；
    - 消息来源保护；
    - 调查；或
    - 服务于信息环境的发布。
    按实际效果识别损害新闻媒体的行为，并依据**第 XIV-A 条**（*安全、情报与秘密权力限制*）和**第 XI-C 条**（*新闻媒体与新闻活动*）将针对新闻媒体的性质视为加重因素。对[必要性](../../core_05_band_accountability.md#necessity)和[比例性](../../core_05_band_accountability.md#proportionality)适用加强审查，任何限制均须严格限缩。
<a id="press-and-journalistic-activity-constitutional-c"></a>
- **必须满足的条件**
  - **主要失效：**国家或运营者意图损害新闻活动，却未通过加强审查的限制分析；
  - **次要失效：**扩张适用[善意](../../core_05_band_accountability.md#good-faith)或**第 IX-C 条**（*真实发布与高影响发布限制*），以致这些标准阻止合法的批判性报道、调查性发布或异议；
  - **第三层失效：**在没有任何发挥新闻功能的新闻采集、调查或发布活动时，以记者证、机构身份或一般商业言论作为判断新闻活动的标准。

### 监督：半独立术语

<a id="materiality-semi-independent"></a>

<a id="materiality-impact-risk-and-proxy-integrity"></a>
#### 实质性、影响、风险与代理指标完整性

**半独立语境**（组成定义仍可在联合触发范围之外适用）：

- **联合触发：**实质性分类、实质影响或风险、代理指标完整性，或受保护条件的实质退化具有实质意义时。
- **范围：**符合联合触发条件时，监督部分负责回答两个问题：影响何时重要到足以产生宪法意义，以及指标是否仍反映现实？评估必须依据真实影响，而非可操纵的代理指标。

**主题组成员。**本组包括：
- [实质](core_05_band_oversight.md#实质)——影响是否大到具有宪法意义。
- [实质性](core_05_band_oversight.md#实质性)——针对系统或事件作出该分类的方法。
- [领域特定实质性](core_05_band_oversight.md#领域特定实质性)——九个领域各自的界线；据此判断某项行为是否具有实质性，以及某个实体是否需要系统章程或机构章程。
- [实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)——禁止通过操纵边界缩小问题全貌。
- [实质影响](core_05_band_oversight.md#实质影响)——影响范围多广、规模多大、程度多严重。
- [实质风险](core_05_band_oversight.md#实质风险)——伤害发生的可能性、速度及其可逆程度。
- [不确定情形下的实质性](core_05_band_oversight.md#不确定情形下的实质性)——答案不明时以审慎为默认。
- [代理指标偏离](core_05_band_oversight.md#代理指标偏离)——指出指标不再符合现实的情形，包括状况恶化而分数被人为做高。
- [实质退化](core_05_band_oversight.md#实质退化)——受保护条件真实下降，例如安全、认识完整性或有意义的能动性下降。

<a id="materiality-operator-phrases"></a>

**操作用语**（全语料阅读辅助，由[实质性](core_05_band_oversight.md#实质性)规范）：

- <a id="materially-implicated"></a>**受到实质牵涉**——由于利害具有实质性，本案涉及这项义务、衡量指标或主题。
- <a id="materially-misaligned"></a>**实质性失准**／**宪法失准**——行为或结构在实质规模上偏离宪法要求。

受到牵涉不必然意味着失准。失准则必然意味着受到实质牵涉。

*衡量（体系路由）：*依监督衡量体系进行衡量。各项具体指标见下列成员定义。

<a id="materiality"></a>
#### 实质性

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：整合性实质性（[实质性](core_05_band_oversight.md#实质性)）（*作为宪法衡量的实质性*）；原则：[实质利害](../../core_00_preamble.md#material-stake)分级代理指标；第一章在**安全**（**第一章 §15.1**）、**真相**（**第一章 §15.2**）、**信任**（**§12**）、**§12**的守护与开放条文、**§13.1**、**§13.2**以及**第一章 §13.3.2**（**实质性**出现在 D/A/C 组件中）多处援引本定义——主要系统评估依据见[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)。
- 集群组成部分：[依赖集群：*实质影响、实质性、按分类分级的治理、监督与能力要求*](core_05_band_oversight.md#实质性影响风险与代理指标完整性)。
- 配合阅读：[实质影响](core_05_band_oversight.md#实质影响)、[实质风险](core_05_band_oversight.md#实质风险)、[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、[领域特定实质性](core_05_band_oversight.md#领域特定实质性)和[可审计性](core_05_band_oversight.md#可审计性)。

</details>

<br>

*通俗地说：实质性是影响或风险达到足够利害程度、从而改变适用义务的门槛。本条说明如何针对系统或事件作出判断：观察彼此关联的整体，而非孤立部分，并计入预期伤害，而不只计算已经发生的伤害。某项义务是否适用于某行为或实体、逐个领域判断，是[领域特定实质性](core_05_band_oversight.md#领域特定实质性)回答的另一问题；本条随后按利害程度调整确实适用的义务。*

- **定义**
  - **适用范围：**分类决定须判断[实质影响](core_05_band_oversight.md#实质影响)或[实质风险](core_05_band_oversight.md#实质风险)对下列对象是否具有宪法上的实质性：
    - 系统（包括[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)）；或
    - 事件、事故或事态（包括依[实质风险](core_05_band_oversight.md#实质风险)判断的预期[伤害](../../core_05_band_accountability.md#harm)），
    并须观察彼此关联的整体，而非孤立部分。
  - **不适用范围：**
    - 没有改变按利害程度分级义务的[实质](core_05_band_oversight.md#实质)门槛琐事、表面修饰或纯粹文书意义；或
    - 仍依据[实质影响](core_05_band_oversight.md#实质影响)和[实质风险](core_05_band_oversight.md#实质风险)评估关联整体的一般分类分歧——这些问题归其各自规范处理，或仍属一般分歧，不能取代实质性认定。
<a id="materiality-determination-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**依照[实质利害](../../core_00_preamble.md#material-stake)，判断在观察相关系统或事件的关联整体时，影响是否足以改变适用义务，包括：
    - [实质影响](core_05_band_oversight.md#实质影响)；
    - [实质风险](core_05_band_oversight.md#实质风险)（包括预期[伤害](../../core_05_band_accountability.md#harm)）；以及
    - [系统性实质性](../../core_05_band_continuity.md#systemic-materiality)（存在全系统影响时）。

    **主要评估：**计入本案涉及的一切影响类型，包括：
    - 已发生的影响；
    - 预期伤害；以及
    - 相关时的[系统性实质性]，
    并解释针对关联整体而非方便选取的一部分所得的结论。

    对于事件，须判断其是否与有感知者的[福祉](../../core_05_band_continuity.md#wellbeing)相关，包括对该福祉可能造成的预期伤害，而不能只看：
    - 系统指标；
    - 流程标签；或
    - 机构便利。
  - **次要衡量指标：**[依赖关系](../../core_05_band_continuity.md#dependency)——检验某事之所以被称作“不具实质性”，是否仅因各部分被分别评估，而关联整体实际上会被判定为实质。事件影响有感知者时，须计入依赖关系所传导的下游影响，而非只看对该有感知者的直接冲击。

    **次要评估：**核对主要结论时，判断合并观察各部分而非逐一观察，是否会改变分类，包括：
    - 孤立；
    - 汇总；
    - 依赖关系；以及
    - 对事件而言，对依赖受影响有感知者或受事件干扰事项的其他有感知者或系统造成的下游影响。
  - **第三层衡量指标：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)和[实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)——用于边界操纵、规避汇总或代理指标妨碍诚实的实质性分析之处。

    **第三层评估：**若运营者依赖：
    - 边界；
    - 代理指标；或
    - 非正式的低分类，
    则适用[实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)和[代理指标偏离](core_05_band_oversight.md#代理指标偏离)，将真实的实质性分析与结构性操纵或分数造假区分开来。
<a id="materiality-determination-c"></a>
- **必须满足的条件**
  - 只有将分类记录在案、做到[可审计](core_05_band_oversight.md#可审计性)，并以真正具有宪法意义的影响为依据，实质性认定才成立。
  - **主要失效：**
    - 只有纸面意义或不具实质性的标签，对相关系统或事件适用的宪法义务——治理、监督、能力要求或其他按利害分级的义务——没有造成实际变化；
    - 遗漏实质影响类型的认定，包括事件的预期伤害，或事件是否与有感知者的[福祉](../../core_05_band_continuity.md#wellbeing)相关；或
    - 缺乏正当理由支持结论的认定。
  - **次要失效：**通过以下方式将合并后具有实质性的影响称为不具实质性：
    - 拆分影响；
    - 规避汇总；或
    - 忽略依赖关系。
  - **第三层失效：**认定依据被操纵的边界或“指标看起来正常”，而[实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)或[代理指标偏离](core_05_band_oversight.md#代理指标偏离)已可合理观察到。

*通俗地说：九个领域问题用于判断某项行为是否具有实质性，以及运营方是否必须发布系统章程或机构章程。每个问题都适用于运营方的活动；义务强度按实质利害调整。*

- **定义**
  - **适用范围：**清单的两种用途；两者都判断义务是否适用。一旦义务适用，其强度仍依[实质利害](../../core_00_preamble.md#material-stake)，按照[实质性](core_05_band_oversight.md#实质性)调整。
    - **行为测试：这项行为具有实质性吗？**对于正式行为，清单提供[具有实质约束力的行为](../../core_05_band_accountability.md#materially-binding-act)所需的“实质性”部分：他人必须遵循或可以视为已定而加以依赖的行为，且其影响符合任何领域的“何时具有实质性”测试，即构成具有实质约束力的行为，须设置四个席位并建立行为记录。若某项行为在九个领域均不具实质性，则无论如何贴标签，它都不是具有实质约束力的行为。对于非正式行为的活动，例如经营服务、保管记录或在生态系统中开展工作，清单判断该活动是否具有实质性，进而判断哪些规范主体的义务适用。权限问题针对行为；其余大多数问题主要针对持续活动。
    - **实体测试：该实体是否需要系统章程或机构章程？**实体以自身名义采取某项行为，或安排他人采取该行为时，该行为或活动即视为实体自身的行为或活动。若实体自身所做之事在九个领域中的任何一个具有实质性，且影响超出其自身家庭或界限严密的私人圈子，则该实体至少属于 L 类（L 类指地方性、影响有限的实体），必须发布系统章程或机构章程。[第七章 §3 何时需要系统章程和机构章程](../../core_07_charters.md#3-when-system-and-institutional-charters-are-required)规定此规则，**CS-3**（*系统分类机制*）定义各类别。所有领域均未达到界线的实体保留为 P 类，可自愿发布系统章程或机构章程。单个成员独自行动，不会使整个实体纳入适用范围。
  - <a id="domain-specific-materiality-private-unit"></a>**适用范围：**本条及 **CS-3**（*系统分类机制*）中“私人单元”的含义：单个有感知者、一个家庭，或界限严密且所有成员均自愿加入的私人圈子；其行为和影响都仅限于成员之内。影响到他人或受到他人依赖的事项超出私人单元。向他人开放的一般社区活动不属于私人单元；九项问题仍适用于这些活动。
  - **适用范围：**行为测试对小型企业的适用方式；小型企业指由一名或少数有感知者经营的企业。除非某项行为越过界线，否则企业可自行决定自身事务，无需设置席位。
    - **企业自己的决定：**企业生产或销售什么、一般交易范围内的价格、聘用对象、营业时间以及采购对象，在企业不能左右市场条件且交易对象可以退出时，均不构成具有实质约束力的行为。只有在九个领域至少一个具有实质性的行为才须设置席位，日常决定不逐项拆分。
    - **一次制定的政策：**重复适用的涵盖性决定，例如退款规则、租赁规则或预约政策，在企业发布或更改该政策时，作为一项具有实质约束力的行为记录一次。将已公布政策用于个案，是执行既有记录行为的文书步骤，除非偏离政策或改变其效果，否则无需另设席位。
    - **日常选择的限额：**采纳文书可公布预先授权的日常选择限额，例如支出或招聘限额，使企业不必为每项选择另行接受审查。限额不得高于九项问题所隐含的程度，应当公布并接受审查，且不能改变界线。核心条文不设数值。
    - **共同设置席位：**小型企业确实作出涵盖行为时，可依[第八章 §6 按比例缩放与合并承载](../../core_08_functional_independence_segregation_of_duties.md#6-proportional-scaling-and-merged-hosting)（*共同持有席位*），将其他席位交由当地群体承载。
  - **适用范围：**九项问题，用以判断某项行为或实体的持续活动是否具有实质性。每项问题都划出一条界线。超过界线，该活动具有实质性，该领域的义务即适用；低于界线，该活动不具实质性，但所有宪法约束仍然适用（见“必须满足的条件”中的“无许可制度”规则）。每项问题均说明超过界线的测试、低于界线的情形，以及相关义务由何处规定。
    - <a id="domain-specific-materiality-survival"></a>**生存与基本服务获取。***若该实体停止运作，他人会失去维持生存所需的东西吗？*
      - 具有实质性时：实体提供、控制或能够切断食物、水、住所、能源、医疗保健或安全通行，而依赖者无法及时获得替代来源。
      - 不具实质性时：分享的是他人可轻易从别处获得的东西。
      - 规范主体：**第 I 条**（*环境生存*）和**第 III 条**（*生存与基本服务获取*）。
    - <a id="domain-specific-materiality-safety"></a>**安全。***活动可能伤害未选择承担该风险且无法退出的人吗？*
      - 具有实质性时：活动对未明知接受风险且无法自由退出的有感知者，造成可信因果路径（从实体行为到伤害之间可信且可追溯的路径），可能导致身体或心理[伤害](../../core_05_band_accountability.md#harm)。典型情形包括照护依赖者、可能造成伤害的产品和服务、危险材料和车辆、作为医疗或心理照护提供的建议，以及实体所指挥人员的工作条件。
      - 不具实质性时：成年人明知且自愿接受、可以自由退出，且属于日常生活本来就存在的风险。
      - 规范主体：[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、**第 III-D 条**（*安全工作条件*）、**第 VII 条**（*自我所有权*）和**第 VIII 条**（*家庭、照护与发展中的有感知者*）。
    - <a id="domain-specific-materiality-authority"></a>**对他人的权限。***实体是否作出他人必须遵循或可视为最终决定、并会改变他人可获得或可做事项的决定？*
      - 具有实质性时：实体作出正式行为，他人必须遵循或可以视为已定而加以依赖，且该行为影响其获取生存必需品、教育、安全、生计、权利或地位（此类行为即为[具有实质约束力的行为](../../core_05_band_accountability.md#materially-binding-act)，其是否具有实质性依据本清单判断，不会反过来影响清单）；或实体排斥、惩戒或除名成员，对上述任何事项造成实质影响。
      - 不具实质性时：提供任何人都无须接受且不会阻止他人获取资源的援助、商品、劳务或服务；私人单元内部的选择；以及不约束任何人的草案、建议和邀请。
      - 规范主体：**第 VI 条**（*平等基本权利*）、**第 X 条**（*自决、能动性与参与*）、**第 XII 条**（*利益相关方参与、代表与正当程序*）以及第八章。
    - <a id="domain-specific-materiality-livelihood"></a>**生计与经济条件。***他人是否依赖该实体取得收入，或依赖其价格和条件获得必需品？*
      - 具有实质性时：实体是他人的主要收入来源（作为雇主、付款方、买方或平台），为他人所需且难以替代的东西制定价格或条件，或拥有[第一章 §11 市场结构](../../core_01_a_values_principles.md#11-market-structure)所述的市场力量。
      - 不具实质性时：可自由退出者之间的偶发交易，以及实体无法左右市场条件的一般贸易。
      - 规范主体：**第 III-C 条**（*劳动与经济底线*）和**第 V 条**（*资源分配、依赖关系与生态系统资金*）。
    - <a id="domain-specific-materiality-custody"></a>**保管。***实体是否保管对他人重要的事物，而他人依赖实体保障这些事物的安全？*
      - 具有实质性时：实体保管资金、资产、凭证、密钥，或关于其他有感知者的记录与数据；其范围超出成员为实体自身工作所投入的部分，且他人依赖实体维持这些事物的安全、准确或可用；或实体保管[地位记录](../../core_05_band_accountability.md#standing-record)，或担任论坛、认证机构或记录机关。非成员的个人数据或敏感数据亦计入。
      - 不具实质性时：成员共同筹集并用于群体自身材料的资金，以及经成员知情、为发送群体通知而保留的联系人名单。
      - 规范主体：**第 II-E 条**（*数据处理与网络依赖*）、**第 IX 条**（*肖像、体验数据与发布权*）、**第 XVI 条**（*审计、透明度与独立核验*）以及[第十章 §3.7 记录保管与开启权限](../../core_10_standing_assessment.md#37-record-custody-and-opening-authority)。
    - <a id="domain-specific-materiality-information"></a>**信息与真相。***他人是否会把实体所说的内容当成真相，并据此决定安全、金钱、健康、权利或地位事项？*
      - 具有实质性时：实体陈述、发布、评级或认证某事项，而他人可预见地会将其视为真实内容，作为上述决定的依据，且传播范围超出了解消息来源的人；或实体运营[信息领域](../../core_05_band_participation.md#info-sphere)基础设施，例如平台、索引或评级系统，供他人查找或判断信息。
      - 不具实质性时：明确作为意见、艺术、个人叙述或通信呈现的内容，以及在知晓消息来源者之间准确分享信息。
      - 规范主体：[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)、**第 IX-C 条**（*真实发布与高影响发布限制*）、**第 XIII-C 条**（*禁止虚假信任与误导性依赖*）和**第 XV 条**（*信息领域完整性*）。
    - <a id="domain-specific-materiality-dependence"></a>**依赖关系与退出。***若他人离开、替换该实体，或该实体失灵，他们会失去实际重要的东西吗？*
      - 具有实质性时：他人已开始依赖该实体，以致拒绝、替换或离开该实体会使他们遭受实质损失（获取机会、数据、收入、社群，或难以恢复的时间）；或该实体失灵或退出会影响其他人（[依赖关系](../../core_05_band_continuity.md#dependency)、[级联失效](../../core_05_band_continuity.md#cascading-failure)）。
      - 不具实质性时：他人可放弃而不致遭受实质损失的依赖关系。
      - 规范主体：**第 V-A 条**（*依赖关系图谱与资源流透明度*）、**第 XXI 条**（*互操作性、可携性与退出完整性*）和**第 II-F 条**（*连续性与运营者停运*）。
    - <a id="domain-specific-materiality-ecology"></a>**生态。***若活动今天停止，生态系统能否自行恢复？反过来说：该实体是否在帮助某个地区恢复？*
      - 具有实质性时：活动损害[生态恢复能力](../../core_05_band_continuity.md#ecological-recovery-capacity)。符合以下任一测试即足够：
        - 在该类生态系统规定的期限内，生态系统无法在没有协助的情况下恢复原有功能；
        - 根据该类生态系统的最佳可用证据，活动使生物多样性、土壤、水、气候稳定性或栖息地连通性可衡量地接近临界点（超过该水平后生态系统无法自行恢复其功能）；或
        - 对可再生存量的消耗速度超过其再生速度。
      - 始终适用：依**第 I-D 条**（*生存风险与生态恢复能力*），任何规模下，凡存在可信因果路径可能导致恢复能力不可逆丧失的情形，均受涵盖，不受上述测试答案影响。
      - 不具实质性时：使用量未超过生态系统的再生能力。除非已知系统承受压力，或物种、栖息地受到威胁，否则一般家庭与社区活动预期应处于生态恢复能力范围内。[生态足迹](../../core_05_band_continuity.md#ecological-footprint)是一项披露指标，不决定此处界线。
      - 帮助地区恢复：积极修复生态系统的工作，例如重新种植、栖息地或溪流修复、清除入侵物种、重建土壤或清理污染，不属于损害，也不会仅因该项问题使实体具有实质性。在生态系统可承受范围内进行时，这属于一般社区活动。只有在以下情形下才具有实质性：
        - 修复工作本身符合上述三项测试之一（例如引入会扩散的物种，或改变水流并损害下游地区）；或
        - 跨越另一领域的界线（例如保管他人依赖的土地或资金，或发布他人会依赖的恢复成效声明）。
      - 将恢复工作作为贡献：依据[第十章 §4.3 贡献路径描述目录与衡量角色](../../core_10_standing_assessment.md#43-contribution-route-descriptor-catalog-and-measurement-roles)，恢复工作获认可为生态守护；每位成员都可作为个人申请人申请记录，无需系统章程或机构章程（[第十章 §3.7 记录保管与开启权限](../../core_10_standing_assessment.md#37-record-custody-and-opening-authority)）。
      - 规范主体：**第 I-A 条**（*环境前提与生态完整性*）和**第 I-D 条**（*生存风险与生态恢复能力*）。
    - <a id="domain-specific-materiality-systemic"></a>**系统性与不可逆影响。***该活动能否单独或与其他活动共同集中权力、攫取共享资源、传播失效，或锁定不可撤销的状态？*
      - 具有实质性时：实体的活动单独进行、与受共同控制的其他实体共同进行，或在同一共享系统中进行时，可能集中权力或攫取共享功能、引发跨系统级联，或锁定实际上无法逆转的状态；或该活动造成可信因果路径，可能导致[生存风险](../../core_05_band_continuity.md#existential-risk)。
      - 不具实质性时：影响局部、有限且可逆。
      - 规范主体：[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、**第 XII-D 条**（*防止攫取的保障*）、**第 XVII 条**（*系统生命周期、环境与可逆性*）和**第 I-D 条**（*生存风险与生态恢复能力*）。
  - **不适用范围：**
    - 按实质利害调整义务强度；该事项由[实质性](core_05_band_oversight.md#实质性)规定。
    - 义务本身；由上述规范主体规定。
    - 贡献：哪些工作算作贡献以及程度如何，由第十章规定，不取决于本条认定。
    - 任何批准或许可：领域特定实质性认定只为适用义务对实体分类，不授予任何权限。
<a id="domain-specific-materiality-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此用它判断九个领域中的答案，是否依据实体实际开展、决定、保管和影响的事项，并以书面理由记录，供他人核查。

    **主要评估：**逐一检视九项问题。每项都判断行为或活动是否符合“何时具有实质性”测试。根据实体实际开展、决定、保管和影响的事项判断，而非看标签、规模或法律形式。逐领域记录答案和理由。任何一项答是，该行为或活动即具有实质性。若问题是实体是否需要系统章程或机构章程，则将问题应用于实体以自身身份开展的一切活动；任何一项答是，该实体即纳入适用范围。若实体显然未跨越任何界线，则由实体自行撰写一份简短声明，说明所有领域均低于界线并陈述理由，即已足够。

    按照以下规则一并应用九项问题：
    - **任何一项答是即足够：**任何一项问题答是，实体即纳入适用范围。一个领域答否不能抵消另一个领域答是。
    - **关联运营方合并计算：**将实际构成同一运营事项的运营方活动合并计算。适用于两种情形：
      - **由同一权力中心运营的运营方：**同一有感知者、机关或运营方能够指挥或推翻各运营方的做法（提供什么、提供给谁、按什么条件提供，或是否继续），或各运营方作为同一服务的一部分开展相同活动时，即构成同一运营事项。本测试借鉴[实质控制界线](../../core_05_band_accountability.md#material-control-line)中的共同实际控制概念，但这是独立测试，针对运营方的活动，而非同一行为中各席位的独立性。仅有资金支持、共用场所或供应商、成员重叠，以及共同专业实践中采用同一承载者的文书（**CI-4.7**（*执业许可、执业审查与共同专业实践*））均不使运营方构成同一运营事项。只有资助使资助者有权指挥或推翻有关活动时，资助者才属于该运营事项；以及
      - **对承压共享系统施加压力的运营方：**许多运营方共同使用或加重同一条河流、市场或网络的负荷，且该系统已经承压时，应按每个运营方对总压力的增量判断，而非孤立评估。造成有意义增量的运营方具有实质性；只造成微不足道增量的运营方则不具实质性，即使整个系统已超过界线亦然。

      为了低于界线而拆分实体，属于[实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)所禁止的边界操纵。
    - **对弱势者降低界线：**受影响者处于发展阶段、依赖他人，或无法保护自己或退出时，各界线均应降低。
    - **对无法撤销的伤害降低界线：**若影响无法撤销（[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)），只要存在可信的致害路径即足够，无须证明其很可能发生。
    - **一般社区活动属于预期情形，实体须作出说明：**给予、制作、教学、照护、接待和分享通常低于所有界线，除非符合某一领域自身的测试。与任何申请人一样，声称低于所有界线的实体负有说明责任（[第四章 §1 专属执行与举证责任分配](../../core_04_burden_traceability_verification.md#1-exclusive-enforcement-and-burden-allocation)）。对于一般社区活动，主要评估中的简短书面声明即为该说明。质疑该声明者必须指出某个领域中的具体越界情形，之后实体须说明为何仍低于该界线。领域“何时具有实质性”测试列出的每种情形，例如安全领域中的依赖者照护，都是明确的越界事项：质疑者若证明实体从事其中一项，即已指出该事项。规模、人数、定期聚会，以及受服务者对实体的重视，均不构成越界。若实体作出说明后某项明确越界事项仍存疑，则适用[不确定情形下的实质性](core_05_band_oversight.md#不确定情形下的实质性)。依其他规则推定具有实质性的某些活动，例如安排面对面个人服务或运营活动市场（**CS-3**（*系统分类机制*）§6.2（*一般适用示例*）），其说明须回应该推定。低于界线只表示实体无需系统章程或机构章程，也不承担额外义务；这并不决定贡献的界线：无论在此是否具有实质性，给予、制作、教学、照护、接待和分享都可获认可为贡献（[第十章 §4.1 贡献规模输入维度](../../core_10_standing_assessment.md#41-contribution-magnitude-input-dimensions)）。
    - **核心条文不设数值；采纳者的数值仅供参考：**采纳文书可公布指引数值，说明界线所在，例如保管资金上限或某类生态系统的恢复期限。每个数值均须连同理由发布。数值只能重述领域问题对该类活动的含义，绝不能设得高于该含义。实体一旦符合“何时具有实质性”测试，无论数值为何都已超过界线。数值是说明中的证据，而非说明的替代品；不得用来移动界线或决定质疑结果。
  - **次要衡量指标：**[实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)和[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)——检验“低于界线”的答案是否仅因活动被拆分到多个实体，或未结合其施加压力的共享系统进行判断才成立。

    **次要评估：**判断将受共同控制实体的活动合并计算，并计入同一共享系统中的其他实体后，同一活动是否会跨越界线。
<a id="domain-specific-materiality-c"></a>
- **必须满足的条件**
  - **无许可制度：**超过界线即开始承担相应义务，但绝不构成组建或运营实体的门槛；**第 XI-E 条**（*机构组建与企业创设*）规定的狭义限制除外。低于界线不免除实体任何[宪法约束](../../core_05_band_integrative.md#constitutional-constraint)。安全、真相和权利底线——包括**第 I-A 条**（*环境前提与生态完整性*）及**第 I-D 条**（*生存风险与生态恢复能力*）的环境保护——均完整约束该实体。
  - **质疑途径：**依据此清单作出的认定，应通过原有途径提出质疑；本条不增设机关、论坛或费用。系统适用[§7.4 质疑系统分类记录](../../corpus_systems/cs_03_a_system_classification_machinery.md#74-challenge-and-contestability)。机构适用[第九章 D 部分 §14.2 重新开启触发条件](../../core_09_d_institutional_alignment_certification.md#142-reopening-triggers)和[§14.4 质疑途径](../../core_09_d_institutional_alignment_certification.md#144-challenge-path)。质疑者须指出具体越界事项，实体须以书面说明和理由作答。任何一项答是即使实体至少属于 L 类，因此质疑途径保持简便，具体有六项安排：
    - **先由实体答复：**质疑首先提交实体已公布的质疑途径，答复须符合[第 XXVI-C 条](../../core_06_rights_part_e.md#article-xxvi-c-timely-resolution-and-anti-delay-floor)（*及时解决与反拖延底线*）规定的时限。答复未解决事项或未按时作出时，可诉诸论坛；若延误会危及权利、证据或独立性，则可直接诉诸论坛。
    - **未指出越界事项的质疑应退回补正，而非裁决：**实体要求质疑者指出一项具体越界。这是完整性检查，不是实体裁决。该步骤不耗用质疑者的任何时限，质疑者可再次提交。向论坛提交的此类文件归入[CF-5.1 已公布的受理类别](../../corpus_forum/cf_05_routing_operations_transfer_certification_representative_treatment.md#cf-51-published-intake-classes)中的常规类别，受理时不得拒绝。
    - **关联质疑合并审理一次：**针对同一实体的相同越界事项提出的质疑，或针对本条认定为同一运营事项之多个实体的质疑，依[第十三章 §3 移送、合并与协调——连续性与防止攫取](../../core_13_forum.md#3-transfer-consolidation-and-coordination--continuity-and-anti-capture)作为同一事项审理。
    - **事实未变时认定继续有效：**针对已指出越界事项的认定持续有效，直至实体活动发生实质变化，或有新的越界证据提出；这与[第九章 D 部分 §14.2 重新开启触发条件](../../core_09_d_institutional_alignment_certification.md#142-reopening-triggers)一致。若再次质疑但不存在上述情形，可援引现有认定作答。
    - **质疑不停止实体运营：**分类不限制运营（[第 XI-E 条](../../core_06_rights_part_b.md#article-xi-e-institutional-formation-and-business-creation)（*机构组建与企业创设*））。质疑待决期间实体继续运营；结果是实体须发布或补正系统章程或机构章程。认定实体属于 L 类时，认定日期即视为依[第七章 §3 何时需要系统章程和机构章程](../../core_07_charters.md#3-when-system-and-institutional-charters-are-required)发出的请求（*请求系统章程或机构章程*）：一周内答复，三十日内发布。若证明他人受到伤害，论坛仍可依[第十三章 §5 升级处理与认证](../../core_13_forum.md#5-escalation-and-certification)给予临时保护。
    - **论坛预先规划处理能力：**分类质疑大量涌入，例如界线变动或共享系统中的实体重新分类，属于可预见的激增情形，依[CF-16.2 储备、替代与激增处理能力](../../corpus_forum/cf_16_staffing_reserve_capacity_structural_records.md#cf-162-reserve-substitute-and-surge-capacity)处理。核心条文对此不设数值。
  - **主要失效：**
    - 事实表明实体符合任何领域“何时具有实质性”测试，却仍称实体低于界线；
    - 实体声称低于界线却不提供书面说明，或要求质疑者反证；
    - 仅凭规模、人数、定期聚会、人气或谨慎的生态恢复工作就认定越界，或在质疑未指出任何特定领域中具体越界事项时仍认定实体纳入适用范围；
    - 让一个领域的否定答案抵消另一个领域的肯定答案；
    - 退回或忽略质疑，却不说明欠缺内容，或利用退回补正步骤耗尽质疑者的时限；
    - 采纳者设定的数值超过领域问题所隐含的程度，或在事实已表明实体超过界线时依靠数值声称其仍低于界线；
    - 因实体超过界线而阻止其组建或运营；或
    - 因实体低于界线而允许其忽视[宪法约束](../../core_05_band_integrative.md#constitutional-constraint)。安全、真相和权利底线——包括**第 I-A 条**（*环境前提与生态完整性*）及**第 I-D 条**（*生存风险与生态恢复能力*）的环境保护——均完整约束该实体。
  - **次要失效：**通过拆分、边界操纵或规避汇总使实体低于界线；或利用“一般社区活动”的标签掩盖实际越界。

<a id="operating-party"></a>

#### 运营方

<details>
<summary><strong><span style="color: #2563eb;">溯源</span></strong></summary>

- 宪法框架：[宪法四联体](../../core_00_preamble.md#constitutional-tetrad)：监督、问责与及时性；[宪法的两个目标](../../core_00_preamble.md#two-constitutional-aims)；按[实质利害](../../core_00_preamble.md#material-stake)调整。
- 下游：[领域特定实质性](core_05_band_oversight.md#领域特定实质性)、[Chartered Party](../../core_05_band_continuity.md#chartered-party)（已发布或必须发布章程的运营方）以及**CS-3**（*系统分类机制*）。
- 区分：领域特定实质性的九项问题所针对的主体就是运营方，可能是系统、机构或较小群体。Chartered Party 的范围更窄。这个名称本身不增加义务、类别或门槛。

</details>

<br>

*通俗地说：运营方是实际开展活动的主体，可以是一个 sentient、共同行动的一群 sentient、系统或机构。领域特定实质性的九项问题适用于该主体。只要其活动在任一领域具有实质性，它至少属于 L 类，并须发布系统章程或机构章程；否则仍为 P 类。称其为运营方不会增加义务或门槛。*

- **是什么**
  - **范围内：**以自身名义采取行动或安排活动的 sentient、共同行动的群体、[系统](../../core_05_band_continuity.md#system)或[机构](../../core_05_band_continuity.md#institution)。领域特定实质性可将相关运营方合并视为一次运营。
  - **范围外：**群体成员在群体内部单独采取的行动；被测试的行为或活动本身；运营方内的职位及其持有人；任何许可证或门槛。
<a id="operating-party-a"></a>
- **衡量与评估**
  - **主要评估：**根据实际开展、决策、持有和影响活动的主体识别运营方，而非依据名称、规模或法律形式。由同一权力中心运作的运营方应合并视为一次运营；改名或改变形式不会中断义务。
  - **次要评估：**结合[治理](../../core_05_band_accountability.md#governance)和[实质控制界线](../../core_05_band_accountability.md#material-control-line)，识别实际控制所在。
<a id="operating-party-c"></a>
- **必须成立的要求**
  - 适用义务随活动延续，不因改名、拆分、合并、继承或法律形式变化而中断。
  - **主要失效：**利用名称、规模、法律形式或拆分来掩盖实际运营方，或使活动看似低于界线。
  - **次要失效：**某项行为或活动没有任何运营方负责。
<a id="materiality-integrity-constraint"></a>

#### 实质性完整性约束

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：原则：[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)（评估中的汇总与边界完整性）；[第一章 §13.2.4 代理指标偏离失效规则](../../core_01_b_interaction_interpretation.md#1324-proxy-divergence-invalidation)（可能操纵实质性的指标与现实差距）。
- 配合阅读：[实质性](core_05_band_oversight.md#实质性)、[系统边界](../../core_05_band_continuity.md#system-boundaries)、[系统边界完整性](../../core_05_band_continuity.md#system-boundary-integrity)、[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、[可审计性](core_05_band_oversight.md#可审计性)和[问责](../../core_05_apex_accountability_leg.md#accountability)。

</details>

<br>

*通俗地说：不得通过重新划分范围、拆分组成部分或重新分类，来把大问题伪装成小问题。*

- **定义**
  - **适用范围：**禁止违背[系统边界完整性](../../core_05_band_continuity.md#system-boundary-integrity)，通过操纵[系统边界](../../core_05_band_continuity.md#system-boundaries)、汇总或分类来缩小实质性问题。
  - **不适用范围：**一般的实质性分歧，或诚实澄清边界、且未通过拆分、汇总操纵或重新分类缩小合并后具有实质性的影响。
<a id="materiality-integrity-constraint-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[实质性](core_05_band_oversight.md#实质性)——检验是否有人通过重划范围、拆分部分或重新分类规避问题，令实质性问题显得较小。

    **主要评估：**查找会破坏诚实[实质性](core_05_band_oversight.md#实质性)判断的结构性手法，包括：
    - 拆分；
    - 规避汇总；以及
    - 边界操纵。
  - **次要衡量指标：**[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、[实质性](core_05_band_oversight.md#实质性)、[可审计性](core_05_band_oversight.md#可审计性)和[代理指标偏离](core_05_band_oversight.md#代理指标偏离)——这些共同指标可以揭穿实质性判断中的操纵或代理指标造假。

    **次要评估：**核对主要结论时，计入可能掩盖合并后实质影响的[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、[可审计性](core_05_band_oversight.md#可审计性)和[代理指标偏离](core_05_band_oversight.md#代理指标偏离)路径。
<a id="materiality-integrity-constraint-c"></a>
- **必须满足的条件**
  - **主要失效：**通过结构性操纵，将合并后具有实质性的影响视为不具实质性。
  - **次要失效：**通过边界或汇总操纵规避[可审计性](core_05_band_oversight.md#可审计性)，或在[代理指标偏离](core_05_band_oversight.md#代理指标偏离)可合理观察时依赖“指标看起来正常”的说法。

<a id="material-impact"></a>

#### 实质影响

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：整合性实质性（[实质性](core_05_band_oversight.md#实质性)）（*作为宪法衡量的实质性*）；原则：[实质利害](../../core_00_preamble.md#material-stake)分级代理指标；[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)；[第一章 §16 深入探讨守护——§16.1 分布式理解](../../core_01_c_stewardship_capacity_principles.md#161-distributed-understanding)（理解程度随**实质性**而分级）；[13.1.3 比例性](../../core_01_b_interaction_interpretation.md#1313-proportionality)（权衡索引中的实质影响）。
- 集群组成部分：[依赖集群：*实质影响、实质性、按分类分级的治理、监督与能力要求*](core_05_band_oversight.md#实质性影响风险与代理指标完整性)。
- 配合阅读：[伤害](../../core_05_band_accountability.md#harm)、[风险](../../core_05_band_continuity.md#risk)、[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、[依赖关系](../../core_05_band_continuity.md#dependency)、[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)、[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)和[透明度](core_05_band_oversight.md#透明度)。

</details>

<br>

*通俗地说：影响波及多远、规模多大、程度多严重；观察整个系统，而非只看标题或文书手续。*

- **定义**
  - **适用范围：**用于[伤害](../../core_05_band_accountability.md#harm)、[风险](../../core_05_band_continuity.md#risk)及宪法评估的影响，包括：
    - 波及范围；
    - 影响规模；以及
    - 严重程度。
  - **不适用范围：**
    - 没有波及范围、规模或严重程度利害的单纯关注度、可见度或文书意义；或
    - 对预期[实质风险](core_05_band_oversight.md#实质风险)的分析——该事项由其自身条目规定。
<a id="material-impact-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**整合性实质性（[实质性](core_05_band_oversight.md#实质性)）——实质性分类的范围与严重程度输入。

    **主要评估：**追踪影响对整个系统的波及范围、规模和严重程度，包括：
    - 直接影响；
    - 间接影响；
    - 延迟影响；
    - 累积影响；以及
    - 跨系统后果。
  - **次要衡量指标：**[伤害](../../core_05_band_accountability.md#harm)、[风险](../../core_05_band_continuity.md#risk)、[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)和[依赖关系](../../core_05_band_continuity.md#dependency)——若只看各组成部分会低估影响，这些共同指标可纠正影响评估。

    **次要评估：**核对主要结论时，计入可能改变实质性分类的[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、[依赖关系](../../core_05_band_continuity.md#dependency)及跨系统扩散路径。
<a id="material-impact-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - 以预期风险的讨论取代对实际波及范围、规模或严重程度的分析；或
    - 实质影响未触发[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)、[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)和[透明度](core_05_band_oversight.md#透明度)规定的适当约束。
  - **次要失效：**影响被拆分或因依赖关系而隐藏，却被标为不具实质性，尽管合并分析会将其判定为实质性。

<a id="material-risk"></a>

#### 实质风险

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：整合性实质性（[实质性](core_05_band_oversight.md#实质性)）（*作为宪法衡量的实质性*）；原则：[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)（尾部风险、生存风险立场）；[13.1.3 比例性](../../core_01_b_interaction_interpretation.md#1313-proportionality)（**风险**、**不可逆伤害**、**生存风险**索引）。
- 配合阅读：[伤害](../../core_05_band_accountability.md#harm)、[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)、[风险](../../core_05_band_continuity.md#risk)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)和[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)。

</details>

<br>

*通俗地说：伤害发生的可能性、到来的速度和可逆程度，包括罕见但严重的结果。*

- **定义**
  - **适用范围：**预期[伤害](../../core_05_band_accountability.md#harm)，包括：
    - 发生的可能性；
    - 到来的速度；以及
    - 可逆程度。
  - **不适用范围：**
    - 没有可信伤害路径的臆测性担忧；或
    - 已经发生的[伤害](../../core_05_band_accountability.md#harm)——其属于伤害／[实质影响](core_05_band_oversight.md#实质影响)，不只是预期风险。
<a id="material-risk-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**整合性实质性（[实质性](core_05_band_oversight.md#实质性)）——实质风险分类中的可能性与不可逆性输入。

    **主要评估：**观察整个系统，并计入：
    - 预期结果；
    - 罕见但严重的（尾部）结果；
    - [伤害](../../core_05_band_accountability.md#harm)可能多快发生；以及
    - 伤害可能达到何种不可逆程度。
  - **次要衡量指标：**[伤害](../../core_05_band_accountability.md#harm)、[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)、[风险](../../core_05_band_continuity.md#risk)和[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)——忽略尾部风险或系统性风险路径时，这些共同指标可纠正风险分类。

    **次要评估：**核对主要结论时，计入可能改变实质风险分类的[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)、[风险](../../core_05_band_continuity.md#risk)及[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)路径。
<a id="material-risk-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - 将已经发生的伤害仅标为未来风险；或
    - 未依据[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、[风险](../../core_05_band_continuity.md#risk)和[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)处理并约束实质风险。
  - **次要失效：**[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)仍有可信可能，却排除尾部伤害或不可逆伤害路径。

<a id="materiality-under-uncertainty"></a>

#### 不确定情形下的实质性

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：原则：[13.1.3 比例性](../../core_01_b_interaction_interpretation.md#1313-proportionality)（不确定情形下的可逆性）；[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)（预防遗漏伤害）。
- 配合阅读：[实质影响](core_05_band_oversight.md#实质影响)、[实质风险](core_05_band_oversight.md#实质风险)、[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、[领域特定实质性](core_05_band_oversight.md#领域特定实质性)和[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)。

</details>

<br>

*通俗地说：不确定某事是否具有实质性时，默认采用较安全的较高分类；不要等待确定，也不要寄望于较低标签。*

- **定义**
  - **适用范围：**[实质影响](core_05_band_oversight.md#实质影响)或[实质风险](core_05_band_oversight.md#实质风险)尚不确定时的默认处理方式。
  - **不适用范围：**
    - 实质性已确定且不存在剩余实质性不确定因素的情形；或
    - 不确定性不具实质性后的常规[实质性](core_05_band_oversight.md#实质性)——此类情况依确定后的分类处理，不适用此预防性默认规则。
<a id="materiality-under-uncertainty-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**整合性实质性（[实质性](core_05_band_oversight.md#实质性)）——无法排除实质性时采用预防性默认规则。

    **主要评估：**无法排除实质性时默认采取预防措施；包括不确定情况下仍可能发生[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)的情形。
  - **次要衡量指标：**[实质影响](core_05_band_oversight.md#实质影响)、[实质风险](core_05_band_oversight.md#实质风险)、[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)和[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)——这些共同指标要求在不确定时采取保守分类。

    **次要评估：**核对主要结论时，计入要求采用保守默认分类的[实质影响](core_05_band_oversight.md#实质影响)、[实质风险](core_05_band_oversight.md#实质风险)和[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)路径。
<a id="materiality-under-uncertainty-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - 实质影响或风险仍不确定，却等待确定后才进行分类；
    - 实质影响或风险仍不确定，却乐观地采用较低分类；或
    - [按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)要求采用保守分类时，未在不确定情形下采用该分类。
  - **次要失效：**[不可逆伤害](../../core_05_band_accountability.md#irreversible-harm)或[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)要求采取预防措施，却仍采取乐观态度或非正式低分类。

<a id="proxy-divergence"></a>

#### 代理指标偏离

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：监督衡量体系（*作为宪法衡量的真相与认识完整性*）；问责衡量体系（*作为宪法衡量的激励一致性与代理指标完整性*）；原则：[第一章 §13.2.4 代理指标偏离失效规则](../../core_01_b_interaction_interpretation.md#1324-proxy-divergence-invalidation)、[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)，以及[第一章 §18 守护纪律下的治理](../../core_01_c_stewardship_capacity_principles.md#18-governance-under-stewardship-discipline)。
- 集群组成部分：[依赖集群：*实质影响、实质性、按分类分级的治理、监督与能力要求*](core_05_band_oversight.md#实质性影响风险与代理指标完整性)。
- 配合阅读：[实质性](core_05_band_oversight.md#实质性)、[实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)、[系统边界完整性](../../core_05_band_continuity.md#system-boundary-integrity)、[激励一致性](../../core_05_band_integrative.md#incentive-alignment)、[可审计性](core_05_band_oversight.md#可审计性)和[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)。

</details>

<br>

*通俗地说：当分数不再反映现实——例如仪表板、类别标签或合规指标所说的，与实际状况不符——就发生了偏离；也包括通过做高分数使其看似正常，而真实状况仍然糟糕、继续恶化或根本未被衡量。*

- **定义**
  - **适用范围：**代理指标与其声称代表的、具有宪法实质意义的现实之间存在实质差距，包括：
    - 差距本身；以及
    - 在实际情况持续恶化、继续变差或未被衡量时，改善、维持或操纵代理指标的行为、设计、报告方式或激励安排。
    代理指标包括：
    - 衡量指标；
    - 模型信号；
    - 正式类别；
    - 合规指标；以及
    - 行政简写。
    所声称代表的现实包括权利、风险、负担、伤害、能力和结果。
  - **不适用范围：**一般测量噪声；未使代理指标脱离宪法相关现实的轻微且不具实质性的差距；或如实反映真实结果的指标改善。
<a id="proxy-divergence-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)和[问责衡量体系](../../core_05_apex_accountability_leg.md#measuring-accountability)——*有感知者能否看见、核实并信赖系统所呈现的内容？*／*奖励结构、市场力量和可问责性是否使义务真正落实？*在此用它们检验代理指标是否仍反映宪法上具有实质意义的现实，以及代理指标偏离后，奖励、报告或门槛决定是否仍依赖这些指标；包括分数遭操纵或被刻意维护的情形。

    **主要评估：**若证据表明代理指标不再反映宪法上具有实质意义的现实，检验优化、报告、门槛决定或审查是否仍依赖该指标。查找做高分数的手法，包括：
    - 优化仪表板；
    - 操纵门槛；
    - 选择性抽样；
    - 操纵分母；
    - 排除特定人群；
    - 自动改善分数；
    - 模型奖励劫持；
    - 合规表演；以及
    - 用叙事替代证据。
    若指标无法追溯至实际观察到的实质结果，或激励会可预见地使指标偏离这些结果，该指标就不可靠。
  - **次要衡量指标：**[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)、[实质性](core_05_band_oversight.md#实质性)、[实质性完整性约束](core_05_band_oversight.md#实质性完整性约束)和[可审计性](core_05_band_oversight.md#可审计性)——即使所报告的指标看似稳定，这些共同指标仍可揭穿代理指标完整性问题。

    **次要评估：**核对主要结论时，查找以下情况：
    - 选择效应；
    - 边界操纵；
    - 人群缺失；
    - 反馈循环；
    - 操纵激励；
    - 对抗性适应；以及
    - 被有利局部指标掩盖的总体伤害，
    并结合[实质性](core_05_band_oversight.md#实质性)和[可审计性](core_05_band_oversight.md#可审计性)一并评估。
  - **第三层衡量指标：**[福祉](../../core_05_band_continuity.md#wellbeing)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)和权利底线结果——当代理指标取代有感知者实际经历的衡量指标时。

    **第三层评估：**代理指标取代结果衡量指标时，追溯至[福祉](../../core_05_band_continuity.md#wellbeing)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)或权利底线的落实情况，将持久的宪法结果与代理指标的处理量区分开。
<a id="proxy-divergence-c"></a>
- **必须满足的条件**
  - 只有在完整系统运行条件下——包括激励或设计原本会导致分数造假的情形——代理指标仍与宪法上具有实质意义的现实一致，系统才符合**代理指标偏离**纪律。
  - **主要失效：**
    - 差距具有实质性，却将代理指标视为决定性依据；
    - 实质结果仍不达标，却声称指标改善证明已合规；
    - 设计无需履行底层义务也能满足的指标；或
    - 压制指标已脱离现实的证据。
  - **次要失效：**代理指标偏离已可合理观察，却以“指标看起来正常”为由跳过对权利底线、安全、真相、福祉、生态或能动性结果的直接评估。
  - **第三层失效：**报告指标与有感知者实际经历之间的差距已可合理观察，却拒绝纠正。

- **定义**
  - **适用范围：**受保护的宪法条件维持程度出现不可忽略的下降，包括：

<a id="material-degradation-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**整合性实质性（[实质性](core_05_band_oversight.md#实质性)）——用于实质性分类的退化信号。

    **主要评估：**判断受保护条件是否发生不可忽略的下降时，依据[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)和[风险](../../core_05_band_continuity.md#risk)计入规模和全系统影响。
  - **次要衡量指标：**[实质性](core_05_band_oversight.md#实质性)、[系统性实质性](../../core_05_band_continuity.md#systemic-materiality)、[风险](../../core_05_band_continuity.md#risk)和[代理指标偏离](core_05_band_oversight.md#代理指标偏离)——当代理指标掩盖下降时，这些共同指标可纠正退化评估。

    **次要评估：**指标掩盖实质退化时，核对主要结论须适用[实质性](core_05_band_oversight.md#实质性)和[代理指标偏离](core_05_band_oversight.md#代理指标偏离)。
<a id="material-degradation-c"></a>
- **必须满足的条件**
  - **主要失效：**未依据[实质性](core_05_band_oversight.md#实质性)将实质退化视为实质问题。
  - **次要失效：**在[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、[认识完整性](core_05_band_oversight.md#认识完整性)或[有意义的能动性](../../core_05_band_participation.md#meaningful-agency)发生实质退化时，仍维持代理指标看似稳定。

#### Def.O1 透明度、可审计性与核验

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 配合阅读：适用[问责](../../core_05_apex_accountability_leg.md#accountability)、[可质疑性](../../core_05_band_accountability.md#contestability)、[程序公平](../../core_05_band_participation.md#procedural-fairness)、[受保护报告（举报）](../../core_05_band_accountability.md#protected-reporting-whistleblowing)、[实质性](core_05_band_oversight.md#实质性)、[风险](../../core_05_band_continuity.md#risk)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)、[认识完整性](core_05_band_oversight.md#认识完整性)，以及在实质牵涉时适用的第二至第四章机制。

</details>

<br>

**纳入范围。**事项在实质上涉及以下内容时，适用本集群：
- 与决策有关行为的透明度；
- 向需要了解者披露经评估的系统性风险；
- 证据保全；
- 可审计性及足以重构事件经过的记录；
- 对可能失效模式进行完整评估；
- 可由外部观察、可用于审计和独立核验的指标；
- 独立核验；或
- 在分级或对抗条件下，核验是否可及且独立。
若事项不在此范围内，各个条目仍可单独适用，无须因此引入整个集群。

符合纳入范围时，本集群共同规范披露、审计、核验（包括外部可观察性）以及保证深度；第二至第四章要求以可追溯、可质疑的证据证明系统做了什么、合规主张是否成立时，适用本集群。

**监督框架。**依[宪法四元结构](../../core_00_preamble.md#constitutional-tetrad)中的**监督**一柱，监督要求能够审计——重构事件经过、独立核验并取得审计权限；此处及**第 XVI 条**（*审计、透明度与独立核验*）对此负责。[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)是若干审计程序中的一种，规模特别大、利害特别高（论坛监督下的一致性审查及认证结果见[第九章](../../core_09_a_system_alignment_certification_evaluation.md#chapter-nine-system-alignment-certification)）；它不会吞并本集群，也不取代其他审计方式。

**系统类别与比例原则。**透明度、可审计性及核验义务依 **[corpus_systems.md](../../corpus_systems.md)**、CS-3——系统分类与处理方式规定的系统类别，以及实质影响、依赖关系和风险分级。高类别系统（**A 类**、**B 类**、**C 类**）须满足高于低类别系统（**L 类**、**P 类**）的要求，包括：
- 更深入的保证；
- 更细致的记录；
- 更有力的独立核验；以及
- 更广泛的审计范围。

**阅读顺序。**先读必须披露的内容（[透明度](core_05_band_oversight.md#透明度)、[公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)、[风险披露](core_05_band_oversight.md#风险披露)）；再读外部人士能否重构经过（[可审计性](core_05_band_oversight.md#可审计性)及审计支持）；最后读行为是否可由外部观察并独立核查（[可核验性](core_05_band_oversight.md#可核验性)）。

**集群成员。**本集群包括：

- [透明度](core_05_band_oversight.md#透明度)——与决策有关的功能、限制和风险说明；
- [公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)——高影响系统须达到的公共披露底线，包括合法替代方式；
- [风险披露](core_05_band_oversight.md#风险披露)——向需要了解者传达经评估的系统性风险；
- [可审计性](core_05_band_oversight.md#可审计性)——外部人士能否重构和核验系统在相关实质性时间、状态和情境中的行为；
- [证据保全](core_05_band_oversight.md#证据保全)——识别、保护并确保实质相关证据可供审查；
- [评估完整性约束](core_05_band_oversight.md#评估完整性约束)——声称合规前涵盖可信的失效、滥用、交互及对抗路径；以及
- [可核验性](core_05_band_oversight.md#可核验性)——在实际可及、独立、负担适度且压力条件下可靠的前提下，对行为和影响进行外部观察与衡量，并独立核实观察结果。

**反规避。**划分披露、保全、日志记录、指标、审计抽样、核验界面和独立性等环节，若某一渠道形式上满足要求，却破坏了实际重构、质疑或适当保证深度，即属不合规。参见[§15.1.1 反分割原则](../../core_01_b_interaction_interpretation.md#1511-anti-segmentation-principle)。

参见**反分割原则**。

<a id="transparency"></a>

##### 透明度

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 集群组成部分：[Def.O1 *透明度、可审计性与核验*](core_05_band_oversight.md#defo1-透明度可审计性与核验)。
- 下游：原则：[宪法四元结构](../../core_00_preamble.md#constitutional-tetrad)中的**监督**一柱；[第一章 §16 深入探讨守护](../../core_01_c_stewardship_capacity_principles.md#16-stewardship-in-depth)、[13.2.1 维护认识完整性](../../core_01_b_interaction_interpretation.md#1321-preservation-of-epistemic-integrity)。
- 配合阅读：[认识完整性](core_05_band_oversight.md#认识完整性)、[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)、[可质疑性](../../core_05_band_accountability.md#contestability)、[可审计性](core_05_band_oversight.md#可审计性)、[公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)、[风险披露](core_05_band_oversight.md#风险披露)、[可核验性](core_05_band_oversight.md#可核验性)，以及**[corpus_systems.md](../../corpus_systems.md)**、CS-2——信息类型与处理方式（**O 类**——开放的公共监督基线披露数据）。

</details>

<br>

*通俗地说：向受影响的有感知者提供足够信息，使他们真正理解并质疑系统的运作方式、限制和风险；不能用噪音将这些信息淹没。*

- **定义**
  - **适用范围：**向受影响的有感知者提供足够信息，说明系统对外的行为、限制、不确定性及其依赖关系，使他们能够理解系统做什么、产生什么风险。仍可依法适用正当的安全与保密限制，并须符合[认识完整性](core_05_band_oversight.md#认识完整性)和[13.2 认识披露约束](../../core_01_b_interaction_interpretation.md#132-epistemic-disclosure-constraints)。
    - 若实质性系统、机构、论坛程序或类似受治理领域依法可在线发布信息，则在[公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)适用之处，其基线透明度披露须按该类别要求免费向公众开放，不得设付费墙或仅供内部人员获取。
    - 若发布原始材料会违反合法保护，规范主体仍须尽可能在线发布最充分的公共替代内容，不得削弱问责或[可质疑性](../../core_05_band_accountability.md#contestability)，例如：
      - 汇总；
      - 去标识化；
      - 汇总披露；
      - 延迟披露；或
      - 限定条件下的审计访问。
  - **不适用范围：**
    - 单独的[可审计性](core_05_band_oversight.md#可审计性)重构渠道；
    - [公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)本身的 O 类底线机制；或
    - 与受影响方的决策无关的一般商业营销披露——这些事项依其各自规范或一般商业言论处理。
<a id="transparency-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验受影响方是否获得与决策有关的功能、限制和风险说明，而不是信息量、噪音或仅供内部人员查阅的内容。

    **主要评估：**将披露内容与[实质影响](core_05_band_oversight.md#实质影响)和[依赖关系](../../core_05_band_continuity.md#dependency)进行比较。
  - **次要衡量指标：**[认识完整性](core_05_band_oversight.md#认识完整性)、[实质影响](core_05_band_oversight.md#实质影响)、[依赖关系](../../core_05_band_continuity.md#dependency)、[可审计性](core_05_band_oversight.md#可审计性)和[可核验性](core_05_band_oversight.md#可核验性)——即使披露量很大，这些共同指标仍可揭示透明度不足。

    **次要评估：**核对主要结论时：
    - 识别是否用信息量、晦涩表达或格式代替与决策有关的清晰说明；以及
    - 适用符合[认识完整性](core_05_band_oversight.md#认识完整性)的安全与保密正当限制。

    实际上，无法核查的披露不构成与决策有关的披露；不得把不可核验的披露视为与决策有关的清晰说明。[可核验性](core_05_band_oversight.md#可核验性)规定这些核查条件，包括：
    - 实际可及性；
    - 独立于运营者自我声明；
    - 负担适度；以及
    - 在压力、误用和对抗压力下仍然可靠。
  - **第三层衡量指标：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)——当信息量、格式或程序不透明代替了与决策有关的清晰说明时。

    **第三层评估：**运营者依赖披露量或格式时，适用[代理指标偏离](core_05_band_oversight.md#代理指标偏离)，将真正的透明度与用信息淹没有感知者区分开来。
<a id="transparency-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - 向受影响的有感知者倾倒数据、提供大堆文件、设置付费墙或仅限内部人员访问，却未就功能和风险提供真正与决策有关的清晰说明；或
    - 作出实质遗漏或披露，且可预见地阻碍知情参与，或在必要时妨碍[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)。
  - **次要失效：**以安全或保密为由限制必要的实质说明，却不符合[必要性](../../core_05_band_accountability.md#necessity)和[比例性](../../core_05_band_accountability.md#proportionality)。
  - **第三层失效：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)已可合理观察，却仍把披露量或格式视为决定性依据。

- 配合阅读：[透明度](core_05_band_oversight.md#透明度)、[可质疑性](../../core_05_band_accountability.md#contestability)、[可审计性](core_05_band_oversight.md#可审计性)、[风险披露](core_05_band_oversight.md#风险披露)、[系统章程](../../core_05_band_continuity.md#system-charter)、[系统边界](../../core_05_band_continuity.md#system-boundaries)、[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)、[系统认证记录](../../core_05_band_continuity.md#system-certification-record)、[系统分类记录](../../core_05_band_continuity.md#system-classification-record)、[系统数据类型记录](../../core_05_band_continuity.md#system-data-types-record)、[按分类分级的治理](core_05_band_oversight.md#按分类分级的治理)以及**[corpus_systems.md](../../corpus_systems.md)**、CS-2——信息类型与处理方式（**O 类**）。

</details>

<br>

*通俗地说：高影响系统必须向公众发布的最低披露内容，使有感知者能够理解、监督和质疑系统——包括目的、类别、依赖关系、状态、风险、表现、失效、治理、利益相关方影响、宪法一致性，以及系统章程、分类、数据类型和认证记录的公共部分；无法发布原始私人记录或非基线记录时，须提供有力的公共替代内容。*

- **定义**
  - **适用范围：**为使有感知者能够监督和质疑具有实质影响的系统而规定的公共披露底线，尤其适用于 **[corpus_systems.md](../../corpus_systems.md)**、CS-3——系统分类与处理方式所述的**A 类**、**B 类**和**C 类**。涵盖范围依据管理该系统的[系统章程](../../core_05_band_continuity.md#system-charter)（或等效的已发布范围文书）、指定类别和实际观察到的[系统边界](../../core_05_band_continuity.md#system-boundaries)确定。披露内容须涵盖有感知者理解以下事项所需的信息：
    - 系统目的及其功能；
    - 系统分类；
    - 依赖结构及依赖该系统的事项；
    - 运行状态及其运作方式；
    - 实质风险、表现和失效；
    - 治理方式及实质性审计结果；
    - 利益相关方所受影响；以及
    - 系统与本宪法的一致程度。
  - **A/B/C 类 O 类文书：**若 **A 类**、**B 类**或**C 类**适用 **O 类**基线，则该底线包括——以公共基线所需的忠实程度，必要时采用合法替代方式——发布或提供可用的公共版本，内容涵盖：
    - 管理该系统的[系统章程](../../core_05_band_continuity.md#system-charter)（或等效的已发布范围文书）；
    - [系统分类记录](../../core_05_band_continuity.md#system-classification-record)；
    - [系统数据类型记录](../../core_05_band_continuity.md#system-data-types-record)；以及
    - 由[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)生成的[系统认证记录](../../core_05_band_continuity.md#system-certification-record)，包括基线可见度要求披露的实质治理与审计结果。
  - **主题覆盖：**公共基线须披露目的、运行状态、实质风险、表现、失效及利益相关方影响；可通过这些记录、系统性风险纳入范围时的[风险披露](core_05_band_oversight.md#风险披露)，以及其他合法的 **O 类**摘要或替代内容满足，而不能省略这些主题。
  - **合法替代方式：**若 **G 类**、**E 类**或其他来源记录仍非公开、非基线或受其他限制，本要求仍适用，包括采取：
    - 汇总；
    - 去标识化；
    - 摘要或延迟披露；以及
    - 可比的替代材料。
  - **O 类／E 类／G 类之间的关系：**
    - 本披露底线按 **O 类**进行分类和处理。
    - **E 类**保存与生存和协调至关重要的内容流；**G 类**保存可供审计访问、但默认不公开的治理与运营来源材料。
    - **E 类**和**G 类**本身都不是公共底线。
    - 从这些类别形成并发布的基线材料——包括替代内容——属于 **O 类**；底层内容流可保留原类别。
    - 系统层级的分类、替代机制及暂缓公开限制由**[corpus_systems.md](../../corpus_systems.md)**、CS-2——信息类型与处理方式作为 **O 类**事项规定。
  - **不适用范围：**
    - 原始 **G 类**、**E 类**或其他受限制的来源记录——从中制作公共替代内容，不会使这些原始记录纳入披露底线；
    - [可审计性](core_05_band_oversight.md#可审计性)规定的结构化或有限制条件的审计访问本身——这本身并非公共底线；或
    - 向需要了解者披露已评估的系统性风险的[风险披露](core_05_band_oversight.md#风险披露)——这些事项各有其规范。
<a id="public-oversight-baseline-disclosure-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验公共披露底线是否确实发布，且可用于监督和质疑；原始记录受限制时，包括提供合法替代内容。

    **主要评估：**将已发布披露内容与依[系统章程](../../core_05_band_continuity.md#system-charter)、指定类别及[系统边界](../../core_05_band_continuity.md#system-boundaries)认证的范围进行比较。若 **A 类**、**B 类**或**C 类**系统适用 **[CS-2 A 部分 §7 A/B/C 类系统 O 类基线](../../corpus_systems/cs_02_a_information_types_and_handling.md#cs-27-type-o-baseline-for-class-abc-systems)**，则确认：
    - [系统章程](../../core_05_band_continuity.md#system-charter)、[系统分类记录](../../core_05_band_continuity.md#system-classification-record)、[系统数据类型记录](../../core_05_band_continuity.md#system-data-types-record)和[系统认证记录](../../core_05_band_continuity.md#system-certification-record)（或规定内容）均有达到公共基线忠实程度且可用的公共版本；
    - 目的、依赖结构、运行状态、实质风险、表现、失效、治理、审计结果、利益相关方影响及宪法合规性均以基线深度得到涵盖；
    - 合法替代内容仍支持有意义的问责和[可质疑性](../../core_05_band_accountability.md#contestability)；以及
    - 存在合法发布基础设施时，内容可免费在线获取。
  - **次要衡量指标：**[透明度](core_05_band_oversight.md#透明度)、[可质疑性](../../core_05_band_accountability.md#contestability)、[认识完整性](core_05_band_oversight.md#认识完整性)、[可审计性](core_05_band_oversight.md#可审计性)和[风险披露](core_05_band_oversight.md#风险披露)——即使存在部分公共材料，这些共同指标仍可揭示披露底线不足。

    **次要评估：**核对主要结论时，查找：
    - 内容单薄的摘要；
    - 以仅供审计访问的内容代替公共披露；
    - 与认证范围相比存在覆盖缺口；
    - 系统章程、分类、数据类型或认证记录缺少必要或可用的公共版本；
    - 缺少对表现、失效、利益相关方影响或实质风险的基线公开；以及
    - 隐瞒系统性行为、违宪行为、实质风险、依赖关系、失效或外部化成本的保留内容。
<a id="public-oversight-baseline-disclosure-c"></a>
- **必须满足的条件**
  - **主要失效：**依据 CS-2（*信息类型与处理方式*），**A 类**、**B 类**或**C 类**适用 **O 类**基线时，公共监督基线披露缺失或不充分。
  - **次要失效：**
    - 用非公开的 **G 类**审计访问、付费墙或表演性摘要充当公共底线；
    - 表演性摘要隐去与决策有关的基线材料；
    - 存在合法在线发布基础设施、且该类别要求公共访问时，仍以付费墙或仅限内部人员的方式提供底线内容；
    - **A 类**、**B 类**或**C 类**系统依据**[CS-2 A 部分 §7 A/B/C 类系统 O 类基线](../../corpus_systems/cs_02_a_information_types_and_handling.md#cs-27-type-o-baseline-for-class-abc-systems)**适用 **O 类**基线时，省略[系统章程](../../core_05_band_continuity.md#system-charter)、[系统分类记录](../../core_05_band_continuity.md#system-classification-record)、[系统数据类型记录](../../core_05_band_continuity.md#system-data-types-record)或[系统认证记录](../../core_05_band_continuity.md#system-certification-record)的可用公共版本；或
    - 省略有关目的、依赖结构、运行状态、实质风险、表现、失效、治理、审计结果、利益相关方影响或宪法合规性的基线信息。
  - **第三层失效：**暂缓公开内容未依 CS-2（*信息类型与处理方式*）和[透明度](core_05_band_oversight.md#透明度)做到范围狭窄、有据可查、合乎比例、可审计且可质疑。

##### 风险披露

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 集群组成部分：[Def.O1 *透明度、可审计性与核验*](core_05_band_oversight.md#defo1-透明度可审计性与核验)。
- 下游：监督衡量体系（*作为宪法衡量的披露与保证*）；原则：[宪法四元结构](../../core_00_preamble.md#constitutional-tetrad)中的**监督**一柱；[4 安全](../../core_01_a_values_principles.md#4-safety-harm-constraint)；[第九章 §3.1 系统范围与风险因素](../../core_09_a_system_alignment_certification_evaluation.md#31-systemic-scope-and-risk-factors)（*SAC 评估与披露的衔接*）；[第九章 B 部分 §8.1](../../core_09_b_system_alignment_certification_record_process.md#81-minimum-record-contents)（*系统认证记录中的认定——并无另设具名风险披露记录*）。
- 配合阅读：[风险评估](../../core_05_band_continuity.md#risk-evaluation)、[风险](../../core_05_band_continuity.md#risk)、[透明度](core_05_band_oversight.md#透明度)、[公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、[可质疑性](../../core_05_band_accountability.md#contestability)、[认识完整性](core_05_band_oversight.md#认识完整性)和[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)。

</details>

<br>

*通俗地说：向需要了解系统性风险的有感知者说明情况——把评估结果锁在抽屉里不算披露。*

- **定义**
  - **适用范围：**向需要了解已评估系统性[风险](../../core_05_band_continuity.md#risk)的人传达风险，使其能够理解、质疑并采取行动。
    - **持续义务：**义务不限于认证周期；凡[透明度](core_05_band_oversight.md#透明度)或[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)要求让需要了解风险的有感知者获知已评估风险时，本义务即适用。
    - **SAC 核验：**若正在进行[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)，且系统性风险纳入范围，则该披露属于认证依[第九章 §3.1 系统范围与风险因素](../../core_09_a_system_alignment_certification_evaluation.md#31-systemic-scope-and-risk-factors)须核验的事项；认定记载于[系统认证记录](../../core_05_band_continuity.md#system-certification-record)，不另设具名风险披露记录。
  - **不适用范围：**
    - [风险评估](../../core_05_band_continuity.md#risk-evaluation)本身——即评估系统性风险的义务；
    - 作为更广泛公共披露底线的[公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)；或
    - 将认定记入[系统认证记录](../../core_05_band_continuity.md#system-certification-record)，而非另立一种与[系统分类记录](../../core_05_band_continuity.md#system-classification-record)或[系统数据类型记录](../../core_05_band_continuity.md#system-data-types-record)并列的记录——这些事项各由其自身条目规定。
<a id="risk-disclosure-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验已评估的系统性风险是否真正传达到需要了解的有感知者，而不只是某处存有一份评估。

    **主要评估：**判断披露是否及时、与决策有关，并依[透明度](core_05_band_oversight.md#透明度)按实质利害适当安排。配合[风险评估](../../core_05_band_continuity.md#risk-evaluation)阅读——没有评估的披露，或没有披露的评估，都会失效。
  - **次要衡量指标：**[风险评估](../../core_05_band_continuity.md#risk-evaluation)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、[可质疑性](../../core_05_band_accountability.md#contestability)和[认识完整性](core_05_band_oversight.md#认识完整性)——即使档案中存在一些风险措辞，这些其他检查仍可揭示披露失效。

    **次要评估：**核对主要结论时，查找大段文字、细节深埋、仅供内部人员使用的渠道或迟延通知，导致需要了解风险图景的有感知者无法及时理解风险的情形。
<a id="risk-disclosure-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - [透明度](core_05_band_oversight.md#透明度)或[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)要求披露风险，却未披露；或
    - 将[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)视为唯一必须披露风险的情境。
  - **次要失效：**将仅供内部阅读的注记、深埋的附录或事后声明当成披露，而需要了解风险的有感知者无法及时使用其中的信息。

<a id="auditability"></a>

##### 可审计性

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 集群组成部分：[Def.O1 *透明度、可审计性与核验*](core_05_band_oversight.md#defo1-透明度可审计性与核验)。
- 配合阅读：[宪法四元结构](../../core_00_preamble.md#constitutional-tetrad)中的**监督**一柱；[问责](../../core_05_apex_accountability_leg.md#accountability)、[可质疑性](../../core_05_band_accountability.md#contestability)、[认识完整性](core_05_band_oversight.md#认识完整性)、[透明度](core_05_band_oversight.md#透明度)、[可核验性](core_05_band_oversight.md#可核验性)、[证据保全](core_05_band_oversight.md#证据保全)和[评估完整性约束](core_05_band_oversight.md#评估完整性约束)。
- 配合阅读：**第 XVI 条**（*审计、透明度与独立核验*）；[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)（*监督下的一种规模特别大的审计程序，不是唯一的审计规范*）；[core_02_definition_structure.md](../../core_02_definition_structure.md)第二至第四章的规范主体层机制。
- 管理人员入口（不具规范效力）：后续步骤卡片：[审计](../../implementation/STEWARD_ENTRY_DOORS.md#audit)。本定义是审计体系的属性层；三层图示见[第 XVI 条](../../core_06_rights_part_c.md#audit-three-layers)（*审计、透明度与独立核验*）。

</details>

<br>

*通俗地说：**可审计性**是外部人士能否真正重构并核验系统做过什么——涵盖所有相关时间、状态和情境，而非只看一张顺利运行的快照。对高利害系统而言，系统一致性认证是这一属性的一种规模特别大的应用方式，但并非唯一审计程序。*

- **定义**
  - **适用范围：**外部人士能否通过足够的[可核验性](core_05_band_oversight.md#可核验性)，系统检查、重构和评估系统行为，包括外部可观察性和独立核验。
    - **覆盖范围：**须涵盖所有具有实质意义的时间、状态和交互情境，不得只涵盖单一快照或顺利运行样本。
    - **监督作用：**依四元结构的**监督**一柱，监督要求具备此项属性；[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)是若干相关审计方式中的一种规模特别大、利害特别高且依赖此属性的程序。
    - **运行能力：**有约束力的义务要求具备运行能力时，可审计性包括核查合规主张是否建立在真实、可重构的能力上，而非仅有文本、断言或尚未实施的控制措施（[权限层级与内部等级](../../core_05_band_integrative.md#authority-stack-and-internal-hierarchy)的优先效力）。
  - **不适用范围：**
    - 单独的原始日志或[可核验性](core_05_band_oversight.md#可核验性)外部可观察性；
    - 单独的[透明度](core_05_band_oversight.md#透明度)或[公共监督基线披露](core_05_band_oversight.md#公共监督基线披露)；或
    - 由[可核验性](core_05_band_oversight.md#可核验性)、[证据保全](core_05_band_oversight.md#证据保全)和 CJS 规定的叶级衡量层级及实施机制——这些事项各有其规范，本身不等于可重构的可审计性。
<a id="auditability-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验外部人士能否重构和核验系统在所有相关实质性时间、状态和情境中的行为，包括核查合规主张是否建立在真实能力而非纸面材料上。

    **主要评估：**须涵盖相关条件和[利益相关方](../../core_05_band_participation.md#stakeholder)，包括与[可质疑性](../../core_05_band_accountability.md#contestability)和[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)有关的条件。检查以下方面是否存在实质失效、[风险](../../core_05_band_continuity.md#risk)及宪法失准：
    - [系统边界](../../core_05_band_continuity.md#system-boundaries)；
    - 运行状态；以及
    - [对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)。
    有约束力的义务要求运行能力时，须判断合规主张是否有经核验的能力支持，而非仅依赖：
      - 文本；
      - 断言；
      - 纸面控制措施；
      - 紧急情形下的做法；或
      - 无法观察的主张。
  - **次要衡量指标：**[可核验性](core_05_band_oversight.md#可核验性)、[证据保全](core_05_band_oversight.md#证据保全)和[可质疑性](../../core_05_band_accountability.md#contestability)——即使纸面上存在一些审计渠道，这些检查仍可揭示可审计性不足。

    **次要评估：**核对主要结论时：
    - 守护工作依赖反复进行且可比较的衡量时，审计途径应支持审查随时间的变化，并在声称已达到门槛时核查后续处理（[第一章 §16.2 制度发展](../../core_01_c_stewardship_capacity_principles.md#162-institutional-development)；[比例性](../../core_05_band_accountability.md#proportionality)）；以及
    - 确认审计范围覆盖相关评估标准、组成部分、依赖关系、行为者、条件和影响，并可用于独立[核验](core_05_band_oversight.md#可核验性)及[监督](../../core_05_apex_oversight_leg.md#oversight-constitutional)。
  - **第三层衡量指标：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)——抽样、指标或仪式性审查代替实际重构时。

    **第三层评估：**运营者依赖只为勾选合规项而设的审计渠道或过于稀疏的抽样时，适用[代理指标偏离](core_05_band_oversight.md#代理指标偏离)，检验外部人士能否真正重构经过，或审查是否只是做样子。
<a id="auditability-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - 审计机制不起作用；
    - 未能支持实际重构和评估；
    - 只采用单一快照、顺利运行样本或狭窄时间窗口，遗漏实质相关的时间、状态或交互情境；
    - 将[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)视为唯一审计程序，或视为可审计性这一属性的替代品；
    - 声称符合宪法，却无法重构或质疑其纸面主张；或
    - 有约束力的义务要求经核验的运行能力时，将以下任何一项当作充分合规依据：
      - 文本；
      - 断言；
      - 尚未实施的控制措施；
      - 支持性材料；
      - 私人文书；
      - 紧急情形下的做法；或
      - 无法观察的主张。
  - **次要失效：**
    - 在实质相关时，审计范围遗漏以下任何项目：
      - 评估标准；
      - 系统组成部分；
      - 依赖关系；
      - 行为者；
      - 条件；
      - 影响；
      - 状态；
      - 情境；或
      - [对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)；
    - 声称具有优先效力或已经合规，却压制[可质疑性](../../core_05_band_accountability.md#contestability)或妨碍可审计核验。
  - **第三层失效：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)已可合理观察，却仍将审计抽样或“指标看起来正常”视为决定性依据。

<a id="evidence-preservation"></a>

##### 证据保全

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 下游：原则：[2.1 不可协商的约束：安全与真相](../../core_01_a_values_principles.md#21-non-negotiable-principle-constraints-safety-and-truth)、[13 宪法冲突解决程序](../../core_01_b_interaction_interpretation.md#13-constitutional-collision-resolution-process)和[13.2.1 维护认识完整性](../../core_01_b_interaction_interpretation.md#1321-preservation-of-epistemic-integrity)；在实质相关时，为维护真相、安全、审查和纠正，须确保相关证据仍可获取。
- 集群组成部分：[Def.O1 *透明度、可审计性与核验*](core_05_band_oversight.md#defo1-透明度可审计性与核验)。
- 配合阅读：[可审计性](core_05_band_oversight.md#可审计性)、[可核验性](core_05_band_oversight.md#可核验性)、[透明度](core_05_band_oversight.md#透明度)、[问责](../../core_05_apex_accountability_leg.md#accountability)、[可质疑性](../../core_05_band_accountability.md#contestability)、[程序公平](../../core_05_band_participation.md#procedural-fairness)、[受保护报告（举报）](../../core_05_band_accountability.md#protected-reporting-whistleblowing)和[救济与补救](../../core_05_band_accountability.md#redress-and-remediation)。

</details>

<br>

*通俗地说：保留重要证据——识别、保护并使其可供审查——一旦已知或理应知道存在严重宪法问题，就应如此处理。*

- **定义**
  - **适用范围：**识别、保护、维护并使实质相关证据可供审查的义务；这些证据用于宪法审查、可质疑性、问责、补救、不当行为路由或地位评估，包括：
    - 记录；
    - 材料；
    - 日志；
    - 来源信息；
    - 证词；
    - 系统状态；
    - 保管信息；以及
    - 无罪或减轻责任的材料。
  - **不适用范围：**一般运营留存或备份，若其未能保护、维护并提供审查、质疑、救济或地位衡量所需的实质材料。
<a id="evidence-preservation-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验实质相关证据是否持续受到保护并可供审查，用于审计、质疑、救济和地位衡量。

    **主要评估：**保全须及时，按实质性和风险确定范围，能够追踪保管链，在可行时具备防篡改能力，并保护隐私、安全、保密和受保护报告。一旦合理知悉或理应知悉存在实质性宪法问题，即须防止：
    - 删除；
    - 更改；
    - 选择性保留；
    - 阻碍访问；或
    - 丧失重构能力。
<a id="evidence-preservation-c"></a>
- **必须满足的条件**
  - **主要失效：**以任何方式处理实质相关证据，致使可审计性、可质疑性、问责、救济途径、受保护报告、正当程序审查或地位衡量失效：
    - 销毁；
    - 更改；
    - 隐匿；
    - 选择性保全；
    - 使其无法获取；或
    - 未加保护。

<a id="evaluation-completeness-constraint"></a>

##### 评估完整性约束

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 集群组成部分：[Def.O1 *透明度、可审计性与核验*](core_05_band_oversight.md#defo1-透明度可审计性与核验)。
- 下游：监督衡量体系（*作为宪法衡量的评估覆盖范围*）；[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)（*SAC 全系统评估*）；[第九章 B 部分 §8.1](../../core_09_b_system_alignment_certification_record_process.md#81-minimum-record-contents)（*系统认证记录中的认定*）；[CS-5——设计、测试、核验与部署](../../corpus_systems/cs_05_design_testing_verification_deployment.md)（*测试、压力测试与回归测试覆盖*）。
- 配合阅读：[可审计性](core_05_band_oversight.md#可审计性)、[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)、[系统章程](../../core_05_band_continuity.md#system-charter)、[系统边界](../../core_05_band_continuity.md#system-boundaries)、[系统边界完整性](../../core_05_band_continuity.md#system-boundary-integrity)、[实质性](core_05_band_oversight.md#实质性)、[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)、[系统创建](../../core_05_band_participation.md#system-creation)和[企业创建](../../core_05_band_participation.md#business-creation)。

</details>

<br>

*通俗地说：不得根据狭窄的演示测试就声称合规——评估必须覆盖重要的失效、误用、交互及对抗路径。系统章程说明预定范围；认证则检查是否实际评估了这些困难路径。*

- **定义**
  - **适用范围：**合规主张不能建立在选择性狭窄场景集合之上；评估和保证工作须先覆盖具有实质可能性的风险路径，包括：
    - 失效；
    - 误用；
    - 交互；以及
    - 对抗路径。
  - **持续义务：**只要运营者、守护者或审查者根据评估或保证工作声称符合宪法、已做好准备或可安全依赖，即适用本约束，不限于认证周期。
  - **系统与机构章程范围程序：**系统、机构、企业或其他受守护形式存在管理其范围的[系统章程](../../core_05_band_continuity.md#system-charter)或[机构章程](../../core_05_band_continuity.md#institutional-charter)（或等效的已发布范围文书）时，评估须将章程所定目的和范围内／范围外限制，与实际观察到的[系统边界](../../core_05_band_continuity.md#system-boundaries)及范围内部和边缘的可信风险路径进行对照测试。系统章程或机构章程的文字不能缩小必须评估的风险路径。
  - **SAC 核验：**若正在进行[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)，则认证须依[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)至[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)核验本约束，包括依[第九章 §3.1 系统范围与风险因素](../../core_09_a_system_alignment_certification_evaluation.md#31-systemic-scope-and-risk-factors)检查章程范围与功能边界，并依[CS-5](../../corpus_systems/cs_05_design_testing_verification_deployment.md)（*面向用户的能力表面*）检查按类别分级的测试／回归覆盖。认定记载于[系统认证记录](../../core_05_band_continuity.md#system-certification-record)。
  - **不适用范围：**
    - 单独作为范围文书的[系统章程](../../core_05_band_continuity.md#system-charter)文字——系统章程陈述预定范围，本身不构成评估覆盖；
    - [系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)的程序机制本身——认证可核验本约束，但约束并非只在认证情境适用；或
    - 未被用作完整宪法评估的一般单元测试或功能测试。
<a id="evaluation-completeness-constraint-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验评估是否涵盖可信的失效、误用、交互及对抗路径，而非仅检查精选的演示场景。

    **主要评估：**按照系统影响、[依赖关系](../../core_05_band_continuity.md#dependency)和[风险](../../core_05_band_continuity.md#risk)确定规模，充分覆盖可信风险路径，包括：
    - 失效；
    - 误用；
    - 交互；以及
    - 具有实质意义时的[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)。
    还须检查：
      - 存在[系统章程](../../core_05_band_continuity.md#system-charter)时，评估是否将章程范围与实际观察到的边界进行测试，而非将系统章程当作完整场景清单；以及
      - 正在进行[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)时，全系统评估及依[第九章 §3 全系统认证评估](../../core_09_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)、[§4 涉及时的评估](../../core_09_a_system_alignment_certification_evaluation.md#4-evaluations-where-implicated)和[§5 权利底线与领域评估](../../core_09_a_system_alignment_certification_evaluation.md#5-rights-floor-and-domain-evaluations)作出的记录，是否反映这些覆盖范围。
<a id="evaluation-completeness-constraint-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - 仍有可信的失效、误用、交互或对抗路径未评估，却将精选演示场景或营销测试套件作为完整评估；
    - 评估不完整或范围经过选择性限定，破坏[实质性](core_05_band_oversight.md#实质性)、[可审计性](core_05_band_oversight.md#可审计性)或[系统边界完整性](../../core_05_band_continuity.md#system-boundary-integrity)；或
    - 将[系统一致性认证](../../core_05_band_continuity.md#system-alignment-certification)视为评估完整性唯一适用的情境。
  - **次要失效：**系统章程文字、机构授权措辞、企业宗旨声明或狭窄的认证演示测试套件被当作完整评估，而以下任何项目仍未评估：
    - 失效；
    - 误用；
    - 交互；或
    - 对抗路径。

##### 可核验性

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 集群组成部分：[Def.O1 *透明度、可审计性与核验*](core_05_band_oversight.md#defo1-透明度可审计性与核验)。

- 配合阅读：[可审计性](core_05_band_oversight.md#可审计性)、[透明度](core_05_band_oversight.md#透明度)、[可质疑性](../../core_05_band_accountability.md#contestability)、[比例性](../../core_05_band_accountability.md#proportionality)、[可行性](../../core_05_band_accountability.md#feasibility)、[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)和[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)。

</details>

<br>

*通俗地说：外部人士能够观察并衡量系统的行为，而且独立人员能在实际情况下核查这些观察结果——不能只依赖运营者内部所见、听信运营者说法，或仅在纸面上保有核验权。*

- **定义**
  - **适用范围：**能否为实现[可审计性](core_05_band_oversight.md#可审计性)，从外部观察、衡量并独立核实系统行为、输出和影响。构成条件包括：
    - 外部可观察性是独立核验的前提；
    - 实际访问（[第 XVI-C 条](../../core_06_rights_part_c.md#article-xvi-c-verification-accessibility)（*核验可及性*）；[可行性](../../core_05_band_accountability.md#feasibility)）；
    - 独立于运营者自我声明；
    - 依据[比例性](../../core_05_band_accountability.md#proportionality)和[实质影响](core_05_band_oversight.md#实质影响)确定适当负担；以及
    - 在一般压力、误用及[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)下保持可靠。
  - **不适用范围：**
    - 单独的内部遥测或面向运营者的仪器；或
    - [可审计性](core_05_band_oversight.md#可审计性)规定的重构义务本身——这些事项各有其规范，本身不等于独立的外部核验。

**纳入范围。**事项在实质上涉及以下内容时，适用本集群：
- 如实呈现状态；
- 具有实质误导性的沟通；
- 压制或扭曲与决策有关的信息；
- 对高影响主张保持科学或经验完整性；
- 如实说明方法及限制；
- 处理不确定性；
- 可预见的运行条件；
- 对抗或扩展规模下的误用情境；或
- 将真相与完整性义务拆分到披露、审计、核验或发布渠道中。
若事项不在此范围内，各组成定义仍可单独适用，无须因此引入整个集群。

符合纳入范围时，本集群规定与决策有关事实和限制的诚实呈现，并要求证据、不确定性、披露和质疑采用诚实方法。若方法、不确定性的处理或可预见情境分析仍不合格，仅勾选披露或发布合规项并不足够。

**集群成员。**本集群包括：

- [真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)——诚实处理与决策有关主张中的已知、未知和不确定事项；
- [认识完整性](core_05_band_oversight.md#认识完整性)——方法与证据基础须诚实且可核查；
- [可预见性与合理可预见](core_05_band_oversight.md#可预见性与合理可预见)——与**真相**和**认识完整性**一并阅读的可预见性机制子块（并非独立的集群首项）；以及
- [发布与高影响沟通](core_05_band_oversight.md#发布与高影响沟通)——与**真相**、**认识完整性**和**可预见性**一并阅读的发布行为底线子块（并非独立的集群首项）。

**反规避。**划分披露、发布、方法、不确定性、完整性、核验和可预见性等环节，若满足一项却破坏另一项，即属不合规。仅形式上符合披露或发布规则并不足够；可预见情境分析、方法完整性或对限制与不确定性的诚实说明仍有实质缺陷时亦然。

参见**反分割原则**。

*衡量（体系路由）：*依监督衡量体系衡量。具体指标见下列[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)和[认识完整性](core_05_band_oversight.md#认识完整性)。

<a id="publication-truthfulness-and-recklessness-floor"></a>

##### 发布真实性与鲁莽漠视底线

*通俗地说：若将内容作为事实发布，不得明知其为虚假；也不得鲁莽地无视准确性、不确定性、语境或实质性解释界限。*

- **定义**
  - **适用范围：**在[信息领域](../../core_05_band_participation.md#info-sphere)内，将内容作为事实断言发布或沟通时，对沟通行为的限制。
  - **不适用范围：**
    - 未作为事实断言呈现的意见、评论或讽刺；以及
    - 善意错误，且既非明知虚假，也非鲁莽漠视准确性、不确定性、语境或实质性解释界限。
<a id="publication-truthfulness-and-recklessness-floor-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验发布的事实是否诚实说明准确性、不确定性、语境及解释限制，并区分明知虚假或鲁莽漠视与善意观察。

    **主要评估：**依据[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)和[善意](../../core_05_band_accountability.md#good-faith)，区分明知虚假或鲁莽漠视下列事项：
    - 准确性；
    - 不确定性；
    - 语境；或
    - 实质性解释界限，
    与善意观察和有界解释。
<a id="publication-truthfulness-and-recklessness-floor-c"></a>
- **必须满足的条件**
  - 依据具体情形，善意发布观察、证据和有界解释，受第十三章**第 IX、XIII 和 XIV 条**共同规范，并须同时符合[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)、[善意](../../core_05_band_accountability.md#good-faith)及[认识完整性](core_05_band_oversight.md#认识完整性)。
  - **主要失效：**明知内容虚假仍发布，或发布时鲁莽漠视：
    - 准确性；
    - 不确定性；
    - 语境；或
    - 实质性解释界限。

<a id="protected-data-and-internal-state-publication-constraint"></a>

##### 受保护数据与内部状态发布约束

*通俗地说：不得发布受限数据，也不得暴露其他有感知者受保护的内在认知或情绪状态。*

- **定义**
  - **适用范围：**在[信息领域](../../core_05_band_participation.md#info-sphere)内，对违反受限数据规则或暴露受保护内部状态的内容发布加以限制。
  - **不适用范围：**一般公开事实、依法发布的信息，或基于系统性伤害理由而非受保护数据或内部状态暴露所作的发布限制。
<a id="protected-data-and-internal-state-publication-constraint-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验发布是否遵守受限数据规则和受保护内部状态界限，而非重构或暴露受保护的认知或情绪状态。

    **主要评估：**发布不得规避**[corpus_systems.md](../../corpus_systems.md)**、CS-2——信息类型与处理方式、[隐私（信息）](../../core_05_band_continuity.md#privacy-informational)、[受保护内部状态边界](../../core_05_band_continuity.md#protected-internal-state-boundary)或 **N 类**处理规则。除非本宪法明确许可，发布不得重构、推断或暴露其他有感知者受保护的内在认知或情绪状态。
<a id="protected-data-and-internal-state-publication-constraint-c"></a>
- **必须满足的条件**
  - **主要失效：**发布违反受限数据规则、规避 CS-2（*信息类型与处理方式*）处理规则，或违反[隐私（信息）](../../core_05_band_continuity.md#privacy-informational)和[受保护内部状态边界](../../core_05_band_continuity.md#protected-internal-state-boundary)而暴露受保护内部状态。

<a id="high-impact-and-systemic-harm-publication-constraint"></a>

##### 高影响与系统性伤害发布约束
*通俗地说：即使发布的内容属实，若可预见地助长定向伤害、胁迫、大规模有害协调或级联失效，也可对其加以限制。*

- **定义**
  - **适用范围：**通过可能广泛影响共享信息环境（[信息领域](../../core_05_band_participation.md#info-sphere)、造成[伤害](../../core_05_band_accountability.md#harm)或影响有感知者协调方式的渠道发布内容。
  - **不适用范围：**没有可预见系统性伤害或有害协调路径的一般真实报道，或依鲁莽漠视底线处理的一般真实性争议。
<a id="high-impact-and-systemic-harm-publication-constraint-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验发布对协调、安全和信息领域完整性的主要影响或[合理可预见](core_05_band_oversight.md#合理可预见)影响，是否符合合乎比例的传播限制。

    **主要评估：**考虑对以下事项的主要及[合理可预见](core_05_band_oversight.md#合理可预见)影响：
    - 协调；
    - [安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)；
    - 对弱点的利用；以及
    - [信息领域](../../core_05_band_participation.md#info-sphere)完整性。
<a id="high-impact-and-systemic-harm-publication-constraint-c"></a>
- **必须满足的条件**
  - 即使发布内容在事实上准确，若其主要或[合理可预见](core_05_band_oversight.md#合理可预见)的效果是助长下列行为，仍须加以限制：
    - 定向[伤害](../../core_05_band_accountability.md#harm)；
    - [胁迫与操纵](../../core_05_band_participation.md#coercion-and-manipulation)；
    - 大规模有害协调；
    - [级联失效](../../core_05_band_continuity.md#cascading-failure)；或
    - 实质损害[认识完整性](core_05_band_oversight.md#认识完整性)的模式。
  - 依据**[corpus_systems.md](../../corpus_systems.md)**、CS-3——系统分类与处理方式，**A 类**及**B 类**系统须对传播机制和保障措施施加更严格且合乎比例的约束。
  - **主要失效：**发布未遵守针对上述主要或合理可预见影响所要求的合乎比例的传播限制和保障措施，包括对**A 类**和**B 类**系统要求的加强限制。

<a id="security-sensitive-disclosure-balance"></a>

##### 安全敏感披露权衡

*通俗地说：权衡披露收益与其助人攻破保障措施或操纵系统的风险；为善意安全研究者（白帽）提供真正可用的低风险发现发布渠道，并在修复措施到位前暂缓可能助长攻击的细节。*

- **定义**
  - **适用范围：**可能助长对保障措施的利用之披露，包括善意安全研究者发布发现的方式。
  - **不适用范围：**没有利用风险权衡的一概保密；不会助人绕过保障措施的一般透明度披露；或缓解措施完成后永久压制研究者发布低风险发现。
<a id="security-sensitive-disclosure-balance-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验披露收益是否高于可预见的利用、规避或对抗性操纵风险。

    **主要评估：**依照第二至第四章和第一章，并结合[风险](../../core_05_band_continuity.md#risk)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)和[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)，权衡披露收益和以下可预见风险：
    - 利用；
    - 规避；或
    - 对抗性操纵。
  - **次要衡量指标：**善意研究者发布渠道及延迟发布攻击细节的时间安排——依据 **S 类**延迟披露和 **CJS-3.22**（*受约束的保密与受保护调查条款*）进行共同衡量。

    **次要评估：**评估是否存在可用渠道，使低风险发现能够发布；并检验是否依照**[corpus_systems.md](../../corpus_systems.md)**、CS-2——信息类型与处理方式的 **S 类**延迟披露，以及 **CJS-3.22**（*受约束的保密与受保护调查条款*），在安全缓解措施完成前延迟发布可能助长攻击的细节。
<a id="security-sensitive-disclosure-balance-c"></a>
- **必须满足的条件**
  - 必须为善意安全研究者提供可用且不受报复的低风险信息发布渠道，包括告知漏洞存在及发布不助长攻击的细节，不得仅因研究者发布行为而将其视为禁止披露。
  - 可能助长攻击或具有其他高风险的安全细节，须在安全缓解措施完成前暂缓发布；或在 CS-2 信息类型与处理方式规定的 **S 类**（或等效）限制理由终止前予以暂缓，并依 **O 类**摘要规则处理。
  - **主要失效：**在符合第二至第四章、第一章、[风险](../../core_05_band_continuity.md#risk)、[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)及[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)的情况下：
    - 在利用风险或对抗性操纵风险高于披露收益时，发布会对规避保障或对抗性操纵造成实质助益的内容；
    - 压制善意研究者发布低风险发现；或
    - 缓解措施完成后，在不再有正当理由适用 **S 类**（或等效）限制时，仍无限期暂缓发布可披露的细节。

<a id="truth-constitutional-constraint"></a>

##### 真相（宪法约束）

*通俗地说：主张与决策有关时，须诚实说明已知、未知和不确定之处；不得欺骗、扭曲或以结构误导他人。*

<a id="truth-constitutional-constraint-o"></a>
- **定义**
  - **适用范围：**涉及实质性决策相关主张、陈述、风险沟通或合规声明时，对系统内部运作和外部沟通施加不可协商的约束。要求：
    - 诚实说明已知、未知和不确定事项；
    - 抵制欺骗、扭曲及结构性误导呈现；以及
    - 按第二至第四章的利害程度确定评估方法。
  - **依赖：**[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)——依据[第一章 §2.1 不可协商的原则约束：安全与真相](../../core_01_a_values_principles.md#21-non-negotiable-principle-constraints-safety-and-truth)，两者是配对的不可协商约束；安全具有实质利害时，真相义务包括如实沟通风险和不确定性。
  - **不适用范围：**
    - 仅有礼貌语气或程序礼节；或
    - 权利、安全或治理真相认定以外的一般经济信号，例如市场价格或赔率——这些本身不构成本约束。
<a id="truth-constitutional-constraint-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验与实质决策有关的主张是否诚实说明已知、未知和不确定事项，并抵制欺骗、扭曲及结构性误导呈现。

    **主要评估：**判断对知情决策和可审计性的实际影响，并依[实质影响](core_05_band_oversight.md#实质影响)、[依赖关系](../../core_05_band_continuity.md#dependency)和[风险](../../core_05_band_continuity.md#risk)调整审查强度；要求方法诚实、如实处理不确定性，并在证据否定既有结论时予以修正。
  - **次要衡量指标：**[认识完整性](core_05_band_oversight.md#认识完整性)、[可审计性](core_05_band_oversight.md#可审计性)、[透明度](core_05_band_oversight.md#透明度)和[实质性](core_05_band_oversight.md#实质性)——即使存在正式披露，这些共同指标仍可揭示真相要求未获满足。

    **次要评估：**核对主要结论时，纳入可能妨碍诚实理解或核验的[认识完整性](core_05_band_oversight.md#认识完整性)、[可审计性](core_05_band_oversight.md#可审计性)和[透明度](core_05_band_oversight.md#透明度)路径。
  - **第三层衡量指标：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)——当指标、市场信号或机构断言代替诚实的宪法评估时。

    **第三层评估：**运营者依赖代理指标、赔率、价格或合规指标时，适用[代理指标偏离](core_05_band_oversight.md#代理指标偏离)，将持久真实情况与代理指标处理量或机构断言区分开来。
<a id="truth-constitutional-constraint-c"></a>
- **必须满足的条件**
  - **主要失效：**通过以下方式实质损害可靠理解或可审计完整性：
    - 欺骗；
    - 扭曲；
    - 压制；
    - 选择性披露；或
    - 结构性误导呈现——包括以礼貌语气或程序形式取代对已知、未知及不确定事项的诚实处理。
  - **次要失效：**在实质相关时，以术语、层层堆叠的复杂内容或程序不透明妨碍[可质疑性](../../core_05_band_accountability.md#contestability)或[可审计性](core_05_band_oversight.md#可审计性)。
  - **第三层失效：**第一章禁止替代使用时，仍将价格、赔率或市场结算来源作为权利、安全或治理真相认定的充分依据；或在[代理指标偏离](core_05_band_oversight.md#代理指标偏离)已可合理观察后拒绝纠正。

<a id="epistemic-integrity"></a>

##### 认识完整性

*通俗地说：评估所依据的方法和证据必须诚实且可核查；声望、不透明性或文书手续不能代替真相。*

<a id="epistemic-integrity-o"></a>
- **定义**
  - **适用范围：**宪法相关评估所用方法、证据基础和沟通内容的完整性，包括清楚说明：
    - 限制；
    - 不确定性；
    - 相互冲突的证据；以及
    - 可受质疑的推理步骤——
    使[真相（宪法约束）](core_05_band_oversight.md#真相宪法约束)不能通过程序形式、模型不透明或不可审计的推理遭到规避。
  - **不适用范围：**
    - 单独的方法文档；
    - 机构声望排名；或
    - 没有宪法相关评估利害的一般文风润色——这些本身都不等于认识完整性。
<a id="epistemic-integrity-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验方法、证据及可质疑推理是否诚实且可核查，避免以文书手续、黑箱不透明或声望代替真相。

    **主要评估：**在安全与保密限制内，按利害程度要求适当公开方法；并留意是否以以下任何一项代替真正的完整性：
    - 权威；
    - 声望；
    - 规模；或
    - 复杂性。
  - **次要衡量指标：**[可审计性](core_05_band_oversight.md#可审计性)、[可核验性](core_05_band_oversight.md#可核验性)、[透明度](core_05_band_oversight.md#透明度)和[可质疑性](../../core_05_band_accountability.md#contestability)——即使方法已有正式记录，这些共同指标仍可揭示认识完整性不足。

    **次要评估：**核对主要结论时，在相关之处同时检查[可审计性](core_05_band_oversight.md#可审计性)、[可核验性](core_05_band_oversight.md#可核验性)和[可质疑性](../../core_05_band_accountability.md#contestability)，并依[可预见性](core_05_band_oversight.md#可预见性)纳入可预见的误用和对抗测试。
  - **第三层衡量指标：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)——当权威、声望、规模或复杂性代替可证明的完整性时。

    **第三层评估：**运营者依赖权威、模型不透明或无法核实的断言时，适用[代理指标偏离](core_05_band_oversight.md#代理指标偏离)，将持久的认识完整性与程序形式区分开来。
<a id="epistemic-integrity-c"></a>
- **必须满足的条件**
  - **主要失效：**
    - 主张听起来真实，却未诚实说明方法、限制和可质疑推理；
    - 评估或沟通方式妨碍诚实处理不确定性；或
    - 实质要求审计时仍采用不可审计的推理。
  - **次要失效：**方法选择可预见地阻碍核验或有意义的质疑；在可合理取得可观察证据时，完整性主张仍以无法核验的断言为依据。
  - **第三层失效：**[代理指标偏离](core_05_band_oversight.md#代理指标偏离)已可合理观察，却仍将正式方法文件或机构声望视为决定性依据。

##### 可预见性与合理可预见

<details>
<summary><strong><span style="color: #2563eb;">追溯</span></strong></summary>

- 配合阅读：适用[实质性](core_05_band_oversight.md#实质性)、[评估完整性约束](core_05_band_oversight.md#评估完整性约束)、[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)、[可审计性](core_05_band_oversight.md#可审计性)、[比例性](../../core_05_band_accountability.md#proportionality)、[系统边界](../../core_05_band_continuity.md#system-boundaries)，以及在实质牵涉时适用的第二至第四章机制。

</details>

<br>

**纳入范围。**事项在实质上涉及以下内容时，适用本子块：
- 在行动之前，能否合理识别下列事项：
  - 结果；
  - 风险；
  - 伤害；
  - 误用路径；或
  - 运行条件；
- “我们无法预见”之类的主张是否有正当依据；
- 分析深度、范围和规模是否符合[实质影响](core_05_band_oversight.md#实质影响)、[实质风险](core_05_band_oversight.md#实质风险)、[风险](../../core_05_band_continuity.md#risk)和[依赖关系](../../core_05_band_continuity.md#dependency)；或
- 评估是否不完整，以致妨碍[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)、[风险](../../core_05_band_continuity.md#risk)评估或[可预见性](core_05_band_oversight.md#可预见性)。
若事项不在此范围内，各个条目仍可单独适用，无须引入完整组合。

符合纳入范围时，本嵌套子块是 Def.O2 *真相与认识完整性*中可预见性机制的共同规范归属。第二至第四章中所有“合理可预见”用法，均专由这些定义规范；援引时须保持明确可追溯性（[第二章 §3——定义体系内部一致性](../../core_02_definition_structure.md#3-consistency-across-the-definition-stack)）。

**子块成员。**本子块包括：

- [可预见性](core_05_band_oversight.md#可预见性)——与影响相称的合理分析：所需深度、评估边界、不完整性失效及有正当依据的不可预见主张；以及
- [合理可预见](core_05_band_oversight.md#合理可预见)——谨慎分析者运用已知方法，在行动前能够识别的结果。

**反规避。**划分深度、边界、主张举证责任、不完整性和合理可预见性等环节，若满足一项却破坏另一项，即属不合规。在纳入范围内，未提供符合审计要求的正当依据却声称不可预见，或在对抗、扩展、重复或误用情境具有实质意义时只评估最佳情况，均属不合规。

参见**反分割原则**。

<a id="foreseeability"></a>
##### 可预见性

*通俗地说：进行与影响相称的合理分析——利害越高，分析越深入；涵盖必要边界，包括交互、依赖关系和对抗性使用；若声称某事不可预见，须说明理由。断言和核对清单都不够。*

- **定义**
  - **适用范围：**与影响相称的合理分析标准，包括：
    - 依[比例性](../../core_05_band_accountability.md#proportionality)，按[实质影响](core_05_band_oversight.md#实质影响)、[风险](../../core_05_band_continuity.md#risk)和[依赖关系](../../core_05_band_continuity.md#dependency)确定分析深度；
    - 必需的评估边界，包括：
      - 交互；
      - 依赖关系；
      - 对抗性使用；以及
      - 相关的[系统边界](../../core_05_band_continuity.md#system-boundaries)；
    - 实际进行该评估的义务；以及
    - 依[合理可预见](core_05_band_oversight.md#合理可预见)规定，对不可预见主张承担说明责任。
  - **不适用范围：**
    - 经尽责评估后仍不可预见的结果；
    - 对所有可设想结果进行无边界推测性审查——该事项属于[合理可预见](core_05_band_oversight.md#合理可预见)条目的排除范围；或
    - 对每个低利害案件都要求一律采用最高强度分析——分析深度须按影响调整，并非不受限制地追求最大强度。
<a id="foreseeability-burden-a"></a>
<a id="foreseeability-failure-a"></a>
<a id="foreseeability-scaling-a"></a>
<a id="foreseeability-scope-a"></a>
<a id="foreseeability-diligence-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验分析深度是否符合影响、风险和依赖关系，是否涵盖必要边界，是否实际执行评估，以及不可预见主张是否有符合审计要求的正当依据。

    **主要评估：**纳入依[可预见性](core_05_band_oversight.md#合理可预见)能够通过已知方法和模式识别的事项，并按以下因素调整：
    - [实质影响](core_05_band_oversight.md#实质影响)；
    - [风险](../../core_05_band_continuity.md#risk)；以及
    - [依赖关系](../../core_05_band_continuity.md#dependency)。
    评估边界还须涵盖：
    - 交互；
    - [依赖关系](../../core_05_band_continuity.md#dependency)；
    - 对抗性使用；以及
    - 相关的[系统边界](../../core_05_band_continuity.md#system-boundaries)。
    对不可预见主张提供符合[可审计性](core_05_band_oversight.md#可审计性)要求的正当依据。识别会妨碍尽责分析、[风险](../../core_05_band_continuity.md#risk)评估或[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)的不完整情形。
<a id="foreseeability-burden-c"></a>
<a id="foreseeability-failure-c"></a>
<a id="foreseeability-scaling-c"></a>
<a id="foreseeability-scope-c"></a>
<a id="foreseeability-diligence-c"></a>
- **必须满足的条件**
  - 分析深度须按[实质影响](core_05_band_oversight.md#实质影响)和[风险](../../core_05_band_continuity.md#risk)调整——既不能对每个低利害案件一律采用最高强度，也不能在影响很大时仅作表面分析。
  - 评估边界须包括：
    - 交互；
    - [依赖关系](../../core_05_band_continuity.md#dependency)；
    - 对抗性使用；以及
    - 相关的[系统边界](../../core_05_band_continuity.md#system-boundaries)。
  - 不可预见主张须有符合[可审计性](core_05_band_oversight.md#可审计性)要求的正当依据——单纯断言不足。
  - **主要失效：**
    - 仅勾选项目、却未真正评估可预见性；
    - 未提供符合审计要求的正当依据，仅断言某事不可预见；
    - 为了缩小评估范围而自利地排除事项，低于必需边界；
    - 未达到本标准或未进行必需的可预见性评估；
    - 影响很大却只作表面分析；
    - 将范围限制在必需边界以下；
    - 不可预见主张缺乏充分理由；或
    - 不完整性妨碍[可预见性](core_05_band_oversight.md#可预见性)、[风险](../../core_05_band_continuity.md#risk)评估或[安全（宪法约束）](../../core_05_band_continuity.md#safety-constitutional-constraint)。

<a id="reasonably-foreseeable"></a>

##### 合理可预见

*通俗地说：谨慎分析者运用已知方法，在行动前能够识别的结果，包括对抗及扩展规模下的结果；不是所有可以设想的结果，也不是纯粹事后诸葛亮。*

- **定义**
  - **适用范围：**依[可预见性](core_05_band_oversight.md#可预见性)，使用领域知识和分析方法能够识别的结果。
  - **不适用范围：**所有可以设想的结果、纯粹事后回顾，或只有依赖合理尽责所不要求的知识或方法才能知道的结果。
<a id="reasonably-foreseeable-a"></a>
- **衡量与评估方式**
  - **主要衡量指标：**[监督衡量体系](../../core_05_apex_oversight_leg.md#measuring-oversight-preamble-measurement-family)——*有感知者能否看见、核实并信赖系统所呈现的内容？*在此检验合理尽责下能够识别的结果是否纳入评估，包括对抗和扩展条件；不得通过事后诸葛亮式规避或只看最佳情况而将其排除。

    **主要评估：**纳入对抗和扩展条件，包括[对抗、扩展及受操纵条件](core_05_band_oversight.md#对抗规模化与遭利用的条件)。
<a id="reasonably-foreseeable-c"></a>
- **必须满足的条件**
  - **主要失效：**排除上述结果。
