*用直白的话说：让感知者以及他们所依赖的生命系统长期运转下去 — 稳定、可持续、能够反弹，并且生态健全 — 而不是眼下看起来还行。*

- **它是什么**
  - **范围内：** 用[宪法宗旨分解](#continuity-aim-decomposition)所列延续构件与测量族来对照本宗旨判断系统。该宗旨是感知者及其所依赖的生命支撑系统的长时域稳定、可持续性、韧性与生态福祉。
  - **依赖于：** [序言 §1](core_00_preamble.md#continuity)中点名的主题。每一用语的详细范围与如何测量规则住在其自身定义上；从[宪法宗旨分解](#continuity-aim-decomposition)开始：
    - [尽责管理](../../core_05_band_continuity.md#stewardship-constitutional)；
    - [自愈](../../core_05_band_continuity.md#self-healing-constitutional)；
    - [可持续性](../../core_05_band_continuity.md#sustainability)；
    - [生态完整性](../../core_05_band_continuity.md#ecological-integrity-constitutional)；
    - [环境先决条件](../../core_05_band_continuity.md#environmental-preconditions-constitutional)；
    - [代际责任](../../core_05_band_continuity.md#intergenerational-responsibility-constitutional)；
    - [依赖](../../core_05_band_continuity.md#dependency)；与
    - [相称跨系统贡献](../../core_05_band_continuity.md#proportionate-cross-system-support-constitutional)。
  - **范围外：** [原住民延续](../../core_05_band_continuity.md#indigenous-continuity-constitutional)，除非正文明示将其纳入；由带文件与 CJS 主责的叶定义细节、测量层级与实施机制。
<a id="continuity-aim-constitutional-m"></a>
<a id="continuity-aim-constitutional-a"></a>
- **如何测量与评估**
  - **主要测量：** [延续测量族](#continuity-measurement-family) — *感知者与系统能否持久 — 在生态上、可靠地、并穿越失败？* 亦见[宪法宗旨分解](#continuity-aim-decomposition)。本行只指向那些测量；如何测量的规则坐落在每一项被链接的定义上。
  - **主要评估：** 在[宪法四元](core_00_preamble.md#constitutional-tetrad)下判断，按[实质利害](core_00_preamble.md#material-stake)缩放。问一问系统是否保持持久能力去修复、适应、诚实面对风险，并留在生态限度之内 — 而不是今天的数字看起来是否平静。把所主张的延续结果系到[构成](#continuity-aim-decomposition)条件上，依据第四章与[第一章 §11.1.5](core_01_c_stewardship_capacity_principles.md#1115-constitutional-outcome-claims-discipline)。
<a id="continuity-aim-constitutional-c"></a>
- **必须成立什么**
  - **主要失败：**
    - 用**延续**永远推迟修补；
    - 把「稳定」当作合规，当它建立在隐蔽风险倾倒、不可逆伤害或把生态负担转嫁给他人之上；
    - 用普通的「让灯一直亮着」话术去阻断[可质疑性](../../core_05_band_accountability.md#contestability)或[及时解决](../../core_05_band_accountability.md#timely-resolution-constitutional)；或
    - 以实质击败[繁盛](../../core_05_apex_flourishing_aim.md#flourishing-constitutional)的方式追求**延续**，而没有[第一章 §6](core_01_b_interaction_interpretation.md#6-process-conflict-resolution)下的明确许可。
