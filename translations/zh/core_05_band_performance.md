本文件是**宪法绩效**测量族的家园 — 关于系统是否真正在无无谓浪费的情况下交付宪法结果的问题。详细定义本身**不在此处**。它们全部住在[延续带](core_05_band_continuity.md)。
- 原因：那些定义属于延续的尽责管理主题 — 持久能力、浪费，以及所耗资源换得真实结果。见[效率 / 能力 / 负担主题组](core_05_band_continuity.md#constitutional-efficiency)与[相称性–负担–效率簇](core_05_band_continuity.md#proportionality-necessity-feasibility-burden-and-efficiency-cluster)。
- 这些问题仍服务两项宪法宗旨（[**繁盛**](core_00_preamble.md#flourishing)与[**延续**](core_00_preamble.md#continuity)）。

<a id="measuring-constitutional-performance-preamble-measurement-family"></a>
### 测量宪法绩效（序言测量族）

*用直白的话说：这些问题问宪法成果是否真正在不浪费感知者时间、努力或材料的情况下得到交付。*

*宪法绩效测量族的第五章家园。序言 §2 在总览表中保留直白的类别问题；族表、宪法用途与定义路由住在此处。*

*实质性*（[实质性认定](core_05_band_oversight.md#materiality-determination)）是整合性的 — 不是单独的测量类别；它在[实质利害](core_00_preamble.md#material-stake)下缩放本族适用的强度。

| 测量族 | 直白问题 | 主要宪法用途 |
|---|---|---|
| [宪法效率](core_05_band_continuity.md#constitutional-efficiency) | 宪法成果是否真正正在被交付？ | 防止替代指标取代真实保护 |
| [可避免负担](core_05_band_continuity.md#avoidable-burden) | 系统是否在浪费感知者时间、努力、材料、基础设施或能源？ | 减少不必要的摩擦 |
| [生产能力](core_05_band_continuity.md#productive-capacity-constitutional) | 感知者与系统能否继续产出对齐成果？ | 在无生态负担转嫁的情况下保护持久能力 |

这些横断测量问系统是否有效交付宪法成果、避免无谓浪费，并保全继续产出对齐结果的能力 — 对[**繁盛**](core_00_preamble.md#flourishing)与[**延续**](core_00_preamble.md#continuity)都是工具。

- 操作性测量层级住在第五章定义家园上 — 见[宪法效率](core_05_band_continuity.md#constitutional-efficiency)、[可避免负担](core_05_band_continuity.md#avoidable-burden)、[生产能力](core_05_band_continuity.md#productive-capacity-constitutional)与[负担减轻义务](core_05_band_continuity.md#burden-reduction-duty-constitutional)。
- 绩效目标、奖赏与资源测量仅在仍可追溯到宪法成果的限度内有效。
- 它们不得替代宪法效率、[生产能力](core_05_band_continuity.md#productive-capacity-constitutional)或权利底线遵从。
- 一并阅读[第七章 §3 整系统认证评价](../../core_07_a_system_alignment_certification_evaluation.md#3-whole-system-certification-evaluation)，凡整系统绩效具有实质性而在范围内。
