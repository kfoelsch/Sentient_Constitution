### 1. 第八章记录不得更改

*用直白的话说：本章从第八章已经做成的经核实记录开始。它不得重开事实、猜测一条缺失的轨道，或挑选评级以得到偏好结果。*

第九章从第八章下产出的经核实轨迹记录开始。它只使用适用于该决定的记录，并使贡献记录与违规记录保持分开：

- 若贡献适用，使用**贡献轨迹记录**，包括：
  - 其经核实事实；
  - 贡献轴槽位；
  - 支持证据；
  - 范围；
  - 时间期间；
  - 审查状态；以及
  - 贡献描述符。
- 若违规适用，使用**违规轨迹记录**，包括：
  - 其经核实事实；
  - 违规轴槽位；
  - 支持证据；
  - 范围；
  - 时间期间；
  - 审查状态；
  - 过程或回应品格；以及
  - 违规描述符。

一项问题 3 决定可以只处理贡献、只处理违规，或两者都处理。若一条轴不适用，决定可以在没有它的情况下推进。决定者不得靠猜测、依赖一项指控，或制造一份人为的零值记录来填补缺口。

第九章必须精确按第八章所确立者使用事实与测量。它不得：

- 重开事实；
- 为产出想要的后果而挑选槽位；
- 重新计算 LEQU 影响；或
- 把两轴合成一个净分。

下列各项不算轨迹：

- 指控；
- 收件标签；
- 未经裁决的主张；
- 名声；
- 路由标签；或
- 临时描述。

提交案件本身不是轨迹。

问题 3 决定本身并不更改第八章槽位。若评议所核实了流程链错误或实质性新事实 — 包括日后发现的效果 — 它可以搁置该记录，或要求按第八章予以更新、更正或替代。任何新槽位必须遵循第八章的测量过程，保全审计轨迹，并使两轴保持分开。

[权利底线](core_06_rights_part_a.md#chapter-six-foundational-rights)不依赖轨迹，也不能被一项轨迹决定更改。任何后果都不得减低固有尊严、平等道德地位、生存关键通路，或质疑、审查、上诉与救济所要求的路径。

<a id="2-automatic-integration-review-and-continuity"></a>
### 2. 自动整合、审查与连续性

*用直白的话说：当一份经核实记录打开或更改时，一份整合记录必须自动跟上，使两条轨道保持分开，并保持可检查 — 包括在计算机停机时。*

轨迹系统必须在一份适用的第八章记录被打开、更新、更正或替代时，自动创建或更新一份分开的**整合记录**。整合记录交叉引用其源记录，但不改动它们。系统必须使贡献记录与违规记录保持分开，而不是把它们合成一份滚动余额或终身分数。

每一份整合记录必须标明：

1. 每一份源记录及其当前版本；
2. 每一项适用的固定贡献轴或违规轴测量；
3. 每一项归一化描述符与附着；
4. 受影响的感知者、利益、系统与具名路径；
5. 违规侧的纠正、救济、保障与锁定；
6. 贡献侧的当前性与能力许可结果；
7. 每一条具名路径的最终轨迹效果；
8. 实施里程碑、审查路由与再评估触发；以及
9. 任何第十章门户状态。

凡经核实输入与已公布规则产出确定结果之处，自动化可以完成任何步骤。除非本宪法或已采纳实施要求审查，否则不需要额外的人工批准。系统必须把不确定、有争议、新颖、具有实质裁量或高影响的问题提交给获授权的审阅者或评议所。一份需要审查的记录仍可被自动汇编并路由。

下列处理顺序适用于自动决定与人工决定：

1. 核验第八章记录及其当前审查状态；
2. 在不更改任一槽位的情况下归一化共享描述符与附着；
3. 先决定违规、纠正与预防 — 救济与纠正，然后锁定，然后在使用处的自愿公开问责表达；再适用锁定设计与执行（定义与附着、相称性与校准、记录可见性与升级、特殊违规规则，以及特殊锁定）；
4. 其次决定贡献后果 — 当前性以及能力门槛与许可，但仅针对未被锁定阻断的具名路径；
5. 为每一条具名路径陈述一项最终轨迹效果；
6. 陈述恢复与再评估条件；
7. 核验实践可执行性；以及
8. 在指定成为争点时，把合格的违规轴槽位 7–9 认定路由到[第十章](core_10_a_misconduct_designation.md#chapter-ten-anti-constitutional-misconduct)。

每一项自动或人工结果都必须以其输入、规则、中间步骤、结果与审查路由可被受影响方与获授权审阅者检查并质疑的形式，予以保全。

在技术中断期间，获授权机构必须使用人工连续性过程，保全同样的必填字段、处理顺序、证据保管、审查权利与适用时限。技术恢复后，系统必须对账人工记录与电子记录，保全两条审计轨迹，说明任何差异，并且从不悄悄覆盖一项决定。

<a id="3-descriptor-integration-and-attachment-normalization"></a>
### 3. 描述符整合与附着归一化

*用直白的话说：描述符说明经核实的帮助或伤害是**如何**发生的。本章按原记录导入它们。它不得悄悄重新分类它们以改变结果。*

描述符回答经核实受益或伤害**如何**发生，并作为问题 2 产出在[第八章归一化描述符目录](core_08_standing_assessment.md#43-route-descriptor-measurement-roles)下被指派。附着陈述对问题 3 在法律上或宪法上相关的回应品格。描述符与附着可堆叠、非排他，并从属于固定的第八章槽位。经核实事实支持时，一份整合记录可以携带若干个。

整合记录必须从其源轨迹记录导入每一项适用描述符，不得添加、删除或实质重新分类它。它可以把遗留标签、本地显示名称或稳定标识符映射到第八章目录，但该映射必须保持可检查，并且不得改变底层经核实事实或测量角色。实质性描述符错误或遗漏必须经第八章更正或替代过程返回。

<a id="64-concurrent-character-and-non-exclusivity"></a>
<a id="65-constitutional-floor-rule"></a>
违规附着可以同时包括救济性或恢复性品格、强制性或限制自由的保障品格、宪法底线性品格、集体问责品格、过失、隐瞒、复发，以及与职责相关的品格。宪法底线性品格适用于经核实行为违反宪法约束、权利底线、至上性、反规避义务，或实践中的质疑与救济通路之处。任何普通或领域特定回应都不得授权低于那些底线的结果。

<a id="73-stackable-harm-and-conduct-descriptors-violation-nature-supplement"></a>
贡献描述符可以取向匹配的能力门槛与许可。违规描述符与附着可以取向匹配的救济、保障与锁定范围。描述符与附着都不构成第二条测量梯子，也都不供给第十章指定。

<a id="4-violation-correction-and-prevention"></a>
### 4. 违规、纠正与预防

*用直白的话说：发生了不好的事。我们如何做成一项耐久修复？本节按顺序回答 — **救济与纠正**，然后**预防**锁定，然后在恢复性路径使用时的**自愿公开问责表达**，最后是**救济对等**规则，防止本节便宜的一半跑过昂贵的一半。一旦第八章核实了违规，救济与纠正只从那份记录而来 — 修好被打破的，并改变造成它的原因 — 然后预防锁定把敏感具名路径关住，直到那些条件被满足。公开承认或道歉若被使用，是补充性的，从不替代修复或锁定。过往贡献不软化该义务、不取消锁定，也不替代经核实的修复。评议所监督实施与质疑；它们不从经核实记录发明不同的后果。*

违规、纠正与预防只从违规轨迹记录决定。贡献不是救济、纠正、保障、锁定指派或自愿公开问责表达的输入。它日后可以显示履行一项义务的能力，但不能改变该义务，或支撑该义务的未解决状态。

<a id="41-remedy-and-correction"></a>
#### 4.1 救济与纠正

*用直白的话说：在经核实**违规**之后，本小节指派耐久修复中的**救济**与**纠正**部分。**救济**为受伤害者修好被打破的。**纠正**改变造成它的原因。**预防** — 轨迹锁定及相关具名路径限度 — 始于 [§4.2](#42-general-standing-locks)，设计与执行在 [§5](#5-lock-design-and-enforcement)，并且在复发风险仍在时不得被放弃。凡恢复性路径包括公开承认或道歉之处，适用 [§4.3](#43-voluntary-public-accountability-expression)。*

每一项经核实违规都必须就两项并行纠正产出加以检验：

- **救济：**
  - 承认；
  - 修复；
  - 恢复；
  - 补偿；
  - 在字面修复不可能时的替代保障；或
  - 对受影响感知者与利益的可比补救。
- **纠正：** 为处理原因并停止延续所需的改变，覆盖：
  - 行为；
  - 系统；
  - 记录；
  - 激励；
  - 监督；
  - 保障；或
  - 角色资格。

修好原因并不取消向受伤害者修复的义务。向受伤害者修复并不取消修好原因、保持所需保障到位，或在同一伤害再次发生的风险仍真实时保持预防锁定到位的义务。能够修好问题，并不降低违规轴槽位有多严重。

整合记录必须在明处说明：

- 谁受影响、发生了何种伤害；
- 欠何种救济、它延伸多远；
- 适用何种纠正义务；
- 谁负责落实它们；
- 资金从何处来；
- 工作必须何时开始、适用何种里程碑；
- 现在进展到何处；
- 谁监督跟进；以及
- 若发生拖延会怎样。

评议所监督合法实施、质疑、临时救济与及时推进。它们不取代第九章从经核实记录指派违规、纠正与预防的义务。

<a id="42-general-standing-locks"></a>
<a id="42-prevention--general-standing-locks"></a>
#### 4.2 预防 — 一般轨迹锁定

*用直白的话说：这是耐久修复中的**预防**部分。轨迹锁定通过关闭或限制会让同一伤害在违规仍未解决或未修复时继续或再次发生的具名路径，来降低风险。它本身不是惩罚，也不是人气或名声分数。*

**轨迹锁定**是一项预防与降风险措施。它在经核实违规仍未解决或实质未获救济时，阻断或限制一条具名路径。具名路径包括信任、角色、权威、信用、监督、承认、**治理投票**与**受影响方参与**路径。它必须标明被阻断的具名路径、意在降低的风险、受保护对象或利益、纠正条件、审查路由与再评估点。

**路径区分 — 治理投票 vs 受影响方参与：**

- **治理投票**覆盖在 [第十二章 §4.1](../../core_13_governance.md#41-entitlement-and-eligibility) 下参与治理投票与可比正当性机制约束性集体选择，包括**基础宪法选择**。它**不**包括已获授权系统、机构或有界决定域内部的按利害加权声音。
- **受影响方参与**覆盖按利害加权的影响、约束性受影响方选择，以及 [受影响方权重](core_05_band_participation.md#stakeholder-weight) 与 [约束性受影响方选择](core_05_band_participation.md#binding-stakeholder-choice-cluster) 下可比的受影响方的系统参与路径。它**不**抹去[受影响方](core_05_band_participation.md#stakeholder)地位本身，也**不**替代一项**治理投票**锁定。

凡经核实的受影响方路径腐败、俘获、虚假利害滥用或强制性参与权重博弈是触发之处，适用 [§5.5](#55-special-locks) 下的[受影响方参与轨迹锁定](#55-special-locks)。

锁定的宗旨是通过把感知者从违规发生的环境、角色或具名路径 — 并在需要时从与感知者的接触 — 中移出，来降低风险。该分离服务三项宗旨：

1. **遏制** — 阻止同一伤害经同一场景或具名路径继续；
2. **受影响方安全** — 使已经受伤者免于进一步暴露；以及
3. **降风险** — 在救济与纠正仍未完成时，降低同一模式复发的机会。

锁定必须为降风险所需、相称、可审计、可质疑、不宽于所需，并在受保护宗旨允许时有时限。它附着于经核实认定 — 不是身份、地位、指控、一般性不悦或名声。暴力、强制、残忍、欺骗、隐瞒、故意、复发、过失、职责或规避等品格，仅在被分开核实时才可以塑造范围、审查强度、保障与审查；它从不移动槽位。

这些要求的设计与执行由 [§5](#5-lock-design-and-enforcement) 统管：定义与附着；相称性与校准；记录可见性与升级；然后在同一附着字段中陈述的特殊违规规则与特殊锁定。无抵消与贡献可见性仍由[第八章 §2.2](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge) 统管；本章在设计与执行锁定时适用该规则。

<a id="43-voluntary-public-accountability-expression"></a>
#### 4.3 自愿公开问责表达

*用直白的话说：公开道歉或承认若在一条恢复性路径上被使用，必须自愿、真诚、非贬损。单单拒绝并不提高制裁。虚假或滥用性道歉不算修复。*

凡经核实违规的恢复性路径包括公开承认或道歉之处，可问责方可自愿选择该表达，作为补充性问责行为。

- 该选择在它支撑修复、信任恢复或共同体愈合时被允许。
- 此类表达必须：
  - 非强制；
  - 知情；
  - 直至交付可撤回；
  - 可就自愿性与真实性接受独立审查。
- 拒绝参与公开表达本身不得提高基线制裁、加宽轨迹锁定，或替代 [§4.1](#41-remedy-and-correction) 下所欠的救济或纠正。
- **不真实或滥用性表达：** 在实质上不真诚、操纵性、表演而无真实问责，或对受影响方或公众滥用的公开承认或道歉，不满足恢复性要求。
  - 它可以对可问责方携带负面正义后果 — 包括降低康复信用，以及 **Article XXIII-B**（《非琐碎限制、返还与恢复性问责约束》）与[第八章](core_08_standing_assessment.md#chapter-eight-compliance-violation-and-standing-model)下的其他合法限制。
  - 把虚假或滥用性道歉当作充分修复，或用它来回避 [§4.1](#41-remedy-and-correction) 与 [§4.2](#42-general-standing-locks) 下必要的保护、补救或锁定，即不合规。
- 任何格式都不得在真实问责与相称补救所必要者之外施加下列任何一项：
  - 贬损待遇；
  - 被强迫的自我贬低；
  - 不可逆的名声伤害。

反宪法不当行为专门化 — 包括指定触发规则以及与不真实表达挂钩的指定关联后果 — 由[第十章 §4.3](core_10_a_misconduct_designation.md#4-3-voluntary-public-accountability-expression-anti-constitutional)（*自愿公开问责表达（反宪法）*）统管。

<a id="44-remedy-parity-and-lock-preconditions"></a>
#### 4.4 救济对等与锁定前置条件

*用直白的话说：锁定签发便宜；修复、恢复与审查运行昂贵。若放任不管，本章便宜的一半继续运转，而昂贵的一半挨饿。本小节把它们绑在一起：普通锁定在同一认定的救济档实际打开之前不得附着；当采纳者某一锁定类别的救济或恢复工作落后于其时钟时，该类新的普通锁定默认取最轻形式，既有者进入审查。最严重的锁定获豁免，以免灌满救济队列就能把它们弹开。*

**已打开救济前置条件。** 除[第十一章 §5](core_11_forum.md#interim-protection)（*临时保护*）下的临时保护措施外，[§4.2](#42-general-standing-locks) 下的一般轨迹锁定在同一经核实认定的 [§4.1](#41-remedy-and-correction) 整合记录**打开**之前，不得附着于具名路径 — 打开意味着至少受影响方、所欠救济、责任方、资金来源与开始日期已在明处陈述。锁定附着不要求救济完成；要求的是已打开的救济记录。未带已打开救济记录而附着的锁定有缺陷，必须在[第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline) 层级时钟上被补救，或收窄到临时保护范围。

**救济对等绊索。** 采纳者必须就其所管理的每一期间与每一锁定类别公布：已签发的一般锁定数量、已开始的救济、已完成的救济、已决定的恢复，以及待决的再评估。凡某一锁定类别的救济开始或恢复审查超过其第十一章 §6 层级外沿之处：

- 该类新的一般锁定默认取 [§7](#7-final-standing-effect) 下的**开放并带保障**，除非整合记录记载了要求**阻断**的具体不可逆伤害或安全风险；
- 该类既有一般锁定按同一层级时钟进入 [§8](#8-restoration-and-reassessment) 下的强制再评估；以及
- 该能力失败作为 [§9.2](#92-remedy-system-durability) 下的耐久失败被记录，并按[第十一章 §3](core_11_forum.md#3-transfer-consolidation-and-coordination) 能力失败规则路由，在其能力受质疑的族系或系统之外。

**豁免。** 绊索不放松 [§5.5](#55-special-locks) 特殊锁定、附着于违规轴槽位 **7**、**8** 或 **9** 认定的锁定，或 [§5.4](#54-special-violation-rules) 下强制性或限制自由的保障。在 [§10.10](#1010-contest-pathway-or-info-sphere-flooding) 下核实为质疑路径灌水的提交，不计入触发本规则的积压。

**测量。** 已签发锁定与已开始救济及已决定恢复之比，是[宪法绩效测量族](core_05_band_performance.md#performance-measurement-family)下的宪法绩效指标。该比率在连续期间扩大，是违规侧[可避免负担](core_05_band_continuity.md#avoidable-burden)与救济侧 [§9](#9-enforcement-realism) 纸面路径失败的证据；它不是中性运营指标。

<a id="5-lock-design-and-enforcement"></a>
### 5. 锁定设计与执行

*用直白的话说：一旦在 [§4.2](#42-general-standing-locks) 下需要锁定，本节说明如何设计并执行它 — 如何规定锁定、如何校准它、如何保持可见与可审查、哪些特殊锁定是强制的，以及哪些特殊违规规则改变范围或过程。它不重开第八章测量，也不让贡献抵消锁定。*

按此顺序设计锁定：

- 说明它附着于什么（[§5.1](#51-definition-and-attachment)）。
- 使之不宽于风险所要求（[§5.2](#52-proportionality-and-calibration)）。
- 把条款放在明处，并保持审查路径（[§5.3](#53-record-visibility-and-escalation)）。
- 适用任何塑造该附着的特殊违规规则（[§5.4](#54-special-violation-rules)）。
- 适用任何强制特殊锁定，使用同一附着字段（[§5.5](#55-special-locks)）。
- 过往善行不取消经核实伤害、不跳过修复、也不打开已被锁定的具名路径 — 该无抵消规则住在[第八章 §2.2](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge)，并在此处适用。
- [§4](#4-violation-correction-and-prevention) 已经说明贡献不决定锁定。
- 贡献日后能做什么，见 [§6](#6-contribution-consequences-second) 与 [§8](#8-restoration-and-reassessment)。

<a id="51-definition-and-attachment"></a>
#### 5.1 定义与附着

每一项锁定都必须被设计成使整合记录能够以操作性形式标明：

- 被阻断或限制的具名路径；
- 锁定意在降低的风险；
- 受保护对象或利益；
- 在收窄或解除之前必须满足的纠正条件；
- 审查路由；以及
- 再评估点。

锁定只附着于经核实认定 — 不是身份、地位、指控、一般性不悦或名声。暴力、强制、残忍、欺骗、隐瞒、故意、复发、过失、职责或规避等品格，仅在被分开核实时才可以塑造范围、审查强度、保障与审查；它从不移动违规轴槽位。

凡锁定宗旨包括降风险之处，适用两项附着限定：

1. **复发不确定性：** 凡同一伤害是否会复发仍不确定之处，该不确定性本身就是风险输入。锁定设计必须把关于复发的不完整、有争议或有时限证据纳入风险评估，而不是把不确定性当作把敏感具名路径保持开放的理由。
2. **与风险因素隔离：** 凡为遏制或安全所需之处，锁定必须把责任感知者与会再造暴露的风险因素隔离 — 包括其他违规者的网络、关联、场景与环境 — 并在该接触会更新风险时，与受保护对象或利益隔离接触。

**锁定本身不限制什么。** 轨迹锁定本身并不切断：

- 普通言论、请愿、作证、辩护或揭发；
- 作为受影响方的参与；
- [权利底线](core_06_rights_part_a.md#chapter-six-foundational-rights)；
- 生存关键通路；或
- 就并非经核实违规具名路径一部分的工作领取常规工资的权利。

锁定仍可以关闭与经核实风险挂钩的信任、角色、权威、信用、监督、承认、影响、**治理投票**或**受影响方参与**路径。它不得用那些具名路径限度作为后门，去消灭上述保护。

本节后文的特殊违规规则与特殊锁定不取代本小节。每一项都必须填写同一附着字段、适用同一经核实认定门、在降风险为宗旨时适用同一限定，并尊重锁定本身不限制者。

<a id="52-proportionality-and-calibration"></a>
#### 5.2 相称性与校准

锁定设计必须权衡被降低的风险以及提高它们的条件，包括具名路径敏感性、未解决的救济与保障缺口、通知或补救后的复发、持续安全风险、角色不对称、隐瞒或规避、控制扩散、制度促成、评议所完整性伤害、跨管辖连续性、可审查性，以及纠正的实际时间。

所得锁定必须为降风险所需、相称、不宽于所需，并在受保护宗旨允许时有时限。校准可以随那些条件变化而收紧或收窄范围，但不得把锁定转成惩罚、名声打分，或替代 [§4.1](#41-remedy-and-correction) 下所欠的救济与纠正。[§5.5](#55-special-locks) 下的特殊锁定仍必须满足其自身纠正条件；校准不得放弃一项强制特殊锁定。

<a id="53-record-visibility-and-escalation"></a>
#### 5.3 记录可见性与升级

整合记录必须在明处就每一项锁定 — 包括 [§5.5](#55-special-locks) 下的每一项特殊锁定 — 说明：

- 哪些具名路径被阻断或限制；
- 何种风险与受保护利益正当化该锁定；
- 锁定的范围与期限，包括任何时限；
- 适用何种纠正条件，以及它们如何关联 [§4.1](#41-remedy-and-correction) 下的救济与纠正状态；
- 谁可以质疑或审查该锁定，以及经何路由；
- 若发生拖延或不合规会怎样；以及
- 什么触发再评估。

锁定在有效期间必须保持可审计、可质疑。因拖延、规避或不合规而升级，必须保全同一可检查记录。恢复与再评估条件在 [§8](#8-restoration-and-reassessment) 下陈述；实践可执行性在 [§9](#9-enforcement-realism) 下核验。

<a id="54-special-violation-rules"></a>
#### 5.4 特殊违规规则

这些规则塑造锁定或保障如何在 [§5.1](#51-definition-and-attachment) 下附着。它们不移动违规轴槽位。凡一项规则导致具名路径限度或自由限制之处，整合记录仍必须点名具名路径、风险、受保护利益、纠正条件、审查路由与再评估点。

<a id="54-negligence-and-neglect-as-violation-nature"></a>
**过失与疏忽：**

- **具名路径 / 认定：**
  - 在存在职责之处可独立记录。
  - 在合理可期待者清楚之处可独立记录。
  - 在感知者具有可行能力去预防、减轻或升级实质伤害之处可独立记录。
- **风险：** 经同一职责失败、疏忽模式或未受监测的具名路径复发。
- **受保护对象或利益：** 暴露于被疏忽伤害者。
- **纠正条件：** 当伤害具有实质性时，过失或疏忽必须被当作真实职责失败 — 不得当作文书错误被刷掉。把行为点名为过失或疏忽并不改变违规轴槽位；槽位保持第八章所测量者。
- **审查路由与再评估：** 若同一疏忽是否会再次发生仍不清楚，该不确定性本身在 [§5.1](#51-definition-and-attachment) 下算作风险。不完整的复发证据不是把敏感具名路径保持开放的理由。

**错位奖赏：**

- **具名路径 / 认定：**
  - 使用宪法错位、反宪法或严重破损的系统，抽取实质奖赏 — 报酬、奖金、地位、信用、排名、通路或影响。
  - 任何会让该感知者继续把该滥用兑现的相关具名路径。
- **风险：** 同一感知者或旁观者继续博弈破损激励；错位系统保持有利可图；伤害在奖赏路径保持开放时继续。
- **受保护对象或利益：** 被滥用过程伤害的感知者；若剥削者保留受益或用来取得它的通路，会受损的依赖者与系统。
- **纠正条件：**
  - 关闭或锁定该感知者用来抽取受益的奖赏、信用与影响具名路径，直至滥用被停止且激励结构被纠正。
  - 通过滥用错位系统取得的实质奖赏，为宪法目的予以没收，除非收回它们会造成更大宪法伤害，因而需要暂时保留。
  - 在通知后明知继续博弈系统，或隐瞒受益的感知者，不被当作诚实接受者。下列各项仍可用，且本身不是违规：
    - 及时受保护报告；
    - 善意争议；
    - 审查期间的记录保全；以及
    - 配合补救。
  - 下列各项本身不被当作滥用没收对象：
    - 在感知者不知道系统错位时，普通工作的普通报酬；
    - 为修复受影响方伤害而支付的款项；以及
    - 经可质疑过程达成的公平和解。
- **审查路由与再评估：**
  - 记录必须显示系统如何被滥用。
  - 记录必须显示该感知者知道什么。
  - 记录必须显示取得了何种受益。
  - 记录必须显示任何隐瞒。
  - 记录必须显示还有谁受伤或依赖该安排。
  - 记录必须显示为何锁定具名路径、收回奖赏，或允许暂时保留。
  - 系统必须保全证据。
  - 系统必须在相称处冻结或分离有争议奖赏。
  - 系统必须修好破损激励。
  - 系统必须把合格的违规轴槽位 7–9 认定送往第十章。
  - 任何相关锁定必须满足 [§5.1](#51-definition-and-attachment)，包括与再造同一可剥削具名路径的网络或环境隔离。

<a id="54-duty-to-resist-unlawful-or-unconstitutional-instructions"></a>
**抵抗义务。**

<a id="operative-steward-statement-unlawful-instruction"></a>
> **操作性尽责管理声明。** **主责：** 第九章 §5.4 抵抗义务。共享标准：第一章 §9.1.1。质疑底线：Article XII-B。**禁止动作：** 不得遵从。不得把掩护当作义务转移。不得为了帮忙而关闭质疑路径。**时限：** 现在即按共享筛查运行：收到指令 → 拒绝 → 记录 → 升级。保全质疑路径。

**具名序列。** 收到指令 → 拒绝 → 记录 → 升级。记录 [CS-4 §10](../../corpus_systems/cs_04_critical_system_stewardship.md#10-inspectable-attributable-action) 最低可检查行动集合。两类尽责管理者使用同一序列。尽责管理指针（过程支持；不得收窄本节）：[`implementation/STEWARD_ENTRY_DOORS.md#shared-refusal-and-logging`](../../implementation/STEWARD_ENTRY_DOORS.md#shared-refusal-and-logging)。

- **具名路径 / 认定：**
  - 任何要求非法或违宪行为的指令、命令、政策或合同，都不创造有效的合规抗辩。
  - 签发、传送、批准或实质执行此类指令，是可独立测量的违规行为。
  - 委托人将承担责任的声明，并不转移义务，也不创造有效的合规抗辩。
- **风险：** 经服从、指挥链或合同掩护而延续非法或违宪伤害。
- **受保护对象或利益：** 会因遵从而受伤者，以及合法具名路径的完整性。
- **纠正条件：** 凡行使实质尽责管理或运营权威、并具有拒绝、质疑、记录或升级的实质能力者 — 包括[第一章 §9.1.1](core_01_c_stewardship_capacity_principles.md#911-shared-stewardship-standard) 下的人类操作者与 AI 尽责管理者 — 必须相称、善意地这样做，并在适用处使用受保护报告与评议所路径。该义务不是仅针对 AI 的检验。
- **审查路由与再评估：** 抵抗、报告与升级记录喂入 [§5.1](#51-definition-and-attachment) 下的锁定与救济设计；贡献不能开脱底层指令行为。经核实失败按同一第八章贡献轴与违规轴，对两类尽责管理者记录。

<a id="54-collective-accountability-and-acquiescent-participation"></a>
**集体问责：**

- **具名路径 / 认定：**
  - 跨越团队、委员会、指挥链、合同或分布式系统的扩散，不抹去责任。
  - 责任仍落在下列任何一项实质促成违规之处：
    - 贡献；
    - 明知默许；
    - 控制；
    - 受益；
    - 隐瞒；
    - 可行预防；或
    - 未能升级。
- **风险：** 共享或碎片化控制会让促成性具名路径保持开放。
- **受保护对象或利益：** 被集体或碎片化模式伤害者。
- **纠正条件：**
  - 证明每一责任感知者实际做了什么或未能做什么 — 不得仅凭群体成员身份惩罚。
  - 看穿被用来隐藏谁负责的空壳、改名实体、纸面转让与拆分角色。
  - 无株连：共享一个团队、公司或网络本身不够。
- **审查路由与再评估：** 每一责任行动者的锁定若有，仍必须满足 [§5.1](#51-definition-and-attachment)，包括与再造促成模式的网络或环境隔离。

**强制性或限制自由的保障：**

- **具名路径：**
  - 拘禁。
  - 另一项自由限制。
- **风险：** 经核实行为、可责性、强制、暴力、可信威胁或可比危险，使自由限制为遏制或安全所必要。
- **受保护对象或利益：** 受影响方，以及该限制意在保护的公共安全利益。
- **纠正条件与过程：**
  - 完整的刑事过程或等效宪法保护在限制之前适用。
  - 这些过程保护在自由被限制时一律适用；它们本身并不创造定罪。
- **审查路由与再评估：** 同一过程保护统管质疑、收窄与解除；复发不确定性以及与风险因素隔离在 [§5.1](#51-definition-and-attachment) 下适用。

<a id="55-special-locks"></a>
#### 5.5 特殊锁定

这些锁定在其经核实触发被满足时是强制的。每一项都必须使用 [§5.1](#51-definition-and-attachment) 附着字段记录。除非经该锁定所陈述的纠正条件与审查路由，否则不得解除、收窄或中止。

**评议所服务轨迹锁定。** 触发：在回避被要求且公正性被实质损害之处，经核实未能回避。

- **具名路径：**
  - 实体认定；
  - 上诉；
  - 审查；
  - 紧急；
  - 认证者；
  - 有争议的合议组协调；
  - 后备；
  - 替补；以及
  - 跨评议所族系的实质支持性评议所角色。
- **风险：** 偏颇裁决、评议所完整性伤害，以及在同一或相关评议所场景中不回避的复发。
- **受保护对象或利益：** 受影响事项的当事方，以及公众对评议所公正性的信任。
- **纠正条件：**
  - 除非完整独立恢复记录被满足，并给出理由说明更窄保护已足够，否则不得解除、收窄或中止该锁定。
  - 再评估要求：
    - 充分披露；
    - 经合理查询识别受影响事项；
    - 可行纠正、撤销、再审、通知与证据保全；
    - 返还或其他实践修复；
    - 配合审查；
    - 角色分离与回避再资格；
    - 在合法处展示一段合规的较低风险服务；以及
    - 一项独立认定：复发风险与公众信任伤害已被实质降低。
  - 专长稀缺、人手短缺、先前服务、名声、道歉或贡献本身不能解除该锁定。
- **审查路由：** 在被损害的评议所路径之外的独立审查。
- **再评估点：** 上述独立恢复认定。故意、隐瞒、反复、报复性或影响结果的失败，接受提高的审查。复发不确定性，以及与再造公正性风险的评议所角色、网络与环境隔离，在 [§5.1](#51-definition-and-attachment) 下适用。

**受影响方参与轨迹锁定。** 触发：经核实认定对象腐败、俘获、强制、博弈或以其他方式实质滥用一条**受影响方参与**路径 — 包括虚假或夸大的利害主张、强制性参与权重抽取、在约束性受影响方选择中买票或可比买影响、在受影响方代表中隐瞒实质冲突，或把受影响方声音当作俘获受影响系统、机构或有界决定域的载体。

- **具名路径：**
  - 按利害加权的影响；
  - 约束性受影响方选择参与；
  - 受影响方代表权威；以及
  - 在受影响系统、机构或有界决定域内，[受影响方权重](core_05_band_participation.md#stakeholder-weight) 与 [约束性受影响方选择](core_05_band_participation.md#binding-stakeholder-choice-cluster) 下可比的受影响方的系统参与路径。
- **本身不限制：**
  - [受影响方](core_05_band_participation.md#stakeholder)地位，或该感知者被实质影响的承认；
  - **治理投票**路径、**基础宪法选择**，或 [第十二章 §4.1](../../core_13_governance.md#41-entitlement-and-eligibility) 下可比正当性机制约束性集体选择；
  - 权利底线最低限度、生存关键通路，或宪法所要求的审计、质疑与救济路径。
- **风险：** 继续俘获或扭曲受影响方声音、虚假利害主导、被强制的参与权重，以及在同一或相关域中受影响方路径滥用的复发。
- **受保护对象或利益：** 受影响的受影响方、约束性受影响方选择的完整性，以及相关系统、机构或有界决定域的非俘获。
- **纠正条件：**
  - 除非独立恢复记录被满足，并给出理由说明更窄保护已足够，否则不得解除、收窄或中止该锁定。
  - 再评估要求：
    - 更正或撤回虚假或夸大的利害主张；
    - 在所欠之处向受影响的受影响方给予救济；
    - 披露滥用中使用的冲突与影响渠道；
    - 在受影响域中针对复发的结构或程序保障；
    - 配合审查；以及
    - 一项独立认定：受影响方路径复发风险已被实质降低。
  - 先前贡献、名声、利害规模、运营者不可或缺性或道歉本身不能解除该锁定。
- **审查路由：** 在被俘获的受影响方参与路径之外的独立审查。
- **再评估点：** 上述独立恢复认定。故意、隐瞒、反复、报复性或影响结果的滥用，接受提高的审查。复发不确定性，以及与再造俘获风险的代理网络隔离，在 [§5.1](#51-definition-and-attachment) 下适用。
- **不替代：** 受影响方参与轨迹锁定不是**治理投票**锁定的替代，**治理投票**锁定也不是本锁定的替代。凡两条具名路径都被分开核实的事实牵涉之处，每一项锁定都必须在其自身记录上附着并被正当化。

**反宪法信任锁定。** 触发：对责任感知者、群体、机构、继任载体、受控实体或实质协调的代理所作的最终第十章指定。

- **具名路径：**
  - 对 Class A/B/C 系统的直接或间接影响。
  - 宪法评议所。
  - 对齐承认。
  - 关键系统尽责管理。
  - 审计、证据、安全、通路延续、调查、执行、返还与受保护报告路径。
  - 影响那些功能的任命、预算、所有权、投票、采购、标准、排名、通路分配、模型治理或政策权威。
  - look-through 覆盖还到达：
    - 空壳与名义人；
    - 顾问俘获与资金杠杆；
    - 合同否决与信息瓶颈；
    - 数据保管、特权通路，以及可比功能控制手段。
  - [§5.1](#51-definition-and-attachment) 下的全局非限制限度适用；本锁定不对那些受保护路径再增加切断。
- **风险：** 在指定后果仍未解决时，再起的反宪法影响、俘获或代理控制。
- **受保护对象或利益：** 宪法秩序、被覆盖系统、评议所、问责路径，以及会暴露于再起影响的当事方。
- **纠正条件：**
  - 恢复是例外。
  - 恢复要求：
    - 经独立核实的返还或合法替代恢复；
    - 对受污染治理、系统、记录与决定的结构性纠正；
    - 足以绘制依赖的披露与配合；
    - 耐久的反复发与代理控制保障；
    - 所要求的监测与再资格；以及
    - 一项已公布认定：再起影响更安全且与宪法兼容。
  - 对严重或灾难性指定，被覆盖系统与评议所影响保持禁止，除非独立审阅者作出具体、已公布认定：恢复任职是：
    - 必要的；
    - 相称的；
    - 非俘获的；以及
    - 对被保护宪法利益而言，比继续排除更安全。
- **审查路由：** 带已公布认定的独立审查。
- **再评估点：**
  - 上述已公布恢复或恢复任职认定，是任何收窄或解除的检查点。
  - 在 [§5.1](#51-definition-and-attachment) 下，在风险仍在时，使该感知者与代理网络、继任实体以及与协调违规者共享的场景保持隔离。
- **一并阅读：** [第十章 §4.2](core_10_a_misconduct_designation.md#4-2-prevention-anti-constitutional-locks)（*预防 — 反宪法锁定*），用于最终指定后 ACM 特定的自由限制与监禁专门化；本小节仍是操作性信任锁定文本。

<a id="6-contribution-consequences-second"></a>
### 6. 贡献后果居后

*用直白的话说：在 [§4](#4-violation-correction-and-prevention) 与 [§5](#5-lock-design-and-enforcement) 下指派违规、纠正与预防之后，本节问经核实贡献仍可以做什么。它可以支撑承认，以及未被锁定的具名路径的准备。它从不抵消经核实伤害、取消锁定，或打开被阻断的具名路径。*

本节从适用于该决定的经核实第八章贡献记录开始。从那些记录它问两件事：

- 该贡献仍然有多当前；以及
- 对一条开放具名路径的任何能力许可，是否对照其已公布门槛被满足。

过往善行不设定 [§4](#4-violation-correction-and-prevention) 与 [§5](#5-lock-design-and-enforcement) 下的救济、纠正义务、保障或锁定。善行也不能取消或平衡经核实伤害 — 第八章的该[无抵消规则](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge)仍适用。

按此顺序决定贡献后果：

- 确认承认资格：承认必须有证据支撑、可质疑、可审查、非垄断，并按平等标准向非正式、无报酬、同伴组织、互助、维护、修复、教学与共同体尽责管理工作开放。平等标准包括职责分离：在[第一章 §10.2 职责分离](core_01_c_stewardship_capacity_principles.md#102-segregation-of-duties) 与[第八章 §3.7 非正式与小范围记录](core_08_standing_assessment.md#37-informal-and-small-scope-records) 下，非正式工作的核验席位由任何有已公布权威依赖该记录的无利害机构满足，而不是由核验者的正式性满足；要求非正式群体无法触及的正式机构核验的门槛，是 [§6.2 能力门槛与许可](#62-competency-bars-and-clearances) 的看门模式。
- 适用近时性与当前性（[§6.1](#61-recency-and-currentness)）。
- 对未被锁定阻断的具名路径适用能力门槛与许可（[§6.2](#62-competency-bars-and-clearances)）。
- 把每一条具名路径结果交给 [§7](#7-final-standing-effect)；恢复与再评估仍在 [§8](#8-restoration-and-reassessment)。

<a id="61-recency-and-currentness"></a>
#### 6.1 近时性与当前性

*用直白的话说：一份较旧的经核实贡献对当下能力与可靠性仍说明多少？系统为问题 3 准备自动回答。无人必须手工重新权衡普通贡献。仅当贡献被争议时，人工审查才开始。近时性不改写第八章测量，单单时间也不治愈未解决违规。*

近时性严格是一项**问题 3 许可与准备输入**。它不更改第八章贡献轨迹记录、贡献轴槽位、LEQU 测量、描述符或历史承认。

对当前信任、角色、权威、监督或承认敏感决定，轨迹系统必须**自动**为每一项适用的经核实贡献计算当前性权重。当经核实输入与已公布公式（或更严的已公布角色特定规则）产出确定结果时，对未被争议的贡献不需要额外人工批准。该过程必须无缝运行，除非该贡献 — 或用来权衡它的输入 — 被争议、不确定，或以其他方式要求 [§2](#2-integration-record-and-decision-order) 下的审查。

除非更角色特定的已公布规则更严且在宪法上有效，当前轨迹权重使用 10 年半衰期，按整日计算：

`currentness weight = 2^(-days / 3652.5)`

整年年龄的示意权重（精确日数可能略有差异）：

| 年龄（年） | 当前性权重 |
|---:|---:|
| 0 | 1.000 |
| 5 | 0.707 |
| 10 | 0.500 |
| 15 | 0.354 |
| 20 | 0.250 |
| 25 | 0.177 |
| 30 | 0.125 |
| 35 | 0.088 |
| 40 | 0.063 |
| 45 | 0.044 |
| 50+ | 无（仅历史） |

系统对每一项贡献分开适用该权重。50 年之后，贡献仍留在历史记录中，但不供给当前许可权重。持续或被维持的贡献可以用当前记录证明，而不是当作单一旧事件。近时性规则不适用于未解决违规：单单时间流逝并不纠正、救济、替代或解决它。

当一项贡献或其当前性输入被争议时，系统仍必须汇编并保全自动计算，把争议路由到获授权审查，并使结果保持可检查。争议不抹去历史贡献记录。

自动计算的整合记录就每一项用作当前性输入的贡献显示：

- 哪一份贡献记录与版本；
- 所使用的年龄或持续状态基础；
- 所得当前性权重；
- 该权重是自动产出还是经争议审查后产出；
- 该贡献对许可目的是否仅为历史；以及
- 是否适用了更严的已公布角色特定规则。

<a id="62-competency-bars-and-clearances"></a>
<a id="62-competency-gates"></a>
#### 6.2 能力门槛与许可

*用直白的话说：能力门槛是一条具名路径已公布的标准。能力许可是说明经核实准备满足该门槛的轨迹效果结果。一旦许可生效且路径开放，它默认保持开放。有些角色需要定期再测；技术评议所决定哪些。角色相关能力的真实变化 — 例如中风后，或损害所需判断的心理健康状况 — 可以触发再评估。许可从不打开仍被轨迹锁定阻断的具名路径。*

**能力门槛**是已公布的、具名路径特定的资格标准。任何受影响者都必须能够看见该规则、核对其如何被适用，并在错误时质疑它。简言之，它陈述该角色或通路要求何种准备。

**能力许可**是经核实准备满足该门槛时的正面轨迹效果结果。简言之，它回答：该感知者当前是否满足这条具名路径的门槛？

门槛可以要求下列证据：

- 当前经核实贡献；
- 已展示技能；
- 相关经验；
- 培训；
- 角色特定资格；以及
- 被观察到的可靠性。

门槛有多难必须匹配：

- 该角色能对他人影响多少；
- 他人对它依赖多少；以及
- 若该感知者未准备好，可预见风险有多严重。

**例子。** 同伴互助协调者可能需要在共享照护工作中展示的可靠性，而不是正式学位。供水系统或关键基础设施运营者可能需要角色特定培训加上近期已展示技能。评议所成员或认证者可能需要经核实的与公正性相关的经验，以及对该具名路径的当前资格。教学、维护、修复与共同体尽责管理记录，在它们显示正式凭证会显示的同一准备时，可以支撑许可。

门槛或许可过程不得变成任意看门、不透明的凭证主义、名声替代、社会声望筛查、内部人赞助、正式渠道垄断，或因无法触及的专门化而排除。同等可展示性标准适用于正式与非正式经验。

每一项门槛与许可结果都必须被设计成使整合记录能够标明：

- 具名路径及其敏感性；
- 所适用的已公布门槛；
- 技能与经验契合；
- 角色相称性；
- 当前性；
- 贡献对角色的相关性；
- 包容通路；
- 审查路由；以及
- 再评估触发。

**默认延续。** 一旦能力许可被授予且受影响具名路径开放，许可默认保持有效。那不是永久资格。已公布再测、角色相关能力的实质变化、适用的轨迹锁定，或本节下另一再评估触发，可以重开、限制或撤回许可。

**定期再测。** 有些能力需要定期再测；有些不需要。哪些具名路径需要再测、多频繁、用何种方法，由[技术评议所领域](core_11_forum.md#42-technical-forum-domains)下已公布标准设定，包括其合法范围内的专科技术评议所。那些标准必须角色相称、可检查、可质疑。

**实质能力变化。** 当经核实事实显示具名路径实际所要求能力的实质变化时 — 例如中风后运动或语言丧失，或损害该角色所需判断的心理健康状况 — 许可也可以被再评估。再评估必须针对利害所系的角色相关能力，而不是残疾或健康状况本身。它必须保持必要、相称、可审查，并与第五、六章下的可及性与反歧视底线一致。凡便利安排、支持或更窄具名路径会保全安全准备之处，必须在撤回许可之前予以考虑。

整合记录必须在明处就每一项许可结果说明：

- 许可是授予、未授予，还是仅在具名保障下授予；
- 适用了哪一项已公布能力门槛；
- 使用了哪些经核实贡献与其他准备输入；
- [§6.1](#61-recency-and-currentness) 下的当前性如何影响结果；
- 开放许可是仍在默认延续下，还是在已公布再测日程下；
- 谁可以质疑或审查门槛或许可，以及经何路由；以及
- 什么触发再评估，包括在适用处的实质能力变化。

[§4.2](#42-general-standing-locks) 与 [§5](#5-lock-design-and-enforcement) 下适用的轨迹锁定统管。能力许可不能打开被阻断的具名路径、放弃权利底线、抹去违规、替代救济或纠正，或降低违规轴槽位。门槛与许可之后的具名路径结果在 [§7](#7-final-standing-effect) 下陈述。

<a id="7-final-standing-effect"></a>
### 7. 最终轨迹效果

*用直白的话说：当前面步骤完成后，系统必须一次一条具名路径地陈述什么开放、受限或被阻断。该陈述不是尊严等级，也不是合并分数。*

一旦 [§2](#2-integration-record-and-decision-order) 中前面步骤完成，轨迹系统必须**自动**陈述每一条具名路径的最终轨迹效果。该陈述必须列出每一项开放许可与每一条受限制具名路径。当经核实输入与已公布规则产出确定结果时，不需要额外人工批准。有争议、不确定、新颖、具有实质裁量或高影响的问题仍自动汇编并路由，然后按 [§2](#2-integration-record-and-decision-order) 进入获授权审查。

**分开角色。** 自动整合可以把经核实记录、救济、纠正义务、锁定、门槛、许可与描述符一并使用。每一项仍有自己的工作，无一可以做另一项的工作。更近或自动化审查本身，不是施加更严限制的理由。任何限制都必须必要、匹配经核实事实、有证据支撑、可审查，并与 **Article XXIII**（《冲突解决、升级与紧急相称性》）一致。

整合记录必须就每一条受影响具名路径分开陈述最终效果：

- **开放** — 能力许可对照已公布门槛生效，且无锁定阻断该具名路径；
- **开放并带保障** — 准备已确立，但具名、相称的保障仍被要求；
- **受限** — 仅所述范围或层级可以开放；
- **阻断** — 轨迹锁定统管；
- **仅恢复** — 贡献可以支撑修复可信或受监督的较低风险服务，但不是普通具名路径通路；或
- **无效果** — 经核实记录不正当化一项更改。

记录必须显示下列哪一项产出了该效果：

- 不可更改输入；
- 描述符；
- 救济；
- 锁定；
- 当前性认定；
- 能力门槛；以及
- 许可。

它还必须暴露所使用的输入、权重、规则与审查路由。最终效果不是尊严等级、合并功绩分数、普遍名声标签，或底层记录的替代。

<a id="71-anti-aggregation-of-named-pathway-effects"></a>
#### 7.1 具名路径效果的反聚合

*用直白的话说：本章说明轨迹不是什么。本小节阻止任何人建造它所不是的东西。效果一次一条具名路径地陈述，并只向给该具名路径设门者显示。把它们缝成画像、等级或公开展示，就是建造本章禁止的合并分数 — 这样做本身就是违规。*

- **披露范围：** 一条具名路径的最终效果向对象、向该具名路径的看门人，以及向获授权审阅者披露。它不作为惯例向其他具名路径的看门人披露。
- **被禁止的聚合：** 下列各项建造合并分数，并在[第八章](core_08_standing_assessment.md#chapter-eight-compliance-violation-and-standing-model)下是可独立测量的违规行为，与 [Article VII-B](core_06_rights_part_b.md#article-vii-b-internal-state-boundary-and-type-n-protection)（《内部状态边界与 Type-N 保护》）一并阅读，本小节为其聚合纪律在轨迹上的镜像：
  - 把跨具名路径的最终效果汇编成：
    - 一份画像；
    - 一份合成；
    - 一项排名；
    - 一个层级；
    - 一枚徽章；
    - 一项公开展示；或
    - 一项可比制品；
  - 把一项效果转移到并未产出它的具名路径；或
  - 从对象的效果集合推断一般可信、价值或风险。
- **有界例外：** [廉正评议所](core_11_forum.md#45-integrity-forums)在审查俘获或模式主张、[第十章](core_10_a_misconduct_designation.md#chapter-ten-anti-constitutional-misconduct)指定审查，以及 [§9.4](#94-anti-evasion-and-look-through-authority) look-through 时，可以在回避规则与[第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline) 时钟下，仅就该程序查看跨路径记录。[第八章 §3.2](core_08_standing_assessment.md#32-related-record-cross-references) 关联记录之间的交叉引用仍在；它们是记录链接，不是合成。
- **公开 LEQU 展示：** 违规轴与贡献轴槽位不作为感知者的一般属性公布。它们出现在记录中、评议所程序中，以及在该槽位是该具名路径合法输入时向具名路径看门人的披露中。

<a id="72-plain-statement-of-effect-and-burden"></a>
#### 7.2 效果与负担的直白陈述

*用直白的话说：任何人都不该从后果才得知一项轨迹效果对他们做什么。记录必须用直白语言告诉对象：精确哪些具名路径受影响、他们必须做什么、持续多久、到何处质疑 — 并且采纳者必须测量感知者是否把轨迹体验为分数，因为若落地如此，说它不是分数的规则就毫无价值。*

- **向对象的直白语言陈述：** 当**无效果**以外的最终效果附着时，对象必须收到一份直白语言陈述。该陈述必须满足[第一章 §3.4](core_01_a_values_principles.md#34-plain-language-accessibility-stewardship-duty) 与 **Article XX-A**（《相称可理解权》），并必须点名：
  - 每一条受影响具名路径；
  - 在效果有效期间对象可以做什么、不可以做什么；
  - 纠正条件与再评估点；
  - 预期期限或审查节奏；以及
  - **Article XII-B**（《质疑、审查与救济权》）下的质疑路由。
- **诚实成本：** 轨迹锁定关闭真实的门，可检查行动义务是承担它的尽责管理者身上的真实负担。采纳者必须在向受影响感知者描述轨迹的材料中，把那些成本连同轨迹不是什么一并直白陈述。只描述轨迹的限度而省略其重量，是[真理](core_01_a_values_principles.md#32-truth-epistemic-integrity-constraint)缺陷。
- **感受负担量度：** 采纳者必须在[参与测量族](core_05_apex_participation_leg.md#participation-measurement-family)下测量，受影响感知者是否把轨迹效果体验为一般价值等级、名声分数或永久地位，而不是有界具名路径条件。法律类别与生活类别之间的实质分歧，是[第一章 §6.2.4](core_01_b_interaction_interpretation.md#624-proxy-divergence-invalidation) 下的[替代指标偏离](core_05_band_oversight.md#proxy-divergence)：它必须经设计、披露或 [§7.1](#71-anti-aggregation-of-named-pathway-effects) 执行被记录、升级并纠正 — 不得被解释掉。

<a id="8-restoration-and-reassessment"></a>
### 8. 恢复与再评估

*用直白的话说：非永久的锁定必须有一条真实的回来之路。恢复不是自动宽恕、记录抹除，或让过往帮助取消经核实伤害。*

每一项非永久锁定都必须提供一条真实的审查路由。恢复可以要求已完成的纠正、返还、救济、证据保全、保障实施、监测、再资格、受监督的较低风险服务，或另一项经核实的复发风险降低。单单历史地位不能正当化无限期排除。

再评估在记录所陈述的触发被满足时，或在实质性新的经核实事实要求审查时开始。它问：

1. 救济与纠正义务是否实际完成；
2. 受影响感知者与利益是否得到实践补救；
3. 复发、规避、依赖与具名路径风险是否实质下降；
4. 当前能力与可靠性是否满足任何适用门槛并支撑许可；
5. 继续限制是否仍必要且相称；以及
6. 再开通路是否与权利底线及受保护宪法利益兼容。

恢复不是自动宽恕、记录抹除或贡献抵消。部分完成仅在剩余保护足够时，才可以正当化更窄锁定。在其他方面已完成救济之后的重复，可以支撑复发持续锁定。评议所服务、受影响方参与与反宪法信任锁定的特殊恢复规则，优先于本一般规则。

<a id="81-rest-state-and-archival"></a>
**静息状态与归档。** 贡献在 [§6.1](#61-recency-and-currentness) 下有当前性半衰期；违规记录也必须有静息状态，否则一项已解决认定会无限期跟随感知者，并变成[第八章 §2.1](core_08_standing_assessment.md#21-standing-records-as-the-unit-of-application) 所禁止的永久地位。一旦恢复完成，且无锁定、救济义务或纠正义务仍打开，违规记录离开有效整合：

- 槽位 **1**、**2** 或 **3** 认定在完成恢复时归档；
- 槽位 **4**、**5** 或 **6** 认定在一段已公布期间之后归档，该期间不得超过 [§6.1](#61-recency-and-currentness) 贡献半衰期；
- 槽位 **7**、**8** 或 **9** 认定无限期保持有效，受 [§5.5](#55-special-locks) 恢复规则与第十章约束。

归档不是删除。[证据保全](core_05_band_oversight.md#evidence-preservation)继续；归档记录在有记载的展示说明它关涉进行中事项的复发风险时，仍可为评议所触及；归档记入[第八章 §3.4](core_08_standing_assessment.md#34-versioning) 下的版本历史。归档记录不产出具名路径效果，不向具名路径看门人披露，也不是能力门槛的输入，除非针对特定高敏感具名路径的已公布门槛陈述更长回溯，且该陈述本身满足[必要性](core_05_band_accountability.md#necessity)与[相称性](core_05_band_accountability.md#proportionality)。

<a id="9-enforcement-realism"></a>
<a id="9-enforcement-realism-and-remedy-systems"></a>
### 9. 执行现实性与救济系统

*用直白的话说：轨迹后果与补救只有在真实制度能够交付它们时才算数。本节是该机制的宪法底线。日常人员、资金、积压与继任规则住在制度层。*

第九章主责问题 3 后果及相关补救必须在制度上真实的宪法底线。[救济系统](core_05_band_accountability.md#remedy-system-constitutional)是交付质疑、收件、保全、审查、修复、监测、保障执行与锁定审查的耐久能力 — 不是纸面路径。实施细节由 [CI-27](../../corpus_institutions/ci_27_remedy_systems_institutional_redress_capacity.md)（*救济系统与制度补救能力*）主责。与 **Article XII-B**（《质疑、审查与救济权》）及[第十一章](core_11_forum.md#chapter-eleven-forums-and-jurisdiction)一并阅读，用于评议所监督。

若后果只存在于纸面，轨迹整合即失败。采纳者必须维持实践、及时的能力，以实施纠正、资助救济、审查限制、保全记录、执行保障，并防止经成本、拖延、边界、重组或形式身份变更而逃脱。

<a id="91-remediation-capacity-and-funding"></a>
#### 9.1 补救能力与资金

纠正、修复、补偿、监测、保障与复发预防要求真实的：

- 制度能力；
- 技术能力；以及
- 财务能力。

开支、无力偿债、不便、接管、解散、资产转让或重组本身，不击败经核实义务。继任者、遗产、接管人与可比受让人继承相称义务 — 无论责任行动者是个人、机构还是系统 — 除非证明了伤害更小的合法转让。

成本不得被外化到：

- 受影响感知者；
- 共同体；
- 生态对象；或
- 公共救济系统

凡责任行动者可以合法承担之处。

<a id="92-remedy-system-durability"></a>
#### 9.2 救济系统耐久

评议所、监督机构、投诉办公室、技术审查机构与权利敏感行政系统必须具有充分的：

- 人员；
- 资金；
- 独立性；
- 记录能力；
- 可及性；以及
- 继任规划。

能力义务随下列各项缩放：

- 风险；
- 案件量；
- 脆弱性；以及
- 权利敏感性。

儿童保护、环境执行、福利行政、拘禁监督、公共卫生回应与可比高影响系统，要求能够及时完成下列各项的耐久救济系统：

- 收件；
- 保全；
- 审查；以及
- 执行。

那些系统必须满足[第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline) 层级里程碑与流程阶段窗口。它们还必须满足[技术评议所领域](core_11_forum.md#42-technical-forum-domains)下已公布的能力、测量与里程碑标准。技术评议所设定并维持那些标准；它们不是救济系统或制度的指挥层级。人员、资金、积压、继任与绩效的问责，仍在[首要利害](core_11_forum.md#2-default-venue-and-primary-stakes)评议所族系 — 通常是[机构](core_11_forum.md#43-institutional-forums)，或在俘获、过程失败或系统对齐崩溃为首要时的[廉正](core_11_forum.md#45-integrity-forums)。救济系统能力的制度实施细节由 [CI-27](../../corpus_institutions/ci_27_remedy_systems_institutional_redress_capacity.md)（*救济系统与制度补救能力*）主责。

下列各项在可预见地使质疑或救济落空时违反本规则：

- 设计出的积压；
- 不可及的收件；
- 长期资金不足；
- 依赖单一脆弱办公室；或
- 长期里程碑失败。

**廉正**、**宪法**或**环境**评议所席位，或审理感知地位裁断的**技术评议所领域**席位的任命不足，是本小节下的耐久失败，与[第十二章 §1.2](../../core_13_governance.md#12-eligibility-contested-selection-and-democratic-minimums)一并阅读。

<a id="92-remedy-parity-funding-floor"></a>
**救济对等资金底线。** 对采纳者所管理的每一系统类，为救济、恢复与再评估所资助的能力，不得少于为同一类锁定管理、执行与保障施加所资助的能力。该比率必须与 [§4.4](#44-remedy-parity-and-lock-preconditions) 绊索数字一并公布。偏离对等的采纳者必须在[第十二章 §3.1](../../core_13_governance.md#31-stewardship-direction) 下记录理由，并在记录上显示救济开始与恢复审查仍在满足其层级时钟；预算对等不免除已触发的 [§4.4](#44-remedy-parity-and-lock-preconditions) 绊索，已满足的绊索也不免除悄悄偏离对等。无法为一类系统资助救济的采纳者，不得为该类建立锁定机制。

<a id="93-cross-jurisdiction-continuity"></a>
#### 9.3 跨管辖连续性

经核实的救济、锁定、保障与审查义务，凡适用法允许承认、合作、执行或备用审查之处，跨边界仍可被主张。逃亡、搬迁、评议所挑选、跨境结构或分布式运营本身，不使它们落空。

<a id="94-anti-evasion-and-look-through-authority"></a>
#### 9.4 反规避与 look-through 权威

评议所与实施系统必须能够看穿形式结构，到达功能控制、受益、连续性与责任。再设立、空壳、合同分层、名义所有权转让、资产剥离、记录碎片化与继任者重新贴标，不抹去经核实义务。look-through 决定必须保持基于证据、行动者专属、可质疑、相称、可审查。

<a id="95-timely-implementation-and-reassessment"></a>
<a id="95-timely-implementation"></a>
#### 9.5 及时实施

救济开始、纠正里程碑、锁定审查与再评估必须满足[及时性](core_05_apex_timeliness_leg.md#timeliness-constitutional)、[第十一章 §6](core_11_forum.md#6-timely-resolution-materiality-tiers-and-anti-delay-discipline) 与 **Article XXIV-C**（《及时解决与反拖延底线》）。加剧伤害、隐瞒未履行或击败审查的拖延，是问题 3 的新经核实事实，并可以正当化升级保障，而不更改原第八章槽位。

权利与轨迹后果只有在感知者能够援引它们、核验它们、资助实践修复、获得及时审查，并对功能上负责的行动者执行义务时，才是真实的。

<a id="101-informal-ecological-stewardship-competency-clearance"></a>
<a id="101-informal-ecological-stewardship-competency-gate"></a>
<a id="101-informal-ecological-stewardship--competency-clearance"></a>
#### 10.1 非正式生态尽责管理 / 能力许可

- **线索：** 一份经核实的同伴互助栖息地恢复记录携带生态尽责管理与勤勉描述符；日后一条具名路径范围的生态能力门槛与许可成为争点。
- **经此路由：**
  - [§1](#1-immutable-chapter-eight-inputs)（*贡献轴槽位与描述符保持固定*）；
  - [§3](#3-descriptor-integration-and-attachment-normalization)（*描述符导入*）；
  - [§6.1](#61-recency-and-currentness) 与 [§6.2](#62-competency-bars-and-clearances)（*当前、与角色相关的工作可以对照包容的、具名路径范围的门槛支撑许可*）；以及
  - [第八章 §3.7 *非正式与小范围记录*](core_08_standing_assessment.md#37-informal-and-small-scope-records)（*依赖机构核验并持有该记录；合作社成员是主张者，不是核验者*）。
- **不可协商：** 贡献轴槽位不更改。凡经核实、当前、与角色相关的工作满足已公布门槛之处，不要求正式谱系；凡无利害依赖机构核验了该记录之处，不要求正式机构核验。
- **深度指针：** 同一事实族的问题 2 例示 — [第八章 §4.6 例 1](core_08_standing_assessment.md#46-question-2-measurement-illustrations)。

<a id="102-ecological-negligence-with-concealment"></a>
#### 10.2 带隐瞒的生态过失

- **线索：** 一份固定违规轴记录把生态与过失不当行为与通知后经核实隐瞒堆叠在一起。
- **经此路由：**
  - [§1](#1-immutable-chapter-eight-inputs)（*槽位保持固定*）；
  - [§3](#3-descriptor-integration-and-attachment-normalization)（*描述符与附着取向回应*）；
  - [§4](#4-violation-correction-and-prevention)（*救济、纠正与预防*）；以及
  - [§5.4](#54-special-violation-rules)（*过失 / 隐瞒塑造锁定与保障附着*）。
- **不可协商：** 隐瞒从不移动违规轴槽位。它只可以取向救济、监测、资源尽责管理限制与提高的核验。
- **深度指针：** 同一事实族的问题 2 例示 — [第八章 §4.6 例 2](core_08_standing_assessment.md#46-question-2-measurement-illustrations)。

<a id="103-forum-integrity-deception-or-recusal-failure"></a>
#### 10.3 评议所完整性欺骗或回避失败

- **线索：** 评议所场景中经核实的不诚实披露，或在回避被要求且公正性被实质损害之处经核实未能回避。
- **经此路由：** [§5.4](#54-special-violation-rules)（*欺骗 / 隐瞒附着*）；[§5.5](#55-special-locks)（*评议所服务轨迹锁定*）。
- **不可协商：** 经核实的应回避失败触发评议所服务轨迹锁定，无论该认定是否到达第十章指定轨道。

<a id="104-recurrence-after-completed-restitution"></a>
#### 10.4 完成返还后的复发

- **线索：** 返还或可比救济已完成，但人际暴力或可比模式的经核实复发风险仍在。
- **经此路由：**
  - [§4.1](#41-remedy-and-correction)（*救济完成不抹去预防义务*）；
  - [§4.2](#42-general-standing-locks)（*保护性或复发持续锁定*）；
  - [§5.2](#52-proportionality-and-calibration)；以及
  - [§8](#8-restoration-and-reassessment)。
- **不可协商：** 已完成返还不要求在经核实复发风险仍在时解除锁定。任何继续锁定必须保持所需、相称、可审查，并与权利底线兼容。

<a id="105-champion-repair-while-a-lock-remains-active"></a>
#### 10.5 锁定仍有效时的冠军修复

- **线索：** 杰出修复或高贡献在一份关联贡献记录上可见，而轨迹锁定仍阻断一条具名路径。
- **经此路由：**
  - [§6](#6-contribution-consequences-second)（*贡献居后，且仅针对未被锁定阻断的具名路径*）；
  - [§8](#8-restoration-and-reassessment)；以及
  - [第八章 §2.2](core_08_standing_assessment.md#22-linked-records-and-no-offset-bridge)（*无抵消桥*）。
- **不可协商：** 杰出修复可以支撑恢复可信。它不打开仍被轨迹锁定阻断的具名路径，也不买断对受影响感知者所欠的救济。

<a id="106-institutional-vehicle-and-successor-evasion"></a>
#### 10.6 机构载体与继任者规避

- **线索：** 一机构携带反复伤害、俘获或规避，包括经空壳、重新贴标或继任载体。
- **经此路由：**
  - [§5](#5-lock-design-and-enforcement)（*具名路径锁定与机构限制*）；
  - [§9.1](#91-remediation-capacity-and-funding)（*继任者与资金连续性*）；以及
  - [§9.4](#94-anti-evasion-and-look-through-authority)。
- **不可协商：** 仍要求行动者专属证明。重新贴标、空壳替换与形式身份变更不击败经核实义务。凡经核实事实支持之处，后果可以包括中止、接管、结构性分离、解散与继任控制限制。

<a id="107-misaligned-reward-retention"></a>
#### 10.7 错位奖赏保留

- **线索：** 在充分通知奖赏路径宪法错位或被滥用之后，行动者明知保留受益而无及时受保护报告。
- **经此路由：** [§5.4](#54-special-violation-rules)（*错位奖赏* — 没收、保留、具名路径锁定，以及依赖方 / 第三方依赖核算）。
- **不可协商：** 通知后明知保留可以创造违规后果。善意争议与受保护报告仍受保护。

<a id="108-top-slot-anti-constitutional-allegation"></a>
<a id="108-anti-constitutional-misconduct-allegation"></a>
#### 10.8 反宪法不当行为指控

- **线索：** 一份合格的违规轴槽位 7–9 记录提出可能的反宪法不当行为指定，而普通问题 3 效果也到期。
- **经此路由：**
  - [§2](#2-integration-record-and-decision-order)（*处理顺序第 8 步 — 第十章门户*）；
  - [§4](#4-violation-correction-and-prevention) 与 [§5](#5-lock-design-and-enforcement)（*从固定记录而来的普通救济、纠正与保护锁定*）；
  - [§5.5](#55-special-locks)（*反宪法信任锁定*）；以及
  - [第十章](core_10_a_misconduct_designation.md#chapter-ten-anti-constitutional-misconduct)（*仅指定*）。
- **不可协商：** 普通第九章救济、纠正与保护锁定从固定违规记录推进。第十章分开决定指定。只有最终指定触发反宪法信任锁定。

<a id="109-rights-floor-waiver-or-unconstitutional-contract-devices"></a>
#### 10.9 权利底线放弃或违宪合同装置

- **线索：** 一份固定违规轴记录显示，把通路、就业、平台参与或可比结社，以所谓权利底线放弃、封口、覆盖或违宪合同条款为条件 — 包括使轨迹、审计或可质疑性寒蝉的无效保密协议或流动限制装置。
- **经此路由：**
  - [§4](#4-violation-correction-and-prevention)（*救济、纠正与预防*）；
  - [§4.2](#42-general-standing-locks)（*范围限于被滥用的信任、角色、信用或影响路径的一般轨迹锁定*）；
  - [§5.1](#51-definition-and-attachment)（*附着字段*）；以及
  - [§5.4](#54-special-violation-rules)（*抵抗义务*，凡该文书要求非法或违宪遵从之处）。
- **不可协商：** 本线索不在 [§5.5](#55-special-locks) 下创造特殊锁定。条款无效与指定标准仍在[第十章 §5.2](../../core_11_b_misconduct_pattern_applications.md#52-rights-floor-waivers-and-unconstitutional-contract-terms)。第九章从经核实记录附着普通具名路径锁定；只有最终指定触发 [§10.8](#108-anti-constitutional-misconduct-allegation) 下的反宪法信任锁定。

<a id="1010-contest-pathway-or-info-sphere-flooding"></a>
#### 10.10 质疑路径或信息圈灌水

- **线索：** 一份固定违规轴记录显示故意、轻率或可预见地冷漠的体量、冗余、自动化或合成流量，击败、拖延至超出实践救济，或实质降级质疑、收件、裁决、发表或信息圈核验路径。
- **经此路由：**
  - [§4](#4-violation-correction-and-prevention)（*救济、纠正与预防*）；
  - [§4.2](#42-general-standing-locks)（*对被滥用的路由、提交、排名、通路或影响路径的保护性具名路径锁定*）；
  - [§5.1](#51-definition-and-attachment) 与 [§5.2](#52-proportionality-and-calibration)（*所需、相称、可审查的范围*）；以及
  - [第十一章](core_11_forum.md#chapter-eleven-forums-and-jurisdiction)（*运营收件分诊与反博弈 — 监督而不发明轨迹效果*）。
- **不可协商：** 本线索不创造灌水锁定或其他 [§5.5](#55-special-locks) 类型。指定侧标准路由仍在[第十章 §5.3](../../core_11_b_misconduct_pattern_applications.md#53-flooding-the-zone-and-contest-pathway-denial) 与 [§5.4](../../core_11_b_misconduct_pattern_applications.md#54-info-sphere-zone-flooding)。普通保护锁定从固定记录推进，无论指定日后是否附着。

<a id="1011-infrastructure-denial-or-dependency-cutoff"></a>
#### 10.11 基础设施拒绝或依赖切断

- **线索：** 一份固定违规轴记录显示拒绝、毁灭、停用或依赖切断，使生存关键通路、救济、审计、核验或宪法运营基础设施在实质上无法使用。
- **经此路由：**
  - [§4](#4-violation-correction-and-prevention)（*救济、纠正与预防*）；
  - [§4.2](#42-general-standing-locks)（*保护性或通路延续具名路径锁定*）；
  - [§5.1](#51-definition-and-attachment)（*包括与再造切断风险的网络或控制点隔离*）；
  - [§5.4](#54-special-violation-rules)（*仅在经核实危险支持时的强制性或限制自由保障*）；以及
  - [§9](#9-enforcement-realism)（*救济系统耐久与反规避*）。
- **不可协商：** 本线索不在 [§5.5](#55-special-locks) 下创造基础设施锁定。指定侧标准路由仍在[第十章 §5.9](../../core_11_b_misconduct_pattern_applications.md#59-infrastructure-denial-destruction-or-dependency-cutoff-conduct)。[§5.1](#51-definition-and-attachment) 下的全局非限制限度仍保护言论、请愿、受影响方参与、权利底线，以及锁定不得消灭的生存关键通路。

<a id="1012-stakeholder-participation-corruption-or-false-stake-abuse"></a>
#### 10.12 受影响方参与腐败或虚假利害滥用

- **线索：** 一份固定违规轴记录显示经核实的腐败、俘获、虚假或夸大的利害主张、强制性参与权重抽取、在约束性受影响方选择中买影响，或对已获授权系统、机构或有界决定域内部一条**受影响方参与**路径的可比实质滥用。
- **经此路由：**
  - [§4](#4-violation-correction-and-prevention)（*救济、纠正与预防*）；
  - [§4.2](#42-general-standing-locks)（*路径区分 — 治理投票 vs 受影响方参与*）；以及
  - [§5.5](#55-special-locks)（*受影响方参与轨迹锁定*）。
- **不可协商：** 受影响方参与轨迹锁定在其经核实触发被满足时附着。它限制受影响域中按利害加权的影响与约束性受影响方选择。它本身不剥夺**治理投票**、**基础宪法选择**或[受影响方](core_05_band_participation.md#stakeholder)地位。**治理投票**锁定不是本锁定的替代。

<a id="1013-obstruction-of-accountability"></a>
#### 10.13 阻碍问责

- **线索：** 一份固定违规轴记录显示经核实的**阻碍问责** — 对可问责机制的干扰，例如证据完整性、核验、评议所过程、轨迹记录、救济时钟，或质疑与补救路径 — 包括第八章记录**阻碍问责不当行为**或把阻碍作为行为品格堆叠之处。
- **经此路由：**
  - [§4](#4-violation-correction-and-prevention)（*救济、纠正与预防*）；
  - [§4.2](#42-general-standing-locks)（*对被滥用的可问责、质疑、证据、轨迹或救济路径的具名路径范围锁定*）；
  - [§5.4](#54-special-violation-rules)（*隐瞒、规避、欺骗与职责相关塑造*）；
  - [§5.5](#55-special-locks)（*仅当 [§10.3](#103-forum-integrity-deception-or-recusal-failure) 下评议所完整性 / 应回避触发被满足时的评议所服务轨迹锁定*）；以及
  - [§10.8](#108-anti-constitutional-misconduct-allegation)（*当 `s` = 7–9 且反宪法不当行为被实质指控时的第十章门户*）。
- **不可协商：** 本线索不创造阻碍锁定或其他 [§5.5](#55-special-locks) 类型。阻碍品格从不移动违规轴槽位。普通具名路径锁定在任何槽位都从固定记录推进。指定侧标准路由仍在[第十章 §5.11](../../core_11_b_misconduct_pattern_applications.md#511-obstruction-of-accountability-criteria-interaction)；只有最终指定触发 [§10.8](#108-anti-constitutional-misconduct-allegation) 下的反宪法信任锁定。把经核实阻碍*行为*与作为结构条件的[解决路径俘获](core_05_band_accountability.md#capture-of-resolution-pathways)区分开。

<a id="1014-verified-cruelty-character"></a>
#### 10.14 经核实残忍品格

- **线索：** 一份固定违规轴记录携带经核实[残忍](core_05_band_accountability.md#cruelty)行为品格 — 把痛苦本身当作目的，或超出必要与相称性的无端或贬损施加 — 无论暴力或强制描述符是否也堆叠。
- **经此路由：**
  - [§4.1](#41-remedy-and-correction)（*救济与纠正必须保持非贬损*）；
  - [§4.2](#42-general-standing-locks)（*对会让同一残忍继续或复发的具名路径的保护性或保障锁定*）；
  - [§4.3](#43-voluntary-public-accountability-expression)（*自愿公开表达若被使用，必须保持非贬损*）；
  - [§5.2](#52-proportionality-and-calibration)；以及
  - [第八章 §4.2](core_08_standing_assessment.md#42-violation-severity-input-dimensions)（*行为品格堆叠*）。
- **不可协商：** 残忍品格从不移动违规轴槽位。贡献不能抵消未解决的残忍品格预防。救济、限制与自愿公开问责表达本身不得把痛苦当作目的，也不得添加无端或贬损痛苦。本线索不创造残忍锁定或其他 [§5.5](#55-special-locks) 类型。
