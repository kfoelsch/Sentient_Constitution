*用直白的话说：让问题按时穿过发现、质疑、解决与修复 — 已公布的时钟若让伤害继续累积，那就不是及时性。*

- O: 让问题按时穿过发现、质疑、解决与修复 — 本条目所点名的四元腿。
  - **范围内：** 原则层应答义务，按[实质利害](core_00_preamble.md#material-stake)缩放，贯穿：
    - 发现；
    - 可质疑性；
    - 解决；
    - 补救；以及
    - 尽责管理纠正
    于宪法协调生命周期。
  - **依赖于：** 本腿要起作用所需的条件与通道。每一用语的详细范围与如何测量规则住在其自身定义上；从[四元腿分解](#timeliness-tetrad-leg-decomposition)开始：
    - [及时解决](../../core_05_band_accountability.md#timely-resolution-constitutional)；
    - [解决路径俘获](../../core_05_band_accountability.md#capture-of-resolution-pathways)；
    - [宪法效率](../../core_05_band_continuity.md#constitutional-efficiency)；与
    - [可避免负担](../../core_05_band_continuity.md#avoidable-burden)。
  - **范围外：** 由[及时解决](../../core_05_band_accountability.md#timely-resolution-constitutional)、姐妹叶与 CJS 主责的叶定义细节、测量层级与实施机制。
<a id="timeliness-constitutional-m"></a>
- M: 问题是否真正按时移动？本行只点名该看什么；如何测量的规则坐落在每一项被链接的定义上。主题地图：[四元腿分解](#timeliness-tetrad-leg-decomposition)。
<a id="timeliness-constitutional-a"></a>
- A:
  - 在[宪法四元](core_00_preamble.md#constitutional-tetrad)下判断，按[实质利害](core_00_preamble.md#material-stake)缩放。
  - 问一问及时性是否真实 — 保全权利的速度，不是原始吞吐量 — 而不只是仪式。
  - 一并阅读：
    - [及时解决](../../core_05_band_accountability.md#timely-resolution-constitutional)；
    - [解决路径俘获](../../core_05_band_accountability.md#capture-of-resolution-pathways)；
    - [宪法效率](../../core_05_band_continuity.md#constitutional-efficiency)；
    - [可避免负担](../../core_05_band_continuity.md#avoidable-burden)；
    - [尽责管理缺陷](../../core_05_band_continuity.md#stewardship-defect-constitutional)；与
    - [审查与纠正义务](../../core_05_band_continuity.md#review-and-correction-duty-constitutional)。
  - 及时性横断参与、监督与问责，但在形式结构存在而实质问题并不移动之处，仍可被独立掏空。
<a id="timeliness-constitutional-c"></a>
- C: 不合规当：
  - 仪式、已公布的 SLA 或吞吐量指标使发现、质疑、解决或修复实质停滞；
  - 设计出的积压；
  - 自己造成的拖延；
  - 无限期未决；
  - 在纠正本可行时，经通知后仍推迟修复；或
  - 效率主张跳过核实、个别化归属或质疑权利。

*用直白的话说：这些问题问问题是否真正按时移动 — 不是仪表盘是否显示吞吐量。这是及时性测量族的第五章家园；序言 §2 保留直白的类别问题，族表与定义路由住在此处。*

*实质性*（[实质性认定](../../core_05_band_oversight.md#materiality-determination)）是整合性的 — 不是单独的测量类别；它在[实质利害](core_00_preamble.md#material-stake)下缩放本族适用的强度。

| 测量族 | 直白问题 | 主要宪法用途 |
|---|---|---|
| [及时解决](../../core_05_band_accountability.md#timely-resolution-constitutional) | 争议是否在救济仍要紧时得到解决？ | 防止拖延掏空权利 |
| 反拖延与解决路径纪律 | 激励与结构是否避免设计出的积压、俘获与空洞期限？ | 检出拖延体制与[解决路径俘获](../../core_05_band_accountability.md#capture-of-resolution-pathways) |

这些测量问过程时钟、解决路径与修复速度是否让[宪法四元](core_00_preamble.md#constitutional-tetrad)的**及时性**腿在实践中保持真实 — 而不只是纸上存在。
