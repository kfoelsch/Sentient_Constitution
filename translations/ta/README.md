# தமிழ்ப் பதிப்பு — முன்னோடி (பிணைக்காதது)

<details>
<summary><strong><span style="color: #2563eb;">தொகுப்பில் இடம் (செயல்படாதது): கோப்பு அமைப்பும் வாசிப்பு விதிகளும்</span></strong></summary>

> கீழே உள்ள உள்ளடக்கம் **வாசிப்பவருக்கான வழிகாட்டல் மட்டும்**. இது பிணைக்கும் கடமைகளைச் சேர்க்கவோ, குறைக்கவோ, சுருக்கவோ செய்யாது.
>
> இந்தக் கோப்புறை ஒரு **வாசிப்பு-மொழி முன்னோடி**. இது **உணர்வுள்ளோர் அரசியலமைப்பு அல்ல**. இது எண்ணிடப்பட்ட `core_*` கோப்புகளை மாற்ற **முடியாது**. இது **அனுப்பும் பதிப்பு அல்ல**. இதைப் படிப்பது [இந்த அரசியலமைப்பை ஏற்றுக்கொள்வது](../../core_15_amendment_ratification.md#10-ratification-and-adoption) **அல்ல**. மொழிபெயர்ப்பும் ஆங்கில மூலமும் முரண்படுவதாகத் தோன்றினால், பிற்காலப் பதிப்பு வேறு சொல்லும் வரை ஆங்கில எண்ணிடப்பட்ட `core_*` வெல்லும். காண்க [Reader-language editions](../../doc_architecture.md#reader-language-editions).
>
> **தொகுப்புப் பதிப்பில் பொருத்தப்பட்டது:** `SC-Corpus-2026.08.09` (நடைமுறை 2026-08-09; [README.md](../../README.md)). **முன்-வெளியீடு.**

</details>

<br>

*எளிய சொற்களில்: செலவையும் முறையையும் அளக்க இது தமிழ் வரைவு; இரண்டாவது அரசியலமைப்பு உரை அல்ல.*

**மொழிவட்டாரம்.** செந்தமிழ் எழுத்து (இந்தியா, இலங்கை, புலம்பெயர்ந்தோர்). இது ஒரு அரசை நிலைநிறுத்தாது. இந்தி இந்தியாவின் ஒரே கதவு அல்ல; தமிழ் தனிக் கதவு. தெலுங்கு, வங்காளம், மராத்தி மற்றும் பிறவும் தனிக் கதவுகளாகவே இருக்கும்.

**முதல் வெட்டு, கட்டமைப்பின்படி.** அனுப்பும் வரிசை முதலில் எளிய-நுழைவுச் சுருக்கங்களையும், உரிமைத் தளத் தாளையும், பொதுக் கதவையும் கேட்கிறது. இந்த முன்னோடி வேண்டுமென்றே [முகவுரை](core_00_preamble.md) மற்றும் [அத்தியாயம் ஒன்று, பகுதி அ](core_01_a_values_principles.md) ஆகியவற்றை மொழிபெயர்க்கிறது, எண்ணிடப்பட்ட ஒரு `core_*` எவ்வளவு செலவாகும் என்பதை அளக்க. அத்தியாயம் ஒன்று, பகுதி ஆவும் இங்கு சேர்க்கப்பட்டுள்ளது.
