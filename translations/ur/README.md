# اردو ایڈیشن — پائلٹ (پابند نہیں)

<summary><strong><span style="color: #2563eb;">کارپس میں مقام (غیرِ عملی): فائل کی ساخت اور پڑھنے کے قواعد</span></strong></summary>

> نیچے کا مواد **صرف قارئین کی رہنمائی** ہے۔ یہ پابند فرائض نہیں بڑھاتا، گھٹاتا یا تنگ کرتا۔
>
> یہ فولڈر **قارئین کی زبان کا پائلٹ** ہے۔ یہ **شعوری آئین نہیں**۔ یہ نمبر والے `core_*` فائلیں بدل **نہیں** سکتا۔ یہ **ارسال ایڈیشن نہیں**۔ اسے پڑھنا [اس آئین کو اختیار کرنا](../../core_15_amendment_ratification.md#10-ratification-and-adoption) **نہیں** ہے۔ اگر ترجمہ اور انگریزی اصل میں اختلاف نظر آئے تو انگریزی نمبر والے `core_*` جیتتے ہیں جب تک بعد کا ایڈیشن اور نہ کہے۔ دیکھیں [Reader-language editions](../../doc_architecture.md#reader-language-editions)۔
>
> **کارپس ایڈیشن پر پن:** `SC-Corpus-2026.08.09` (نافذ 2026-08-09؛ [README.md](../../README.md))۔ **قبل از اشاعت۔**

<br>

*سادہ الفاظ میں: یہ لاگت اور طریقہ ناپنے کے لیے اردو مسودہ ہے، دوسرا آئینی متن نہیں۔*

**لوکیل۔** معیاری تحریری اردو (نستعلیق/یونیکوڈ)۔ کسی ریاست کو نہیں جمائے۔ ہندی کا بدل نہیں۔ پنجابی، سندھی، پشتو اور دیگر الگ دروازے رہتے ہیں۔

**اگلا جھرمٹ، تعمیر کے مطابق۔** پانچ ارسال زبانوں کے بعد: پرتگالی (برازیلی)، بنگالی، پھر فرانسیسی، پھر اردو۔ یہ پائلٹ جان بوجھ کر [تمہید](core_00_preamble.md) اور [باب یکم، حصہ الف](core_01_a_values_principles.md) کا ترجمہ کرتا ہے تاکہ ایک نمبر والے `core_*` کی لاگت ناپی جا سکے۔ قارئین کا دروازہ سیاسی مداخلت نہیں۔
