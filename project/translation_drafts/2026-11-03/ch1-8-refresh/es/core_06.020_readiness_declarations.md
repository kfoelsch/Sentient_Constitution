# Borrador de traducción — `core_06.020_rights_part_e.md`, Artículo XXVIII-A, exigibilidad y ruta de logro

Un Piso de Derechos es exigible para un alcance definido (población, clase de sistema, entorno o región) cuando los datos verificados demuestran que las instituciones, capacidades y cultura necesarias están listas. La declaración la emite, con razones publicadas, una parte independiente del custodio del registro, una vez satisfechos los criterios verificados. Retenerla entonces constituye demora autogenerada conforme a XXVIII-B; las entidades afectadas pueden impugnar una declaración prematura o retenida. Para sistemas, debe emitirse dentro del plazo máximo del nivel correspondiente a la clase (A: 7 días; B: 14; C: 30; L: 60; P: 90) desde que se cumplan los criterios verificados, lo reflejen o no los datos del registro. Para otros alcances, el límite es 14 días. La verificación debe completarse dentro del plazo de recepción del nivel correspondiente (o B para otros alcances). La secuenciación de alcances y la impugnación se rigen por CI-6.275 §4. Una vez declarado exigible, el alcance sigue siéndolo; la pérdida posterior de capacidad es falla institucional, no retirada silenciosa del derecho.

Cada plan cubre todos los dominios del Piso de Derechos dentro de su alcance. La medición inicial de cobertura y utilidad práctica se publica antes del primer portón dependiente; lo no medido cuenta como no alcanzado y prioritario para medir, nunca como aprobado. El objetivo es el piso constitucional completo. El reinicio de línea de base mueve fechas y responsables, no objetivo ni medición inicial. Cada dominio tiene responsable, recursos comprometidos, hitos fechados y fecha final, según clase afectada e interés material.
