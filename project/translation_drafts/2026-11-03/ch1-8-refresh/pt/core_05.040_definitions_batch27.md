#### Tipos e tratamento de dados institucionais

<details>
<summary><strong>Rastreio</strong></summary>

- Titular canônico: Capítulo Dez §3 Avaliação integral, item 8, e §8.1 Conteúdo mínimo; leia com Capítulo Nove A §3.4 Avaliação de tipos e tratamento. Leia com certificação institucional, Registro institucional e Registro de Tipos de Dados do Sistema.

</details>

*Em termos simples: abrange dados que a Instituição trata fora de qualquer Sistema. A avaliação registra tipos e tratamento no Registro institucional. Dados dentro de um Sistema são avaliados uma vez no registro do Sistema e citados pela Instituição.*

- **What it is**
  - **In scope / out of scope / dependencies:** Abrange avaliação de tipos de dados materialmente no escopo tratados fora de Sistemas, inclusive tratamento sob a classificação aplicável mais restritiva. Achados ficam na seção de dados do Registro institucional, sem registro separado. Dados dentro do Sistema são avaliados/registrados uma vez no Registro de Tipos de Dados do Sistema e citados. Depende da Instituição, certificação institucional e registros de dados. Requisitos no Capítulo Dez §3 item 8, §8.1 e Capítulo Nove A §3.4. Aqui consta apenas o sentido do Capítulo Cinco.
<a id="institutional-data-types-and-handling-a"></a>
- **How to measure and assess**
  - Avalie tipos materiais tratados fora de Sistemas, classificação e tratamento, cronograma de reavaliação e registro dos achados sem repetir avaliação de Sistema.
<a id="institutional-data-types-and-handling-c"></a>
- **What must hold**
  - **Primary failure:** Falhas: omitir dados materiais fora de Sistema; aplicar classificação menos restritiva; omitir reavaliação exigida; duplicar ou substituir achados de dados do Sistema.
