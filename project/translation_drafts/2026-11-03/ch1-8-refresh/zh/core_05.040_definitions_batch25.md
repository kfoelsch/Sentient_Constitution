#### 主导论坛

<details>
<summary><strong>溯源</strong></summary>

- 规范归属：第九章B部分§6.2监督顺序；并读§6.1.1认证中的四个席位。与认证轮次、记录席及验证或授权席合读。

*通俗地说，主导论坛是带领认证轮次的诚信论坛。它指示开启一份统一协调记录，汇总各组成部分的结论并说明结果。*

- **What it is**
  - **In scope / out of scope / dependencies:** 范围：带领每轮认证的诚信论坛，除非第十四章针对主要利益指定另一合法主导者。它就结果担任验证或授权席，并指示记录席持有人开启一份协调记录。范围外：给出有限组件结论的论坛/权限；保管记录的记录席持有人。主导论坛负责顺序，不得在同一行为中兼任记录席。依赖认证轮次、记录席和验证/授权席。步骤见第九章B部分§6.2，四席中的位置见§6.1.1。本条仅定义第五章含义。
<a id="lead-forum-a"></a>
- **How to measure and assess**
  - 按连续性测量族评估：每轮是否指定主导论坛，且同一行为中不兼任记录席；是否从不把组件结论缺失或沉默视为授权。
<a id="lead-forum-c"></a>
- **What must hold**
  - **Primary failure:** 主要失败：主导论坛同时保管同一行为的记录；必要组件工作完成前即授权范围。
