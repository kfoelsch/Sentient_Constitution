#### 依赖限制

*通俗地说，这是记录中对他人可以依赖某系统或机构到何种程度的限制。它随认证结果列明，也可在异议/审查待决期间由命令设定。*

- **What it is**
  - **In scope / out of scope / dependencies:** 范围：随认证结果记录或在异议/审查待决期间下令设定的依赖边界。临时认证须列明这些边界。范围外：认证条件是运营者必须履行的要求，依赖限制则约束他人可依赖的范围；暂缓作为推迟/阻止行动或结果的独立措施。依赖临时认证、系统记录及认证条件。记录要求见C §8.1.8，异议期间限制见B §6.3，上线禁令见B §7.1。本条仅定义第五章含义。
<a id="reliance-limits-a"></a>
- **How to measure and assess**
  - 按连续性测量族评估：记录是否列明各项限制及其保护对象；事项待决期间的依赖是否保持在限制内。
<a id="reliance-limits-c"></a>
- **What must hold**
  - **Primary failure:** 主要失败：临时认证未记录依赖限制而仅停留纸面；依赖系统超出明示限制。
