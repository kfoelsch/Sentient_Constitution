#### மறுதிறந்த ஆய்வு

<details>
<summary><strong>தடமறிதல்</strong></summary>

- அதிகாரப்பூர்வ உரிமையாளர்: அத்தியாயம் ஒன்பது C §9.2 மறுதிறப்பு தூண்டிகள்; §9 மறுசான்றளிப்பு மற்றும் மறுதிறப்புடன் படிக்கவும். சான்றளிப்பு சுற்று, தூண்டி, அமைப்பு பதிவுடன் படிக்கவும்.

</details>

*எளிய பொருள்: ஏற்கெனவே பதிவு உள்ள அமைப்பு/நிறுவனத்திற்கு, முக்கிய மறுதிறப்பு தூண்டி செயல்பட்டதால் அடுத்த திட்டமிட்ட மறுசான்றுக்கு முன் தொடங்கும் சான்றளிப்பு சுற்று. முந்தைய பதிவுடன் இணைந்த புதிய பதிவைத் திறக்கும்.*

- **What it is**
  - **In scope / out of scope / dependencies:** உள்ளடக்கம்: முக்கிய தூண்டி நிகழ்ந்ததால் அடுத்த திட்டமிட்ட மறுசான்றுக்கு முன் தொடங்கும் சுற்று; அதே மன்ற நடைமுறையுடன் முடிவைத் தரும். விலக்கு: அட்டவணை மறுசான்றளிப்பு; சான்றளிப்பு குறைக்கு பதிலாக மன்றம் ஆணையிடும் புதிய ஆய்வு. சுற்று, தூண்டி, அமைப்பு பதிவைச் சார்ந்தது. தூண்டி/புதிய பதிவு C §9.2 மற்றும் §9 இல். இங்கு அத்தியாயம் ஐந்தின் பொருள் மட்டும்.
<a id="reopened-review-a"></a>
- **How to measure and assess**
  - தொடர்ச்சி அளவீட்டில்: முடிந்த பதிவுடன் இணைந்த புதிய பதிவு திறக்கிறதா; முக்கிய தூண்டி செயல்படும் போது தொடங்கி அடுத்த அட்டவணை வரை காத்திருக்கவில்லையா எனப் பாருங்கள்.
<a id="reopened-review-c"></a>
- **What must hold**
  - **Primary failure:** முக்கியத் தோல்வி: தூண்டி முக்கியமாக இருக்கும்போது தாமதித்தல்; தூண்டிக்குப் பின் மறுதிறந்த ஆய்வுக்குப் பதில் திட்டமிட்ட மறுசான்றைப் பயன்படுத்துதல்.
