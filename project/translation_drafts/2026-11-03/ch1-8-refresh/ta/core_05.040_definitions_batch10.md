#### சவால் பாதை

<details>
<summary><strong>தடமறிதல்</strong></summary>

- அதிகாரப்பூர்வ உரிமையாளர்: அத்தியாயம் ஒன்பது C §10.1 பாதை திறக்கும் நேரம்; B §6.2.1 முதலில் சவால் பாதை, C §10.2 சவால் செய்யும் பாதைகளுடன் படிக்கவும். குழுக் கூறு இல்லை. அமைப்பு மற்றும் நிறுவனச் சான்றளிப்பு பதிவுகளுடன் படிக்கவும்.

</details>

*எளிய பொருள்: சான்றளிப்பை எதிர்க்க உணர்வுள்ளவர் பயன்படுத்தும் வெளியிடப்பட்ட வழி—யார் பெறுவர், எவ்வாறு தாக்கல் செய்வது, காலக்கெடு என்ன. எந்த மன்றமும் ஒப்பமிடுவதற்கு முன் பதிவில் பெயரிடப்பட வேண்டும்; முடிவு வெளியானதும் திறக்கும்.*

- **What it is**
  - **In scope / out of scope / dependencies:** உள்ளடக்கம்: பதிவில் குறிப்பிடப்பட்ட வெளியிடப்பட்ட வழி; அத்தியாயம் ஒன்பது C §10.2 இன் சவால்தன்மைப் பாதைகளில் ஒன்று. சர்ச்சை ஏற்படும் இடத்திற்கேற்ற பாதைகள் B §6.3 இன் சவால் சங்கிலியாகும். முதல் முடிவுடன் திறந்து, அமைப்புக்கு பங்குதாரர்கள் இருக்கும் வரை திறந்திருக்கும். விலக்கு: சவால் தானே (சவால்தன்மை மற்றும் நியாய நடைமுறை ஆளும்); பாதையையும் தகுந்த/மாற்று ஆய்வு மன்றத்தையும் இணைக்கும் சவால் இருக்கை; இயக்குநரின் உள் ஆய்வு, விற்பனையாளர் சான்று அல்லது தொழில்நுட்ப ஒப்புதல். இரு சான்றளிப்பு பதிவுகளையும் சார்ந்தது. திறக்கும் நேரம் C §10.1; ஒப்புதலுக்கு முன் பெயரிடும் விதி B §6.2.1. இங்கு அத்தியாயம் ஐந்தின் பொருள் மட்டும்.
<a id="challenge-path-a"></a>
- **How to measure and assess**
  - தொடர்ச்சி அளவீட்டில்: ஒப்புதலுக்கு முன் பதிவில் பெறுநர், தாக்கல் முறை, காலக்கெடு உள்ளதா; முடிவை நம்பச் சொல்வதற்கு முன் பாதை திறக்கிறதா, பங்குதாரர்கள் இருக்கும் வரை திறந்திருக்கிறதா என மதிப்பிடுக.
<a id="challenge-path-c"></a>
- **What must hold**
  - **Primary failure:** முக்கியத் தோல்வி: பாதை பெயரிடாத பதிவை ஒப்புதல்; பங்குதாரர்கள் இருக்கும்போது பதிவை எதிர்க்க திறந்த பாதை இல்லாத அமைப்பை ஒத்திசைந்தது எனக் கூறுதல்.
