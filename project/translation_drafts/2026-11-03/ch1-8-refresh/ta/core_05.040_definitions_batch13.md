#### புதிய ஆய்வு

<details>
<summary><strong>தடமறிதல்</strong></summary>

- அதிகாரப்பூர்வ உரிமையாளர்: அத்தியாயம் ஒன்பது B §7.2 சான்றளிப்பு குறைகள் மற்றும் திருத்தம்; C §9 மறுசான்றளிப்பு, மறுதிறப்புடன் படிக்கவும். சான்றளிப்பு சுற்று, மறுதிறந்த ஆய்வு, அமைப்பு பதிவுடன் படிக்கவும்.

</details>

*எளிய பொருள்: சான்றளிப்பு குறைக்கு பதிலாக மன்றம் தேர்ந்தெடுக்கும் பதில்களில் ஒன்றாக ஆணையிடும் அடுத்த சான்றளிப்பு சுற்று. மற்ற அடுத்த சுற்றுகளைப் போலவே புதிய பதிவைத் திறக்கும்.*

- **What it is**
  - **In scope / out of scope / dependencies:** உள்ளடக்கம்: அத்தியாயம் ஒன்பது B §7.2 கீழ் குறைக்கு பதிலாக ஆணையிடப்படும் அடுத்த சுற்று; நிபந்தனையுடன் சான்றளித்தல், ஒத்திவைத்தல், மறுத்தல், ரத்து, இடைவெளி மாற்றம் அல்லது மறுஆய்வு திறத்தல் ஆகியவற்றில் ஒன்று. அதே மன்ற நடைமுறையைக் கடந்து முடிவுடன் நிறைவடையும். விலக்கு: திட்டமிட்ட மறுசான்றளிப்பு அல்லது அமைப்பின் முதல் சான்றளிப்பு. சான்றளிப்பு சுற்று, மறுதிறந்த ஆய்வு, அமைப்பு பதிவைச் சார்ந்தது. தெரிவு B §7.2; புதிய பதிவு C §9. இங்கு அத்தியாயம் ஐந்தின் பொருள் மட்டும்.
<a id="fresh-review-a"></a>
- **How to measure and assess**
  - தொடர்ச்சி அளவீட்டில்: பிற பதில்களுக்குப் பதில் புதிய ஆய்வை ஏன் ஆணையிட்டது என மன்றம் கூறுகிறதா; புதிய ஆய்வு முடிந்த பதிவுடன் இணைந்த புதிய பதிவைத் திறந்து குறிப்பிடப்பட்ட முடிவுடன் நிறைவுறுகிறதா என மதிப்பிடுக.
<a id="fresh-review-c"></a>
- **What must hold**
  - **Primary failure:** முக்கியத் தோல்வி: புதியதற்குப் பதில் முந்தைய பதிவைத் திறந்தே வைத்தல்; அல்லது ஆணையிட்ட புதிய ஆய்வை முடிவின்றி விடுதல்.
