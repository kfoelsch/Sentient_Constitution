## Institution Class — فئة المؤسسة

*تعكس فئة المؤسسة أكبر أثر مادي لما تقرره أو تحتفظ به أو تتحكم فيه، عبر أنظمتها أو بصورة مستقلة. ولا يحدد اسمها أو شكلها القانوني أو قائمة ميثاقها فئتها.*

- **ماهيتها:** **ضمن النطاق:** الفئة المسندة للمؤسسة وفق أكبر أثر مادي لها، ويُقيّم عبر الأنظمة التي تشغلها أو ترعاها أو تتحكم فيها ماديًا، وقراراتها ومقتنياتها خارج أي نظام. وتحدد الفئة عمق التقييم المؤسسي ومواعيده. **خارج النطاق:** الفئة المستقلة لنظام ضمن [محفظة المؤسسة](core_05.040_band_continuity.md#portfolio)، التي تقرر لذلك النظام ولا يعاد تقريرها في تقييم المؤسسة. **يعتمد على:** [المؤسسة](core_05.040_band_continuity.md#institution)؛ المحفظة؛ [سجل الشهادة المؤسسية](core_05.040_band_continuity.md#institutional-certification-record). ترد عوامل التصنيف وقاعدة السيطرة المشتركة ومحفزات إعادة التصنيف في [الفصل العاشر §2.1](core_10.000_institutional_alignment_certification.md#21-institution-class). وهذا المدخل لمعنى الفصل الخامس فقط.
<a id="institution-class-a"></a>
- **كيفية القياس والتقييم:** **المقياس الأساسي:** [عائلة قياس الاستمرارية](core_05.010_apex_continuity_aim.md#measuring-continuity-preamble-measurement-family). طابق الفئة مع نشاط النظام المرصود وقرارات المؤسسة ومقتنياتها، وطبّق عوامل التصنيف الحاكمة، وتأكد من ظهور الفئة وأسبابها في سجل الشهادة المؤسسية.
<a id="institution-class-c"></a>
- **ما يجب تحققه:** **الإخفاق الأساسي:** إسناد الفئة اعتمادًا على الاسم أو الشكل القانوني أو الميثاق المؤسسي وحده؛ أو إغفال أثر المؤسسة خارج الأنظمة؛ أو عدم إدراج نظام خاضع لسيطرة عملية مشتركة.

## Institutional Alignment Certification — شهادة المواءمة المؤسسية

*هي فحص مستقل للمؤسسة نفسها لا لأحد أنظمتها. ويتحقق مما إذا كانت تعمل وفق ميثاقها، ومساءلة المكاتب صاحبة السلطة، واتجاه حوافزها إلى الدستور أو بعيدًا عنه. ويستشهد بشهادة كل نظام تديره ولا يكرر تقييمه. ولا يعمل بوصفه ترخيصًا؛ فلا تحتاج المؤسسة إلى إذن لتنشأ أو تعمل.*

- **ماهيتها:** **ضمن النطاق:** عملية تحت إشراف المحفل، والسجل المؤسسي المحدود الناتج عنها، التي تثبت بها المؤسسة مواءمتها للدستور ضمن نطاق وفئة ومدة سجل ودورية مراجعة محددة. وتشمل أمور مستوى المؤسسة: تطابق الممارسة مع [الميثاق المؤسسي](core_05.040_band_continuity.md#institutional-charter) ومبرر المحفظة مع الأنظمة الفعلية؛ ونسبة السلطة إلى مكاتب خاضعة للمساءلة؛ وتوجيه المكافآت والأهداف والحوافز إلى المواءمة؛ وعمل [خريطة أدوار الميثاق](core_05.040_band_continuity.md#charter-role-map) وحفظ سجلات المكانة عبر مسار مستقل قابل للاستخدام؛ وسريان شهادة مواءمة كل نظام وما يعنيه ذلك للمؤسسة. ويستشهد بشهادة كل نظام برابط ويستخدم النتائج والحالات وقواعد إعادة الفتح نفسها.
  - **خارج النطاق:** شهادة مواءمة أي نظام تشغله المؤسسة، فهي تخص النظام ولا تتكرر ولا تتجاوز هنا؛ أو إذن التأسيس أو الانضمام أو التشغيل الذي تحميه [المادة XI-E](core_06.005_rights_part_b.md#article-xi-e-institutional-formation-and-business-creation) ولا تشترطه هذه العملية؛ أو الإحالة بين المحافل أو طلب حكم في الفصل الرابع عشر؛ أو [سجل المكانة](core_05.035_band_accountability.md#standing-record) وأي أثر للمكانة.
  - **يعتمد على:** المؤسسة؛ الميثاق المؤسسي؛ شهادة مواءمة النظام. يحدد [الفصل العاشر](core_10.000_institutional_alignment_certification.md#chapter-ten-institutional-alignment-certification) من يلزم اعتماده وما يُقيّم وشاغلي المقاعد وكيف يصل إخفاق النظام إلى وضع المؤسسة ومتى تفتح المراجعة. هذا المدخل لمعنى الفصل الخامس فقط.
<a id="institutional-alignment-certification-a"></a>
- **كيفية القياس والتقييم:** **المقياس الأساسي:** عائلة قياس الاستمرارية. تحقق من أن المؤسسة من الفئة L أو أعلى لديها سجل شهادة مؤسسية نافذ أو ضمن المهلة المسجلة للشهادة الأولى؛ وأن كل نتيجة عن نظام تعتمد على سجل شهادته الخاص دون إعادة تقييم؛ وأن الميثاق اختُبر على التشغيل المرصود لا نصه فقط؛ وأن إخفاق أو سحب أو انتهاء شهادة نظام انتقل إلى وضع المؤسسة وفق قاعدة التسلسل؛ وألا تكون العملية شرطًا للتأسيس أو التشغيل.
<a id="institutional-alignment-certification-c"></a>
- **ما يجب تحققه:** **الإخفاق الأساسي:** استخدام الشهادة المؤسسية كترخيص أو بوابة أو عتبة إذن للتأسيس أو التشغيل؛ أو إعادة تقييم نظام أو تغيير نتيجة شهادته في دورة المؤسسة؛ أو عمل مؤسسة بميثاق أو محفظة أو حوافز لم تختبرها دورة الشهادة بينما تدعي أنها معتمدة. **الإخفاق الثانوي:** قراءة نص الميثاق فقط دون التشغيل المرصود؛ عدم وصول شهادة نظام فاشلة إلى وضع المؤسسة؛ وقوع المحفل القائد أو مكتب السجل ضمن خط سيطرة المؤسسة؛ أو كون السجل غير محدد المدة أو غير قابل للطعن أو مخفيًا. **الإخفاق الثالثي:** تقسيم المؤسسة أو محفظتها بحيث لا يبلغ أي جزء الفئة التي توجب الشهادة.

## Institutional Certification Record — سجل الشهادة المؤسسية

*هو ملف قضية قابل للتدقيق لمؤسسة واحدة ضمن مراجعة يشرف عليها محفل. يبين ما فُحص عن المؤسسة، وسجلات شهادات الأنظمة التي تعتمد عليها، والقرار وكيفية الطعن فيه. وهو محدد المدة وقابل للطعن، وليس سجل شهادة نظام أو سجل مكانة.*

- **ماهيته:** **ضمن النطاق:** السجل المحدود القابل للمراجعة الناتج عن [شهادة المواءمة المؤسسية](core_05.040_band_continuity.md#institutional-alignment-certification)، وهو [سجل الإجراء الملزم ماديًا](core_05.035_band_accountability.md#materially-binding-act-record) لإجراء الشهادة المؤسسية. ويحدد المؤسسة وإصدار ميثاقها وخريطة أدوار الميثاق النافذين وفئتها ونتائجها وسجلات شهادة الأنظمة المستشهد بها والنتيجة وشروط الشهادة ومسارات الطعن. وهو محدد النطاق والمدة وقابل للطعن.
  - **خارج النطاق:** [سجل شهادة النظام](core_05.040_band_continuity.md#system-certification-record) الذي يبقى سجل نظام واحد ويُستشهد به ولا يُدمج؛ أو [سجل المكانة](core_05.035_band_accountability.md#standing-record) الذي يختص به الفصلان الحادي عشر والثاني عشر؛ أو تقرير المؤسسة السنوي أو بيان تدقيقها أو تصديقها المعروض بدل السجل.
  - **يعتمد على:** شهادة المواءمة المؤسسية؛ سجل شهادة النظام. ترد الحدود الدنيا للمحتوى وقواعد النزاهة في [الفصل العاشر §8](core_10.000_institutional_alignment_certification.md#8-institutional-certification-record). وهذا المدخل لمعنى الفصل الخامس فقط.
<a id="institutional-certification-record-a"></a>
- **كيفية القياس والتقييم:** **المقياس الأساسي:** عائلة قياس الاستمرارية. تحقق من أن السجل يسمي إصدارات الميثاق وخريطة الأدوار وسجل كل نظام مستشهد به؛ وأن يحتفظ به مكتب خارج خط السيطرة المادية للمؤسسة ويمكن الطعن فيه عبر مسار منشور؛ وأن تفتح الدورة اللاحقة سجلًا جديدًا مرتبطًا وتترك السابق على حاله.
<a id="institutional-certification-record-c"></a>
- **ما يجب تحققه:** **الإخفاق الأساسي:** تقديم تقرير المؤسسة الذاتي أو سجل نظام وحده كسجل مؤسسي؛ تعديل سجل مكتمل في مكانه؛ حفظ سجل موضوعه المؤسسة لدى أمين داخل خط سيطرتها؛ أو معاملته كسجل مكانة أو أثر مكانة.

## Institutional Data Types and Handling — أنواع البيانات المؤسسية والتعامل معها

*تشمل البيانات التي تتعامل معها المؤسسة خارج أي نظام. ويسجل التقييم هذه البيانات وطريقة التعامل معها في سجل الشهادة المؤسسية. أما البيانات داخل نظام فتُقيّم مرة واحدة في سجل ذلك النظام وتشير إليها المؤسسة.*

- **ماهيتها:** **ضمن النطاق:** تقييم أنواع البيانات الواقعة ماديًا ضمن النطاق التي تتعامل معها المؤسسة خارج أي نظام، بما يشمل التعامل مع كل نوع وفق أشد تصنيف منطبق. وتظهر النتائج في قسم أنواع البيانات من سجل الشهادة المؤسسية ولا تنشئ سجلًا مستقلًا. **خارج النطاق:** البيانات داخل نظام، التي تُقيّم وتُسجل مرة واحدة بموجب [سجل أنواع بيانات النظام](core_05.040_band_continuity.md#system-data-types-record) ويُشار إليها في السجل المؤسسي. **يعتمد على:** المؤسسة؛ شهادة المواءمة المؤسسية؛ سجل الشهادة المؤسسية؛ سجل أنواع بيانات النظام. ترد متطلبات التقييم والتسجيل وإعادة التقييم في [الفصل العاشر §3، البند 8، و§8.1](core_10.000_institutional_alignment_certification.md#81-minimum-record-contents) و[الفصل التاسع، الجزء أ، §3.4](core_09.000_system_alignment_certification_evaluation.md#34-data-types-and-handling-evaluation). وهذا المدخل لمعنى الفصل الخامس فقط.
<a id="institutional-data-types-and-handling-a"></a>
- **كيفية القياس والتقييم:** **المقياس الأساسي:** عائلة قياس الاستمرارية. تحقق من أنواع البيانات المادية خارج أي نظام وتصنيفها والتعامل معها وجدول إعادة تقييمها، ومن تسجيل النتائج دون تكرار تقييم بيانات النظام.
<a id="institutional-data-types-and-handling-c"></a>
- **ما يجب تحققه:** **الإخفاق الأساسي:** إغفال بيانات مادية خارج أي نظام؛ أو تطبيق تصنيف أقل تقييدًا حيث ينطبق الأشد؛ أو إغفال إعادة التقييم؛ أو تكرار نتائج أنواع بيانات نظام أو استبدالها.
