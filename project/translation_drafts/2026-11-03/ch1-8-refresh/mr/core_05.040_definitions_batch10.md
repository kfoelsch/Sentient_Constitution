- **What it is**
  - **In scope / out of scope / dependencies:** व्याप्ती: प्रमाणन नोंदीत नाव दिलेला प्रकाशित मार्ग; अध्याय नऊ C §10.2 मधील आव्हानयोग्यता मार्गांपैकी एक. वाद कुठे उद्भवतो त्यानुसार मार्गांची जुळणी B §6.3 ची आव्हान-साखळी ठरते. पहिल्या निकालासह उघडतो आणि प्रणालीचे हितधारक असताना खुला राहतो. वगळलेले: आव्हान स्वतः (आव्हानयोग्यता व योग्य प्रक्रिया); मार्ग आणि सक्षम पुनरावलोकन/पर्यायी मंच एकत्र ठेवणारी आव्हान-आसन व्यवस्था; ऑपरेटरचे अंतर्गत पुनरावलोकन, विक्रेता हमी किंवा तांत्रिक मंजुरी. प्रणाली व संस्थात्मक प्रमाणन नोंदींवर अवलंबून. उघडण्याची वेळ C §10.1; मंजुरीपूर्वी नोंदविण्याचा नियम B §6.2.1. येथे फक्त अध्याय पाचचा अर्थ.
