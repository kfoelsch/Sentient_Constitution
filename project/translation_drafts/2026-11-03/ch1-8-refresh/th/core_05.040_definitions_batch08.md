#### รอบการรับรอง

<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า ส่วน B §6.2 ลำดับการกำกับดูแล; อ่านร่วมกับบทที่เก้า ส่วน C §9 การรับรองซ้ำและการเปิดพิจารณาใหม่. องค์ประกอบกลุ่ม: ไม่มี. อ่านร่วมกับ [เวทีหลัก](core_05.040_band_continuity.md#lead-forum), [บันทึกการรับรองระบบ](core_05.040_band_continuity.md#system-certification-record) และ [บันทึกการรับรองสถาบัน](core_05.040_band_continuity.md#institutional-certification-record).

*กล่าวอย่างง่าย: กระบวนการรับรองครบหนึ่งรอบสำหรับระบบหรือสถาบันหนึ่งแห่ง ตั้งแต่กำหนดกรอบจนบันทึกผล แต่ละรอบมีผลลัพธ์และเปิดบันทึกใหม่ที่เชื่อมกับบันทึกก่อนหน้า รอบถัดไปอาจเป็นการรับรองซ้ำ การพิจารณาที่เปิดใหม่ หรือการพิจารณาใหม่.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: งานรับรองทั้งหมดของระบบหรือสถาบันหนึ่งแห่ง รวมถึงกรณีถอนหรือไม่รับรอง. ไม่รวมการประเมิน/ข้อค้นพบย่อย การดำเนินงานของระบบที่รับรองแล้วระหว่างรอบ หรือผลลัพธ์เอง. ขึ้นกับเวทีหลักและบันทึกทั้งสอง. ลำดับงานอยู่ในบทเก้า B §6.2; บันทึกรอบถัดไปอยู่ใน C §9. รายการนี้กำหนดความหมายในบทห้าเท่านั้น.
<a id="certification-pass-a"></a>
- **How to measure and assess**
  - การวัด: กลุ่มการวัดความต่อเนื่อง—สิ่งมีชีวิตที่รู้สึกและระบบดำรงอยู่ได้ทางนิเวศ เชื่อถือได้ และผ่านความล้มเหลวหรือไม่? ประเมินว่าทุกรอบระบุชนิดและผล และรอบถัดไปสร้างบันทึกใหม่ที่เชื่อมโยงโดยไม่เปลี่ยนบันทึกเดิมหรือไม่.
<a id="certification-pass-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ใช้บันทึกเดิมแทนการเปิดบันทึกใหม่สำหรับรอบถัดไป หรือจบรอบโดยไม่ระบุผล.
