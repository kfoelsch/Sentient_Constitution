#### ตัวกระตุ้นการเปิดใหม่

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า C §9.2 ตัวกระตุ้นการเปิดใหม่; สำหรับสถาบันอ่านบทสิบ §9.2 ด้วย. อ่านกับการทบทวนที่เปิดใหม่และบันทึกระบบ.

</details>

*กล่าวอย่างง่าย: การเปลี่ยนแปลงหรือรายงานสำคัญที่ให้เหตุเปิดการรับรองก่อนกำหนด ตัวกระตุ้นต้องระบุในบันทึก.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: การเปลี่ยน/รายงานสำคัญตามรายการ เช่น ระบบหรือบริบทเปลี่ยน สิ่งที่สังเกตหรือรายงาน ความไม่สอดคล้องของชั้น/ประเภทข้อมูล ประเด็นธรรมนูญ/ธรรมาภิบาลผู้ดำเนินการ หรือความไม่สอดคล้องในการประเมิน เปิดใหม่เฉพาะกรณีสำคัญ; การละเมิดธรรมาภิบาลเป็นหนึ่งในนั้น. ไม่รวมวันรับรองซ้ำตามกำหนดซึ่งไม่ใช่ตัวกระตุ้น. ขึ้นกับการทบทวนที่เปิดใหม่และบันทึกระบบ. ระบบอยู่ C §9.2; สถาบันอยู่บทสิบ §9.2. รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="reopening-trigger-a"></a>
- **How to measure and assess**
  - ประเมินว่าบันทึกระบุตัวกระตุ้น และตัวกระตุ้นสำคัญทำให้เปิดการทบทวนใหม่หรือไม่.
<a id="reopening-trigger-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: บันทึกไม่ระบุตัวกระตุ้น; เพิกเฉยตัวกระตุ้นสำคัญเพราะใกล้วันรับรองซ้ำ.
