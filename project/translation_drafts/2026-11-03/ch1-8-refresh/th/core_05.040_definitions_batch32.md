#### กรอบเวลาตามระดับ

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า C §9.3.4 กรอบเวลาตามระดับ; อ่านกับบทสิบสี่ §6 การแก้ไขทันเวลา ระดับสาระสำคัญ และวินัยป้องกันความล่าช้า. อ่านกับรอบรับรองและการคุ้มครองชั่วคราว.

*กล่าวอย่างง่าย: เวลาจำกัดในขั้นหนึ่งของเรื่องรับรอง กำหนดตามระดับสาระสำคัญของเรื่อง ระดับโดยสันนิษฐานตรงกับชั้น และเป้าหมายรับเรื่องที่ตรงกันคือเป้าหมายของระดับนั้น.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: เวลาและขีดจำกัดภายนอกของระดับสาระสำคัญที่กำหนดให้เรื่องรับรอง ระดับสันนิษฐานว่าตรงกับชั้นระบบ/สถาบัน และเป้าหมายรับเรื่องของระดับนั้นคือเป้าหมายที่ตรงกัน. ไม่รวมช่วงแจ้งก่อนเริ่มใช้งาน (ตามชั้นและความต้องการผู้ได้รับผล); รอบรับรองซ้ำ; หรือเป้าหมาย/ขีดจำกัดของบทสิบสี่เอง. ขึ้นกับรอบรับรองและการคุ้มครองชั่วคราว. การใช้กรอบอยู่บทเก้า C §9.3.4; ระดับ/เป้าหมาย/ขีดจำกัดอยู่บทสิบสี่ §6. รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="tier-window-a"></a>
- **How to measure and assess**
  - ประเมินว่าเรื่องถูกจัดในระดับที่ตรงชั้น และการเกินกำหนดได้รับการทบทวนตามบทสิบสี่หรือไม่.
<a id="tier-window-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ระบบอัตโนมัติ/ตัวกรองขยายกรอบเวลาหรือเป้ารับเรื่อง; การเกินกำหนดไม่ได้รับการทบทวนตามที่กำหนด.
