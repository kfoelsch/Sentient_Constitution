*กล่าวอย่างง่ายคือ **การปฏิเสธการรับรอง** คือการไม่รับรองระบบที่ยังไม่มีสถานะรับรอง เพราะผู้ดำเนินการยังไม่แสดงทั้งความเต็มใจและความสามารถในการแก้ปัญหา นี่คือผลจริง ไม่ใช่คำขู่ และเปลี่ยนสถานะการรับรองของระบบ แต่ไม่ได้ทำให้ระบบหยุดทำงานด้วยตัวมันเอง*

- **ความหมาย**
  - **รวมถึง:** ผลไม่รับรองระบบที่ยังไม่มีสถานะรับรอง ในการรับรองครั้งแรก การทบทวนใหม่ หรือรอบรับรองอื่น เพราะการตรวจความพร้อมแก้ไขไม่แสดงว่าผู้ดำเนินการเต็มใจและสามารถแก้ความไม่สอดคล้องหรือข้อบกพร่องการรับรองได้
  - **ไม่รวมถึง:**
    - [การเพิกถอนการรับรอง](core_05.040_band_continuity.md#certification-revocation) ซึ่งนำการรับรองที่มีอยู่แล้วออก;
    - การเลื่อนการรับรอง ซึ่งเลื่อนการตัดสินในช่วงเวลาจำกัดและไม่ได้ปฏิเสธสิ่งใด;
    - คำสั่งหยุดดำเนินงาน ซึ่งตัดสินแยกตามการคุ้มครองสิ่งจำเป็นต่อการอยู่รอดใน [บทที่เก้า ส่วน C §9.3.5](core_09.010_system_alignment_certification_record_recertification.md#935-class-a-reliance); และ
    - ผลต่อสถานะหรือข้อค้นพบการละเมิด—มีเพียง[บทที่สิบเอ็ด](core_11.000_standing_assessment.md#chapter-eleven-compliance-violation-and-standing-model)ที่ตัดสินสถานะ
    เรื่องเหล่านี้อยู่ในหัวข้อของตนเอง
  - **ขึ้นอยู่กับ:** [การรับรองความสอดคล้องของระบบ](core_05.040_band_continuity.md#system-alignment-certification)
  - เงื่อนไขและกระบวนการอยู่ใน[บทที่เก้า ส่วน B §7.4](core_09.005_system_alignment_certification_record_process.md#74-denial-and-revocation); ผลอยู่ใน[§7.5 ผลของการปฏิเสธ](core_09.005_system_alignment_certification_record_process.md#75-effects-of-denial-and-revocation) หัวข้อนี้ให้ความหมายตามบทที่ห้าเท่านั้น
<a id="certification-denial-a"></a>
- **การวัดและประเมิน**
  - **การวัดหลัก:** [กลุ่มการวัดความต่อเนื่อง](core_05.010_apex_continuity_aim.md#measuring-continuity-preamble-measurement-family) — *สิ่งมีความรู้สึกนึกคิดและระบบจะดำรงอยู่ได้อย่างเป็นมิตรต่อระบบนิเวศ เชื่อถือได้ และผ่านพ้นความล้มเหลวได้หรือไม่?*

    **การประเมินหลัก:**
    1. การปฏิเสธอาศัยข้อค้นพบในบันทึกว่าผู้ดำเนินการยังไม่แสดงความเต็มใจและความสามารถในการแก้ไข ไม่ใช่ขนาด อายุ ความมั่งคั่ง หรือผลประโยชน์ของคู่แข่ง;
    2. ระบุมาตรการคุ้มครองชั่วคราวและข้อจำกัดการพึ่งพาก่อนการปฏิเสธมีผล และแจ้งผู้มีความรู้สึกนึกคิดที่พึ่งพาระบบ; และ
    3. ผู้ดำเนินการได้รับแจ้งข้อค้นพบและมีโอกาสตอบหรือแสดงขั้นตอนหลักฐานก่อนตัดสินใจ
<a id="certification-denial-c"></a>
- **สิ่งที่ต้องคงไว้**
  - **ความล้มเหลวหลัก:**
    - ปฏิเสธโดยไม่มีข้อค้นพบความพร้อมในบันทึก หรือด้วยเหตุที่ไม่เกี่ยวกับการแก้ไข;
    - ให้การรับรองแบบมีเงื่อนไขทั้งที่ข้อค้นพบกำหนดให้ปฏิเสธ;
    - ถือว่าการปฏิเสธเป็นคำสั่งตัดสิ่งจำเป็นต่อการอยู่รอดก่อนมีสิ่งทดแทน; หรือ
    - ปฏิเสธการรับรองโดยไม่แจ้งผู้ที่พึ่งพาระบบ
