*กล่าวอย่างง่าย: ช่องทางที่เผยแพร่ให้สิ่งมีชีวิตที่รู้สึกใช้คัดค้านการรับรอง โดยระบุผู้รับ วิธีส่ง และกำหนดเวลา ต้องระบุในบันทึกก่อนเวทีใดลงนาม และเปิดเมื่อเผยแพร่ผล.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: ช่องทางเผยแพร่ที่ระบุในบันทึก เป็นหนึ่งในช่องทางโต้แย้งได้ตามบทเก้า C §10.2; ช่องทางตามที่เกิดข้อพิพาทประกอบเป็นห่วงโซ่การโต้แย้งตาม B §6.3 เปิดพร้อมผลแรกและเปิดต่อไปตราบที่ระบบมีผู้มีส่วนได้เสีย. ไม่รวมการคัดค้านเอง (อยู่ภายใต้ความโต้แย้งได้และกระบวนการที่เป็นธรรม); ที่นั่งพิจารณาซึ่งเชื่อมช่องทางกับเวทีทบทวน/สำรองที่มีอำนาจ; หรือการทบทวนภายในผู้ดำเนินการ การรับรองของผู้ขาย และการลงนามทางเทคนิค. ขึ้นกับบันทึกการรับรองระบบและสถาบัน. เวลาเปิดอยู่ใน C §10.1; กฎให้ระบุก่อนลงนามอยู่ใน B §6.2.1. รายการนี้กำหนดความหมายบทห้าเท่านั้น.
<a id="challenge-path-a"></a>
- **How to measure and assess**
  - ประเมินตามการวัดความต่อเนื่องว่า ก่อนลงนามบันทึกระบุผู้รับ วิธีส่ง และกำหนดเวลาหรือไม่; ช่องทางเปิดก่อนมีผู้ต้องพึ่งผล และเปิดต่อไปขณะที่ระบบมีผู้มีส่วนได้เสียหรือไม่.
<a id="challenge-path-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ลงนามบันทึกที่ไม่ระบุช่องทาง; อ้างว่าระบบสอดคล้องทั้งที่มีผู้มีส่วนได้เสียแต่ไม่มีช่องทางเปิดให้คัดค้านบันทึก.
