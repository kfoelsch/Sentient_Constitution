#### การทบทวนที่เปิดใหม่

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า C §9.2 ตัวกระตุ้นการเปิดใหม่; §9 การรับรองซ้ำและการเปิดใหม่. อ่านกับรอบรับรอง ตัวกระตุ้น และบันทึกระบบ.

</details>

*กล่าวอย่างง่าย: รอบรับรองของระบบ/สถาบันที่มีบันทึกอยู่แล้ว เริ่มก่อนกำหนดรับรองซ้ำครั้งถัดไปเพราะเกิดตัวกระตุ้นสำคัญ และเปิดบันทึกใหม่ที่เชื่อมกับฉบับเดิม.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: รอบที่เริ่มก่อนกำหนดถัดไปเพราะตัวกระตุ้นสำคัญ ใช้กระบวนการเวทีเดิมและจบด้วยผล. ไม่รวมการรับรองซ้ำตามกำหนด; หรือการทบทวนใหม่ที่เวทีสั่งเพื่อตอบข้อบกพร่อง. ขึ้นกับรอบ ตัวกระตุ้น และบันทึกระบบ. ตัวกระตุ้น/บันทึกใหม่อยู่บทเก้า C §9.2 และ §9. รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="reopened-review-a"></a>
- **How to measure and assess**
  - ประเมินว่าเปิดบันทึกใหม่เชื่อมฉบับที่เสร็จแล้ว; เริ่มเมื่อมีตัวกระตุ้นสำคัญ ไม่รอถึงกำหนดรับรองซ้ำหรือไม่.
<a id="reopened-review-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ล่าช้าทั้งที่ตัวกระตุ้นสำคัญ; ใช้การรับรองซ้ำตามกำหนดแทนการทบทวนที่เปิดใหม่หลังตัวกระตุ้นเกิด.
