- เจ้าของหลัก: บทที่เก้า B §7.2 ข้อบกพร่องและการแก้ไขการรับรอง; อ่านร่วมกับ C §9 การรับรองซ้ำและการเปิดใหม่. อ่านกับรอบการรับรอง การทบทวนที่เปิดใหม่ และบันทึกระบบ.

*กล่าวอย่างง่าย: รอบรับรองครั้งถัดไปที่เวทีสั่งเพื่อตอบข้อบกพร่อง เป็นหนึ่งในทางเลือกตอบสนอง และเช่นเดียวกับรอบถัดไปอื่น จะเปิดบันทึกใหม่.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: รอบถัดไปที่สั่งตามบทเก้า B §7.2 เพื่อตอบข้อบกพร่อง โดยเป็นทางเลือกจากรับรองแบบมีเงื่อนไข เลื่อน ปฏิเสธ เพิกถอน เปลี่ยนช่วงเวลา หรือเปิดทบทวนใหม่ ดำเนินตามกระบวนการเวทีและจบด้วยผล. ไม่รวมการรับรองซ้ำตามกำหนดหรือการรับรองครั้งแรกของระบบ. ขึ้นกับรอบการรับรอง การทบทวนที่เปิดใหม่ และบันทึกระบบ. เลือกคำตอบตาม B §7.2; บันทึกใหม่ตาม C §9. รายการนี้กำหนดความหมายบทห้าเท่านั้น.
<a id="fresh-review-a"></a>
- **How to measure and assess**
  - ประเมินว่าเวทีระบุเหตุผลที่สั่งทบทวนใหม่แทนคำตอบอื่นหรือไม่; การทบทวนเปิดบันทึกใหม่ที่เชื่อมกับบันทึกเสร็จแล้วและจบด้วยผลชัดแจ้งหรือไม่.
<a id="fresh-review-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ปล่อยบันทึกเดิมเปิดแทนบันทึกใหม่; หรือสั่งทบทวนใหม่แล้วไม่มีผลลัพธ์.
