#### การละเมิดธรรมาภิบาล

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่สิบ §9.6 เปิดทบทวนระบบของสถาบันใหม่; อ่านร่วมกับบทเก้า C §9.2 ตัวกระตุ้นการเปิดใหม่. อ่านกับการทบทวนที่เปิดใหม่ ระบบที่อ้างถึง ข้อค้นพบสาเหตุ และสถาบัน.

</details>

*กล่าวอย่างง่าย: ชื่อในบทสิบสำหรับความล้มเหลวด้านธรรมาภิบาลของสถาบันที่ทำให้เปิดทบทวนระบบอีกครั้ง เป็นเหตุเปิดใหม่ ไม่ใช่การละเมิดสถานะ มีเพียงกรณีสำคัญที่ทำให้เปิด.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: ความล้มเหลวด้านธรรมาภิบาลของสถาบันที่เปิดทบทวนระบบ ได้แก่ การวินิจฉัยว่าธรรมาภิบาลของตนล้มเหลว การปฏิเสธ/เพิกถอนการรับรองสถาบันด้วยเหตุด้านธรรมาภิบาล หรือข้อค้นพบสาเหตุที่โยงเหตุไปยังสถาบัน เปิดเฉพาะกรณีสำคัญ และแต่ละคำวินิจฉัยเปิดแต่ละระบบได้ครั้งเดียว. ไม่รวมการละเมิดสถานะตามบทสิบเอ็ด/สิบสอง; ความมีผลของการรับรองระบบที่อ้างถึงซึ่งบันทึกระบบเองกำหนด. ขึ้นกับการทบทวนที่เปิดใหม่ ระบบที่อ้างถึง ข้อค้นพบสาเหตุ และสถาบัน. เหตุเปิด เกณฑ์สาระสำคัญ และการแจ้งอยู่ในบทสิบ §9.6; รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="governance-violation-a"></a>
- **How to measure and assess**
  - ประเมินว่าบันทึกสถาบันระบุแต่ละระบบที่แจ้งและวันที่หรือไม่; การเปิดใหม่ไม่เปลี่ยนผล สถานะ หรือเงื่อนไขรับรองของระบบ และไม่หยุดสถาบันหรือระบบหรือไม่.
<a id="governance-violation-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ถือการละเมิดธรรมาภิบาลเป็นการละเมิดสถานะหรือเหตุหยุดระบบ; ไม่แจ้งจนเวทีที่วินิจฉัยต้องเป็นผู้แจ้ง.
