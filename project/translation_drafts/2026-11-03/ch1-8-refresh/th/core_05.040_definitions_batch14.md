#### การรับรองเต็มรูปแบบ

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า C §9.3 การรับรองชั่วคราวและเต็มรูปแบบ รายการนี้อยู่ข้างกลุ่มการรับรองความสอดคล้องของระบบแต่ไม่เป็นส่วนหนึ่ง อ่านร่วมกับการรับรองชั่วคราว การรับรองซ้ำ บันทึกระบบ/การจัดประเภท และความคลาดเคลื่อนของตัวแทน.

</details>

*กล่าวอย่างง่าย: สถานะช่วงเวลายาวขึ้นที่ระบบได้รับหลังการรับรองซ้ำชั่วคราวที่สะอาด โดยไม่มีปัญหาปัจจุบันหรือสัญญาณปัญหาใกล้เกิด ไม่ถาวร และสิ้นสุดเมื่อประเมินไม่ผ่านหรือมีคำเตือนจากตัวเลขติดตาม.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: สถานะของระบบที่เคยรับรองชั่วคราว ทำการรับรองซ้ำชั่วคราวที่สะอาดต่อเนื่องครบจำนวน และครั้งล่าสุดไม่พบความไม่สอดคล้องปัจจุบัน/สัญญาณใกล้เกิด ใช้ช่วงเวลาตามชั้น มีอายุจำกัด และเปิดทบทวนได้. ไม่รวมการรับรองชั่วคราว; การรับรองมีเงื่อนไขซึ่งผูกได้กับทั้งสองสถานะ; ใบอนุญาตถาวร คะแนนชื่อเสียง หรือผลด้านสถานะ (บทสิบเอ็ดเท่านั้นตัดสิน). ขึ้นกับการรับรองชั่วคราวและการรับรองซ้ำ. จำนวนขั้นต่ำ การลดระดับ และช่วง tier อยู่ในบทเก้า C §9.3; รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="full-certification-a"></a>
- **How to measure and assess**
  - ประเมินว่าทำจำนวนการรับรองซ้ำสะอาดต่อเนื่องตามชั้นครบ; ไม่มีความไม่สอดคล้องเปิด ข้อบกพร่องไม่แก้ การตรวจเกินกำหนด หรือการทดสอบถดถอยไม่ผ่าน; ตัวกระตุ้น/แนวโน้มในบันทึกไม่ข้ามหรือเข้าใกล้เกณฑ์ ตรวจสอบอิสระได้ และไม่ได้กำหนดแคบจนตรวจไม่พบปัญหา.
<a id="full-certification-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ให้สถานะเต็มก่อนครบขั้นต่ำหรือทั้งที่มีปัญหา/สัญญาณใกล้เกิด; คงไว้หลังรับรองซ้ำไม่ผ่านหรือทบทวนใหม่พบความไม่สอดคล้อง; กำหนดตัวบ่งชี้แคบจนไม่มีสิ่งชี้ปัญหา; ใช้สถานะเต็มเพื่อข้ามหรือชะลอตัวกระตุ้นเปิดทบทวน.
