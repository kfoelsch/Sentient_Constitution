#### ผู้ดำเนินการ

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า C §9 การรับรองซ้ำและเปิดใหม่; อ่านกับบทสิบ §7.4 การปฏิเสธ/เพิกถอนสถาบัน. อ่านกับระบบและฝ่ายปฏิบัติการ.

</details>

*กล่าวอย่างง่าย: ฝ่ายที่ดำเนินงาน ดูแล หรือควบคุมระบบอย่างมีนัยสำคัญและรับผิดชอบต่อระบบในการรับรอง บทเก้าใช้คำว่า “ผู้ดำเนินการหรือผู้ดูแล” ซึ่งแคบกว่าฝ่ายปฏิบัติการที่หมายถึงผู้ทำกิจกรรมใดก็ได้.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: ฝ่ายที่ดำเนินงาน/ดูแล/ควบคุมระบบอย่างมีนัยสำคัญและตอบรับผิดในกระบวนการรับรอง หากสถาบันทำเช่นนั้น สถาบันเป็นผู้ดำเนินการของระบบนั้น ในการรับรองสถาบันเอง บทสิบอ่านอำนาจกำกับของสถาบันเป็นผู้ดำเนินการเมื่อใช้กฎปฏิเสธ/เพิกถอนบทเก้า. ไม่รวมฝ่ายปฏิบัติการที่ไม่ได้เดินระบบรับรอง; ตำแหน่ง/สำนักงานภายในผู้ดำเนินการหรือสิ่งมีชีวิตที่ครองตำแหน่ง. ขึ้นกับระบบและฝ่ายปฏิบัติการ. หน้าที่ผู้ดำเนินการอยู่บทเก้า; กฎอ่านสถาบันอยู่บทสิบ §7.4. รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="operator-a"></a>
- **How to measure and assess**
  - ประเมินว่าบันทึกระบบระบุชื่อผู้ดำเนินการ/ผู้ดูแล และการตรวจความพร้อมใช้เกณฑ์เดียวกันกับผู้ดำเนินการทุกฝ่ายหรือไม่.
<a id="operator-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ระบบไม่มีผู้ดำเนินการ/ผู้ดูแลที่ระบุชื่อ; ใช้เกณฑ์ความพร้อมต่างกันตามผู้ดำเนินการ.
