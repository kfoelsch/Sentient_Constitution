#### การรับรองซ้ำที่สะอาด

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า ส่วน C §9.3.1 สถานะสองแบบ อ่านร่วมกับการรับรองซ้ำ การรับรองชั่วคราวและเต็มรูปแบบ. องค์ประกอบกลุ่ม: ไม่มี.

</details>

*กล่าวอย่างง่าย: การรับรองซ้ำสะอาดเมื่อไม่มีความไม่สอดคล้องในปัจจุบัน และไม่มีตัวบ่งชี้การติดตามที่ชี้ว่าจะเกิดความไม่สอดคล้องในเร็ววัน เฉพาะการรับรองซ้ำที่สะอาดนับสู่การรับรองเต็มรูปแบบ.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: การรับรองซ้ำที่ไม่พบความไม่สอดคล้องปัจจุบันหรือสัญญาณใกล้เกิด จำนวนการรับรองซ้ำชั่วคราวที่สะอาดต่อเนื่องตามกำหนดเป็นองค์ประกอบหนึ่งของการรับรองเต็มรูปแบบ. ไม่รวมการรับรองซ้ำที่ล้มเหลวซึ่งพบความไม่สอดคล้องและเริ่มนับใหม่เป็นศูนย์; หรือกรณีไม่มีความไม่สอดคล้องปัจจุบันแต่มีสัญญาณใกล้เกิด—ไม่ใช่ความล้มเหลวแต่ไม่สะอาด. ขึ้นกับการรับรองซ้ำ ชั่วคราว และเต็มรูปแบบ. จำนวนและข้อกำหนดอยู่ในบทเก้า C §9.3.1; รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="clean-recertification-a"></a>
- **How to measure and assess**
  - ประเมินตามการวัดความต่อเนื่องว่า นับเพิ่มเฉพาะรอบที่สะอาด และรอบที่ล้มเหลวเริ่มนับใหม่เป็นศูนย์หรือไม่.
<a id="clean-recertification-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: นับว่าสะอาดทั้งที่ยังมีความไม่สอดคล้อง ข้อบกพร่อง การตรวจเกินกำหนด หรือการทดสอบถดถอยที่ไม่ผ่าน; เพิ่มจำนวนทั้งที่มีสัญญาณความไม่สอดคล้องใกล้เกิด.
