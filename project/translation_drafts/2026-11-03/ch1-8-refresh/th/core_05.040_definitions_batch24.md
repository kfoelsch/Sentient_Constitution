#### การรับรองชั่วคราว

<details>
<summary><strong>การติดตาม</strong></summary>

- เจ้าของหลัก: บทที่เก้า C §9.3 การรับรองชั่วคราวและเต็มรูปแบบ อ่านกับการรับรองเต็ม การรับรองซ้ำ บันทึกระบบ และการย้อนกลับได้.

</details>

*กล่าวอย่างง่าย: สถานะเฝ้าระวังใกล้ชิดสำหรับระบบใหม่หรือระบบที่เพิ่งไม่ผ่านการประเมิน ตรวจซ้ำในช่วงสั้นจนได้สถานะช่วงยาวของการรับรองเต็มรูปแบบ.*

- **What it is**
  - **In scope / out of scope / dependencies:** ขอบเขต: สถานะของระบบที่รับรองครั้งแรก รวมระบบติดตั้งใหม่; หลังการรับรองซ้ำไม่ผ่าน; หรือหลังทบทวนเปิดใหม่/ใหม่ที่พบความไม่สอดคล้อง ใช้ช่วงสั้นกว่าการรับรองเต็มของชั้นเดียวกัน และระบุขีดจำกัดการพึ่งพาในบันทึก. ไม่รวมการรับรองเต็ม; การรับรองมีเงื่อนไขที่ใช้ได้ทั้งสองสถานะ; การเลื่อนหรือไม่รับรอง. ขึ้นกับการรับรองซ้ำ. กฎเข้า/ออก ความสัมพันธ์ช่วงเวลา และช่วง tier อยู่บทเก้า C §9.3. รายการนี้ให้ความหมายบทห้าเท่านั้น.
<a id="provisional-certification-a"></a>
- **How to measure and assess**
  - ประเมินว่าการรับรองครั้งแรก/หลังล้มเหลวถูกบันทึกเป็นชั่วคราวไม่ใช่เต็ม; มีช่วงสั้นกว่าและขีดจำกัดการพึ่งพา; ระบบที่ครบเกณฑ์เต็มถูกเลื่อนระดับ ส่วนที่ยังไม่ครบคงชั่วคราวพร้อมเหตุผล.
<a id="provisional-certification-c"></a>
- **What must hold**
  - **Primary failure:** ความล้มเหลวหลัก: ถือระบบใหม่/หลังล้มเหลวว่าได้รับรองเต็ม; ระบุสถานะชั่วคราวโดยไม่มีช่วงสั้นหรือขีดจำกัดการพึ่งพา; คงสถานะโดยไม่มีเหตุหลังครบเกณฑ์เต็ม; หยุดระบบที่การหยุดจะตัดสิ่งจำเป็นต่อชีวิตก่อนมีสิ่งทดแทน ราวกับสถานะชั่วคราวบังคับให้หยุด.
