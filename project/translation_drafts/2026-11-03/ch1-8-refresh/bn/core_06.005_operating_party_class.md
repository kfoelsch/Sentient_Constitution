# অনুবাদ খসড়া — `core_06.005_rights_part_b.md`, Article XI-E (Operating Party-এর শ্রেণি)

লাইসেন্সের শর্তযুক্ত নির্ধারণ এটিও স্থির করে যে কাজটি নিরাপত্তার দিক থেকে বস্তুগত; তাই অন্যদের জন্য লাইসেন্সপ্রাপ্ত কাজ করা Operating Party অন্তত Class L। দক্ষতার clearance একাই Operating Party-কে Class L করে না; Domain-Specific Materiality অনুযায়ী তার শ্রেণি নির্ধারিত হয়। লাইসেন্স বা clearance-এর শর্তটি কাজটি করা সংবেদনশীল সত্তার ওপর প্রযোজ্য, Operating Party-এর শ্রেণি যাই হোক; আর Class L হওয়ার জন্য কখনো লাইসেন্স বা clearance লাগে না। এককভাবে বা ছোট পেশাগত চর্চায় লাইসেন্সপ্রাপ্ত কাজ করা ব্যক্তি যৌথ পেশাগত চর্চার মাধ্যমে Class L-এর দায় পালন করতে পারেন। এই পথ চর্চার সব কাজের জন্য উন্মুক্ত। তালিকাভুক্ত কাজে শেষ-আশ্রয় হোস্ট, প্রযুক্তিগত ফোরামের মানদণ্ড এবং লাইসেন্স/clearance যাচাই প্রযোজ্য (CI-15.205 §7)।
