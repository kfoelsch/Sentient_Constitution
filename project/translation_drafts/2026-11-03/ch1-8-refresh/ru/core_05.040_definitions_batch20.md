#### Оценка одной системы

<details>
<summary><strong>Прослеживаемость</strong></summary>

- Канонический источник: глава десятая §1.1 Кто проходит сертификацию; читать с §7.4 Отказ и отзыв для учреждения. Также читать с циклом сертификации и записями системы/учреждения.

</details>

*Проще говоря, это один цикл сертификации и одна запись для учреждения, эксплуатирующего ровно одну систему, которой нужен системный устав. Запись системы содержит блок выводов об учреждении и одновременно служит записью учреждения.*

- **What it is**
  - **In scope / out of scope / dependencies:** Входит один цикл/запись для учреждения с ровно одной системой, требующей устава. Форум, состав и сроки — от цикла системы плюс пункты оценки учреждения. Основания отказа/отзыва для системы и учреждения указываются отдельно. Не входят учреждения с несколькими системами (их запись ссылается на каждую системную запись), учреждения без систем (собственная запись) и каскад сверх правил 1 и 2, применимых здесь. Зависит от цикла и обеих записей. Особый случай — глава десятая §1.1; основания для учреждения — §7.4. Здесь только значение главы пятой.
<a id="one-system-evaluation-a"></a>
- **How to measure and assess**
  - Оценить, содержит ли запись все обязательные выводы об учреждении; указаны ли отдельно системное основание и основание учреждения.
<a id="one-system-evaluation-c"></a>
- **What must hold**
  - **Primary failure:** Основные нарушения: пропустить пункт учреждения из-за чистой оценки системы; позволить системному основанию решить статус учреждения или наоборот, не указав применимое основание.
