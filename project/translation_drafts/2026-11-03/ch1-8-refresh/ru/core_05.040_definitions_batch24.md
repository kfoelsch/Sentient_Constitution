#### Предварительная сертификация

<details>
<summary><strong>Прослеживаемость</strong></summary>

- Канонический источник: глава девятая C §9.3 Предварительная и полная сертификация. Читать с полной сертификацией, повторной сертификацией, записью системы и обратимостью.

</details>

*Проще говоря, это статус усиленного контроля для новой системы или системы после недавней неудачной оценки. Проверки идут чаще, пока система не заслужит более длинный период полной сертификации.*

- **What it is**
  - **In scope / out of scope / dependencies:** Входит статус при первой сертификации (включая новую систему), после неудачной повторной сертификации или возобновлённого/нового рассмотрения с выявленным несоответствием. Период короче полного для того же класса; в записи указаны пределы зависимости. Не входят полная сертификация; условная сертификация для любого статуса; отсрочка/отсутствие сертификации. Зависит от повторной сертификации. Правила входа/выхода, интервалы и окна уровней — глава девятая C §9.3. Здесь только значение главы пятой.
<a id="provisional-certification-a"></a>
- **How to measure and assess**
  - Оценить: первая/после провала сертификация записана как предварительная, не полная; установлен более короткий интервал и пределы зависимости; выполнившая полные условия система повышается, а не выполнившая остаётся предварительной с указанной причиной.
<a id="provisional-certification-c"></a>
- **What must hold**
  - **Primary failure:** Основные нарушения: считать новую/провалившуюся систему полностью сертифицированной; бумажный предварительный статус без короткого интервала или пределов зависимости; без причины сохранять статус после выполнения условий полной сертификации; останавливать систему, прекращение которой лишит жизненно необходимого до замены, будто этого требует предварительный статус.
