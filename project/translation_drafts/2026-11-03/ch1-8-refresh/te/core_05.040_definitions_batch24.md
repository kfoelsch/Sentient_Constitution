#### తాత్కాలిక ధృవీకరణ

<details>
<summary><strong>జాడ</strong></summary>

- కానానికల్ యజమాని: అధ్యాయం తొమ్మిది C §9.3 తాత్కాలిక, పూర్తి ధృవీకరణ. పూర్తి ధృవీకరణ, పునఃధృవీకరణ, వ్యవస్థ రికార్డు, తిరగదగినతతో చదవండి.

</details>

*సరళంగా: కొత్త వ్యవస్థ లేదా ఇటీవల మూల్యాంకనంలో విఫలమైనదానికి దగ్గర పర్యవేక్షణ స్థితి. పూర్తి ధృవీకరణ దీర్ఘ వ్యవధి సంపాదించే వరకు తక్కువ వ్యవధిలో మళ్లీ తనిఖీ.*

- **What it is**
  - **In scope / out of scope / dependencies:** పరిధి: మొదటి ధృవీకరణలో వ్యవస్థ (కొత్త అమలుతో సహా), విఫల పునఃధృవీకరణ తర్వాత, లేదా అసమన్వయం కనుగొన్న తిరిగి తెరిచిన/కొత్త సమీక్ష తర్వాతి స్థితి. అదే వర్గం పూర్తి వ్యవధికంటే తక్కువ వ్యవధి; రికార్డులో ఆధార పరిమితులు. మినహాయింపు: పూర్తి ధృవీకరణ; ఏ స్థితికైనా జతయ్యే షరతులతో ధృవీకరణ; ధృవీకరణ ఇవ్వని వాయిదా/నిరాకరణ. పునఃధృవీకరణపై ఆధారితం. ప్రవేశ/నిష్క్రమణ, వ్యవధి సంబంధం, tier గడువులు అధ్యాయం తొమ్మిది C §9.3లో. ఇది అధ్యాయం ఐదు అర్థం మాత్రమే.
<a id="provisional-certification-a"></a>
- **How to measure and assess**
  - నిరంతరత కొలత: మొదటి/విఫలానంతర ధృవీకరణ తాత్కాలికంగా నమోదు చేశారా; పూర్తి వర్గం కంటే తక్కువ వ్యవధి, ఆధార పరిమితులు ఉన్నాయా; పూర్తి అర్హత పొందిన వ్యవస్థను పైకి మార్చి, పొందనిదాన్ని కారణంతో తాత్కాలికంగా ఉంచారా.
<a id="provisional-certification-c"></a>
- **What must hold**
  - **Primary failure:** ప్రధాన వైఫల్యాలు: కొత్త/విఫలమైన వ్యవస్థను పూర్తి ధృవీకరణగా చూడడం; తక్కువ వ్యవధి/ఆధార పరిమితి లేని కాగిత స్థితి; అర్హత నెరవేరినా కారణం లేక తాత్కాలికంగా ఉంచడం; ప్రత్యామ్నాయానికి ముందు జీవనావసరాలు తెగే వ్యవస్థను తాత్కాలిక స్థితి కోరుతుందని ఆపడం.
