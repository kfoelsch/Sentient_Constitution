- **Lo que no es nuevo:** una entidad sucesora, renombrada, dividida o transferida que conserva al mismo operador, control o sistema ([Parte C §9.4 No evasión](core_09.010_system_alignment_certification_record_recertification.md#94-non-evasion); [Capítulo Tres §2.1 Patrones comunes de evasión](core_03.000_definition_integrity.md#21-common-evasion-patterns)).
