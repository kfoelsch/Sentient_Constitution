- **Ce qui n’est pas nouveau :** une entité successeur, renommée, scindée ou transférée qui conserve le même opérateur, le même contrôle ou le même système ([Partie C §9.4 Non-évasion](core_09.010_system_alignment_certification_record_recertification.md#94-non-evasion) ; [Chapitre Trois §2.1 Schémas courants d’évasion](core_03.000_definition_integrity.md#21-common-evasion-patterns)).
  - **Vers le forum compétent pour une personne sentiente nommée :** lorsque la conclusion de certification repose sur l’utilisation du système par une personne sentiente pour commettre une violation, le forum principal transmet les faits au forum compétent pour cette personne.
