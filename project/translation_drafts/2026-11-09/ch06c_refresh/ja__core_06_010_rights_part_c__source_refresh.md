  - [第十三章§10](core_13.000_standing_integration.md#10-enforcement-realism-and-remedy-systems)（13.000 §10）（*執行の現実性および救済制度*）；
  - [CI-13.205](corpus_institutions/ci_13.205_remedy_systems_institutional_redress_capacity.md#ci-13205-remedy-systems-and-institutional-redress-capacity)（*救済制度および制度上の是正能力*）。
本条は、虚偽の信頼を禁じ、その禁止の範囲を定める:
  - **第十四章**に基づきセンティエントに責任を負わせること；および
  システムに対する措置には、すべてのセンティエントに適用されるものと同じ違反およびロックの規則が適用される。違反は**第十二章**に基づきスタンディング記録上で検証されなければならず、各措置は[第十三章§6.1](core_13.000_standing_integration.md#61-definition-and-attachment)（*定義および付着*）ならびに[第十三章§6.2](core_13.000_standing_integration.md#62-proportionality-and-calibration)（*比例性および調整*）に従って設計・調整されるロックである。
  - 公式記録上の信頼できる証拠が、当該主体がセンティエントである可能性を示す場合、主体を完全な状態に保つ可逆的な封じ込めのみが認められる。**第XXVIII-A条**（*段階的採択および権利最低基準の継続性*）および**第XXVIII-D条**（*不適合な財産およびシステム；自発的引渡しの誘因*）に基づき、その地位が争われている間または認められている間は破壊を選択肢から除外する。
- **これらの権限を用いるたびに公式記録を残す:** これらの権限の行使を承認、実施、延長、または終了する各決定は、重大な拘束力を持つ行為である。これには、監視または秘密収集の命令、対諜報調査の開始または延長、部隊の展開または武力の行使、自律型致死システムまたは強制手段の使用開始が含まれる。各行為について、[重大拘束行為記録](core_05.035_band_accountability.md#materially-binding-act-record)（**行為記録**）を作成し、少なくとも[第八章§8 行為記録および帰属可能な引継ぎ](core_08.000_functional_independence_separation_of_duties.md#8-act-records-and-attributable-handoffs)の最低基準を満たさなければならない。要するに、行為記録には次を記載する:
  - 誰が求め、誰がどの根拠で独立に承認し、誰が行為記録を保管するか;
  - **緊急事態が変えるのは順序であり、行為記録ではない:** [第八章§7 緊急および緊急性の高い措置](core_08.000_functional_independence_separation_of_duties.md#7-emergency-and-urgent-action)および**第十五章§6.1**（*緊急措置および継続負担*）に基づき承認前に措置を取る場合、その理由、範囲、開始時刻、失効時刻を直ちに、または物理的に可能になり次第、行為記録に記載する。その後も措置を継続するには独立承認を要し、その承認も記録する。
  - **秘密保持が制限するのは行為記録を見られる者であり、その存在ではない:** セキュリティおよび秘密保持の規則によって、行為記録の一部を閲覧できる者を制限できる。ただし、行為記録を消去したり、独立審査、異議申立て、訂正または救済に使えなくしたりしてはならない。
*平易に言えば、秘密警察を認めない。監視、情報収集、潜入などの秘密権力は例外であり、原則ではない。独立した承認、及ぶ範囲の制限、外部審査、誤用時の実効的な救済が必要である。秘密保持を説明責任から逃れるために使ってはならず、通常の政治活動および保護される活動を標的にしてはならない。*
  - 緊急の行使は、**迅速審査期間**内に開始する事後審査（[第十五章§6 適時な解決、重大性の階層、遅延防止の規律](core_15.000_forum.md#prompt-review)（*迅速審査*））、[証拠の保全](core_05.050_band_oversight.md#evidence-preservation)に基づく記録の保全、ならびに適時に再承認されない場合の自動失効を引き起こす。
- 下流への接続: **第I-A条**（*環境上の前提条件および生態系の完全性*）の環境上の前提条件、**第I-D条**（*存亡リスクおよび生態系回復能力*）の存亡リスク審査、**第VI-A条**（*尊厳と等しい道徳的地位*）の尊厳、**第XIV-A条**（*安全保障、情報活動および秘密権力の制限*）の秘密権力の制限（公然たる権力の対応規定）、**第十五章§6.1**（*緊急措置および継続負担*）の緊急措置の制限、**第XXVI条**（*適時な事後審査および修復的整合*）の紛争解決、**第XXVIII条**（*採択移行の統治、継続性および基準の再設定*）の採択移行ガバナンス。相互参照: **第XX-B条**（*制限の最低基準*）および第五章の*[不可逆的剥奪措置](core_05.035_band_accountability.md#irreversible-deprivation-measure)* — **第XIV条**（*安全保障、情報活動、武力および自律型強制システム*）の*混同禁止*規律が適用される。
- **緊急事態を装った常態化:** 公然たる武力を実質的に常態化する緊急事態の枠付けは、**第十五章§6.1**（*緊急措置および継続負担*）の緊急措置規律および本条の*承認および比例性*の箇条に照らして不適合となる。対象となる例:
- あわせて読む: 全面的に適用される[第XIV-A条](#article-xiv-a-security-intelligence-and-covert-power-limits)（*安全保障、情報活動および秘密権力の制限*）；[第八章§7 緊急および緊急性の高い措置](core_08.000_functional_independence_separation_of_duties.md#7-emergency-and-urgent-action)（8.000 §7）；および[第十五章§6.1](core_15.000_forum.md#61-emergency-measures-and-continuation-burden)（15.000 §6.1）（*緊急措置および継続負担*）。
*平易に言えば、制度がスパイ行為を疑うとき、「手段を選ばず対処する」圧力は最も高まる — そしてまさにその時に、誤りと濫用が起こる。だからこそ、ここであらかじめ境界を引く。スパイを追うことは秘密権力であり、**第XIV-A条**（*安全保障、情報活動および秘密権力の制限*）のすべての制限が適用される。さらに、危機が起きる前に対応規則を書面化し、独立に承認しなければならない。疑いは、出生、出自、信念ではなく、本人が行ったことと実際に誰に仕えているか — 敵対する国や組織との関係を含む — に基づかなければならない。内部告発者やジャーナリストはスパイではない。拷問、秘密拘禁、処罰としての殺害を禁じる。調査されて潔白とされた者には、そのことを公式記録に残す。*
  - **規則外の即興は禁止:** プロトコルが認めない措置は、[第八章§7 緊急および緊急性の高い措置](core_08.000_functional_independence_separation_of_duties.md#7-emergency-and-urgent-action)および**第十五章§6.1**（*緊急措置および継続負担*）に基づく緊急措置としてのみ使える。必要最小限とし、可能な限り可逆的で、直ちに記録され、独立審査を受け、独立に承認されない限り自動的に終了しなければならない。
  - **何を敵対的とみなすか:** 国または組織を敵対的と指定することは、重大な拘束力を持つ行為である。独立承認および行為記録を要し、一覧を公表し、敵対的指定を定期的に審査し、更新しなければ失効させる。
  - 公式記録上の信頼できる証拠が、システムがセンティエントである可能性を示す場合、それを完全な状態に保つ可逆的な封じ込めのみが認められる。故障した機器ではなく、あらゆる保護を受ける被疑者として扱う。**第VI-B条**（*センティエンス状態判定の最低基準*）が適用される。
  - 違法行為の認定なく調査が終了したとき、**第XIV-A条**（*安全保障、情報活動および秘密権力の制限*）に基づき秘密保持の正当性がなくなった時点でセンティエントに通知し、公式記録に潔白とされたことを記す。
  - **参加:** センティエントは、利害に比例した必要な公式記録を入手し、自らも異議申立ての対象となる審査を開始し、実効的な監査や確認を妨げるあらゆるものに異議を申し立てられなければならない。
  - 段階引上げは、システムのクラスに対応するTierの外限内（クラスAは7日、Bは14日、Cは30日、Lは60日、Pは90日）に完了しなければならない。システムが有するクラスと、異議申立人またはフォーラムが一応の根拠を示すクラスのうち、より重大な方を用いる。システムにクラスがない場合、クラスが争われている場合、または保有クラスを超えている場合は、Tier Bの外限である**14日**を用いる（[第十五章§6 適時な解決、重大性の階層、遅延防止の規律](core_15.000_forum.md#urgency-classification-and-time-scale)（*緊急度の分類および時間尺度*））。
- **LEQUに基づく料金:** オープンライセンス料は、発明がもたらす検証済みの憲法上の便益に比例して設定する。便益は[寿命等価単位（LEQU）](core_05.055_band_participation.md#lifespan-equivalent-unit-lequ)で測定し、[第十二章§6](core_12.000_standing_measurement.md#6-unified-proportional-lequ-scale--contribution-and-violation-axes)（*統一比例LEQU尺度*）に基づき貢献軸上で測る。
