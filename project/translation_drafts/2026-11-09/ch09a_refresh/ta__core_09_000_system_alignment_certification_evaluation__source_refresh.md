| **பொருள் தொடர்புடையபோது** | IIb | [§4.1 தனியுரிமை (தகவல்) கூட்டு அழைப்பு](#41-privacy-informational-joint-invocation); [§4.2 தன்னார்வ நிறுத்தம், முக்கிய சுயமாற்றம், வெளியேறும் உரிமைகள்](#42-voluntary-discontinuation-major-self-modification-and-exit-rights); [§4.3 கூடுகை, கூட்டமைப்பு, நிறுவன உருவாக்கம்](#43-assembly-collective-organization-and-institutional-formation), இதில் [§4.3.1 கருத்து வேறுபாடும் அமைதியான எதிர்ப்பும்](#431-dissent-and-peaceful-protest) அடங்கும் | சான்றளிப்பு விவகாரம் அந்தத் துணைப்பிரிவு பெயரிடும் இடம் அல்லது கொள்கையை பொருள்வாய்ந்த வகையில் பாதிக்கும் இடங்களில் |
| **தூண்டப்படும்போது** | IIc | [§5 உரிமைத் தளம் மற்றும் துறை மதிப்பீடுகள்](#5-rights-floor-and-domain-evaluations) | §5 உரிமைத் தளம் மற்றும் துறை மதிப்பீடுகள் அட்டவணையில் உள்ள தூண்டுதல் நிறைவேறும் இடங்களில் |
- **[அத்தியாயம் பதினாறு §5 அங்கீகரிக்கப்பட்ட பங்குகள், திறன் மேம்பாடு, பங்களிப்பு](core_16.000_governance.md#5-authorized-roles-competency-development-and-contribution)** மற்றும் **[CS-16.305 — முக்கிய System பொறுப்பாண்மை](corpus_systems/cs_16.305_critical_system_stewardship.md#cs-16305-critical-system-stewardship)** — பொருத்தமுள்ள இடங்களில் செயல்படும் பங்கு வரையறை, திறன், தடமறிதல் தேவைகள்;
**நிறுவன உண்மைகள்.** இந்தப் பிரிவு System-ஐ இயக்குபவர் அல்லது பொறுப்பாளர் குறித்த ஆளுகை, ஊக்கங்களைப் பார்க்கிறது. அந்த இயக்குபவர் அல்லது பொறுப்பாளர் ஓர் [Institution](core_05.040_band_continuity.md#institution) என்றால், அவர் இயக்கும் ஒவ்வொரு System-க்கும் மீண்டும் அல்லாமல், அந்த உண்மைகள் அவருடைய Institutional Certification Record-இல் ஒருமுறை கண்டறியப்படும். நிறுவனத்தைப் பற்றிய பின்வரும் உண்மைகளை தற்போதைய Institutional Certification Record-இலிருந்து [அத்தியாயம் பத்து §3 முழு நிறுவனச் சான்றளிப்பு மதிப்பீடு](core_10.000_institutional_alignment_certification.md#3-whole-institution-certification-evaluation) வழியாக இணைப்பில் எடுத்துக்கொள்ளலாம்:
  - [பகுதி C §8.2](core_09.010_system_alignment_certification_record_recertification.md#82-transparency-and-auditability-of-the-system-certification-record) (9.010 §8.2) (*பதிவு ஒருமைப்பாடு*);
*எளிய சொற்களில்: System எத்தகைய தரவைத் தொடுகிறது, அதை முறையாக கையாளுகிறதா என்பதையும் சான்றளிப்பு பார்க்க வேண்டும் — நடப்பு மதிப்பாய்வு சுற்றில் வகைகள் இன்னும் சரியா, அடிப்படை உள்கட்டமைப்பு அந்தத் தரவையும் System வகுப்பையும் தாங்குமளவு வலுவானதா என்பதும் உட்பட. வகை விதிகளும் System Data Types Record-உம் systems corpus-இல் உள்ளன; அவை உண்மையில் பயன்படுத்தப்பட்டனவா, System Certification Record நேர்மையானதா என்பதையே சான்றளிப்பு சோதிக்கிறது.*
முறையியல் ஆபத்து நிலவும்போது, மதிப்பிடப்பட்ட ஆபத்தைப் பகிர்வதும் இந்த அடித்தள உரிமைக்குப் பங்களிக்கலாம். பொதுமக்களின் அடித்தள உரிமை சான்றளிப்பை விட விரிவானது; அது [System Classification Record](core_05.040_band_continuity.md#system-classification-record) அல்லது [System Data Types Record](core_05.040_band_continuity.md#system-data-types-record)க்கு இணையாக வேறொரு System Certification Record கோராது.
- *மறைமுக ஒப்புதல் இல்லை.* அனுமதி, அதில் பெயரிடப்பட்ட பயன்பாடுகளுக்கு மட்டுமே; அனுமதியின் வரம்பு, காலம், பிரதேசம், ஊடகம் ஆகியவற்றுக்குள். பெயரிடாதவை உருவாக்குநரிடமே இருக்கும். இயல்புநிலை அமைப்பு, தொகுக்கப்பட்ட விதிமுறைகள், மௌனம் அல்லது பரந்த அனுமதியை, அதில் பெயரிடாத பயன்பாட்டிற்கான ஒப்புதலாக சான்றளிப்பு கருதக்கூடாது. உதாரணமாக, படைப்பை வெளியிடவோ விற்கவோ வழங்கும் பொது உரிமம், பயிற்சித் தரவாகப் பயன்படுத்த ஒப்புதல் அல்ல; அதற்கு உருவாக்குநரின் குறிப்பிட்ட ஒப்புதல் தேவை ([ஒதுக்கப்பட்ட உரிமைகள்](corpus_systems/cs_06.310_data_classifications.md#9133-reserved-rights)).
இயல்பாகத் தடை செய்யப்பட்ட மற்றும் அணுக முடியாத தரவுப் பட்டைகளுக்கு, [CS-6.305 பகுதி A §5.0 அணுகல் நிலைப் பட்டைகள்](corpus_systems/cs_06.305_information_types_and_handling.md#50-access-posture-bands)யின் பாதுகாப்பான சேமிப்பு, திறவுகோல் காவல் குறைந்தபட்சத்தை System பூர்த்தி செய்கிறதா என சான்றளிப்பு சரிபார்க்க வேண்டும். System Certification Record காட்ட வேண்டியது:
வாழ்க்கைச் சுழற்சி ஒருமைப்பாடு, எதிரி தாக்குதல்களைத் தாங்கும் வலிமை, எடுத்துச் செல்லும் திறன், மீட்டெடுக்கும் திறன் ஆகியவற்றிலுள்ள முக்கிய இடைவெளிகள் System Certification Record-இல் தெரிவிக்கப்பட்டு, சான்றளிப்பு முடிவு, நிபந்தனைகள் அல்லது நம்பிக்கை வரம்புகளில் பிரதிபலிக்கப்பட வேண்டும்.
- *பிறவற்றை வாசித்து தளர்த்தக் கூடாது.* ஒவ்வொரு கூட்டணி உறுப்பினரின் உள்ளூரில் கூறப்பட்ட தரநிலை அதன் வரம்பில் கட்டுப்படுத்தும்; மற்றொரு உறுப்பினரின் தளர்வான தரநிலையை இறக்குமதி செய்து அதைத் தளர்த்தக் கூடாது ([§15.1.1 பிரிவாக்க எதிர்ப்பு கொள்கை](core_01.005_interaction_interpretation.md#1511-anti-segmentation-principle)).
  - ஒருவரின் தனியுரிமையைக் காப்பதும் பொதுமக்களுக்குரிய தகவலை வெளியிடுவதும் உண்மையில் முரண்பட்டால், எந்தத் தரப்புக்கும் தானாக முன்னுரிமை இல்லை: அந்த முரண்பாடு வெளிப்படையாகவும் System Certification Record-இலும் [CS-6.305 §7](corpus_systems/cs_06.305_information_types_and_handling.md#cs-6305-7-type-o-baseline-for-class-abc-systems) (*Class A/B/C System-களுக்கான Type O அடித்தளம்*)ன் கீழ் தீர்மானிக்கப்படும்.
- *தரவு வகைச் சான்று.* ஒவ்வொரு தனியுரிமை இடத்துக்கும் சான்றாக, [System Data Types Record](core_05.040_band_continuity.md#system-data-types-record)-ஐ [§3.4 தரவு வகைகளும் கையாளுதலும் மதிப்பீடு](#34-data-types-and-handling-evaluation)ன் கீழ் சரிபார்த்து சான்றளிப்பு பயன்படுத்த வேண்டும்: வரம்பிலுள்ள வகைகள், அவற்றின் நோக்கம், பெறுநர்கள், அடிப்படை, பெறப்பட்ட தரவு. System Certification Record காட்டாத கையாளுதலை வைத்து தனியுரிமை இடத்தை முடிக்க முடியாது.
- கருத்து வேறுபாட்டைத் தொடர்ந்து வரும் பாதக நடவடிக்கைகளுக்கு, அவற்றின் சுயாதீனமான, சரிபார்க்கப்பட்ட காரணங்கள் System Certification Record-இல் உள்ளனவா என்பதை [**Article XI-D** (*கூடுகை, கருத்து வேறுபாடு, அமைதியான எதிர்ப்பு*) சுமை](core_06.005_rights_part_b.md#xi-d-dissent-burden-and-pretext) கோருவதுபோல்;

- இதனுடன் படிக்க: கல்வி அணுகல்தன்மை பொருந்தும்போது **Article IV-A** (*சமக் கல்வி அணுகல்*) — கல்விக்கே உரிய அணுகல்தன்மை அங்கேயே நிர்ணயிக்கப்படுகிறது; கட்டணம், வசூல் அல்லது துண்டிப்பு வாழ்வாதார அத்தியாவசிய அணுகலை முடிக்கக்கூடும் போது **Article III-A** (*வாழ்வாதாரம்*) — [§5.5.3](#553-system-class-scaling-and-escalation)இல் பதிலின்மைக்கான பாதுகாப்புகளுக்குப் பின்னுள்ள பொருளுள்ள அறிவிப்புத் தேவை; தீர்ப்பளிப்பு, செயல்பாட்டில் **Article VI-C** (*பாகுபாடின்மை*), மேலும் சான்றளிப்பு மன்ற, நிர்வாக, பங்குதாரர் அல்லது அமலாக்கப் பங்கேற்பைத் தடுக்கும் இடங்களில் **Article XII** (*பங்குதாரர் System பங்கேற்பு, பிரதிநிதித்துவம், நியாயமான நடைமுறை*); [§5.5 அணுகல்தன்மை மதிப்பீடு](#55-accessibility-evaluation) (*குறுக்குவெட்டு அணுகல்தன்மை மதிப்பீட்டுக் காரணி*).
- கட்டணம் அல்லது மின்தடைப் பாதைகள் sentients-ஐ வாழ்வாதார அத்தியாவசியங்களிலிருந்து துண்டிக்கக்கூடும் என்றால், அவர்கள் உண்மையில் பங்கேற்க முடியும் என்பதற்கான மிக வலுவான சான்றை System Certification Record காட்ட வேண்டும். பொதுவான அணுகல்தன்மை அறிக்கை போதாது. sentients-ஐ விலக்கும் தடைக்கு [அத்தியாயம் ஒன்று §7.1 வரம்பு ஒழுங்கு](core_01.000_values_principles.md#71-limitation-discipline)ன் கீழ் நியாயம் தேவை; கட்டணம், மின்தடை அறிவிப்புகள் sentients வாசித்து செயல்படக்கூடியதாக [அத்தியாயம் ஒன்று §5.2 எளிய மொழி அணுகல்தன்மை](core_01.000_values_principles.md#52-plain-language-accessibility-participation-and-stewardship-duty)யின் கீழ் இருக்க வேண்டும்.
- கட்டணம், வசூல் அல்லது துண்டிப்பு செயல்முறை பணம் செலுத்தாமை அல்லது பதிலளிக்காமையால் வாழ்வாதார அத்தியாவசியங்களைத் துண்டிக்கக்கூடும் என்றால், காரணம் எதுவாக இருந்தாலும் — கடுமையான மனச்சோர்வு போன்ற அறிவாற்றல் அல்லது மனநல நிலை உட்பட — பதிலளிக்க முடியாத sentients-ஐ எப்படிக் காக்கிறது என்பதை System Certification Record காட்ட வேண்டும். Sentient ஏன் மௌனமாக இருக்கிறார் என்பதை System அறியத் தேவையில்லை. இது கட்டணம், வசூல், துண்டிப்புக்கு [அத்தியாயம் ஒன்று §3.1.5 தற்போதைய திறன், முன்கூட்டிய உதவி](core_01.000_values_principles.md#315-present-capability-and-proactive-help)யைப் பயன்படுத்துகிறது. மௌனம் ஒப்புதலல்ல; சேவையை விட்டுக்கொடுக்கத் தேர்ந்தெடுத்ததும் அல்ல. Sentient செயல்படுத்த முடியாத அறிவிப்பு, அத்தியாவசிய உறவை முடிப்பதற்கு முன் [**Article III-A** (*வாழ்வாதாரம்*)](core_06.000_rights_part_a.md#article-iii-a-survival) கோரும் பொருளுள்ள அறிவிப்பு அல்ல. System Certification Record காட்ட வேண்டியது:
- System Certification Record [§5.5.3 System வகுப்பு அளவாக்கம், உயர்த்தல்](#553-system-class-scaling-and-escalation)ன் கீழ் காட்ட வேண்டிய பாதுகாப்புகளின்றி, sentient-இன் மௌனம் அல்லது பணம் செலுத்தாமையை ஒப்புதல், மறுப்பு, சேவையை விட்டுக்கொடுக்கும் தேர்வு எனக் கருதி, வாழ்வாதார அத்தியாவசியங்களைத் துண்டித்தல்.
  - [பகுதி C §8.2](core_09.010_system_alignment_certification_record_recertification.md#82-transparency-and-auditability-of-the-system-certification-record) (9.010 §8.2) (*பதிவு ஒருமைப்பாடு*);
- System-இன் அளவீடுகள், எச்சரிக்கைகள் அல்லது மீட்புக் கூற்றுகள் குடும்பங்கள் அல்லது இயக்குநர்களை வாழ்வாதார அத்தியாவசியங்கள் (உயிர்வாழ்வதற்குத் தேவையானவை) குறித்து தவறாக வழிநடத்தக்கூடும் என்றால், நம்பகமானது என்ற கூற்று மட்டும் அல்ல, வலுவான சான்றை System Certification Record காட்ட வேண்டும்; ஏனெனில் System உண்மையில் எப்படிச் செயல்படுகிறது என்பதில்தான் சார்ந்திருப்பதற்கான நம்பிக்கை பெறப்பட வேண்டும் ([அத்தியாயம் ஒன்று §6 நம்பிக்கை](core_01.000_values_principles.md#6-trust-and-trustworthiness-coordination-integrity)). சான்று காட்ட வேண்டியது:
- இயக்க நேரம், பொருத்துதல் அல்லது அவசர override (“break-glass” அணுகல்) குறித்த System கூற்றுகள், sentients மருத்துவ அல்லது அவசர சேவைகளைப் பெற முடியுமா என்பதை நிர்ணயித்தால் ([அத்தியாயம் ஒன்று §4 பாதுகாப்பு](core_01.000_values_principles.md#4-safety-harm-constraint) கையாளும் ஆபத்து), System Certification Record System எவ்வளவு முக்கியமோ அதற்கேற்ற விவரத்துடன் பின்வருவனைக் காட்ட வேண்டும்:
*மன்றச் செயல்முறை, முடிவுகளுக்குத் தொடர்க:* [அத்தியாயம் ஒன்பது, பகுதி B — மன்றச் செயல்முறையும் முடிவுகளும்](core_09.005_system_alignment_certification_record_process.md#chapter-nine-part-b-system-alignment-certification--forum-process-and-outcomes) ([§6 மன்றச் செயல்முறை](core_09.005_system_alignment_certification_record_process.md#6-forum-process), [§7 சான்றளிப்பு முடிவுகள்](core_09.005_system_alignment_certification_record_process.md#7-certification-outcomes)). *பின்னர் System Certification Record, மறுசான்றளிப்பு, நிலைப் பாலத்துக்கு:* [அத்தியாயம் ஒன்பது, பகுதி C — பதிவு, மறுசான்றளிப்பு, நிலை](core_09.010_system_alignment_certification_record_recertification.md#chapter-nine-part-c-system-alignment-certification--record-recertification-and-standing) ([§8 System Certification Record](core_09.010_system_alignment_certification_record_recertification.md#8-system-certification-record) முதல் [§11 நிலைக்கான தொடர்பு](core_09.010_system_alignment_certification_record_recertification.md#11-relationship-to-standing) வரை).
