- billing, collection లేదా cutoff ప్రక్రియ చెల్లించకపోయినా, స్పందించకపోయినా survival essentialsను నిలిపివేయగలిగితే, కారణం ఏదైనా (తీవ్ర depression వంటి cognitive లేదా mental-health స్థితి సహా) స్పందించలేని sentients‌ను ఎలా కాపాడుతుందో System Certification Record చూపాలి. Sentient ఎందుకు మౌనంగా ఉన్నారో System తెలుసుకోవాల్సిన అవసరం లేదు. ఇది billing, collection, cutoffకు [Chapter One §3.1.5 Present Capability and Proactive Help](core_01.000_values_principles.md#315-present-capability-and-proactive-help)ను వర్తింపజేస్తుంది. మౌనం సమ్మతి కాదు, సేవను వదులుకోవాలనే ఎంపిక కూడా కాదు. Sentient చర్య తీసుకోలేని notice, essential relationను ముగించే ముందు [**Article III-A** (*Survival*)](core_06.000_rights_part_a.md#article-iii-a-survival) కోరే meaningful notice కాదు. System Certification Record చూపాల్సినది:
- [§5.5.3 System Class Scaling and Escalation](#553-system-class-scaling-and-escalation) కింద System Certification Record చూపాల్సిన protections లేకుండా, sentient మౌనం లేదా చెల్లించకపోవడాన్ని సమ్మతి, నిరాకరణ లేదా సేవను వదులుకునే ఎంపికగా భావించి survival essentialsను నిలిపివేయడం.
  - [Part C §8.2](core_09.010_system_alignment_certification_record_recertification.md#82-transparency-and-auditability-of-the-system-certification-record) (9.010 §8.2) (*record integrity*);
- System readings, alerts లేదా recovery claims కుటుంబాలు లేదా operators‌ను survival essentials (sentients జీవించడానికి అవసరమైనవి) గురించి తప్పుదారి పట్టించవచ్చంటే, System విశ్వసనీయమనే మాట మాత్రమే కాక బలమైన సాక్ష్యాన్ని System Certification Record చూపాలి; System ప్రవర్తన ద్వారానే ఆధారపడే నమ్మకం సంపాదించాలి ([Chapter One §6 Trust](core_01.000_values_principles.md#6-trust-and-trustworthiness-coordination-integrity)). సాక్ష్యం చూపాల్సినవి:
- uptime, matching లేదా emergency overrides (“break-glass” access) పై System claims sentients‌కు clinical care లేదా emergency services లభిస్తాయా అన్నది నియంత్రిస్తే ([Chapter One §4 Safety](core_01.000_values_principles.md#4-safety-harm-constraint) పరిధిలోని ప్రమాదం), System ఎంత కీలకమో దానికి సరిపోయే వివరాలతో System Certification Record కింది అంశాలు చూపాలి:
