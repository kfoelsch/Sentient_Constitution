# Chapter One §7.2 — Lighter Rules for Single Questions

## English source passage

**When lighter rules apply.** If the matter is only one of those questions — for example, an ordinary civic gathering with no labor-organizing or institution-forming stake:

- Use [Assembly](core_05.055_band_participation.md#assembly) or [Collective Organization](core_05.055_band_participation.md#collective-organization) as an ordinary supporting definition.
- Do not pull in [System Creation](core_05.055_band_participation.md#system-creation), [Business Creation](core_05.055_band_participation.md#business-creation), or the rest of this definition cluster.
- Do not apply the anti-segmentation package of **§7.2** (*Assembly, Collective Organization, and Institutional Formation*) just because one of those terms appears.

## Draft translation (fr)

**Quand des règles plus légères s’appliquent.** Si la question ne porte que sur un seul de ces sujets — par exemple, un rassemblement civique ordinaire sans enjeu d’organisation du travail ni de création d’institution — alors :
- Utilisez le [rassemblement](core_05.055_band_participation.md#assembly) ou l’[organisation collective](core_05.055_band_participation.md#collective-organization) comme définition auxiliaire ordinaire.
- N’intégrez pas la [création de systèmes](core_05.055_band_participation.md#system-creation), la [création d’entreprises](core_05.055_band_participation.md#business-creation), ni le reste du cluster de définitions.
- N’appliquez pas le dispositif anti-segmentation de **§7.2** simplement parce qu’un de ces termes apparaît.
