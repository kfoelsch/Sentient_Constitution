# Chapter One §7.3 — Whole-System Dissent Check

Source: `core_01.000_values_principles.md` §7.3 Dissent and Peaceful Protest

Source SHA-256: `6b6f07eff0faf4249c4ef3844f8e6ee4b24041768de3ffd4262240bc68854c17`

## English source passage

When a whole system is being evaluated, the evaluation must check how it treats dissent and peaceful protest, using [Chapter Nine §4.3.1 Dissent and Peaceful Protest](core_09.000_system_alignment_certification_evaluation.md#431-dissent-and-peaceful-protest). Until that check is done, no one can claim the system is properly classified, well governed, or compliant where this section applies.

## Draft translation (es)

Al evaluar un sistema completo, la evaluación debe comprobar cómo trata el disenso y la protesta pacífica, conforme al [Capítulo Nueve §4.3.1 Disenso y protesta pacífica](core_09.000_system_alignment_certification_evaluation.md#431-dissent-and-peaceful-protest). Hasta que se complete esa comprobación, nadie puede afirmar que el sistema está correctamente clasificado, bien gobernado o cumple las normas cuando se aplica esta sección.
