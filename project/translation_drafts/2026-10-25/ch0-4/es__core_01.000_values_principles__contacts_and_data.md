# Chapter One excerpt — contact data limits

## English source

**Contacts and data:** A trusted contact is used only if the sentient chose it in advance, and only the information needed to get a response is shared. Outreach uses contact details the system already holds for that purpose and is not a reason to collect more data.

## es draft

**Contactos y datos:** Solo se utiliza una persona de confianza como contacto si el ser sintiente la eligió de antemano, y solo se comparte la información necesaria para obtener una respuesta. El contacto usa los datos que el sistema ya conserva para ese fin y no justifica recopilar más datos.
