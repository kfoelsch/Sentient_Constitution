# Chapter One excerpt — same threshold-setting discipline

## English source

**Under the same discipline:** the requirement-preservation, substance-over-form, anti-nullification, and heightened-scrutiny rules of **CJS-5.125 §11.1 — Market concentration threshold-setting discipline (adopter-tunable)** apply in full. No level may be set so high that it never bites, and concentration hidden behind shell, federated, or split-up structures still counts.

## ru draft

**В рамках той же дисциплины:** в полном объеме применяются правила сохранения требований, проверки существа, а не формы, предотвращения обнуления и усиленной проверки из **CJS-5.125 §11.1 — Порядок установления порогов концентрации рынка (настраиваемый принимающей стороной)**. Ни один уровень нельзя установить настолько высоким, чтобы он никогда не срабатывал; концентрация, скрытая за фиктивными, федеративными или раздробленными структурами, также учитывается.
