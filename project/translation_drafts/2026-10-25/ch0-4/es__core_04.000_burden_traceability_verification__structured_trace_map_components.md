# Chapter Four excerpt — structured trace map

## English source passage

This section requires a **structured trace map**. For every definition that materially applies to system behavior — including every materially required **Chapter Five** definition — the map must link each part to **observable** behavior and real-world effects:

- **what it is (O)** — what the term is about
- **how it is measured (M)** — which measure applies at each layer
- **how it is judged (A)** — how the term must be assessed
- **what must hold (C)** — what must be true in practice

## Draft translation (es)

Esta sección exige un **mapa de trazabilidad estructurado**. Para cada definición que se aplique materialmente al comportamiento del sistema —incluidas todas las definiciones del **Capítulo Cinco** que sean materialmente necesarias— el mapa debe vincular cada parte con conductas **observables** y efectos reales:

- **qué es (O)**: a qué se refiere el término
- **cómo se mide (M)**: qué medida se aplica en cada nivel
- **cómo se juzga (A)**: cómo debe evaluarse el término
- **qué debe cumplirse (C)**: qué debe ser cierto en la práctica
