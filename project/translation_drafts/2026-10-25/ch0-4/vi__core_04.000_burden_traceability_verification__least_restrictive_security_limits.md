# Chapter Four excerpt — least-restrictive security limits

## English source passage

- apply the **least-restrictive** limit that still addresses foreseeable risk, including exploitation, circumvention, or systemic harm, using methods proportionate to system impact, dependency, and risk
- preserve the **maximum achievable** independent audit, verification, and challenge rights
