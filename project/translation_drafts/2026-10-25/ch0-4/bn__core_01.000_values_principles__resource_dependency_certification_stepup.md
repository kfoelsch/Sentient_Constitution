# Chapter One §11.4 — Certification Step-Up for Chokepoints

Source: `core_01.000_values_principles.md` §11.4 Resource and Dependency Concentration

## English source passage

In system alignment certification, a system that becomes a choke point for dependents who cannot realistically switch is stepped up on those facts under [Chapter Nine §5.3.5 System Class Scaling and Escalation](core_09.000_system_alignment_certification_evaluation.md#535-system-class-scaling-and-escalation) and [§2.2 How system class scales every evaluation](core_09.000_system_alignment_certification_evaluation.md#22-how-system-class-scales-every-evaluation). A crossed level there is further evidence, and a level that is unset or set too high does not delay the step-up.
