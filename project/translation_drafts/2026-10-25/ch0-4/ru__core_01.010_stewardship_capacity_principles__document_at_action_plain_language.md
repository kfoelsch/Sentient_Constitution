# Chapter One Part C excerpt — document at action

## English source passage

*In plain terms: when something that matters is done, the record should be made by the doing, at that moment, and by the system itself wherever it can be. No one writes it up later from memory. What is not lawfully restricted should be visible straight away. What is restricted should still leave a visible mark that something was done, and a way to learn more later. The system does the recording, so the steward carries no extra work.*

## Draft translation (ru)

*Проще говоря: когда совершается важное действие, запись о нём должна создаваться одновременно с действием, в этот самый момент, и по возможности самой системой. Никто не должен составлять её позже по памяти. Всё, что законно не ограничено, должно сразу становиться видимым. Ограниченная информация тоже должна оставлять видимый знак того, что действие совершено, и путь, позволяющий узнать больше позднее. Запись ведёт система, не возлагая дополнительную работу на распорядителя.*
