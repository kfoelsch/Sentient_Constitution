# Chapter One Part C excerpt — document at action

## English source passage

*In plain terms: when something that matters is done, the record should be made by the doing, at that moment, and by the system itself wherever it can be. No one writes it up later from memory. What is not lawfully restricted should be visible straight away. What is restricted should still leave a visible mark that something was done, and a way to learn more later. The system does the recording, so the steward carries no extra work.*

## Draft translation (fr)

*En termes simples : lorsqu’un acte important est accompli, son enregistrement doit être créé par l’acte même, à ce moment-là, et par le système lui-même chaque fois que possible. Personne ne doit le reconstituer plus tard de mémoire. Les éléments dont la loi ne restreint pas l’accès doivent être visibles immédiatement. Les éléments restreints doivent tout de même laisser une trace visible de l’acte et un moyen d’en apprendre davantage plus tard. Le système assure l’enregistrement, sans travail supplémentaire pour le responsable.*
