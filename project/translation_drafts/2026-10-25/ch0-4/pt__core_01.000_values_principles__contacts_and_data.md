# Chapter One excerpt — contact data limits

## English source

**Contacts and data:** A trusted contact is used only if the sentient chose it in advance, and only the information needed to get a response is shared. Outreach uses contact details the system already holds for that purpose and is not a reason to collect more data.

## pt draft

**Contatos e dados:** Um contato de confiança só é usado se o ser senciente o tiver escolhido previamente, e apenas as informações necessárias para obter uma resposta são compartilhadas. A tentativa de contato usa os dados que o sistema já possui para essa finalidade e não justifica coletar mais dados.
