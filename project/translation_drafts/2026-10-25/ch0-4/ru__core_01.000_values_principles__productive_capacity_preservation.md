# Chapter One §9.1.1 — Preserve Productive Capacity

Source: `core_01.000_values_principles.md` §9.1.1 Preserve, Expand, and What Does Not Count

Source SHA-256: `6b6f07eff0faf4249c4ef3844f8e6ee4b24041768de3ffd4262240bc68854c17`

## English source passage

Systems must preserve productive capacity and, where feasible, expand it when doing so would improve [Constitutional Efficiency](core_05.040_band_continuity.md#constitutional-efficiency) ([§9.2 Constitutional Efficiency](#92-constitutional-efficiency)).

## Draft translation (ru)

Системы должны сохранять производительную способность и, если это осуществимо, расширять её, когда такое расширение улучшит [конституционную эффективность](core_05.040_band_continuity.md#constitutional-efficiency) ([§9.2 Конституционная эффективность](#92-constitutional-efficiency)).
