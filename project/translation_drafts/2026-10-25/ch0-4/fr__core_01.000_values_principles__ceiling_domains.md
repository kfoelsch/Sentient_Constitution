# Chapter One excerpt — domains requiring consolidation ceilings

## English source

Adopters must define consolidation ceilings for:
- markets;
- platforms;
- infrastructure layers;
- labor-demand markets;
- supplier or resource-control systems;
- data or compute dependencies;
- credentialing role pathways;
- capital-access channels;
- comparable domains.

## fr draft

Les adoptants doivent définir des plafonds de consolidation pour :
- les marchés ;
- les plateformes ;
- les couches d’infrastructure ;
- les marchés de la demande de main-d’œuvre ;
- les systèmes de fournisseurs ou de contrôle des ressources ;
- les dépendances aux données ou au calcul ;
- les parcours professionnels soumis à accréditation ;
- les canaux d’accès au capital ;
- les domaines comparables.
