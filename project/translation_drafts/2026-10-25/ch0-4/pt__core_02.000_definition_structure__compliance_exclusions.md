# Chapter Two excerpt — what does not belong in Compliance

## English source

A few things deliberately do **not** go in the C part:
- what the term is about — that belongs in O;
- which measures apply or how assessment must run — that belongs in M and A.

Chapter Five leaf definitions must carry those C requirements using the Compliance component shape stated in this section.

## pt draft

Algumas coisas deliberadamente **não** pertencem à parte de Conformidade (C):
- o assunto do termo — isso pertence à parte de Objeto (O);
- quais medidas se aplicam ou como a avaliação deve ocorrer — isso pertence às partes de Medição (M) e Avaliação (A).

As definições finais do Capítulo Cinco devem incorporar esses requisitos de C usando o formato do componente de Conformidade definido nesta seção.
