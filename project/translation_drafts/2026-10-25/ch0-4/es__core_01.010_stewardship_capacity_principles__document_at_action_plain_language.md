# Chapter One Part C excerpt — document at action

## English source passage

*In plain terms: when something that matters is done, the record should be made by the doing, at that moment, and by the system itself wherever it can be. No one writes it up later from memory. What is not lawfully restricted should be visible straight away. What is restricted should still leave a visible mark that something was done, and a way to learn more later. The system does the recording, so the steward carries no extra work.*

## Draft translation (es)

*En términos sencillos: cuando se realiza algo importante, el registro debe generarse al mismo tiempo que la acción y, siempre que sea posible, por el propio sistema. Nadie debería reconstruirlo después de memoria. Lo que no esté legalmente restringido debe quedar visible de inmediato. Lo restringido también debe dejar una señal visible de que ocurrió algo y una vía para conocer más adelante lo que falta. El sistema registra, así que la persona encargada no carga con trabajo adicional.*
