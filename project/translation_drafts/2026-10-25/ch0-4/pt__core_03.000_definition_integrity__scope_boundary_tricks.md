# Chapter Three excerpt — scope and boundary tricks

## English source passage

- **Scope and boundary tricks** — arranging what gets counted, and when, so the hard parts never get tested:
  - narrowing evaluation or application to leave out system elements, effects, or conditions that matter
  - splitting responsibility across components, actors, or time so no one has to meet the definition for the whole system
  - looking compliant only under observation, audit, or limited windows while violating the definition in broader operation

## Draft translation (pt)

- **Truques de escopo e limites** — organizar o que será contado e quando, para que as partes difíceis nunca sejam testadas:
  - restringir a avaliação ou aplicação para excluir elementos, efeitos ou condições importantes do sistema
  - dividir a responsabilidade entre componentes, atores ou períodos para que ninguém precise cumprir a definição para o sistema inteiro
  - parecer conforme apenas durante observação, auditoria ou períodos limitados, enquanto se viola a definição na operação mais ampla
