# Chapter Two excerpt — Assessment requirements across layers

## English source

Across all layers, the A part must:
- say what must be assessed;
- say under what conditions assessment must happen;
- say how to handle uncertainty where it matters.

À toutes les couches, la partie Évaluation (A) doit :
- indiquer ce qui doit être évalué ;
- indiquer dans quelles conditions l’évaluation doit avoir lieu ;
- indiquer comment traiter l’incertitude lorsque cela importe.
