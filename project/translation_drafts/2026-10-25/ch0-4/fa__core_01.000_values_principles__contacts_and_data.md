# Chapter One excerpt — contact data limits

## English source

**Contacts and data:** A trusted contact is used only if the sentient chose it in advance, and only the information needed to get a response is shared. Outreach uses contact details the system already holds for that purpose and is not a reason to collect more data.

## fa draft

**تماس‌ها و داده‌ها:** از شخص مورد اعتماد به‌عنوان مخاطب فقط در صورتی استفاده می‌شود که موجود ذی‌شعور از پیش او را انتخاب کرده باشد، و فقط اطلاعات لازم برای دریافت پاسخ به اشتراک گذاشته می‌شود. تلاش برای تماس از اطلاعات تماسی استفاده می‌کند که نظام از قبل برای این منظور نگه داشته است و دلیلی برای گردآوری داده‌های بیشتر نیست.
