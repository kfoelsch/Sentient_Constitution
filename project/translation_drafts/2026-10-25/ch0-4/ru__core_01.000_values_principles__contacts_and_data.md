# Chapter One excerpt — contact data limits

## English source

**Contacts and data:** A trusted contact is used only if the sentient chose it in advance, and only the information needed to get a response is shared. Outreach uses contact details the system already holds for that purpose and is not a reason to collect more data.

## ru draft

**Контакты и данные:** доверенное контактное лицо используется только в том случае, если чувствующее существо выбрало его заранее; передаются лишь сведения, необходимые для получения ответа. Для связи используются контактные данные, уже имеющиеся у системы для этой цели; это не основание собирать дополнительные данные.
