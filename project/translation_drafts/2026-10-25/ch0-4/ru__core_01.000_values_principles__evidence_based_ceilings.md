# Chapter One excerpt — evidence-based ceilings

## English source

In plain terms: adopters must set evidence-based ceilings that trigger scrutiny before consolidation risks in **§11.3.1** (*Consolidation Risk, Pre-Lock-In Impairment*) materialize into lock-in — with separate horizontal and vertical triggers where the domain requires it.

## ru draft

Проще говоря: принимающая сторона должна установить основанные на доказательствах потолки, запускающие проверку до того, как риски консолидации из **§11.3.1** (*Риск консолидации, ущерб до блокировки*) приведут к блокировке; если этого требует область, горизонтальные и вертикальные триггеры должны быть раздельными.
