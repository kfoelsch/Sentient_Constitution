# Chapter One §7.2.1 — Aligned Self-Organization Opening

## English source passage

*In plain terms: you may start legitimate work without a sponsor, and institutions must give credible work a real procedural path — but that path is not power to govern others, and it is not a final decision on the substance.*

The freedom to assemble or create a system includes a real way to start work this Constitution treats as legitimate, without waiting for stewards already in charge to sponsor it. [§17.4 Aligned Self-Organization](core_01.010_stewardship_capacity_principles.md#174-aligned-self-organization) is the operative home. This subsection applies that rule at the Freedom / assembly-and-formation layer.

## Draft translation (es)

*En términos sencillos: puedes iniciar trabajo legítimo sin patrocinador, y las instituciones deben ofrecer a un trabajo creíble una vía procesal real; pero esa vía no concede poder para gobernar a otras personas ni constituye una decisión final sobre el fondo.*

La libertad de reunirse o crear un sistema incluye una forma real de iniciar el trabajo que esta Constitución considera legítimo, sin esperar el patrocinio de quienes ya ejercen la custodia. El lugar operativo de esta regla es [§17.4 Autoorganización alineada](core_01.010_stewardship_capacity_principles.md#174-aligned-self-organization). Esta subsección aplica la regla al nivel de libertad, reunión y formación.
