# Chapter One excerpt — review before lock-in

## English source

Review must not wait until any of the following is already locked down:
- market(s);
- platform(s);
- labor pool(s);
- data layer(s);
- compute layer(s);
- infrastructure dependency(ies).

## fr draft

L’examen ne doit pas attendre que l’un des éléments suivants soit déjà verrouillé :
- marché(s) ;
- plateforme(s) ;
- bassin(s) de main-d’œuvre ;
- couche(s) de données ;
- couche(s) de calcul ;
- dépendance(s) à une infrastructure.
