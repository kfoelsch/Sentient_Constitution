# Preamble excerpt — What Systems Reward

## English source

A system gets more of whatever it pays for, whether in money, status, access, protection, or silence. So the test of a system is not what it says it values but what it rewards. If harming others pays, or telling the truth costs, the system is failing, however good its stated aims.

## es draft

Un sistema obtiene más de aquello que recompensa, ya sea con dinero, estatus, acceso, protección o silencio. Por eso, la prueba de un sistema no es lo que dice valorar, sino lo que recompensa. Si perjudicar a otras personas resulta rentable o decir la verdad tiene un costo, el sistema está fallando, por muy buenos que sean sus objetivos declarados.
