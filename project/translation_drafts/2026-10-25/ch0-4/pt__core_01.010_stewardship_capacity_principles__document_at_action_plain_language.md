# Chapter One Part C excerpt — document at action

## English source passage

*In plain terms: when something that matters is done, the record should be made by the doing, at that moment, and by the system itself wherever it can be. No one writes it up later from memory. What is not lawfully restricted should be visible straight away. What is restricted should still leave a visible mark that something was done, and a way to learn more later. The system does the recording, so the steward carries no extra work.*

## Draft translation (pt)

*Em termos simples: quando algo importante é feito, o registro deve ser criado junto com a ação, naquele momento, e pelo próprio sistema sempre que possível. Ninguém deve escrevê-lo depois com base na memória. O que não estiver legalmente restrito deve ficar visível de imediato. O que estiver restrito ainda deve deixar uma marca visível de que algo foi feito e um caminho para saber mais depois. O sistema faz o registro, sem impor trabalho extra ao responsável.*
