# Preamble excerpt — What Systems Reward

## English source

A system gets more of whatever it pays for, whether in money, status, access, protection, or silence. So the test of a system is not what it says it values but what it rewards. If harming others pays, or telling the truth costs, the system is failing, however good its stated aims.

## pt draft

Um sistema produz mais daquilo que recompensa, seja com dinheiro, status, acesso, proteção ou silêncio. Portanto, o critério para avaliar um sistema não é o que ele diz valorizar, mas o que recompensa. Se prejudicar outras pessoas traz vantagens ou dizer a verdade custa caro, o sistema está falhando, por melhores que sejam seus objetivos declarados.
