# Chapter One §11.4 — Certification Step-Up for Chokepoints

## English source passage

In system alignment certification, a system that becomes a choke point for dependents who cannot realistically switch is stepped up on those facts under [Chapter Nine §5.3.5 System Class Scaling and Escalation](core_09.000_system_alignment_certification_evaluation.md#535-system-class-scaling-and-escalation) and [§2.2 How system class scales every evaluation](core_09.000_system_alignment_certification_evaluation.md#22-how-system-class-scales-every-evaluation). A crossed level there is further evidence, and a level that is unset or set too high does not delay the step-up.


## Draft translation (es)

En la certificación de alineación del sistema, si un sistema se convierte en un cuello de botella para dependientes que no pueden cambiarse de forma realista, se eleva su nivel por esos hechos conforme a [Capítulo Nueve §5.3.5 Escalado y escalamiento de la clase del sistema](core_09.000_system_alignment_certification_evaluation.md#535-system-class-scaling-and-escalation) y [§2.2 Cómo influye la clase del sistema en cada evaluación](core_09.000_system_alignment_certification_evaluation.md#22-how-system-class-scales-every-evaluation). El umbral superado aporta pruebas adicionales; si no se fijó o se fijó demasiado alto, ello no retrasa la elevación.
