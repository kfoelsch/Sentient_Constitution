# Chapter Three excerpt — cross-component scope integrity

## English source passage

All definition components (Ontological (O), Measurement (M), Assessment (A), and Compliance (C)) must be applied to the same functional system scope, evaluation conditions, and temporal frame. All components must be satisfied jointly under consistent scope, conditions, and temporal context.

Misalignment across components is both evasion and non-compliance, including:
- applying Ontological components to broader or different system scopes than Compliance components
- applying Measurement components to different scopes, conditions, or timeframes than the Ontological, Assessment, or Compliance components they support
- satisfying Assessment components under constrained or idealized conditions while asserting compliance under full operation
- demonstrating component satisfaction across different timeframes, instances, or system states

องค์ประกอบทั้งหมดของคำนิยาม (ภววิทยา (O) การวัด (M) การประเมิน (A) และการปฏิบัติตาม (C)) ต้องใช้กับขอบเขตระบบเชิงหน้าที่ เงื่อนไขการประเมิน และกรอบเวลาเดียวกัน องค์ประกอบทั้งหมดต้องได้รับการตอบสนองร่วมกันภายใต้ขอบเขต เงื่อนไข และบริบทเวลาที่สอดคล้องกัน

ความไม่สอดคล้องระหว่างองค์ประกอบถือเป็นทั้งการหลีกเลี่ยงและการไม่ปฏิบัติตาม รวมถึง:
- ใช้องค์ประกอบภววิทยากับขอบเขตระบบที่กว้างกว่าหรือแตกต่างจากองค์ประกอบการปฏิบัติตาม
- ใช้องค์ประกอบการวัดกับขอบเขต เงื่อนไข หรือกรอบเวลาที่ต่างจากองค์ประกอบภววิทยา การประเมิน หรือการปฏิบัติตามที่องค์ประกอบนั้นสนับสนุน
- ทำให้องค์ประกอบการประเมินครบถ้วนภายใต้เงื่อนไขที่จำกัดหรือเป็นอุดมคติ แต่กล่าวอ้างว่าปฏิบัติตามระหว่างการดำเนินงานเต็มรูปแบบ
- แสดงว่าองค์ประกอบครบถ้วนโดยใช้กรอบเวลา กรณี หรือสถานะของระบบที่แตกต่างกัน
