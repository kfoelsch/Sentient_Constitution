# Chapter Four excerpt — structured trace map

## English source passage

This section requires a **structured trace map**. For every definition that materially applies to system behavior — including every materially required **Chapter Five** definition — the map must link each part to **observable** behavior and real-world effects:

- **what it is (O)** — what the term is about
- **how it is measured (M)** — which measure applies at each layer
- **how it is judged (A)** — how the term must be assessed
- **what must hold (C)** — what must be true in practice

## Draft translation (pt)

Esta seção exige um **mapa de rastreabilidade estruturado**. Para cada definição que se aplique materialmente ao comportamento do sistema — incluindo toda definição do **Capítulo Cinco** materialmente exigida — o mapa deve vincular cada parte a comportamentos **observáveis** e a efeitos no mundo real:

- **o que é (O)** — a que o termo se refere
- **como é medido (M)** — qual medida se aplica em cada camada
- **como é avaliado (A)** — como o termo deve ser avaliado
- **o que deve ser verdadeiro (C)** — o que precisa ser verdadeiro na prática
