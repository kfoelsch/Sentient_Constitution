# Chapter One §7.1 — Freedom-Limitation Conflict Routing

Source: `core_01.000_values_principles.md` §7.1 Limitation Discipline

Source SHA-256: `6b6f07eff0faf4249c4ef3844f8e6ee4b24041768de3ffd4262240bc68854c17`

## English source passage

If limiting freedom clashes with other constitutional values or rights, first make sure **Safety** and **Truth** are satisfied. Then work through [§13.1 Core Tradeoff Principles](core_01.005_interaction_interpretation.md#131-core-tradeoff-principles) to [§13.1.5 Rights-Collision Procedure](core_01.005_interaction_interpretation.md#1315-rights-collision-decision-test).

## Draft translation (bn)

স্বাধীনতা সীমিত করা অন্য সাংবিধানিক মূল্যবোধ বা অধিকারের সঙ্গে সংঘাতে পড়লে, প্রথমে **নিরাপত্তা** ও **সত্য** পূরণ হয়েছে কি না নিশ্চিত করুন। এরপর [§13.1 মূল সমঝোতার নীতিমালা](core_01.005_interaction_interpretation.md#131-core-tradeoff-principles) থেকে [§13.1.5 অধিকার-সংঘাত প্রক্রিয়া](core_01.005_interaction_interpretation.md#1315-rights-collision-decision-test) অনুসরণ করুন।
