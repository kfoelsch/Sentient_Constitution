- **Falla secundaria:** *(se usa cuando aplica)* cuando el término se rompe en el capa secundario — por ejemplo cuando la comprobación primaria parece estable pero algo más amplio aún derrota el término, como una ruptura en un sistema del que depende o un sistema conectado con el que interactúa.
- **Falla terciaria:** *(se usa cuando aplica)* cuando el término se rompe en el capa terciario — por ejemplo cuando un proxy o una métrica se trata como suficiente por sí solo, o cuando una divergencia conocida se ignora o se deja sin corregir.
