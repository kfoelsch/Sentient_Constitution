- **Falha primária:** quando o termo se rompe no camada primário — por exemplo quando a medida principal é oca, não rastreável ou contradita por como o sistema realmente funciona.
- **Falha secundária:** *(usa-se quando se aplica)* quando o termo se rompe no camada secundário — por exemplo quando a verificação primária parece estável, mas algo mais amplo ainda derrota o termo, como uma ruptura num sistema do qual depende ou num sistema conectado com o qual interage.
- **Falha terciária:** *(usa-se quando se aplica)* quando o termo se rompe no camada terciário — por exemplo quando um proxy ou uma métrica é tratado como suficiente por si só, ou quando uma divergência conhecida é ignorada ou deixada sem correção.
Nem toda definição enumera os três camadas de falha. Alguns termos declaram só uma falha primária; outros acrescentam falhas secundárias ou terciárias quando o termo precisa de condições de ruptura alinhadas por camada.
