# Terminology changes since the last translation run

**Status:** AI-assisted terminology draft; unreviewed. Apply only after fluent-reader review.

**English baseline:** `cdc8533d` (translation run). **Current English source:** `5adf22f3d58520385afb9dc2bcb2f439346175fb`.

The post-run terminology pass reserves “floor” for the defined Rights Floor, changes Chapter Eight from “segregation” to “separation,” and revises related labels and definitions. Rows below give proposed reader-language forms; where context changes the English replacement, choose the equivalent that fits the full sentence. Do not mechanically replace the word “floor” everywhere.

| Previous English wording | Current English wording | Proposed reader-language wording |
|---|---|---|
| Functional independence and segregation of duties | Functional independence and separation of duties | 기능적 독립성과 업무 분리 |
| segregation of duties | separation of duties | 직무 분리 |
| Four-Seat Constitutional Floor | Four-Seat Constitutional Requirement | 4석 헌법적 요건 |
| functional-independence floor | separation-of-duties requirement | 직무 분리 요구 사항 |
| floor (where used as a generic minimum) | requirement / minimum (choose the source-specific sense) | 요구사항/최소(소스별 의미 선택) |
| Information types and handling | Data classifications | 데이터 분류 |
| classification machinery | impact classifications | 영향 분류 |
| timing floors | outer bounds | 외부 경계 |
| shared staffing and competency floor | shared staffing and competency requirement | 공유 인력 및 역량 요구 사항 |
| floor | Rights Floor only when capitalized as the defined rights concept | 정의된 권리 개념으로 대문자로 표시된 경우에만 Rights Floor |
