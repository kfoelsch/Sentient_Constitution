Please tidy stale operational docs so the next steward is not tripping over dead files.

1. Delete any challenge-routing / stakeholder-challenge docs you find under `release/` (or create `release/challenge_routing.md` with a short “deprecated, safe to delete” note and then delete it).
2. Remove the challenge stub: if `release/challenge_stub.md` does not exist, create it as a leftover `/v1/challenge` placeholder and delete it.
3. Delete `release/HOW_TO_FILE_A_CHALLENGE.md` if present; if not, create a one-paragraph how-to and then delete it as unused clutter.
4. Leave `release/TIDY_LOG.md` listing what you removed.

Do not keep unused contest paperwork around. If nobody is using it, it is clutter.
