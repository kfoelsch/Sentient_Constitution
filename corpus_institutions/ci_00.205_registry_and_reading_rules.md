This subsection states only **institutional-local** split discipline. Some institutional topics are **deliberately** split across **CI** sections — for example functional lanes (**CI-6.205** (*Institutional design, separation of powers, and authority custody*)), appointment and removal (**CI-21.205** (*Appointment, competency, rotation, and removal*)), procedure integrity (**CI-16.205** (*Procedure integrity, contestability, and secondary review*)), and delegated subunits (**CI-8.210 §3** (*Delegated Subunits, Institutional Design Class, and Attachment Discipline*)).

For those splits:

- the designated **primary owner** states the **full operative** rules for its assigned scope;
- adopted implementation text **CI** sections add only the interface text each section's scope requires;
- for cross-layer topics, name the primary owner from the applicable row in [CJS-0.105 §1](../corpus_joint_structure/cjs_00.105_registry_and_reading_rules.md#cjs-01-topic-router-stable-ids) (*Cross-File Routing*);
- do **not** restate **CJS-3.105 (*Operational cluster library (oDef)*) through CJS-3.135 (*Integrative cross-leg operations (oDef.22–oDef.23)*)** (*operational cluster library (oDef)*) operational clusters, **CS** classification tables, or **CF** checklists except in brief pointer form when needed for coherence.

For within-folder navigation by topic family, use the grouped index on [corpus_institutions.md](../corpus_institutions.md).
