# Constitutional joint structure

**Corpus edition:** `SC-Corpus-2026.04.30`  
**Effective date:** 2026-04-18  
*(Edition alignment: these files use the same edition labels as the Sentient Constitution numbered `core_*.md` files (see [README.md](../README.md)), `core_05-05_definitions_a_independent.md`, `corpus_systems.md`, `corpus_institutions.md`, and `corpus_forum.md`.)*

The CJS files are intentionally written in plain language with low jargon to improve accessibility, audit readability, and practical adoption testing.

**Non-core Corpus Document**

These are not core constitutional files. They are still part of the constitutional corpus where the **Corpus** says they are binding implementation text, through **Sentient Constitution Chapter Fifteen**.

The main meanings of constitutional terms, Rights Floors, and definition-satisfaction rules still come from the Sentient Constitution and the owner map in `doc_architecture.md`. The CJS files do not take that authority away from those sources.

**CJS-folder implementation anchors**

- **What these files do:** they explain shared structure between companion files and host the **Cross-domain implementation layer** in the CJS folder.
- **What these files do not do:** they do not replace the day-to-day domain rules owned only by `corpus_systems.md`, `corpus_institutions.md`, or `corpus_forum.md`, except where those files meet at a shared joint interface.
- **When more than one companion applies:** use **CJS-2** for read order and the stricter-wins rule. Use **CJS-3** for requirements that must be satisfied together.
- **Where to find the owner:** use `doc_architecture.md` section 4 and **CJS-2.2** to identify which file owns a topic.
- **How to read local shorthand:** shorthand used inside one subsection stays local to that subsection unless the canonical owner clearly adopts it. If local wording conflicts with canonical definitions, the canonical definitions control.
- **Readability baseline:** keep this text understandable under **Article XX** and apply the shared companion preamble contract in **CJS-1.1**.

**Implementation cross-reference index (routing only):** Joint-structure obligations may connect with **Cross-domain implementation layer** labels **PRIM8**, **PRIM9**, **PRIM10**, **PRIM15**, **PROT1**, **PROT2**, **PROT3**, **PROT4**, **PROT5**, and **PROT6** when those labels materially apply. This index only helps readers find related material. It does not redefine what those labels mean.
