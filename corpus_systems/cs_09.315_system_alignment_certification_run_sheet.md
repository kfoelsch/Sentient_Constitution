This file is the systems implementation home for **CS-9.315** (*System alignment certification run sheet*).

*In plain terms: **CS-9.315** (*System alignment certification run sheet*) is a step-by-step checklist for running a certification from classifying the system to monitoring it once it is live. Each step points to the Chapter Nine section that holds the rule. The checklist adds no duty and changes none.*

## CS-9.315 §1 Purpose and role

*In plain terms: what this file covers, which constitutional text it follows, and who wins if they differ.*

This file lists, in order, the steps of System Alignment Certification as **Chapter Nine** sets them out, with a link for each step to the section that holds the rule. It is a working checklist for the operators, classifiers, and forum members who run a certification.

The run sheet is a procedural aid. It does not create, narrow, or waive any duty. **Chapter Nine** owns the evaluation, review, decision, record, and operating rules, and **Chapter Nine Part D** owns the Institution rules. Where this file and a linked section differ, the section controls.

The six phases it follows are **I Frame**, **II Evaluate**, **III Review**, **IV Decide**, **V Record**, and **VI Operate**. The process chart in [Chapter Nine Part A §1.2 Certification at a glance](../core_09.000_system_alignment_certification_evaluation.md#12-certification-at-a-glance) shows the same flow as a picture.

| 12 | Run the same phases for the Institution: classify it by what it decides and holds, evaluate it on the seven institutional items (including the standing and authenticity of the holders of its covered offices), cite each System's certification record without redoing it, and carry a failed or lapsed System certification into its status by the cascade rule.
