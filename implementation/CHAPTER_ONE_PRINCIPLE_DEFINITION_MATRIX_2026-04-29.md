## Purpose

This matrix converts the Chapter One mapping evaluation into drafting decisions. It does not recommend adding every related definition. It separates current definition links into functional roles and identifies the smallest useful next edits.

Labels:

- P = Primary
- S = Supporting
- C = Collision
- E = Evidence
- B = Boundary
- O = Possible overlap
- N = Intentional non-map

Actions:

- Keep: current attachment is appropriate.
- Add: add or foreground a missing load-bearing definition.
- Demote: keep concept nearby but remove from primary definition list or move to trace/read-with prose.
- Split: divide an oversized definition block into grouped sublists.
- Clarify: add a short boundary sentence or hierarchy note.
- Decide: genuine judgment call before text edits.

## Proposed Edit Discipline

When applying this matrix to Chapter One:

1. Do not change operative rules in the first pass.
2. Reorder or group definition lists before adding new terms.
3. Add a definition only where it is Primary or resolves a visible ambiguity.
4. Demote broad supporting terms to trace/read-with prose when they clutter a definition block.
5. Keep rights-floor ownership disclaimers where Chapter One states principle-layer doctrine.

## Success Test

The pass succeeds if a reader can distinguish:

- the term that defines the principle;
- the terms that evaluate its application;
- the terms that control conflicts;
- the terms that prove or audit compliance;
- the terms that prevent the principle from invading another chapter's role.

If the reader only sees a longer list of links, the pass has failed.
