# Role separation quick reference

**Single-page operator view.** Canonical rules live only in `corpus_institutions.md` and `corpus_forum.md`. This matrix is an index.

| Lane / topic | Incompatible with | Recusal / independence trigger | Canonical owner |
| --- | --- | --- | --- |
| **CI-8.205** Designated functional separation and authority custody | Same sentient holding opposing enforcement and appeal roles in the same matter; approver and sole auditor for same transaction | Material dual role or custody conflict | **CI-8.205** |
| **CI-8.205** Authority custody pointer | Older **CI-8.205** citations resolve to the folded **CI-8.205** authority-custody requirements | Legacy citation or registry lookup | **CI-8.205** pointer to **CI-8.205** |
| **CI-14.205** Appointment / removal | Hiring manager and sole misconduct fact-finder for same sentient | Appearance of bias | **CI-14.205** |
| **CI-8.210** Integrity | Beneficiary and disclosure reviewer for same benefit | Financial / relational conflict | **CI-8.210** |
| **CI-13.205** Procedure | Decision maker and sole appeals body for same case (where split required) | Structural bias | **CI-13.205** + **`corpus_forum.md`** **CF-13.410** / **CF-13.425** |
| **CI-8.215** Assurance line | Operator and independent assurance on same control | Assurance capture | **CI-8.215** / **CI-8.215 §2** |
| **CF-13.430** Forensic support | Investigator and merits judge (same matter) | Anti-self-judging | **CF-13.430** / **CF-13.435** |
| **CF-13.440** Technical forums | Expert advocate and same-chamber final adjudicator (same matter) | Technical capture | **CF-13.440** |
| **CI-13.210** Cross-institution escalation | Escalation receiver and original decision owner without firewall | Collapse of independence | **CI-13.210** |

**Default:** three-lines model (**CI-8.215 §1**); anti-self-judging for forums (**CF-13.425**); investigations structurally separate from subjects (**CI-8.210**, **CF-13.435**).
