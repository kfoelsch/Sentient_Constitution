# Print pack (not adoption)

**Status:** Process / handbook support — **not** binding constitutional or incorporated text. This page **cannot narrow core**. Opening or printing it is not [Chapter Fifteen §10](../core_15_amendment_ratification.md#10-ratification-and-adoption) adoption.  
**Pinned to corpus edition:** `SC-Corpus-2026.08.09` (effective 2026-08-09; [README.md](../README.md)).  
**Job:** One sitting you can print: what the instrument is, the Rights Floor in one-liners, the process chain, and one situation brief.

This is **not** a PDF renderer and **not** a second constitution. The generated one-file pack is [`../doc_architecture/generated/print_pack.md`](../doc_architecture/generated/print_pack.md) (`make print-pack`). If that file and the sources disagree, the sources win.

## What to print (in order)

1. This page’s banner (you are not adopting by printing).
2. [Preamble](../core_00_preamble.md) — the model, four duties, two aims, process pipelines.
3. [Rights Floor wall sheet](../doc_architecture/generated/rights_floor_sheet.md) — one sentence per Chapter Six Article. The numbered `core_06_*` files bind.
4. [PROCESS_PIPELINES_READER.md](PROCESS_PIPELINES_READER.md) — certify → measure help and harm → effects/remedy, with independent review along the side.
5. **One** [easy-entry brief](adoption/easy_entry/README.md#roster) that sounds like your situation. The generated pack inlines [E16](adoption/easy_entry/E16_worker_not_owner.md) as a sample; swap it.

Optional longer sitting (not in the generated file): Chapter Six parts [A](../core_06_rights_part_a.md), [B](../core_06_rights_part_b.md), [C](../core_06_rights_part_c.md), [D](../core_06_rights_part_d.md).

## What this will not pretend to give you

- A typeset book, large-print edition, or hosted PDF.
- A second constitution on GitHub Pages. [`../docs/index.md`](../docs/index.md) remains a pointer; [`../docs/corpus_index.md`](../docs/corpus_index.md) lists blob links. `make pages-site` / the Pages workflow renders the **same** repository files at build time; if they disagree, the repository file wins.
- Adoption, an official record of verified help or harm, or enforcement against a body that has not agreed to follow this Constitution.
