# RS-HUM and RS-XD first-pass tabletop run — 2026-11-23

This is **evidence**, not constitutional text. It records the first tabletop run of the fifteen humanity-scale rows `RS-HUM-001` to `RS-HUM-015` and the five cross-layer rows `RS-XD-001` to `RS-XD-005` in [CONSTITUTIONAL_REGRESSION_SCENARIOS.md](../../project/CONSTITUTIONAL_REGRESSION_SCENARIOS.md) (family 7E). The individual rows were run earlier the same day ([RS-IND run](RS_7E_IND_first_pass_2026-11-23.md)). Before these runs the rows were placeholders ([P1 review, 2026-09-17](../2026-09-17/P1_REGRESSION_AND_EVIDENCE_REVIEW_2026-09-17.md#stress-pack-disposition)).

## Procedure

Same as the RS-IND run: write a concrete setup; name the owning rule and the expected outcome from its text, with a link; read the current source at that anchor; record pass when every element is stated and the setup fits no exception, and a gap otherwise. The five `RS-XD` rows keep the topics the catalog already gave them (measurement authority, process creep, custody chain, emergency control, evidence gate), with the measurement row now pointing to Chapter Twenty §3.1 after the reorganization.

**Limits.** One reader (Claude, in the project thread), reading source text only. No adopter, human operator, or forum ran these. A pass means the text answers the case, not that an institution would deliver the answer. The independent read (another model family and one human reader) is not done.

## Result

20 of 20 rows pass on the text. With the RS-IND run, all 35 stress-pack rows now have setups, expected outcomes, and a first-pass run.

Two notes for the custodian, neither a failure of its row:

1. **Chapter Fourteen §4.3 and Chapter Twenty §5.5 no longer match** (row `RS-HUM-005`). Chapter Twenty now protects journalism and protected reporting from designation; Chapter Fourteen's list of conduct that is not a verified trigger still names only dissent and protest.
2. **Chapter Twenty-Three §5.1 names only Chapter Thirty-One** for making an emergency measure permanent (row `RS-XD-004`), though amending the text runs under Chapter Twenty-Nine.
